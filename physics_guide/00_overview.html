00. 全体像: ハミルトニアンから Fortran・Python まで

この章で分かること: 物理ガイド全体の地図。(1) ハミルトニアンから追跡の写像・転送行列・K64 の Fortran・pysad の Python に至る一本の流れ。(2) K64 の3 系統の実装 (追跡 t*.f、行列 t*e.f、解析微分 q*) と、要素ルーチンの命名則。(3) 各章の位置づけと読み方。(4) ガイド全体の確認の一覧 (どの章で、どの式を、どの独立な基準で確かめたか)。(5) ガイド全体の未確認・K64 とヘルプの誤りの疑いの一覧 (各章の付録からの集約。確定と疑いを分ける)。

前提: 加速器物理の基礎。SAD の内部は知らなくてよい。

読む順: §1 (流れ) → §2 (3 系統) → §4 (章の読み方)。確認の一覧 (§6)、疑いの一覧 (§7) は、必要なときに引く。

5. 全体に共通する約束

  • 記号: 01 §8 の規約。SAD の Fortran の変数名はそのまま使い、使うたびに注釈し、章末の「この章で使う Fortran の変数名」に表にする。
  • 積分強度: SAD の K1、K2... は積分強度 B(n)L/BρB^{(n)}L/B\rhoB(n)L/Bρ [1/mn^nn]。pysad の要素クラスは長さあたり。
  • ヘルプの原文 (K64 版同梱の SADHelp.html): 式は TeX 版と平文版の 2 つ併記で、食い違う箇所がある。各章の付録 A に原文で確認した結果を書いた。
  • K64 と v2 (既定) の違い: 結果が変わるものだけを現在の仕様として書く。K64 の誤りの疑いは各章の付録 B (別枠)。
  • 確認スクリプト: scripts/<章>_0n_*.py、出力 outputs/*.out.txt。独立な基準 (DOP853 の積分、複素ステップや中心差分、行列指数、sympy) で確かめる (README.md の表)。
