== (a) p = γ m0 v + eA を v について解く ==
  γ = sqrt(1 + |p - eA|^2/(m0 c)^2) と置いて v = (p - eA)/(γ m0) とすると、
  1 - v^2/c^2 - 1/γ^2 = 0  (つまり γ の定義 1/sqrt(1 - v^2/c^2) と矛盾しない)
  γ m0 v + eA - p = [0, 0, 0]

== (b) H = p·v - L ==
  H_ルジャンドル - [c sqrt((p-eA)^2 + m0^2 c^2) + eφ] = 0
  途中: p·v - L = γ m0 v·v + m0 c^2/γ + eφ (eA·v は相殺)。
        つまり γ m0 v^2 + m0 c^2/γ = γ m0 c^2 (差 0)
        γ m0 c^2 = c sqrt((p - eA)^2 + m0^2 c^2) (差 0)

== (c) ハミルトンの方程式との整合 ==
  ∂H/∂p_i - v_i = [0, 0, 0]
  成分 x: ∂L/∂r_i (v 固定、後で v(p) を代入) - [-∂H/∂r_i (p 固定)] = 0
  成分 y: ∂L/∂r_i (v 固定、後で v(p) を代入) - [-∂H/∂r_i (p 固定)] = 0
  成分 z: ∂L/∂r_i (v 固定、後で v(p) を代入) - [-∂H/∂r_i (p 固定)] = 0
  → ṗ = ∂L/∂r = -∂H/∂r。ラグランジュの方程式とハミルトンの方程式は同じ運動
