== (a) ΔH の偏微分: 複素ステップ微分 と 手で導いた式 ==
   x' = px (1/pz - 1/p)、y' = py (1/pz - 1/p)、z' = 1 - p/pz + (px^2+py^2)/(2 p^2)  (pz = sqrt(p^2-px^2-py^2))
  (px, py, p) = (0.001, -0.002, 1.000): 最大差 4.61e-17 (相対 4.9e-06)
  (px, py, p) = (0.010, 0.020, 1.003): 最大差 1.78e-16 (相対 1.9e-09)
  (px, py, p) = (0.050, -0.030, 0.970): 最大差 1.94e-16 (相対 4.0e-11)

== (b) D の解: DOP853 (正準方程式) と pysad の D の比較 (長さ 0.3 m。座標は規格化した運動量 px/p) ==
   ここの D は ΔH の流れだけ (H2 の項は含まない)。pysad の D は z に dv の項を含まない (dv は本体 B 側)
  px/p = 0.001, py/p = -0.002, δ = +0.000: x 変化 7.5000e-10、z 変化 -2.8125e-12、pysad との差 3.7e-18
  px/p = 0.010, py/p = 0.020, δ = +0.003: x 変化 7.5028e-07、z 変化 -2.8137e-08、pysad との差 1.1e-17
  px/p = 0.050, py/p = -0.030, δ = -0.030: x 変化 2.5565e-05、z 変化 -1.3042e-06、pysad との差 2.3e-17
  最大差 2.35e-17
