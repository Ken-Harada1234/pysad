== (a) 基底ベクトルと ∂r/∂Q ==
  t = dr0/ds - Matrix([[0, 0, 0]])
  n = -ρ d^2 r0/ds^2 の差: Matrix([[0, 0, 0]])
  b = t × n = Matrix([[0, 1, 0]])
  dt/ds + n/ρ = Matrix([[0, 0, 0]])、dn/ds - t/ρ = Matrix([[0, 0, 0]])、db/ds = Matrix([[0, 0, 0]])
  ∂r/∂X - n = Matrix([[0, 0, 0]])、∂r/∂Y - b = Matrix([[0, 0, 0]])
  ∂r/∂s - (1 + X/ρ) t = Matrix([[0, 0, 0]])

== (b) P = p·∂r/∂Q (F3 = -p·r(Q) から P = -∂F3/∂Q) ==
  P_X - p·n = 0、P_Y - p·b = 0、P_s - (1 + X/ρ) p·t = 0

== (c) シンプレクティック性: 古い (q, p) = (r0 + ..., p) のデカルト座標の変数で、ポアソン括弧 ==
  {Q_i, P_j} の行列 (単位行列なら OK): [[1, 0, 0], [0, 1, 0], [0, 0, 1]]
  {P_i, P_j} = [[0, 0, 0], [0, 0, 0], [0, 0, 0]] (零行列なら OK)
  {Q_i, Q_j} = [[0, 0, 0], [0, 0, 0], [0, 0, 0]] (Q は q だけの関数なので 0)

== (d) 運動量の大きさ ==
  |p|^2 - [P_X^2 + P_Y^2 + P_s^2/(1 + X/ρ)^2] = 0

== (e) ベクトルポテンシャルと磁場 ==
  A のカルテシアン成分 A_cart を、Frenet 成分 (A_X, A_Y, A_t) から A = A_X n + A_Y b + A_t t で作ると、
  A_s ≡ A·∂r/∂s = (1 + X/ρ) A_t (P と同じ規則)。
  A_X = A_Y = 0 の場合に、B = rot A をデカルト座標で直接計算し (X, Y, s は x, y, z から作る)、
  B_X = B·n = ∂_Y A_s/(1+X/ρ)、B_Y = B·b = -∂_X A_s/(1+X/ρ)、B·t = 0 と比べる:
  (X, Y, s) = (1/100, -1/50, 3): B·n = 0.015600000000 (式 0.015600000000)、B·b = -0.462808995766 (式 -0.462808995766)、B·t = 0.00e+00
  (X, Y, s) = (-3/100, 1/50, 7/2): B·n = -0.017200000000 (式 -0.017200000000)、B·b = -0.328489368104 (式 -0.328489368104)、B·t = 0.00e+00
  (X, Y, s) = (1/50, 1/30, 1/2): B·n = -0.025333333333 (式 -0.025333333333)、B·b = -0.497529233596 (式 -0.497529233596)、B·t = 0.00e+00
  最大差 (B·t は 0 のはず) = 0.00e+00
