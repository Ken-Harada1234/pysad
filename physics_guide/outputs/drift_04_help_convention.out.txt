== (1) ヘルプの各式を、exp(:H:) = 「H を時間 1 のハミルトニアンとする流れ」と読む ==
  標準の括弧での :H: g = [H, g] は、流れの逆向き (Δx = [H,x] = -∂H/∂px) になる。確認 (H = px^2/2): [H,x] = -p_x、∂H/∂px = p_x

 -- DRIFT: H = (-√(p²-px²-py²) + 1 - E/v0) L  (ヘルプ原文。平文・TeX とも)
   Δx = ∂H/∂px = L*p_x/sqrt(p**2 - p_x**2 - p_y**2)  → x は px/pz × L だけ進む (正しい)
   Δpx = -∂H/∂x = 0
   Δz = ∂H/∂p = -L*h0*p/sqrt(p**2*p0**2 + 1) - L*p/sqrt(p**2 - p_x**2 - p_y**2)
   E/v0 の符号を + に直した H = (-pz + E/(p0v0)) L では Δz = L*h0*p/sqrt(p**2*p0**2 + 1) - L*p/sqrt(p**2 - p_x**2 - p_y**2)
   物理的な Δz = (-p/pz + v/v0) L (= -(p/pz - 1) L - dv L):
     + の符号の H との差 (数値) = 0.00e+00
     ヘルプの H (- の符号) との差 (数値) = 2.00e+00  (= 2 (v/v0) L = 2.000000)

 -- QUAD: H_2n = ((-p + (px²+py²)/(2p) + E/v0) L + K1 (x²-y²)/2)/n  (ヘルプ原文) ----
   Δpx = -∂H/∂x = -K1*x/n (K1 > 0 で x 方向に収束: 力は -K1 x)
   Δpy = K1*y/n (垂直には発散)
   Δz = ∂H/∂p = L*h0*p/(n*sqrt(p**2*p0**2 + 1)) - L/n - L*p_x**2/(2*n*p**2) - L*p_y**2/(2*n*p**2)
   z' = -1 - (px²+py²)/(2p²) + v/v0 (= -(q²/2) - dv) との差: 0  (E/v0 の符号は + で、物理的に正しい)
   (DRIFT の H の符号は、この H_2n と逆。同じ表記 E/v0 なので、DRIFT の方が誤植とみられる。)

 -- SEXT: H_2 = K2/3! Re(x - i y)^3 (薄いキック) ----
   Δpx = -∂H/∂x = K2*(-x**2 + y**2)/2
   Δpy = -∂H/∂y = K2*x*y
   → Δpx = -(K2/2)(x²-y²)、Δpy = K2 x y: 6 極の標準のキック。K2 > 0 は「水平収束」の符号 (ヘルプの K2 の説明) と整合
   標準の括弧で exp(:H:) g = g + [H,g] と読むと符号が逆: [H, px] = K2*(x**2 - y**2)/2

 -- BEND の線形フリンジ: V = -(1/p)(F1²/(24ρb) px - F1/(12ρb²) y² ... ) (平文版) ----
   Δx = -F1**2/(24*p*rho_b)  (ヘルプの x2 = x1 + dxfr (p-p0)/p の p 依存部分 -dxfr/p と一致)
   Δpy = y*(F1**2 - 4*y**2)/(6*F1*p*rho_b**2)
   ヘルプの py2 = py1 + y (dyfr - dyfra y²)/p1² の y(dyfr - dyfra y²)/p との差 (q の単位 py/p なら 1/p²): 0
   → 平文版の V は、ヘルプ自身の線形フリンジの式 (x2、py2) と、「流れ」の読みで一致する。

== (2) 結論 ==
  ヘルプの exp(:H:) は、H (長さをかけた量) を時間 1 のハミルトニアンとする流れ。
  C_poisson_lie.md の記法 (標準の括弧、転送は exp(-s:H_ham:)) では、ヘルプの :f: は -:f: に当たる。
  ヘルプに括弧の定義は無く、この対応は式どうしの整合から確定した (DRIFT の E/v0 の符号だけは例外で誤植とみられる)。
