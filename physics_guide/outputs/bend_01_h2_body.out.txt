== (a) A_s と磁場、a_s、H の展開 (ρb ≠ ρ0 を許す) ==
  A_s = -(x + h x^2/2) B0 から B_x = 0、B_y = B0  (曲線座標の回転の式 B_x = ∂_y A_s/(1+hx)、B_y = -∂_x A_s/(1+hx))
  a_s = e A_s/P0 = -(x + h x^2/2) hb  (hb = eB0/P0 = 1/ρb)
  H = (x + h x^2/2) hb - (1 + h x) sqrt(p^2 - px^2 - py^2) を (x, px, py) の次数で展開:
    0 次: -p
    1 次: x*(-h*p + h_b)
    2 次: (h*h_b*p*x**2 + p_x**2 + p_y**2)/(2*p)
    3 次: h*x*(p_x**2 + p_y**2)/(2*p)
  0〜2 次の和が -p + (hb - h p) x + h hb x^2/2 + (px^2 + py^2)/(2p) に等しい: 差 = 0
  hb = h (ρb = ρ0) のとき: (hb - h p) x = -h δ x、h hb x^2/2 = x^2/(2ρ^2) で、01a の式 (1a.62) と同じ。

== (b) 偏微分を 1 項ずつ、運動方程式 (定数項 -p は落とす) ==
  項                                  ∂/∂px        ∂/∂x               ∂/∂py      ∂/∂y
  (hb - h p) x                       0            -h*p + h_b         0          0
  h hb x^2/2                         0            h*h_b*x            0          0
  K (x^2 - y^2)/2 (複合機能の K1)         0            K*x                0          -K*y
  px^2/(2p)                          p_x/p        0                  0          0
  py^2/(2p)                          0            0                  p_y/p      0
  合計: x' = p_x/p、px' = -K*x - h*h_b*x + h*p - h_b、y' = p_y/p、py' = K*y
  q = px/p の方程式: q' = (-K*x - h*h_b*x + h*p - h_b)/p
  Fortran の drhop + akxsq x と q' の差 (x, q の係数と定数): 0
  Fortran の akysq y と q_y' の差: 0

== (c) 水平の厳密解、分散、R56 ==
  x(s) = x_e + (x0 - x_e) cos ωs + (q0/ω) sin ωs は x'' = -ω^2 (x - x_e) を満たす: 残差 0、初期条件 x(0) - x0 = 0、x'(0) - q0 = 0
  平衡点 x_e = drhop/(-akxsq) = p/h_b - 1/h  (= ρe - ρ0。K = 0 のとき)
  x0 = q0 = 0、1 次の δ: R16 = ∂x/∂δ = rho*(1 - cos(L/rho)) (= ρ(1 - cos(L/ρ)))、R26 = ∂px/∂δ = sin(L/rho) (= sin(L/ρ))
  z' = -h x - q^2/2 - dv の積分の δ の 1 次: ∂z/∂δ = -L + rho*sin(L/rho) - dv の δ 微分 × L  (= -(L - ρ sin(L/ρ)) + L/γ0^2)
  展開: R16 = L**2/(2*rho) - L**4/(24*rho**3) + O(L**5)、R56(幾何) = -L**3/(6*rho**2) + L**5/(120*rho**4) + O(L**6) (L/ρ の 3 次まで)
