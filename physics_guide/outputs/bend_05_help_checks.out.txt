== (a) 線形フリンジ V (入口) ==
 平文版: Δx = ∂V/∂px = -F1**2/(24*p*rho_b)、Δpy = -∂V/∂y = y*(F1**2 - 4*y**2)/(6*F1*p*rho_b**2)
   ヘルプの py2 (正準の 1/p で読む) との差: 0
   次元 (F1・ρb・y [m]、px 無次元): 各項 → -m/12, -m*p_x/24, m/6
 TeX 版: Δx = ∂V/∂px = -F1**2/(24*p*rho_b)、Δpy = -∂V/∂y = y*(-F1**2*rho_b + 4*y**2)/(6*F1*p*rho_b**2)
   ヘルプの py2 (正準の 1/p で読む) との差: y*(-F1**2*rho_b - F1**2 + 8*y**2)/(6*F1*p*rho_b**2)
   次元 (F1・ρb・y [m]、px 無次元): 各項 → -m/6, -m*p_x/24, m**2/12
 平文版の ∂V/∂p (z の更新) と、ヘルプの z2 の括弧 [dxfr px + (dyfr - dyfra y²/2) y²/(2p)]/p の比較 (px を p·q と読む):
   ∂V_ascii/∂p = (F1**3*p_x*rho_b + 2*F1**2*y**2 - 4*y**4)/(24*F1*p**2*rho_b**2)
   差 (px → q p, ヘルプ z2 の px1 を q と読む) = 0
 → 平文版 V はヘルプ自身の変換式と一致 (x と py)。TeX 版は y² の項の ρb のべき・符号、y⁴ の項の符号が違い、y² の項は次元も合わない (誤植)。

== (b) 本体の s ==
 経路長 (面内) s = ρb p_h Θ (05 章 §5.3。括弧内 asin - asin + ω は円弧の角 Θ)。ヘルプの s は ANGLE × ρb × Θ で、ANGLE× が余計で p_h が無い (p_h = 1 の近軸では ρb Θ)。
 検証 (数値): bend_02_arc_faces.out.txt (d) の「ヘルプの本体の式」の欄。

== (d) 非線形フリンジの py2 ==
 ヘルプ / 導出 = 1/p
 → ヘルプは 1/p1 を余分に持つ (p1 = 1 では一致)。

== (e) 本体の px2: TeX 版と平文版の違い ==
 平文版: ... + sin(ω) pz1 + cos(ω) px1 - x1/ρb sin(ω) (= -(x1/ρb) sin ω)。TeX 版: - x1/(ρb sin ω) (sin ω が分母)。
 TeX 版は ω → 0 (ANGLE = ψ1 + ψ2) で発散し、平文版は x1 の係数が -sin ω/ρb → 0 (面から面への直進に戻る)。平文版を 05 章 (5.22) と同じ形として使う。
