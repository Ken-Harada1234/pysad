== (a) trots (SOL 領域の端): 直線を回して新しい面 z = 0 まで延ばす ==
  入口: Fortran の式と 3 次元の直線・平面の交点の差の最大 = 6.9e-18 (z の増分は交点までの媒介変数 -λ + dz)

== (b) tsolrot (bz = 0): 要素の中央を支点とする剛体回転 + 面への戻し ==
  入口: Fortran の枝と 3 次元の構成の差の最大 = 4.7e-17
  出口: Fortran の枝と 3 次元の構成の差の最大 = 6.5e-17
  (z は、面まで前に進んだ分だけ増える。ent では z + ds2/pz2、(a) の z + zf/pzf と同じ形)

== (c) tsolrot (bz != 0、傾いたソレノイド): らせん軌道の ODE との比較 ==
  dcosphi = cos - 1 (xsincos の戻り値のまま):
     x : Fortran の式 = 1.659841383833e-02、ODE = 1.659873644028e-02、差 = -3.23e-07
     y : Fortran の式 = -1.067483118159e-02、ODE = -1.067594388974e-02、差 = +1.11e-06
     px: Fortran の式 = -2.060758056107e-02、ODE = -2.060901265073e-02、差 = +1.43e-06
     py: Fortran の式 = 2.259113319028e-02、ODE = 2.259071699676e-02、差 = +4.16e-07
     l : Fortran の式 = 9.614095033166e-03、ODE = 9.614095033166e-03、差 = +2.08e-17
  dcosphi = 1 - cos (符号を反転):
     x : Fortran の式 = 1.659873578171e-02、ODE = 1.659873644028e-02、差 = -6.59e-10
     y : Fortran の式 = -1.067594316785e-02、ODE = -1.067594388974e-02、差 = +7.22e-10
     px: Fortran の式 = -2.060901254397e-02、ODE = -2.060901265073e-02、差 = +1.07e-10
     py: Fortran の式 = 2.259071661071e-02、ODE = 2.259071699676e-02、差 = -3.86e-10
     l : Fortran の式 = 9.614126988352e-03、ODE = 9.614095033166e-03、差 = +3.20e-08
  読み: 面の条件の式 (s = plz*xsinphi + pz0*sinphi - pbz*dcosphi) は dcosphi = cos - 1 で ODE と一致する (l の差 1e-17)。
        位置・運動量の更新は dcosphi = 1 - cos のとき ODE に近い。同じ dcosphi で両方は成り立たない。
