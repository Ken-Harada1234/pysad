== (a) 展開 (x, y, p_x, p_y を ε 倍) ==
  ε^0 の係数: -delta - 1
  ε^1 の係数: x*(-delta - 1)/rho
  ε^2 の係数: (p_x**2 + p_y**2)/(2*(delta + 1))
  ε^3 の係数: x*(p_x**2 + p_y**2)/(2*rho*(delta + 1))
  → ε^0 は定数 -(1+δ) (運動に効かない)、ε^1 は -(x/ρ)(1+δ)、ε^2 は (p_x^2 + p_y^2)/(2(1+δ))、ε^3 は x(p_x^2 + p_y^2)/(2ρ(1+δ)) (3 次。落とす)

== (b) 磁場とベクトルポテンシャル (e A_s/P0 = a_s、B/(P0/e) = 規格化した磁場) ==
  偏向磁石 A_s = -(x + x^2/(2ρ)) B0: B_x = 0、B_y = B_0
  四極 A_s = -B′(x^2 - y^2)/2 (ρ→∞): B_x = B_p*y、B_y = B_p*x

== (c) 偏向磁石 ==
  H2 との差 = 0
  x′ = ∂H2/∂p_x = 2*p_x/(2*delta + 2)
  p_x′ = -∂H2/∂x = (delta*rho - x)/rho**2
  p_y′ = -∂H2/∂y = 0
  δ ≪ 1 で x′ ≈ p_x′ = -x/ρ^2 + δ/ρ。符号: x が曲率の中心から外向き、δ > 0 は偏向が弱いので外へ向かう。
  参考: 講義ノートの最終式 "x′ = x/ρ^2 - δ/ρ" は H2 の -∂/∂x の符号が逆。上の式が H2 から出る正しい符号

== (d) 四極 (K = e B′/P0) ==
  H2q = K*(x**2 - y**2)/2 + (p_x**2 + p_y**2)/(2*delta + 2)
  p_x′ = -K*x、p_y′ = K*y、x′ (δ=0) = -K*x、y′ (δ=0) = K*y

== (e) 厳密な H~ の運動方程式と 2 次の展開の差 (偏向磁石、ρ = 10 m、δ = 0) ==
  3 m 進んだ後の (x, p_x) の差 (厳密 - 2 次の展開)。初期値は (x, y, p_x, p_y) = (a, 0, a/2, 0) で振幅 a を 2 倍ずつ (差は a の 2 乗で増えるはず):
   a = 1e-03: |Δx|, |Δp_x| の最大 = 1.903e-07
   a = 2e-03: |Δx|, |Δp_x| の最大 = 7.618e-07  (前の値の 4.00 倍)
   a = 4e-03: |Δx|, |Δp_x| の最大 = 3.053e-06  (前の値の 4.01 倍)
   a = 8e-03: |Δx|, |Δp_x| の最大 = 1.225e-05  (前の値の 4.01 倍)
  → 倍率 4 (= 2^2): 落とした項は H の 3 次 (x p^2/(2ρ(1+δ)) など) で、その運動方程式への寄与 (力) は振幅の 2 次。δ x/ρ などの 2 次の項は H2 に厳密に残してある
