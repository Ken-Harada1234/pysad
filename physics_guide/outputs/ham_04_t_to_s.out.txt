== (a) L~ = L t' と共役運動量 ==
  P_t + H = 0
  P_x - p_x = 0、P_y - p_y = 0
  → t の共役運動量は -H。x, y の共役運動量は (独立変数を替えただけなので) 元の p_x, p_y のまま

== (b) 新しいハミルトニアン H~ = Σ P Q' - L~ ==
  H~ + p_s = 0
  → H~ = -p_s (s' = 1 かつ t' ṡ = 1 を使った)

== (c) H~ を P_s について解いた形と、ハミルトンの方程式 ==
  元の H に P_s の解を代入すると E に戻る: H(P_s = 解) - E = 0
  dx/ds = ∂H~/∂P_X     の ∂ 側 - 元の方程式/ṡ = 0
  dy/ds = ∂H~/∂P_Y     の ∂ 側 - 元の方程式/ṡ = 0
  dP_X/ds = -∂H~/∂x    の ∂ 側 - 元の方程式/ṡ = 0
  dP_Y/ds = -∂H~/∂y    の ∂ 側 - 元の方程式/ṡ = 0
  dt/ds = ∂H~/∂P_t     の ∂ 側 - 元の方程式/ṡ = 0
  → H~ のハミルトンの方程式は、元の方程式の時間微分を ṡ = ∂H/∂P_s で割ったもの (陰関数の微分)
  P_t = -E は H~ が t を含まない (静的な場) ので保存する (全部一致)
