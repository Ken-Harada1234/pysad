== (1) 運動量: 回転 + boost + 規格化 (pn、px、py、pz は独立な記号。pn^2 = px^2+py^2+pz^2 は使わない) ==
E2 - ps1 - h1/c = 0  (E2 - ps1 = h1/cos φ)
δ_new (boost) - δ_new (Fortran) = 0
px_new (boost) - (px - tan φ h1)/cos φ = 0
py_new = py/cos φ (boost は y 方向の運動量を変えない: py2 = py)。

== (2) 位置: 事象 (x, y, s=0, ct=-z) -> 回転 -> boost -> 直進で s2 = 0 の面へ ==
h1_new = (1+δ') - ps_new - h1/cos^2 φ = 0
x_new (導出) - x_F = 0
y_new (導出) - y_F = 0
z_new (導出) - z_F = 0

== (3) 数値 (40 桁): Fortran の式を逐語的に写した関数と、導出した写像 (回転 + boost + 直進) を、質量殻上の点で比べる ==
入口: |Fortran の式 - 導出した写像| の最大 (5 点) = 9.78e-42
出口 ∘ 入口 = 恒等: |出口(入口(v)) - v| の最大 = 8.97e-44

== (4) 入口の写像のヤコビアン: J^T S J = S/cos φ (共形シンプレクティック) ==
max |J^T S J - S/cos φ| = 5.92e-46 (φ = 0.0137、1/cos φ - 1 = 9.38e-5)
(参考) max |J^T S J - S| = 9.38e-5
