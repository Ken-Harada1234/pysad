== (a) ポアソン括弧と正準方程式 ==
  [x, p] = 1、[x, x] = 0、[p, p] = 0
  H = p^2/2 + V(x): [x, H] = p (= ∂H/∂p = x')、[p, H] = -Derivative(V(x), x) (= -∂H/∂x = p')
  dg/ds (鎖則) - [g, H] = 0
  → dg/ds = [g, H] = -:H: g。解は g(s) = exp(-s :H:) g(0) (H が s によらないとき)

== (b) 例 1: ドリフト f = -s p^2/2 ==
  :f: x = p*s、:f:^2 x = 0
  :f: p = 0
  exp(:f:) x = p*s + x (項数 2)、exp(:f:) p = p

== (c) 例 2: f = -s (k x^2 + p^2)/2、w = sqrt(k) ==
  :f: x = p*s、:f: p = -k*s*x
  :f:^2 x = -k*s**2*x、:f:^3 x = -k*p*s**3、:f:^4 x = k**2*s**4*x
  :f:^2 p = -k*p*s**2、:f:^3 p = k**2*s**3*x
  級数 (s の 12 次未満) - [x cos(√k s) + p sin(√k s)/√k] の級数 = 0
  級数 - [-√k x sin(√k s) + p cos(√k s)] の級数 = 0
  最初の項: exp(:f:) x = x + s p - (k s^2/2) x - (k s^3/6) p + ... = -k*p*s**3/6 - k*s**2*x/2 + p*s + x
  → x → x cos(√k s) + p sin(√k s)/√k、p → -√k x sin(√k s) + p cos(√k s) (集束四極の線形写像)
  k < 0 なら cos → cosh、sin → sinh (発散)。k -> 0 の極限はドリフト (b)

== (d) 例 3: 6 極のキック f = -k2 x^3/3 (k2 は係数。SAD の K2 との関係は未確認) ==
  :f: x = 0、:f: p = -k2*x**2、:f:^2 p = 0
  exp(:f:) x = x (項数 1)、exp(:f:) p = -k2*x**2 + p (項数 2)  → 級数が止まる (多項式)
  確認: ハミルトニアン H = k2 x^3/3 の 1 ステップ (長さ 1 の薄いキック) は Δp = -∂H/∂x = -k2 x^2
  新しい (x, p) のポアソン括弧 [x_new, p_new] = 1 (1 なら正準変換 = シンプレクティック)

== (e) 合成の順序 ==
  exp(:f:): x -> p*s + x, p -> p (f = ドリフト)、exp(:g:): x -> x, p -> -k*x + p (g = キック)
  exp(:f:) exp(:g:) x = p*s + x、exp(:f:) exp(:g:) p = -k*p*s - k*x + p
  粒子を f の変換 → g の変換の順に動かした結果: x = p*s + x、p = -k*p*s - k*x + p
  差: x = 0、p = 0 → exp(:f:)exp(:g:) の座標への作用は「f が先、g が後」
  逆の積 exp(:g:) exp(:f:): x = -k*s*x + p*s + x、p = -k*x + p (上と違う。非可換)

== (f) [:f:, :g:] = :[f, g]: と BCH ==
  4 つの多項式 h で [:f:, :g:] h - :[f, g]: h の不一致の数 = 0 (0 ならヤコビ恒等式が成り立つ)
  h = x: exp(:f:)exp(:g:) h - exp(:f+g+[f,g]/2:) h = epsilon**3*p/6
        3 次の項 ([f,[f,g]] + [g,[g,f]])/12 を足すと差 = 0
  h = p: exp(:f:)exp(:g:) h - exp(:f+g+[f,g]/2:) h = -epsilon**3*x/6
        3 次の項 ([f,[f,g]] + [g,[g,f]])/12 を足すと差 = 0
  → exp(:f:) exp(:g:) = exp(:f + g + [f, g]/2 + ([f,[f,g]] + [g,[g,f]])/12 + ...:) (BCH)。f と g が可換 ([f, g] = 0) でない限り exp(:f+g:) とは違う

== (g) 2 次の f と線形写像 ==
  :f: (x, p) = F (x, p) の行列 F = [[0, s], [-k*s, 0]]
  行列指数 exp(F) - [[cos, sin/√k], [-√k sin, cos]] = Matrix([[0, 0], [0, 0]])
  det M = 1、M^T J M - J = [[0, 0], [0, 0]] (0 行列ならシンプレクティック)
  2 次の f (H = (k x^2 + p^2)/2 の -s 倍) で :f: が (x, p) の 1 次式になる → exp(:f:) は行列 exp(F) になる
