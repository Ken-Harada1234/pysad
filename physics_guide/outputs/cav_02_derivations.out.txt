== (a) 端の項 H_f から tcavfrin の式を作る (sympy) ==
  ΔE = ∂_t K = -omega*v*(x**2 + y**2)*cos(dphi - omega*t)/(4*L)
  コードの dh = -w p0 vf (x² + y²)/2 cos(ωt - dphis) との差 = 0
  Δp_x/p0 = -∂_x K / p0 = v*x*(s0 - sin(dphi - omega*t))/(2*L*p0)
  コードの x·vf (sin + s0) との差 = 0
