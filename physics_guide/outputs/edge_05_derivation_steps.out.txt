  漸化式 (y^n の係数): (n+1) cs_{n+1} = cy_n'、(n+1) cy_{n+1} = -cs_n'  (cs_0 = 0、cy_0 = g)
    y^0: cy_0 = g(s)、 cs_0 = 0

    y^2: cy_2 = -Derivative(g(s), (s, 2))/2、 cs_2 = 0

    y^4: cy_4 = Derivative(g(s), (s, 4))/24、 cs_4 = 0
  b_y - (6.1) = 0、b_s - (6.1) = 0

== (d) CAVI の端 ==
  ∇·E = (1/r)∂_r(r E_r) + ∂_s E_z (E_r = -(r/2) E_z') = 0
  H = -√((E - eφ)² - m² - p⊥²) (c = 1): ∂H/∂φ|_(φ=0) = E*e/sqrt(E**2 - m**2 - p_x**2 - p_y**2) = e E/p_z = e/β_z
   → 運動量のキック ΔP = -∫∂H/∂x ds = -(e/β_z) ∫∂_xφ ds: 速度で割る因子 1/β_z が H から自動的に出る (H_f の係数に 1/β は書かれていない)。

== (e) H = -√(p² - (p_x - a_x)² - (p_y - a_y)²) の a_⊥ による展開 ==

== (f) 1 次の摂動: H0 = p²/2、H1 = ε x² h(s) (h(s) = s + s²、区間 0〜S) ==

== (g) 偏向磁石の端のローレンツ力の積分 (p_y = 0 から始める。b_y = ε(g - y² g''/2)、b_s = ε y g'、ε = 1/ρ_b) ==
  端の項: dP_x/ds = gpp*y**2/(2*rho) (P_y = 0)、dP_y/ds = -P_x*gp*y/(P_z*rho)
   ∫ g' ds = 1 (0 → 1 の立ち上がり)、∫ g'' ds = 0。P_x の端の項の積分: ∫ΔP_x(s) ds, ΔP_x(s) = +(y²/(2ρ)) g'(s) (g'' の積分から)
   → ΔP_y = -(P_x/P_z)(y/ρ)、∫ΔP_x ds = y²/(2ρ)。dx/ds = P_x/P_z の摂動: Δx = ∂(P_x/P_z)/∂P_x ∫ΔP_x ds
     ∂(P_x/P_z)/∂P_x = (p**2 - p_y**2)/(-P_xs**2 + p**2 - p_y**2)**(3/2) = (p² - p_y²)/P_z³
     Δx = (y²/(2ρ)) (p² - p_y²)/p_z³ = -∂f/∂p_x (f = -(y²/2ρ) p_x/p_z) と一致 (edge_01 (d))

== (h) K64 の Maxwell フリンジの係数 a、b と三角関数の展開 ==
  sin θ/θ = 1 - theta**2/6 + theta**4/120 + O(theta**6)
  (1 - cos θ)/θ² = 1/2 - theta**2/24 + theta**4/720 + O(theta**6)
  K64: a = 1 - (y/ρ)²/6、b = 1/2 - (y/ρ)²/24 (θ = y/ρ)。θ² までの係数が一致 (θ⁴ 以上は K64 に無い)。
  すなわち Δp_y = -(p_x/p_v) sin(y/ρ)、Δx = ρ(1 - cos(y/ρ)) p²/p_v³ の θ² までの展開。物理的な導出は未 (本文 §8.2)。

== (i) ソレノイドの端: f = k p_φ p_u (u = ln r、p_u = x p_x + y p_y、k = b0/(8p²)) の流れ ==
  [u, p_u] = 1、[φ, p_φ] = 1、[u, p_φ] = 0、[φ, p_u] = 0、[u, φ] = 0、[p_u, p_φ] = 0
  f = k p_φ p_u は (u, φ) を含まないので p_u、p_φ は保存。Δu = -∂f/∂p_u = -k p_φ、Δφ = -∂f/∂p_φ = -k p_u、Δz = -∂f/∂p = +2k p_φ p_u/p (k ∝ 1/p²)。
  K64: bq = -dbz/(8p) (q 単位: p_φ/p を使うので k p_φ = bq p_φ,q): r1 = r e^{bq p_φ}、φ1 = φ + bq p_r、z1 = z + bp p_r p_φ (bp = -2 bq)。
