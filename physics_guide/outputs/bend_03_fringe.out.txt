== (a) 端の磁場 (b = eB/P0、直線座標 (x, y, s)、一様な B0 = 1/ρ の端) ==
  スカラーポテンシャル V = y g - y^3 g''/6 + y^5 g''''/120 - ... (∇²V = 0 を満たす。b_x = ∂_x V = 0 の直線の端)
  b_y = ∂_y V = y**4*Derivative(g(s), (s, 4))/24 - y**2*Derivative(g(s), (s, 2))/2 + g(s)
  b_s = ∂_s V = -y**3*Derivative(g(s), (s, 3))/6 + y*Derivative(g(s), s)
  ∇·b = ∂_y b_y + ∂_s b_s = -y**7*Derivative(g(s), (s, 8))/5040  (y の 5 次 (V の打ち切り) だけが残る)
  ∇×b: (∇×b)_x = ∂_y b_s - ∂_s b_y = 0 (同じく V の打ち切りだけ)、b_x = 0 から他の成分は 0

== (e) tbendal の rbh・rbl、DISFRIN の効き方 ==
  rbh = 1/2 + 1/√12 = 0.7886751346、rbl = 1/(6 rbh) = 0.2113248654、rbh + rbl = 1.000000000000、rbh rbl = 0.166666666667 (= 1/6)。区間 [0,1] の 2 点 Gauss-Legendre の節に一致 (1/2 ± 1/(2√3) = 0.2113248654, 0.7886751346)
