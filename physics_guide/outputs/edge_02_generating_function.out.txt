== (a) 母関数 G から出る点変換 ==
  x2 - (x + V_x + (V·∇)V_x/2) = 0、y2 - (y + V_y + (V·∇)V_y/2) = 0
  (4.29) との差: x2 - x(1 + a/3 + b + t) = 0、y2 - y(1 - a - b/3 + t) = 0
  V = (Δx1, Δy1) = ∂f/∂(px, py) (f = H0 = (4.27))。G の第 2 項は (V·∇)V/2 を作るためのもので、1 次 (K の 1 次の Maxwell) には効かない。
