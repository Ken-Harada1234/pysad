== (a) sympy: 場と端の位置のずれ ==
  m = 2: ∇⊥²Φ = -kappa2*x*y、∂s²Φ = κ'' Im w^m/m! を足すと 0 (∇⊥²Φ + κ'' Im w^m/m! = 0)
       Δ(x + i y) = (Fx + i Fy の κ'' の係数) と -aki κ'' w (w^m/(m+1) - w̄^m) (aki = 1/(4 m!)) の差: 0
  m = 3: ∇⊥²Φ = -kappa2*y*(3*x**2 - y**2)/6、∂s²Φ = κ'' Im w^m/m! を足すと 0 (∇⊥²Φ + κ'' Im w^m/m! = 0)
       Δ(x + i y) = (Fx + i Fy の κ'' の係数) と -aki κ'' w (w^m/(m+1) - w̄^m) (aki = 1/(4 m!)) の差: 0
  m = 4: ∇⊥²Φ = -kappa2*x*y*(x - y)*(x + y)/6、∂s²Φ = κ'' Im w^m/m! を足すと 0 (∇⊥²Φ + κ'' Im w^m/m! = 0)
       Δ(x + i y) = (Fx + i Fy の κ'' の係数) と -aki κ'' w (w^m/(m+1) - w̄^m) (aki = 1/(4 m!)) の差: 0
  (κ(s) = κ0 Θ(s) で κ'' = κ0 δ'(s)。力が δ'(s) なので、運動量は δ(s) 型にスパイクし、位置は端で階段状にずれる: Δw = (1/p) × (κ'' の係数) × κ0。
   運動量の変化 (K の 1 次) は ∫δ'(s) g ds = -g'(0) から、軌道に沿った微分で決まる (四極の章 (4.26) と同じ手順)。
