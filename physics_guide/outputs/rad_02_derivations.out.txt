== (d) tradke の微分 (連鎖律) ==
  dh1r = (1/h1) dh1/dpr = p0**2*pr/(p0**2*pr**2 + 1)   (コード: p p0/h1² = p0² pr/h1²)
  ∂dg/∂θ - コードの -cave (danp uc + anp duc)|_θ = 0
  ∂dg/∂al1 - コードの -cave anp (-uc/al1)       = 0
  ∂dg/∂pr (h1 を通して) - コードの -cave (anp dh1r uc + anp 3 uc dh1r) = 0
  → ddg = -cave (danp uc + anp duc) は、dg = -cave anp uc (anp = anrad h1 θ、uc = cuc h1³ θ/(p0 al1)) の連鎖律どおり。
  xpa = |xp|/pr² の微分: d xpa - [(xp·dxp)/(xpa pr⁴) - 2 xpa dpr/pr] = 0
  K64 の dxpa = (xp·dxp)/xpa/pr² (第 1 項が pr² で、pr⁴ ではない。B138 (4))。δ = 0 (pr = 1) では同じ。
  ddpx = ½ dpx dg の微分: d ddpx = ½ [(d px - d pxr0) dg + dpx ddg]。K64 は第 2 項が ddpx*ddg (= ½ dpx dg ddg) で、dpx ddg ではない (B138 (2))。
