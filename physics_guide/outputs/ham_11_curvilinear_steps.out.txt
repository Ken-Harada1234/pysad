(a) sqrt(1-u) の二項展開: Σ_k C(1/2,k) (-u)^k
  k=0: C(1/2,0) = 1、C(1/2,0)(-u)^0 = 1
  k=1: C(1/2,1) = 1/2、C(1/2,1)(-u)^1 = -u/2
  k=2: C(1/2,2) = -1/8、C(1/2,2)(-u)^2 = -u**2/8
  k=3: C(1/2,3) = 1/16、C(1/2,3)(-u)^3 = -u**3/16
  k=4: C(1/2,4) = -5/128、C(1/2,4)(-u)^4 = -5*u**4/128
  sympy series: 1 - u/2 - u**2/8 - u**3/16 - 5*u**4/128 + O(u**5)
  x^4 の項 5/128: 捨てる x < 8e-6 で |5 x^4/128| = 1.60e-22

(d) 分散の方程式 η'' + η/ρ² = 1/ρ
  η = ρ(1 - cos(s/ρ)): η'' + η/ρ² - 1/ρ = 0

  一般解 ρ + a cos + b sin: η'' + η/ρ² - 1/ρ = 0
  η1(0) = 0、η1'(0) = 0。η1 - ρ = -ρ cos(s/ρ) (同次方程式の解)
