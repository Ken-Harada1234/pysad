== (a) M-01: ndiv の式 (8.8) の ε の読み ==
  δH (BCH: -1/24 [X,[X,Y]] + 1/12 [Y,[Y,X]] から) - h²[|∇V|²/12 - p_i p_j V_ij/24] = 0

   Ω² = A B = ω²(1 + ω²h²/12 + ...)、Ω/ω = 1 + ω²h²/24: 1 + hh**2*omega2/24 + O(hh**3)
   運動量の振幅: p = -x0 Ω sin(Ω t)/A、Ω/A の ω に対する比 = 1 + hh**2*omega2/8 + O(hh**3)
   → ωL ≪ 1 の運動量の跳び (≈ -x0 ω² L) の相対誤差 = Ω/A の変化 ω²h²/8 (= 1/24 + 1/12) と、sin(Ωt) ≈ Ωt の位相の変化 ω²h²/24 の和 = (ωh)²/6
  K2 = 40 /m²、L = 1 m、初期値 (4 mm, 0.8 mrad, -3 mm, -0.4 mrad)。(x, px, y, py) の誤差:

== (b) M-02: dofr(n) の判定量 ==
  D_n = (K_n/L) a^(n+1)/(n+1) と Δw/a (第 1 項) の比 = 4*(n + 2)*factorial(n)
   n = 2: 4 n!(n+2) = 32、判定 D_n > ε は Δw/a > ε/32 (ε = 0.005 で 1.6e-04)
   n = 3: 4 n!(n+2) = 120、判定 D_n > ε は Δw/a > ε/120 (ε = 0.005 で 4.2e-05)
   n = 4: 4 n!(n+2) = 576、判定 D_n > ε は Δw/a > ε/576 (ε = 0.005 で 8.7e-06)
   n = 5: 4 n!(n+2) = 3360、判定 D_n > ε は Δw/a > ε/3360 (ε = 0.005 で 1.5e-06)
   n = 6: 4 n!(n+2) = 23040、判定 D_n > ε は Δw/a > ε/23040 (ε = 0.005 で 2.2e-07)

== (c) M-03: 「長さ × 力」だけの式の rot ==
  C = K0 + K1 z: rot = -K1*t*y/L、-(t/L) Im C(z) との差 = 0、div = t*(K0 + K1*x)/L
     (8.9) - 「長さ×力」 - (i t y/L) C = 0
  C = K0 + K1 z + K2 z²/2: rot = -t*y*(K1 + K2*x)/L、-(t/L) Im C(z) との差 = 0、div = t*(2*K0 + 2*K1*x + K2*x**2 - K2*y**2)/(2*L)
     (8.9) - 「長さ×力」 - (i t y/L) C = 0
  K1 だけ: (i t y/L) K1 z の実部・虚部 = -K1*t*y**2/L、-K1*t*x*y/L (Δp_x に -t K1 y²/L、Δp_y に -t K1 x y/L を足す)
