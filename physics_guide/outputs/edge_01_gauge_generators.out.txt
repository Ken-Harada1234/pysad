== (a) 偏向磁石の直線の端 (b = e B/P0 を 1/ρ で割ったもの。g(s) = B_y(s)/B_0) ==
  A_x = y**4*Derivative(g(s), (s, 3))/24 - y**2*Derivative(g(s), s)/2、A_s = -x*g(s)
  b_x = 0
  b_y - (g - y² g''/2 + y⁴ g''''/24) = 0
  b_s - (y g' - y³ g'''/6)           = 0
  → ∇×A = b (5.31) (y⁴・y³ まで)。A_s = -x g は本体の偏向 (一様な b_y = g)、A_x は端 (g' ≠ 0) だけに現れる。

== (b) 四極: K(s) ==
  b_x - (4.25) = 0、b_y - (4.25) = 0、b_s - K' x y = 0

== (c) 2m 極 (m = 2, 3, 4): Φ = κ Im w^m/m! - κ'' |w|² Im w^m/(4 (m+1)!) ==
  m = 2: ∇×A - ∇Φ = [0, 0, k3*x*y*(x**2 + y**2)/12]
  m = 3: ∇×A - ∇Φ = [0, 0, k3*y*(x**2 + y**2)*(3*x**2 - y**2)/96]
  m = 4: ∇×A - ∇Φ = [0, 0, k3*x*y*(x - y)*(x + y)*(x**2 + y**2)/120]
  (残りは κ''' (k3) の項だけ。b_s = ∂Φ/∂s の κ''' の項で、A の次の次数の補正が要る。κ' (k1)・κ'' (k2) の次数では 0)

== (d) 硬い端の生成関数 f = ∫H₁ ds、H₁ = -(p_x a_x + p_y a_y)/p (p_z ≈ p)。κ' = κ0 δ(s) ==
  m = 2: Δw = ∂f/∂p_x + i ∂f/∂p_y と -(κ0/p) a_w の差 = 0
         (4.27) の f_in との差 = 0
  m = 3: Δw = ∂f/∂p_x + i ∂f/∂p_y と -(κ0/p) a_w の差 = 0
  m = 4: Δw = ∂f/∂p_x + i ∂f/∂p_y と -(κ0/p) a_w の差 = 0
  偏向磁石: a_x = -y² g'/(2ρ) → f = -(p_x a_x/p_z) の ∫ds = (y²/2ρ) p_x/p_z。Δx = ∂f/∂p_x = y**2*(p**2 - p_y**2)/(2*rho*(p**2 - p_x**2 - p_y**2)**(3/2))
     Δp_y = -∂f/∂y = -p_x*y/(rho*sqrt(p**2 - p_x**2 - p_y**2))、Δz = ∂f/∂p = -p*p_x*y**2/(2*rho*(p**2 - p_x**2 - p_y**2)**(3/2))

== (e) 偏向磁石の y⁴ の項: A_x の y⁴ g'''/(24ρ) (g''' = δ'') の寄与 ==
  f₄ = F''(0) = -p_x*p_y**2*y**2/(2*rho*(p**2 - p_x**2 - p_y**2)**(3/2))
  f₂ + f₄ の p_y² までの展開 - (y²/2ρ)(p_x/p_v)(1 - p_y²/(2 p_v²)) = 0   (p_v = √(p² - p_x²))
  → K64 の f (5.34)・(5.36) は p_y を p_z に入れない (p_v = √(p² - p_x²))。この 4 次 (y² p_y² p_x/ρ) の項は入れていない。

== (f) ソレノイドの端: A_φ = r b/2 - r³ b''/16 (b(s) = 軸上の B_z/Bρ) ==
  b_x - b_r x/r = 0、b_y - b_r y/r = 0、b_s - (b - r² b''/4) = 0
  (b_r = -r b'/2 + r³ b'''/16、b_z = b - r² b''/4。b'''' 以上は打ち切り。)
  f = -b0 F'(0) = b0*(p_x*x + p_y*y)*(p_x*y - p_y*x)/(8*(p**2 - p_x**2 - p_y**2))
  f - (-(b0/(8 p_z²)) p_φ p_r) = 0    (p_z² → p² (paraxial) がヘルプの H = -Bz/(8 p² Bρ) p_φ p_r)
  (p_φ = x p_y - y p_x は自由な運動で保存するので、微分は r² だけに掛かる。)
