== (a) COORD の DIR != 0: K64 の行列の積の順序 (sympy) ==
  K64 の DIR != 0 の行列 - R1 R2m R3  = 0 か: True
  K64 の DIR != 0 の行列 - R3 R2m R1  = 0 か (ヘルプの式): False
  (R2m は R2 の s2 の符号を反転したもの)
  DIR = 0 の行列 M0 = R3 R2 R1 の逆 (転置) = R1^T R2^T R3^T = R1(-χ1) R2(-χ2) R3(-χ3)。符号を替えた記号 s_i → -s_i で書く:
    M0^T - R1 R2m R3 (s1 → -s1, s3 → -s3 を入れる前) = 0 か: True
  → K64 の DIR != 0 は、真の逆 M0^T = R1(-χ1) R2m R3(-χ3) の、χ1 と χ3 の符号を反転して入れたもの
     (R1(-χ1) → R1(χ1)、R3(-χ3) → R3(χ3))。逆変換にならない (ヘルプの "NOT the inverse") ことの代数的な理由。

== (c) tbgrote の 6×6 行列と数値微分 ==

== (d) (11.3)(11.4) の 1 次の展開 (§3.5): 原点での 1 次の係数 (sympy) ==
  誤差のパラメータでの 1 次の係数 (∂出力/∂パラメータ、パラメータ = 0。x, p_x, y, p_y, z, δ は一般の値。p_z = sqrt(p² - p_x² - p_y²)、p = 1 + δ):
   x'      = (誤差なしの値) + (p_x*x/p_z)·chi1 + (p_x*y/p_z)·chi2 + (-y)·chi3 + (-1)·DX + (p_x/p_z)·DZ
   p_x'    = (誤差なしの値) + (p_z)·chi1 + (-p_y)·chi3
   y'      = (誤差なしの値) + (p_y*x/p_z)·chi1 + (p_y*y/p_z)·chi2 + (x)·chi3 + (-1)·DY + (p_y/p_z)·DZ
   p_y'    = (誤差なしの値) + (p_z)·chi2 + (p_x)·chi3
   z'      = (誤差なしの値) + (-x*(delta + 1)/p_z)·chi1 + (-y*(delta + 1)/p_z)·chi2 + ((-delta - 1)/p_z)·DZ
   delta'  = (誤差なしの値) + 0
  (原点 x = p_x = ... = 0 の線形項は x_new = x - DX、p_x_new = p_x + chi1 など。)
