== (a) 基本の展開 ==
  sqrt(1 + u) = 1 + u/2 - u**2/8 + u**3/16 + O(u**4)
  sqrt(1 - u) = 1 - u/2 - u**2/8 - u**3/16 + O(u**4)
  1/(1 + δ)   = 1 - delta + delta**2 - delta**3 + O(delta**4)
  → u = (p_x^2 + p_y^2)/(1+δ)^2 は p の 2 次なので、u の 1 次までが p の 2 次、u^2 は p の 4 次 (落とす)

== (b) H の展開 (因子ごと) ==
  (i) sqrt((1+δ)^2 - q^2) = (1+δ) sqrt(1 - u)、u = q^2/(1+δ)^2:
      ε^0 の項: delta + 1
      ε^2 の項: (-p_x**2 - p_y**2)/(2*(delta + 1))
      ε^4 の項: -(p_x**2 + p_y**2)**2/(8*(delta + 1)**3)
      (ε は p_x, p_y を ε 倍するための目印。ε^2 までが 2 次、ε^4 = p の 4 次は落とす)
  (ii) (1 + x/ρ) の因子: 1 + ε x/ρ (これ以上の展開はない。x/ρ ≪ 1 の仮定は、掛け算の項を次数で分類するために使う)
  (iii) 掛け合わせた -(1 + x/ρ) sqrt(...) の、次数 (ε の冪) ごとの項:
      ε^0: -delta - 1
      ε^1: x*(-delta - 1)/rho
      ε^2: (p_x**2 + p_y**2)/(2*(delta + 1))
      ε^3: x*(p_x**2 + p_y**2)/(2*rho*(delta + 1))
      ε^0 は定数 (運動に効かない)、ε^1 は x の 1 次、ε^2 は p の 2 次、ε^3 は x と p^2 の積 = 3 次 (落とす)。落とした項の大きさは、2 次の項の x/ρ 倍

== (c) 偏向磁石の H2 = x^2/(2ρ^2) - δ x/ρ + q^2/(2(1+δ)) を 1 項ずつ ==
  項                  ∂/∂p_x            ∂/∂x              ∂/∂p_y            ∂/∂y
  x^2/(2ρ^2)         0                 x/rho**2          0                 0
  -δ x/ρ             0                 -delta/rho        0                 0
  p_x^2/(2(1+δ))     2*p_x/(2*delta + 2) 0                 0                 0
  p_y^2/(2(1+δ))     0                 0                 2*p_y/(2*delta + 2) 0
  合計: ∂H/∂p_x = 2*p_x/(2*delta + 2)、∂H/∂x = -delta/rho + x/rho**2、∂H/∂p_y = 2*p_y/(2*delta + 2)、∂H/∂y = 0
  → x' = ∂H/∂p_x = p_x/(1+δ)、p_x' = -∂H/∂x = -x/ρ^2 + δ/ρ、y' = p_y/(1+δ)、p_y' = 0

== (d) 四極の H = K (x^2 - y^2)/2 + q^2/(2(1+δ)) を 1 項ずつ ==
  項                  ∂/∂p_x            ∂/∂x              ∂/∂p_y            ∂/∂y
  K x^2/2            0                 K*x               0                 0
  -K y^2/2           0                 0                 0                 -K*y
  p_x^2/(2(1+δ))     2*p_x/(2*delta + 2) 0                 0                 0
  p_y^2/(2(1+δ))     0                 0                 2*p_y/(2*delta + 2) 0
  → x' = p_x/(1+δ)、p_x' = -K x、y' = p_y/(1+δ)、p_y' = +K y

== (e) x'' = p_x'/(1+δ) の δ の展開 (偏向磁石) ==
  p_x'/(1+δ) = (-x/ρ^2 + δ/ρ)/(1+δ) の δ の級数 (2 次まで): -delta**2/rho - delta**2*x/rho**2 + delta/rho + delta*x/rho**2 - x/rho**2
  δ の 1 次までで x'' ≈ -x/ρ^2 + δ/ρ。落とした項: δ x/ρ^2、δ^2/ρ など (x, δ について 2 次)

== (f) ΔH = p - sqrt(p^2 - q^2) - q^2/(2p) の q^2 の展開 (04_quad.md 式 (4.6)) ==
  sqrt(p^2 - Q) = p - Q/(2*p) - Q**2/(8*p**3) - Q**3/(16*p**5) + O(Q**4)
  ΔH = Q**2/(8*p**3) + Q**3/(16*p**5) + O(Q**4)
  → 最初の項は Q^2/(8 p^3) = (p_x^2+p_y^2)^2/(8 p^3) (横方向の運動量の 4 乗)
