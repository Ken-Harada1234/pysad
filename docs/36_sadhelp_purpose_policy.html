SADHelp (1.4.4.2k64 Updated: 10/19/2026) の項目の目的別分類と翻訳方針

この文書で分かること: SADHelp の各項目を目的別 (物理計算、マッチング、ファイル・入出力、GUI・描画など) に分類し、pysad での扱い方針 (直接翻訳、Python で書き直し、Python のライブラリで代替) を示す。 前提: 項目の一覧は docs/34_sad_help_index.md、実装状況は docs/35_pysad_vs_sadhelp.md。 読む順: 先頭の方針の一覧 → 自分の関心のある分類の表 → 末尾の補足。

最終更新: 2026-11-17 (現状のスナップショット。pysad の列は docs/35_pysad_vs_sadhelp.md の 2026-11-16 の照合による。RENUMBER・ElementValues の 2 行は手で直してある。MEASURE・Fork・OpenShared・Shared・SharedSize・System の行と「現状の補足」は v2 の実装に合わせている)

ユーザー方針 (2026-11-06): 直接翻訳するのは、ソースが Fortran/C で内容が物理計算のもの。ソースが .n のものは Python で書き直す (直訳ではない)。ファイル操作・リスト操作・GUI・描画は Python のライブラリ (open, list/numpy, matplotlib 等) に置き換えるので翻訳対象外 (必要なら Python で書き直す)。

分類と SAD 側・pysad の列は docs/35_pysad_vs_sadhelp.md と同じ機械照合 (生成: perf_work/sadhelp_purpose.py、分類は手で割り当て)。

方針の一覧

分類 方針 具体的に
物理計算 (26) 直接翻訳 Fortran/C の式・分割・反復順序を写す (pysad の本体)。ソースが .n のものは Python で書き直す
マッチング・最適化の仕組み (21) 直接翻訳 tffsmatch/tffscalc/qdcell の直訳 (フックの呼び出しを含む)。.n のもの (OptimizeOptics, DownhillSimplex) は Python で書き直す
要素・ビームラインの操作 (7) Python で書き直し pysad のデータ構造 (Element, Lattice, Env) の上で同じ意味になるよう書く。直訳ではない
乱数 (6) 直接翻訳 FLUC の照合に SAD と同じ乱数列が要るので C (tfRandom_.c) を写す (sadrandom.py)
数値計算・フィット (6) Python ライブラリで代替 numpy/scipy (curve_fit, integrate, interpolate, optimize) に置き換える。翻訳対象外、必要なら Python で書き直す
リスト・関数型 (言語機能) (21) Python で書き直し (インタプリタ) SADScript を走らせるために sadscript.py が Python のリスト演算で実装する。pysad を Python から直接使うときは list/numpy
文字列・式 (言語機能) (13) Python で書き直し (インタプリタ) sadscript.py が Python の str で実装。直接使うときは str
ファイル・入出力 (15) Python ライブラリで代替 open/print/csv/json に置き換える。翻訳対象外 (OpenRead の失敗の扱いは gs に合わせた: 開けなければ入力行を打ち切る。11-16)
GUI・描画 (14) Python ライブラリで代替 2026-11-06 の方針は matplotlib への置き換え。現状 (2026-11-16) は例外: GUI (Tkinter.n・KBFrame.n など) と描画 (ListPlot・Plot・OpticsPlot など) は SAD 自身の .n を pysad のインタプリタで解釈し、tkinter に表示する (docs/20・21)。matplotlib の描画 (plot_optics.py) は別に残る
システム・プロセス・並列 (7) Python ライブラリで代替 subprocess / multiprocessing / tempfile に置き換える。翻訳対象外
ユーティリティ (時刻・計測・デバッグ) (5) Python ライブラリで代替 time / datetime / logging に置き換える。翻訳対象外
表示 (表・一覧) (9) Python で書き直し DISP/TYPE のように SAD と同じ文字列を出すものは照合のため書き直す。それ以外 (SHOW, STATUS, MATRIX 等) は ffsextra.py に実装 (docs/04)
制御・入出力 (FFS コマンド) (19) Python ライブラリで代替 入力の切り替え・停止・中断は Python の制御構造とファイル操作で置き換える。翻訳対象外
要素編集・変数 (FFS コマンド) (12) Python で書き直し FREE/FIX/SAVE/RESET/COUPLE 等は pysad の要素値の仕組みで書く
誤差 (FFS コマンド) (1) 直接翻訳 terror.f の乱数の引き方まで写す (照合済み)
FFS フラグ・物理パラメータ (変数) (30) 直接翻訳 tfsetparam/tffsa が読む意味のとおりに使う
表示・書式 (変数) (4) Python で書き直し $FORM/PageWidth/TITLE/CASE は出力の書式。照合に要る $FORM/PageWidth は書き直し済み、描画用は対象外
フック・特殊 (変数) (6) 直接翻訳 FitFunction/MatchingAmplitude/InitialOrbits/OpticsProlog 等は SAD が評価する仕組みごと写す
