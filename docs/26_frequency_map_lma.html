周波数マップと局所運動量アクセプタンス (LMA)

この文書で分かること: 周波数マップ (初期条件の格子ごとのチューンの拡散の地図) と、局所運動量アクセプタンス (位置 s ごとの運動量のずれの限界 δ+(s)・δ−(s)) を、pysad で求める方法 (Python の API と SAD の台本の両方)、アルゴリズム、結果の読み方、信頼して使うための条件と警告、Touschek 寿命への受け渡し、検証、限界。 前提: 追跡 (docs/10) とチューン・共鳴の基礎。共鳴駆動項 (RDT)・ADTS との関係は docs/25 (J²・δ 依存は §13)。入門 (何をどう求めて何と比べたか) は docs/24。 読む順: §1 (何ができるか) → §2 (共通の部分) → §3 (周波数マップ) または §4 (LMA) → 使うときは各節の「信頼して使うための条件と警告」(§3.6・§4.5) → §5〜§11 (検証・条件・限界・実装・追加の検証)。

用語: 周波数マップ は初期条件 (x, y、または δ) の格子ごとに、前半と後半の周回のチューンの差 D = log10 √(Δνx² + Δνy²) を求めて色で表した図 (規則的な運動は D が小さく、カオス的な運動は大きい)。NAFF は追跡データからチューンを高精度に求める周波数解析。LMA は粒子が失われずに周回できる運動量のずれの範囲を位置ごとに求めたもので、Touschek 寿命の見積もりに使う。RF バケット は RF が粒子を捕らえる (z, δ) の領域 (高さ δ_rf)。gs は K64 (SAD のソース) から作った SAD の実行体。v2 / k64 は pysad の既定動作と、PYSAD_COMPAT=k64 で選ぶ K64 と同じ動作。

K64 にない pysad の追加機能。1 つの位置の初期条件の格子から 周波数マップ を作る機能と、位置 s ごとの 局所運動量アクセプタンス (δ+(s)・δ−(s)) を求める機能。どちらも SAD の追跡 (TrackParticles と同じ損失判定の高速追跡、numba) の上に作り、SAD の台本から使える関数 (FrequencyMap[]、MomentumAcceptance[]、TouschekLifetimeLMA[]) と Python の API の両方で使える。K64 の MAIN の TRACK には Fourier 解析 (FOURIER フラグ) があるが、FFS からは使えない (docs/history/work_main_track.md)。チューンの取り出しは pysad/naff.py (NAFF) を使う。

2. 共通の部分 (pysad/trksetup.py)

TrackSetup が FFS の状態 (要素の並び、運動量、RF、RAD・RFSW フラグ、Emittance[] の閉軌道と同期位相、LOSSAMPL・LOSSDZ) を 1 つにまとめる。

from pysad.trksetup import TrackSetup
st, ffs = TrackSetup.from_source(lattice_text, 'RING', rad=True, rfsw=True, alost=0.01)   # USE RING; CELL; CALC; Emittance
st = TrackSetup.from_ffs(ffs)                                                              # 台本で USE・CALC したあとの FFS オブジェクトから
st2 = st.copy(rad=False, rfsw=False)                                                       # 周波数マップ用
  • 閉軌道: 位置 1 の閉軌道は Emittance[] (RADCOD) の値から Newton 法で求め直す (RFSW ON・放射つきは 6 次元、RFSW OFF は δ を決めた 4 次元)。ほかの位置へは 1 粒子を運ぶ (closed_orbit(locs))。1 周後との差を conditions()['orbit_residual'] に記録する (例: ASTRID2 で 2e-18、大きなリング A で 4e-16)。
  • 損失の判定: SAD の TrackParticles (track6n.TrackRun) と同じ。tapert は最初の要素・15 要素ごと・区間の終わりで、|x|,|y| < LOSSAMPL (正方形)、|z| ≤ LOSSDZ、APERT 要素。
    • setup.track(loc, coords, nturn) の区間の分け方は、TrackParticles[{loc, beam}, loc, 1, nturn] の 1 回の呼び出しと同じ (loc→nlat、(nturn−1) 回の 1→nlat、1→loc)。
    • 周ごとの座標を記録するとき (周波数マップ) は 1 周ずつ loc から回す (1 周ずつ TrackParticles[{loc, beam}, loc] を呼ぶのと同じ)。
    • check_every = k (TrackSetup の既定は 0 = SAD と同じ。LMA (momentum_acceptance・MomentumAcceptance[]) の既定は 1、§4.5): k > 0 なら k 要素ごとに区間を分けて判定する。SAD の判定は 15 要素に 1 回なので、 アパーチャが限界のとき、判定点のあいだの最大のずれを見逃し、δ の限界を大きく見積もる (ASTRID2、±10 mm、位置 17 で δ+ = 1.05% (k = 0) に対し 0.83% (k = 1)。線形の見積もり 0.865%)。
  • 周期性: find_periodicity(els, rows) は、マーカー・モニター・空洞を除いた要素の並び (種類と数値の属性) が同じ列の n 回の繰り返しになる最大の n を返す (ASTRID2 で 6、kek-ls_v03_12.lat で 20、24 セルの FODO で 24。セルの長さが全部同じかも確かめる)。誤差・補正は見ない。セルの中の鏡映対称は見ない。
  • 位置の選び方: select_locations(setup, ls, le, step, ds): 要素の境界 (要素の入口、1 始まり) を、範囲・k 要素おき・間隔 ds [m] 以上で選ぶ。同じ s の位置 (長さ 0 の要素の列) は 1 つだけ。
  • 並列の子プロセスは lower_priority() で優先度を下げる (Windows: BELOW_NORMAL)。

3. 周波数マップ (pysad/freqmap.py)

3.1 アルゴリズム

位置 loc の閉軌道に、x・y (px = py = 0、z = 0) と δ の格子点を足した粒子を nturn 周追跡し、位置 loc の (x, px, y, py) を周ごとに記録する。 前半 (nturn/2 周) と後半の各面の信号 z = x̂ − i p̂ (x̂ = x/√β、p̂ = (αx + βpx)/√β) に NAFF (Hann 窓、naff.tune_xp) をかけてチューン ν1・ν2 を求め、

D = log10 √( (νx2 − νx1)² + (νy2 − νy1)² )

を出す (チューンは端数 0〜1、差は −0.5〜0.5 に畳む)。粒子が nturn 周の前に失われた点は、lost_turn > 0 (落ちた周)、D = nan とし、図では黒い × で区別する。

  • 規格化 (α, β): 既定 (norm='data') は、その半分の追跡の標本の 2 次のモーメントから (x, px) の楕円の α・β を求める。δ ≠ 0 の軌道の光学関数は位置 loc の Twiss (δ = 0) と違い、 規格化がずれると NAFF の周波数に 1e-6 の程度の系統誤差が入るため (δ = 0.5% で D の下限が −5.8 → −9.6 に下がった)。norm='twiss' は位置 loc の Twiss の値を使う。
  • δ ≠ 0 の点: RFSW OFF は δ の閉軌道 (4 次元、Newton 法) の上に置く。RFSW ON は線形の分散 (η, η') の上に置く。x・y は δ の軌道からのずれ。
  • D の下限: 線形の運動 (振幅 1 μm) で、δ = 0 のとき D ≈ −11 (FODO)。NAFF の精度で決まる。実用上は D < −6 を規則的とみなす。

3.2 Python の API

import numpy as np
from pysad.freqmap import frequency_map, resonance_check
st = TrackSetup.from_source(src, 'RING', rad=False, rfsw=False, alost=0.1)[0]
r = frequency_map(st, 2, x=np.linspace(5e-4, 18e-3, 41), y=np.linspace(5e-4, 14e-3, 31), nturn=1024, workers=1)
r.save('fmap.table.txt'); r.plot('fmap.png', order=4)          # 表、図 (チューン平面 + 初期条件平面)
r.D, r.nux1, r.nuy1, r.nux2, r.nuy2, r.lost_turn, r.x, r.y, r.dp
resonance_check(*st.tunes_full(), order=4)                      # 作動点に近い共鳴線の表 (整数・半整数を必ず含む)
  • x, y, dp は数または配列。配列が 2 つなら 2 次元の格子。nturn は偶数にする (奇数なら 1 引く)。workers は子プロセスの数 (既定 1)。
  • 表 (save): 条件のコメント行のあと、列 x y dp nux1 nuy1 nux2 nuy2 D lost_turn。FMapResult.load_table(path) で読み直せる。
  • 図 (plot): 左 = チューン平面 (νx1, νy1) を D で色づけして order 次以下の共鳴線を重ねる (点の 2%〜98% を窓にする。外れた点は見えない)、右 = 初期条件の平面を D で色づけ、失われた点は黒い ×。 カラーバーは既定で D = −8 〜 −2。
  • 信頼性の判定と周回数の換算 (§3.6、§10): frequency_map(..., scaling=True, warn=True)。r.D_half (最初の nturn/2 周の D)・r.slope (周回数への依存の傾き)、r.D_norm (1024 周に換算した D = D + log2(nturn/1024))、 r.chaotic(thr=−5) (周回数に依らないカオス的な点の判定 = D_norm > thr)、r.warnings ([(コード, 文)])。信頼できない条件では FMapWarning が出る。表の末尾に列 D_half と、警告の行 # warning = が入る (古い表も読める)。 閉軌道が求まらない (誤差つきで線形に不安定) ときは RuntimeError。誤差つきの TrackSetup は fmapres.apply_alignment_errors(st, seed, quad_dxy=…, streams='type')、統計・フィードダウンの見積もりは pysad/fmapcheck.py。

3.3 SAD の台本から

FFS;
USE RING; CELL; CALC;
NORFSW; NORAD;
LOSSAMPL = 0.1;
f = FrequencyMap[2, 512, X->{0.0005, 0.018, 11}, Y->{0.0005, 0.014, 8}, Output->"fmap.txt", Plot->"fmap.png"];
Print[Diffusion /. f];

FrequencyMap[位置, nturn, X->…, Y->…, DP->…, Window->1, Workers->1, Output->"file", Plot->"file.png", Order->4]。X・Y・DP は数 (固定)、{min, max, n}、または値のリスト。 戻りは {X->…, Y->…, DP->…, NuX->…, NuY->…, NuX2->…, NuY2->…, Diffusion->…, LostTurn->…} (点ごとのリスト。失われた点の Diffusion は −99)。追跡の条件: 既定は RFSW OFF・RAD OFF・FLUC OFF (現在のフラグは使わない。FFS に入ると RFSW は ON なので、NORFSW; を書き忘れると D > −5 の割合が 0.03 から 0.57 になるため。現在のフラグを使うときは UseFlags->True)、LOSSAMPL・LOSSDZ は現在の値。警告は FrequencyMap: WARNING [コード] … で出力される (§3.6)。 例: example/14_nonlinear_dynamics/frequency_map/fn_FrequencyMap_MomentumAcceptance.sad。

3.4 共鳴線との一致

作動点の近くの共鳴線 (距離はチューン平面の距離 |m νx + n νy − p| / √(m² + n²)):

例 整数 νx = p 整数 νy = p 半整数 2νx = p 半整数 2νy = p 最も近い次数 4 以下の線
ASTRID2 (νx = 5.18、νy = 2.14) 0.180 0.140 0.180 0.140 νx − νy = 3 (差の共鳴、距離 0.028)
大きなリング A (νx = 47.58、νy = 17.62) 0.42 0.38 0.08 0.12 νx − νy = 30 (距離 0.028)。3 次は 3νy = 53 (0.047)・νx + 2νy = 83 (0.080)・3νx = 143 (0.087)

大きなリング A は KEK-LS (ESRF 型の HMBA。ESRF の Pantaleo Raimondi 氏と Simone Liuzzo 氏の協力で設計した)。整数・半整数の共鳴は、どちらの作動点でも距離 0.08 以上離れている (大きなリング A の 2νx = 95 の半整数が最も近く 0.08)。

作動点の整数・半整数の共鳴線は、どちらの例でも拡散の大きい領域 (格子の範囲のチューン) の外にある (ASTRID2: 格子のチューンは νx = 0.18〜0.25、νy = 0.14〜0.23 で、整数 0 と半整数 0.5 から遠い。 大きなリング A: 大部分が νx = 0.56〜0.79、νy = 0.60〜0.76 (数点は外れる) で、半整数の νx = 0.5 は格子の左端の外)。振幅が大きくなるとチューンが動いて、次の共鳴線に近づく:

  • ASTRID2 (位置 2、41 × 31、x = 0.5〜18 mm、y = 0.5〜14 mm、1024 周): 失われた点 0。D の範囲 −11.37〜−1.44。D > −4 の 16 点のうち 8 点は νx − νy = 3 (差の共鳴。次数 2、同じ線が 2νx − 2νy = 6 の次数 4)、6 点は 5νy = 11 (次数 5)、 1 点は 4νy = 9、1 点は 4νx = 21 (次数 4)。νx − νy = 3 の線の上では、x の信号に y のチューンの成分が現れる (νx = νy にロックされた点が 377 点。D の中央値は −7.8 の規則的な運動で、島に捕らえられている)。 次数 4 以下の共鳴線から距離 0.003 以内の点 (379 点) とそれより遠い点 (892 点) で、D > −5 の割合は 0.069 / 0.026 (2.7 倍)。
  • 大きなリング A (位置 3、41 × 31、x = 0.2〜6 mm、y = 0.2〜8 mm、1024 周): 失われた点 465 (x ≳ 4.2 mm)。D の範囲 −11.00〜−1.18。D > −4 の 60 点のうち 33 点は νx − νy = 30 (差の共鳴)、 12 点は νx + 2νy = 83、4 点は 3νy = 53、3 点は 3νx = 143、2 点は 2νx + νy = 113、2 点は νx − 4νy = −23 (最も近い次数 5 以下の線)。図 (fmap_kekls.png) では (νx, νy) = (2/3, 2/3) に集まる次数 3 の線 (3νx = 2、3νy = 2、νx + 2νy = 2 の端数の線) の上に D の高い点が並ぶ。次数 4 以下の共鳴線から 0.003 以内の点 (501 点) とそれより遠い点 (305 点) で、D > −5 の割合は 0.170 / 0.089 (1.9 倍)。

この統計 (近い/遠いの比 1.9〜2.7 倍) は図の印象より弱い。格子のチューンの広がり (νx で 0.2〜0.3) のなかに次数 4 以下の線が密に通っていて、点の約 6 割が「近い」側に入るため。結論は「D の大きい領域が、 ラティスの対称性が許す共鳴線 (差の共鳴、3 次、5 次) の上に載る」であり、個々の線が D を決める強さ (駆動項) の定量的な確認は docs/25_resonance_terms_adts.md (共鳴駆動項) の仕事。

図の読み方 (大きなリング A、位置 3、41 × 31 点、x = 0.2〜6 mm、y = 0.2〜8 mm、1024 周): 左はチューン平面 (前半の νx・νy の端数。点が 1 つの初期条件) で、色が D (濃い紫 = 規則的、赤 = 不規則)。線は次数 4 以下の共鳴線で、(2/3, 2/3) に集まる線の上に D の高い点が並ぶ。右は初期条件の (x, y) 面で、同じ色で D を示し、× は追跡中に失われた点 (x が約 4.2 mm より大きい側)。

3.5 RDT・ADTS から予想する共鳴の領域 (pysad/fmapres.py)

from pysad.fmapres import ResonancePredictor, coverage_stats, apply_alignment_errors
pr = ResonancePredictor.from_lattice(lat, loc, rows)      # lat = Lattice、rows = lat.twiss_table(delta=δ)。RDT と ADTS を計算する
m = pr.predict(r.x, r.y, nu=None)                          # {'any': 位相つきで島に捕らえられる点, 'envelope': 位相を問わない包絡, 'by_harmonic': {調和: ...}}

4. 局所運動量アクセプタンス (pysad/lma.py)

4.1 アルゴリズム

位置 loc (要素の入口) の閉軌道 (x, px, y, py, z, δ) に δ = ±Δ を足した粒子を、放射 (FLUC なし) と RF つきで nturn 周追跡し、失われないΔの限界を求める。位置ごと・符号ごとに:

  1. Δ = 0 と Δ = dpmax·k/ncoarse (k = 1..ncoarse、既定 12) を同時に追跡する。外向きに最初に失われた点を挟む区間 (lo: 残った最大の Δ、hi: 失われた最小の Δ) を作る。全部残れば Δ = dpmax ('sat')。
  2. 区間を nsub + 1 等分した nsub 点 (既定 3。nsub = 1 なら普通の二分法) を追跡し、最初に失われた点とその手前の残った点で区間を狭める。hi − lo ≤ tol (既定 1e-4) まで繰り返す。
  3. 結果は lo (確かに残った δ)。真の限界は (lo, hi) の中 (幅 ≤ tol)。
  • 外向きの最初の損失を限界とする。走査の点のあいだの狭い損失の窓は verify=n で探せる (§4.5)。その外側の残る島は見ない (保守的)。
  • 周回数: 既定はシンクロトロン振動 nsynch (既定 2) 周期分、ceil(nsynch/|νs|) (νs は Emittance[] のシンクロトロンチューン)。例: ASTRID2 は νs = 0.00152 で 1312 周、大きなリング A は νs = 0.00408 で 491 周。 周回数を直接 nturn で指定して 1 周期分より短いと警告する。RF なし (RFSW OFF) は既定 512 周。バケットで決まる限界の周回数への依存は §4.5。
  • RF バケット: bucket=True (既定、RFSW ON のとき) は、|z| がバケットの長さの半分 (π + 2|φs|)/k_rf (φs = trf0·k_rf = 同期位相。安定固定点の周り ψ = −π−2φs … π−2φs の外側の端) を超えた粒子も失われたとする (内部では LOSSDZ をこの値にする)。損失の理由は reason_plus・reason_minus に 'rf' (|z|)・'aper' (横の |x|,|y| または APERT)・'sat' (走査の上限まで残った) で記録する。 バケットの外へ出る粒子は、位相の滑りが始まるまでに時間がかかるので、バケット高さの付近の限界は周回数に依存し、nsynch を増やすとバケット高さに近づく。
  • アパーチャ: alost (既定は LOSSAMPL。±alost の正方形)・APERT 要素。判定の間隔は check_every (既定 1 = 要素ごと。0 は SAD の tapert のまま = gs と同じ判定。§2、§4.5)。
  • dpmax の既定: RF あり = バケット高さの 1.25 倍、RF なし = 0.05。
  • 並列: 位置ごとに独立なので子プロセス (workers、既定 2、優先度を下げる) に分ける。workers=1 は親プロセスで順に。コア数 − 1 を超えない。

4.4 Touschek への受け渡し

既存の Touschek (touschek.py: Emittance[] を INTRA ON で走らせると作る TouschekTable) は、一様な運動量受容 a (0.004〜0.242、0.002 刻み) の関数として、要素 l ごとの損失率 R_l(a) (table[3]、要素の数 × 120) を持つ。touschek_lifetime_local は、要素ごとの受容 δ+(l)・|δ−(l)| (要素の中央の s での線形補間。周期なら折り返す) から

1/τ = Σ_l ½ [ R_l(δ+_l) + R_l(|δ−_l|) ]

を求める (対称な受容 a の損失率は +Δ と −Δ を受け取る両方の粒子の損失を含むので、片側ずつ半分)。R_l(a) は dp の表の上の log-log 補間 (表の外は a⁻² で外挿し、外挿した要素の数を extrapolated で返す)。 一様な受容 δ+ = |δ−| = a (表の点) を渡すと、TouschekTable の損失率と一致する (試験)。既存の TouschekLifetime[INF, INF, nz] は一様な受容の寿命。 既存コードは変えていない (表の構造から受け取るだけ)。

Piwinski 型の式 (v2 の既定): K64 の表の損失率 (touckf) は、平坦ビームの関数に ptrans² = tr(P) を入れた近似で、結合が小さくないリングで寿命が ±20% ずれる (B162)。 TouschekLifetimeLMA[] と TouschekLifetime[INF, INF, nz] の v2 の既定は、2 粒子の Møller 散乱の積分 (touschek.touschek_piwinski、lma.touschek_lifetime_local_piwinski) を使う。 式: 静止系 (z* = γz、運動量 p* [mc]) で、同じ位置の 2 粒子の相対運動量 q は N(0, 2P) (P = 位置を固定したときの運動量の共分散。η'・結合・z-δ の相関を含む)。質量中心系の非相対論的な Møller 断面積 dσ/dΩ = (4 r0²/k⁴) (4/sin⁴θ − 3/sin²θ) で、散乱で δ が a+ を超えて増える (または −a− を超えて減る) 率は、ps* の広がりが x-y 面の広がりより十分小さいとき、P の x-y ブロックの固有値 λ1 ≥ λ2 (mc²)、α_i = 1/(4λ_i) として 1/τ_inst = r0² c N / (γ V* √(λ1 λ2)) Σ± J(2β a±)、 J(c) = ∫_c^∞ dk k⁻² W(k/c) e^{−k²α1} e^{−z} I0(z) (z = k²(α2 − α1)/2)、 W(κ) = 2π (κ² − 1 − ln κ)、 V* = (4π)^{3/2} √det(xx*) で、リングの寿命は 1/τ = Σ_slice (al/C) /τ_inst (スライスは K64 の tintrb の分割)。平坦ビームの極限 (λ2 → 0) は Bruck・Piwinski の関数 D(ε) (記憶に基づく式) に一致する。 Emittance[] (INTRA ON) は各スライスの静止系のビームを ffs.touschek['rest'] に記録する。Python: touschek_piwinski(ffs.touschek, a=0.006)、touschek_piwinski(ffs.touschek, ap=δ+ の配列, am=|δ−| の配列)。 台本: TouschekLifetime[INF, INF, nz, Formula->"K64"|"Piwinski"]、TouschekLifetimeLMA[Formula->...] (PYSAD_COMPAT=k64 と Formula->"K64" は K64 の表。nx か ny が有限の TouschekLifetime と EMIT の報告は K64 の表だけ)。 検証 (example/15_lma_touschek/touschek_elegant/touschek_formula*、docs/history/v23_T2.md): 3 次元の一般の積分と実験室系の対のモンテカルロ (厳密な相対論の運動学) に 0.3% 以内、elegant (全要素を 8 分割した標本化) と −1.3〜+0.1%、K64 の表は −14〜+21%。 elegant の touschekLifetime は要素の出口だけを標本化するので、粗いリングでは寿命が +1〜+5% 長く出る。

バンチ内の δ の分布 (B200): v2 の TouschekLifetimeLMA[]・TouschekLifetime[INF, INF, nz] (Piwinski 型) と lma.touschek_lifetime_local_piwinski は既定で BunchDelta・BunchQs つき (->False で切る)。k64 は δ_c = 0 の基準。δ_old = 0 の基準 (K64・Piwinski・elegant) はバンチ内の δ の分布を無視する近似なので、elegant との比較の値は「δ_c = 0 の基準との差」である (比較の値自体は touschek_piwinski を直接呼ぶので変わらない)。 台本 TouschekLifetimeLMA[BunchDelta->True]・lma.touschek_lifetime_local_piwinski(bunch_delta=True)・touschek_bunch.touschek_piwinski_bunch。散乱後の粒子の δ は δ_c + Δ (δ_c = 対の重心の δ ~ N(0, σδ²/2)、Δ は相対運動量の散乱だけで決まる) なので、受容を a ∓ δ_c にして平均する。受容が σδ の 8〜14 倍のとき損失率は ASTRID2 で +1.3〜+2.7%、KEK-LS で +1.8〜+4.3% 増える (寿命が短くなる)。実験室系の 2 粒子の対のモンテカルロ (厳密な相対論の運動学) で δ_c の効果が 2% 以内で再現される。相対運動量の縦成分 q_s の効果 (MC で通常の kick の判定より損失率が ASTRID2 で 2%・KEK-LS で 0.5% 小さい、つまり絶対値の判定との差がその分大きい) は BunchDelta->True だけでは入らない。BunchQs->True を足すと q_s の効果も入る (3 次元の積分 touschek_bunch.qs_ratio。絶対値 / kick の損失率の比が MC と ASTRID2 +4.81・+2.22% (MC +4.84・+2.22%)、KEK-LS +4.5・+1.7% (MC +4.5・+1.8%) で 0.3% 以内。12 スライスで求めて補間するので全周で 70 秒。ASTRID2 全周で a/σδ = 9・14・23 の寿命が δ_c = 0 に対し δ_c だけ −2.5・−1.2・−0.5%、q_s も入れて −4.1〜−4.3・−1.9・−0.7% (補間の不確かさ ±0.3%))。elegant・K64・Piwinski の式は kick の基準を δ_old = 0 とし、elegant の touschekLifetime には δ の分布を入れる機能が無い。a ≲ 3σδ では使えない (警告)。詳細・限界は pysad/touschek_bunch.py の冒頭と docs/history/v24_A.md §A3、検証は example/15_lma_touschek/touschek_elegant/touschek_bunch_mc.py。

LMA の信頼性の基準: (1) 解析・追跡・elegant の比較が条件つきで揃っている、(2) 既知の不一致に原因がある、(3) 既定で安全な値を返す、(4) 使えない条件で警告を出す。条件は ASTRID2 (0.58 GeV、45.7 m、δ_rf = 1.618%、νs = 0.00152) と 大きなリング A (kek-ls_v03_12.lat、3 GeV、603 m、δ_rf = 2.994%、νs = 0.00408) の ±10 mm (例の値)、RF・放射つき。詳細・数値は docs/history/v23_L2.md、例は example/15_lma_touschek/lma/lma_*。

図の読み方: 大きなリング A の標準セル 1 個 (s = 0〜30 m)、±10 mm のアパーチャ、RF・放射つきの局所運動量アクセプタンス (491 周)。横軸は s [m]、縦軸は δ+ (青) と δ− (橙) [%]。破線は RF バケットの限界と線形の見積りの小さい方 (±3%)。全位置で追跡の値が RF バケットの限界 (δ_rf = 2.994%) に一致し、アパーチャで決まる位置はない。

(a) check_every の既定は 1 (要素ごとの判定)。SAD の tapert (15 要素ごと = 0) は、アパーチャが限界の位置で δ を大きく見積もる (ASTRID2 の 25 位置で δ+ を最大 1.46 倍、δ− を 1.52 倍。位置 17: 1.048% 対 0.829%)。 要素ごとの判定は elegant (要素ごとの MAXAMP) と δ+ 3.5e-5、δ− 7.0e-5 以内。5 要素ごとは 1 との差 2.6e-5 以下。0 を明示するとアパーチャで決まる位置があれば警告する (gs の TrackParticles と同じ判定で比べるときに使う)。 時間は ASTRID2 (199 要素) で +7%、大きなリング A (3563 要素、全位置が RF バケットで 0・1・5 が同じ値) で ×2.4 (156 s → 383 s、11 位置)。時間を節約するときは 5。

(b) RF バケットの限界とアパーチャの限界 (lmabucket.py)。LMA の値 = min(RF バケットの限界、実効のアパーチャの限界):

  • RF バケットの限界は、解析式 rf_bucket_analytic (δ_rf² = (2A/(kCα))[2 cos φs − (π − 2φs) sin φs]、Emittance[] の bucket_height と 1e-6 で一致)、縦方向の 1 次元の写像 bucket_limits_1d (解析式の RF の力 + 追跡で測った非線形の経路長 Δz = −C (a1 δ + a2 δ²) と放射の δ 依存)、6 次元の追跡 bucket_limits_6d (アパーチャ無限大) の 3 通りで求まる。1 次元の写像と 6 次元の追跡は 1e-4 以内で一致 (ASTRID2: 1.643% と 1.635〜1.6375%、大きなリング A: 3.012% と 3.021%)。 理想化した解析式 (減衰なし・α 一定) との差 (ASTRID2 で δ+ が +1.5%、δ− が +0.4%) は、放射の減衰・α2 (a2/a1 = −0.76) と離散写像で説明がつき、LMA の δ+ が δ_rf を 1% 超える のは有限の周回数と、この効果。 出発点のベータトロン振幅 (δ = 0 の閉軌道から出発すると経路長が変わる) で位置により 1.4% 変わる (分散の大きい位置の 6 次元の限界 1.660%、δ の閉軌道から出発すると 1.6375%)。
  • アパーチャの限界は、RF・放射なしの 4 次元の追跡 (δ を固定)。シンクロトロン振動で半周期のうちに δ の符号が反転するので、実効の限界は min(δ+_aper, |δ−_aper|) になる (追跡で確認: δ0 = −0.86% の粒子が半周期後に δ = +0.86% で x = +10 mm に当たって失われた)。
  • limit_types(setup, result) が位置ごとに rf・aper・both を返す。ASTRID2 (±10 mm) の 25 位置 (δ+・δ−) はすべてアパーチャで決まる (LMA − min の最大: δ+ 2.6e-5、δ− 2.6e-4 (分散の大きい 12 位置の δ− で LMA が実効の限界を 3% 超える。原因は切り分けていない))。 大きなリング A (±10 mm) の 11 位置は RF バケット 7 点 + バケットとアパーチャ (3.03%) が 2 tol 以内 4 点で、LMA = min(rf, aper) が一致 (差 0)。 check_every = 0 の値 (δ+ = 1.635%、理由 'rf') は限界の種類を表さない。reason は最初に失われた粒子を落とした直接の原因 ('rf' は |z| の判定が先に効いたとき) で、限界の種類とは別。バケットの限界でも、バケットから出てすべった粒子はアパーチャに当たって 'aper' と記録されうる。

(c) 周回数。バケットで決まる限界は、シンクロトロン振動 1.5 周期以上で 1% 以内、2 周期 (既定) で二分の幅以内、3 周期で収束する。1 周期以下は限界が 40〜60% 大きく出る (ASTRID2 の位置 2 の 6 次元: 0.25 周期 2.52%、1.0 周期 1.98%、1.5 周期 1.64%、2.0 周期 1.634%、3.0 周期 1.634%)。 大きなリング A (11 位置) は周回数 491・1000・1500・2000 で δ± の変化が 5e-5 以内。elegant (1500 周) と同じ判定 (bucket=False、アパーチャまで追跡) で同じ 1500 周にすると、δ+ の差は +5.2e-5、δ− の差は 1.3e-5〜7.8e-5 (elegant の最終刻み 7.8e-5 以内)。 turncheck (既定 2): 限界の tol 手前の粒子を 2 倍の周回数で追跡し、失われれば T± (tol より大きく下がる) と警告する。

(d) 狭い損失の窓。verify=n: 限界の手前 [0, δ] を n 点で再追跡し、窓があれば限界をその手前に下げる (nwin_*・win_*・旗 W±・警告)。ASTRID2 (25 位置、n = 100、刻み 1.6e-4)・大きなリング A (11 位置、n = 150、刻み 2e-4) で窓は 0 個 (限界は verify なしと同じ)。既定は 0 (ASTRID2 で ×5.9、大きなリング A で ×2.8)。刻みより狭い窓・限界の外側に残る島は見ない。

(e) 1 セルから全周。RF 空洞は 1 か所なので周期性は崩れ、閉軌道の δ がセルごとに U0/E0 ずつ変わる (ASTRID2 1.06e-5、大きなリング A 9.9e-5)。全セル (ASTRID2 6、大きなリング A 20) の同じ位置の LMA の差は、ASTRID2 で 2.6e-5 (tol 1e-4)・ 4.9e-6 (tol 5e-6)、大きなリング A で 4.9e-5 (二分の刻み 1 つ) で、空洞からの距離への系統的な依存はない。周期性の許容 tol = 1e-4 の根拠は、二分の幅と U0/E0 (どちらも 1e-4 以下)。U0/E0 が大きいリング (24 セルの FODO で 5e-4) は測っていない。 periodicity_report(setup)・cell_locations(setup) が、要素の並びが周期的でない (誤差・挿入光源・セルの長さの違い)・閉軌道がセルで違う (許容 1e-7 + 2 (U0/E0) max(|η|, |η'|)) ときに警告して全周の位置を返す。台本の Cell->True も同じ警告。

(f) FLUC (量子励起)。TrackSetup.copy(fluc=True)・seed で走る。結果は 1 つの標本なので、複数の種の平均・分散を使う (警告が出る)。ASTRID2 (2 周期、4 位置、6 種): FLUC あり − なし = −1.8e-5〜+1.3e-5 (平均)、種の分散 1.4e-5〜3.2e-5。 elegant の ISR あり (6 種) は ISR なしと 9e-5 以内。13120 周 (20 周期、σδ の成長は定常の 45%) でも 5 種の平均は FLUC なしと 2.1e-5 以内。 振幅 (0.8〜1.6%) が σδ (4.3e-4) の 20〜40 倍なので、量子励起による振幅の変化 ≈ σδ²/δ が 2e-6〜2e-5 と二分の幅より小さいため。大きなリング A (σδ = 6.9e-4、位置 16・89、6 種、tol 1e-4): pysad の FLUC あり (491 周と 1500 周で同じ) は δ+ = 3.027%・3.029% (σ 1.1〜1.3e-4)、δ− = −3.017%・−3.005% (σ 4e-5〜5e-5)、FLUC なしとの差 +0.8e-5〜+8.1e-5 (σ 以内)。elegant の ISR あり 1500 周 (6 種) は δ+ = 3.008%・3.010% (σ 1.0e-4・1.2e-4)、δ− = −3.022%・−3.009% (σ 5.9e-5・7.7e-5)、pysad との差は δ+ で +1.9e-4 (σ の 1.5〜2 倍)、δ− で +0.5e-4〜+0.4e-4 (ISR なしの差 +5.7e-5〜+1.05e-4 に近い)。elegant の ISR あり 491 周は位置 89 で δ± = +3.19%・−3.25% (σ 7e-4・1.4e-3) と収束しない (バケットから出た粒子がアパーチャに届かないため。ISR なしの場合と同じ理由。pysad はバケットの判定があるので 491 周でよい)。

(g) 誤差つき・挿入光源。誤差 (fmapres.apply_alignment_errors、四極 50 µm・0.2 mrad、6 極 50 µm、偏向 50 µm・0.1 mrad の rms) つきの ASTRID2 (3 種) は全周の位置で走る (25 位置、1 つ約 5.5 分)。find_periodicity が nper = 1 を返し、 periodicity_report・cell_locations・Cell->True が警告する。誤差で閉軌道が歪む (cod1 の x・y 0.3〜0.9 mm) ため、δ± は誤差なしより小さくなる (δ+ の平均で −0.6〜−1.5e-3、閉軌道の歪みの 0.5 mm / アパーチャ 10 mm × 0.8% ≈ 4e-4 と同じ桁)。 1 セルの結果を誤差つきの全周に使うと、同じ位置の別のセルとの差が 0.8〜2.6e-4 になる。MPW 版 ASTRID2 (ASTRID2_v01_02_id.sad の RINGMPW) は周期性が崩れる (nper = 1) ので警告し、全周 32 位置で走る (δ+ = 0.836〜1.590%、δ− = −0.856〜−1.572%、δ_rf = 1.571%。LMA = min(rf, aper) が 2.8e-4 以内)。 結合の強いリング・補正つき・大きなリング A の誤差つきは未確認。

(h) 警告 (LMAResult.warnings・cond['warnings']・warnings.warn・表の # WARNING:): LOSSAMPL ≥ 0.1 m (アパーチャ未設定)、check_every = 0 でアパーチャで決まる位置がある、FLUC ON、RFSW OFF、周回数がシンクロトロン振動 1 周期未満、 走査の上限 (dpmax) まで残った限界、δ = 0 で失われた、周回数の依存 (turncheck)、verify で窓、閉軌道の残差 > 1e-9。位置ごとの旗は LMAResult.flags(i) と表の最後の列 (W±・T±・S±・0±)。

7. 未確認・限界

  • 周波数マップは、誤差なしのほかに誤差つき (全周の追跡、§9.4・§10.1)・MPW つき (§9.5・§10.2)・k64 (§9.6)・RFSW ON・RAD ON・FLUC ON (§10.3) でも走ることを確かめた (複数の種・強さ・種類を統計、KEK-LS も)。LMA は、誤差つき ASTRID2 (3 種) と MPW 版 ASTRID2 でも全周で走ることを確かめた (§4.5 (g))。補正つき・KEK-LS の誤差つきは実走した (§11)。結合の強いリングの補正つきは未確認。 誤差つき・結合のあるリングの D は、誤差なしと別の量 (D > −5 が 7〜12 倍) で、結合が強いと νx・νy の対応が崩れる (警告 coupling)。FLUC つきは D が乱数の種に依る。 FLUC ON の LMA は 1 つの標本 (複数の種の平均・分散で使う。警告)。2 周期では効果は二分の幅以下 (§4.5 (f))。
  • 周波数マップの D は、粒子が nturn の途中で失われた点では nan。nturn が短いと D の下限 (§3.1) が上がる。共鳴線の上の粒子 (島の中に捕らえられた粒子) は、νx = νy のように 2 面のチューンが同じ値になり、D は小さい (規則的な運動) ことがある (ASTRID2 の例の νx − νy = 3 の線)。
  • LMA の損失の判定は、既定 (check_every = 1) では要素ごと。SAD の tapert のまま (check_every = 0) だと、アパーチャが限界のとき δ の限界を最大 1.5 倍大きく見積もる (§2、§4.5 (a)。警告が出る)。 check_every ≥ 1 は SAD の TrackParticles と判定が違う (gs と判定を比べるときは 0 にする)。check_every = 1 と 5 の差は小さい (ASTRID2 で 2.6e-5 以下)。
  • Touschek 寿命の式 (elegant との比較): K64 の表の式 (touckf) は、同じビーム・同じ一様な δ で独立な式 (Piwinski 型) と −14〜+21% 違う (結合 1% で +0〜+6%、丸いビームで ±20%。原因は x-y 面の運動量の分布を平坦ビームの 1 次元の関数と tr(P) で近似していること。B162)。elegant の式は独立な式と −1.3〜+0.1% (elegant は要素の出口だけの標本化で、粗いリングで +1〜+5% 長く出る)。v2 の既定は Piwinski 型。限界: 受容 a が σδ の 10 倍以下では、バンチ内の δ の分布 (a − δ_old) を入れていない (4 つの式とも共通) ことが 5〜20% 効きうる (概算。docs/history/v23_T2.md §7)。K1≠0 の BEND の K1 は B' 一様ではなく (1 + hx)∂b/∂x 一様の定義 (B160・docs/29 A59。誤りではない) で、elegant の CSBEND には K2 = −hK1 を足して合わせた。ASTRID2 の LMA には影響が無かった。
  • バケット高さの付近の限界は、周回数に依存する。シンクロトロン振動 1.5 周期以上で 1% 以内、2 周期 (既定) で二分の幅以内、1 周期以下は 40〜60% 大きく出る (§4.5 (c)。turncheck と警告)。RF バケットの高さ δ_rf は Emittance[] の値 (解析式と 1e-6 で一致)。 限界は δ_rf より 1〜2% 大きい (放射の減衰・α2・ベータトロン振幅。1 次元の写像と 6 次元の追跡が 1e-4 以内で一致、§4.5 (b))。RF の高調波・バケットの外の運動量の分布は見ていない。
  • 1 セルの結果を全周に延ばす (touschek_lifetime_local の period) のは、RF の位置の違い (空洞が 1 か所) と閉軌道の δ の違いを無視する。別のセルの同じ位置との差は、ASTRID2 (U0/E0 = 1e-5) で 5e-6〜2.6e-5、大きなリング A (U0/E0 = 1e-4) で 4.9e-5 以下 (§4.5 (e))。U0/E0 が tol (1e-4) より大きいリングは未確認。周期でない (誤差・挿入光源) ときは警告する。

  • 損失の判定の位置は要素の境界。要素の中の損失は見ない。
  • 互換モードは v2 で確かめた。k64 の周波数マップは確かめた (ASTRID2・KEK-LS で v2 との差は小さい。チューンの差の中央値 9e-5・3e-5、§9.6)。LMA の k64 は確かめた (ASTRID2 の 8 位置で v2 と δ± が 6e-8 以内。check_every = 1。k64 の最初の tapert の扱い (B33) の違いは check_every = 0 のときだけで、見ていない)。
  • 周波数マップの D の絶対値の閾値 (D > −5 など) は周回数・窓で動く (周回数 2 倍で約 −1、§9.2)。1024 周への換算 D_norm がある (§3.6、§10.5。512〜4096 周)。RDT・ADTS の予想は 1 次の共鳴だけで、ASTRID2 の D の大きい領域 (νx − νy = 3 など 2 次の共鳴) は予想できない (§9.1)。

10.4 K1 の設定

ASTRID2 の偏向磁石は K1 ≠ 0 だが端の角が 0 なので、set_bend_k1_edge('face') は効かず D が同じ。set_bend_k1_def('lin') (B' 一様) は D の相関 0.47、点ごとのチューンの差の中央値 4.8e-3 (作動点・最小振幅は同じ)。 端の角を足した変形 (E1 = E2 = 0.02): face が D の相関 0.924、lin が 0.634、k64 が 0.983。K1 ≠ 0 の偏向磁石のあるリングの周波数マップは K1 の定義を記録して使う。

10.5 D の閾値・周回数

規則的な点の D は周回数 2 倍で −1.00 ± 0.05 (ASTRID2・KEK-LS、256〜4096 周)。1024 周への換算 D_norm = D + log2(nturn/1024) で判定すると、D > −5 の割合の周回数による変化が 7 倍 (固定) から 2 倍に減る (ASTRID2: 512 → 4096 周で固定 0.065 → 0.009、換算 0.021 → 0.045。KEK-LS: 固定 0.269 → 0.095、換算 0.127 → 0.181)。512〜4096 周で使う (256 周は不可)。点ごとの傾きは診断用。窓なしは不可、Hann p = 1〜3 は同等、格子は 88 点以上で分布が同じ。

10.6 K64 (gs) との比較 (誤差つき)

ASTRID2 (all ×1、種 1、6 点、512 周) で、pysad の誤差の値を gs の台本に書いて比べた (gs の乱数列は pysad に渡せない)。規則的な 4 点は座標が 1.6e-15〜1.4e-12 m、D が 4 桁一致し、カオス的な 2 点は初期値の 1e-13 m の摂動の増幅と同じ大きさの差になる (PYSAD_COMPAT=k64 の追跡。v2 の既定 (四極 4 次) では座標が 1.9e-5〜3.9e-2 m 食い違う)。詳細は history/26_frequency_map_lma_validation.md。
