31. オリジナル SAD (K64) に対する pysad の未対応・未確認の一覧

この文書で分かること: オリジナルの SAD (K64) に対して pysad が「まだ対応していないもの」「対応したが gs で確かめていないもの」「gs が動かず比べられないもの」を、機能の分類ごとに 1 か所にまとめた一覧。pysad で計算する前に、自分の使う機能が使えるか・どこまで確かめられているかを調べるときに使う。 前提: 互換モード (v2 = 既定、k64 = PYSAD_COMPAT=k64) の意味は docs/28 を見る。表の「モード」の欄は下に説明がある。 読む順: §1〜§5 の表 (未翻訳 → モード差 → 一部未対応 → 未確認 → 既知の差 → gs 側の問題) → §6 (対応していて載せない項目) → §7 優先度 → §9 (機能の分類ごとの詳細。放射・スピン、共鳴・ADTS、LMA、6 極の最適化、DXF)。ファイル別の翻訳状況は docs/33。

最終更新: 2026-11-23

この文書は、オリジナルの SAD (K64 版、src/*.f・Packages/*.n・SADHelp) に対して、pysad がまだ対応していないものと対応したが gs で確かめていないものを、機能の分類ごとに 1 か所にまとめたものです。

  • 互換モード: pysad は 2 つのモードを持つ。k64 は K64 (gs) と同じ動作 (gs との数値比較はこのモード)、v2 (既定) は K64 のバグを修正し機能を加えてある動作。環境変数 PYSAD_COMPAT=k64|v2 か pysad.compat.set_mode() で切り替える (28_v2_vs_k64.md)。各項目の「モード」の欄が k64 ならそのモードだけの話、v2 なら v2 モードだけの話、両 ならモードによらない。
  • v2 の値の根拠は、解析式・独立な数値計算 (ローレンツ力・Thomas-BMT の数値積分など)・保存則・別のコードとの一致で、gs ではない。v2 で実装・修正している機能の多くは、gs が動かない・K64 が誤っているので gs と比較できない。 「未確認」にはその旨を書いた。使った条件は電子、0.2〜4.2 GeV のリングと輸送路 (空間電荷は 5〜50 MeV、RADLIGHT は 10.2 MeV)、ソレノイド bz = 0.3〜3 1/m (一部 20 1/m まで) で、実機の強い結合・挿入光源のずれのあるリングでは確かめていない。大きなリング A (3 GeV、周長 603 m、pysad/tests/kek-ls_v03_12.lat)・PF リング・ASTRID2 (MPW 入りを含む) では多くの項目を gs と比べた。SP8 (大きなリング B、8 GeV、周長 1436 m) は数値だけ。
  • 出所: 旧 16 §9・旧 17 §6〜§8・旧 19 §9〜§11・旧 20 §5〜§6 の未対応の項目 (1 項目ずつ照合してこの文書に集約した。33_fortran_status.md はファイル別の翻訳状況)、23_physics_guide.md §22 (解析式の未導出・未検証)、history/work_unimpl.md、30_sad_bug_report.md、v2 の作業の記録 (history/v2_changes_*.md・history/v2next_*.md・history/v24_*.md)、28_v2_vs_k64.md、example/ の各例の「gs と pysad の比較」・「未確認・限界」節、06_sadscript_library.md ほか各解説文書。この文書の整理前の全文 (版ごとの節つき) は history/46_unimplemented_and_unverified_history.md、§6 の経過の語りは history/31_unimplemented_and_unverified_history.md。
  • 基準は gs (SAD K64) の実動作です。gs が落ちる・誤った値を返すものは「gs 側の問題」(§5) に分けています。K64 のバグの番号は 30_sad_bug_report.md の B 番号です。
  • 例 の欄は、その項目を示す example/ の例です (パスは example/ からの相対)。v2 の機能の例は example/ の機能別フォルダ (01_lattice_elements〜13_packages、14_nonlinear_dynamics・15_lma_touschek・16_spin_polarization)。
