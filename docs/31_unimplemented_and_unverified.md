# 31. オリジナル SAD (K64) に対する pysad の未対応・未確認の一覧

**この文書で分かること**: オリジナルの SAD (K64) に対して pysad が「まだ対応していないもの」「対応したが gs で確かめていないもの」「gs が動かず比べられないもの」を、機能の分類ごとに 1 か所にまとめた一覧。pysad で計算する前に、自分の使う機能が使えるか・どこまで確かめられているかを調べるときに使う。
**前提**: 互換モード (v2 = 既定、k64 = `PYSAD_COMPAT=k64`) の意味は docs/28 を見る。表の「モード」の欄は下に説明がある。
**読む順**: §1〜§5 の表 (未翻訳 → モード差 → 一部未対応 → 未確認 → 既知の差 → gs 側の問題) → §6 (対応していて載せない項目) → §7 優先度 → §9 (機能の分類ごとの詳細。放射・スピン、共鳴・ADTS、LMA、6 極の最適化、DXF)。ファイル別の翻訳状況は docs/33。

最終更新: 2026-11-23

この文書は、オリジナルの SAD (K64 版、`src/*.f`・`Packages/*.n`・SADHelp) に対して、pysad が**まだ対応していないもの**と**対応したが gs で確かめていないもの**を、機能の分類ごとに 1 か所にまとめたものです。

- **互換モード**: pysad は 2 つのモードを持つ。`k64` は K64 (gs) と同じ動作 (gs との数値比較はこのモード)、`v2` (既定) は K64 のバグを修正し機能を加えてある動作。環境変数 `PYSAD_COMPAT=k64|v2` か `pysad.compat.set_mode()` で切り替える ([28_v2_vs_k64.md](28_v2_vs_k64.md))。**各項目の「モード」の欄が `k64` ならそのモードだけの話、`v2` なら v2 モードだけの話、`両` ならモードによらない。**
- v2 の値の根拠は、解析式・独立な数値計算 (ローレンツ力・Thomas-BMT の数値積分など)・保存則・別のコードとの一致で、gs ではない。**v2 で実装・修正している機能の多くは、gs が動かない・K64 が誤っているので gs と比較できない。** 「未確認」にはその旨を書いた。使った条件は電子、0.2〜4.2 GeV のリングと輸送路 (空間電荷は 5〜50 MeV、RADLIGHT は 10.2 MeV)、ソレノイド bz = 0.3〜3 1/m (一部 20 1/m まで) で、**実機の強い結合・挿入光源のずれのあるリングでは確かめていない**。大きなリング A (3 GeV、周長 603 m、[`pysad/tests/kek-ls_v03_12.lat`](../pysad/tests/kek-ls_v03_12.lat))・PF リング・ASTRID2 (MPW 入りを含む) では多くの項目を gs と比べた。SP8 (大きなリング B、8 GeV、周長 1436 m) は数値だけ。
- 出所: 旧 16 §9・旧 17 §6〜§8・旧 19 §9〜§11・旧 20 §5〜§6 の未対応の項目 (1 項目ずつ照合してこの文書に集約した。[33_fortran_status.md](33_fortran_status.md) はファイル別の翻訳状況)、[23_physics_guide.md](23_physics_guide.md) §22 (解析式の未導出・未検証)、[history/work_unimpl.md](history/work_unimpl.md)、[30_sad_bug_report.md](30_sad_bug_report.md)、v2 の作業の記録 (`history/v2_changes_*.md`・`history/v2next_*.md`・`history/v24_*.md`)、[28_v2_vs_k64.md](28_v2_vs_k64.md)、`example/` の各例の「gs と pysad の比較」・「未確認・限界」節、[06_sadscript_library.md](06_sadscript_library.md) ほか各解説文書。この文書の整理前の全文 (版ごとの節つき) は [history/46_unimplemented_and_unverified_history.md](history/46_unimplemented_and_unverified_history.md)、§6 の経過の語りは [history/31_unimplemented_and_unverified_history.md](history/31_unimplemented_and_unverified_history.md)。
- 基準は gs (SAD K64) の実動作です。gs が落ちる・誤った値を返すものは「gs 側の問題」(§5) に分けています。K64 のバグの番号は [30_sad_bug_report.md](30_sad_bug_report.md) の B 番号です。
- `例` の欄は、その項目を示す `example/` の例です (パスは `example/` からの相対)。v2 の機能の例は [`example/`](../example/README.md) の機能別フォルダ (`01_lattice_elements`〜`13_packages`、`14_nonlinear_dynamics`・`15_lma_touschek`・`16_spin_polarization`)。

凡例: 「未翻訳」は pysad に物理が入っていない。「一部未対応」は一部の入力・経路だけ未対応。「未確認」はコードはあるが gs と数値で比べていない。「モード」は上のとおり。

### 9.1 放射・スピン・偏向磁石・磁石の端

- **B239 (限界、直さない): 低い γ の短い磁石・硬い端の磁石の放射**。K64・v2 (B167) は一様磁場の長い円軌道 (n ≫ 1/θ) のスペクトルを使う。3 GeV/c の陽子 (γ = 3.35) で 15° の扇形 1 台は θγ = 0.87、1.5 GeV/c で 0.49 で、1 台の放射は放射の円錐より短い磁石の放射 (端の放射・磁石間の干渉)。古典の全エネルギー損失 U0 と減衰率は Larmor の積分で端に依らず厳密 (B167 で 1e-6、独立な写像と 4e-5 の確認)。2 次モーメント (量子励起 = εx・σδ・Touschek) は硬い端で対数発散し、有限の立ち上がり幅 (F1) の模型に依る。一意な独立な基準が取れないので閉じた。**誤差の範囲 (目安。計算で確かめていない見積り)**: 影響を受けるのは量子励起だけ (U0・減衰は厳密)。補正の大きさは短い磁石の放射と長い軌道の放射の違いで、θγ に依る: θγ = 0.5〜1 (1.5〜3 GeV/c の陽子、15° の磁石) で数 10% (10〜50%) のオーダー、θγ ≈ 3 で数 % 以下、θγ ≳ 10 で 1% 以下と見込む。独立な写像との一致 (εx 4e-5・σδ 8e-6) は長い円軌道のスペクトルを前提にした輸送 (減衰・分散・RF の位置) の確認で、この補正を含まない。**θγ ≲ 1 の陽子・イオンの εx・σδ・Touschek 寿命は、この目安の範囲で不確か**。電子 (θγ ≫ 1: 3 GeV で 3000 以上) は影響なし。**判断: 実装しない** (理由と、スケーリングからの目安の見直しは9.1 の表の B239 の行)。
- B238 の残り (**原因を特定、直していない**): SOL 内の加速のスピンは積分と 8e-6 (γ の 15% の加速。30% で 1.4e-5)。原因: 加速で運動量の向きが変わる分を K64 は磁場による曲げと同じに扱い、スピンを (1+aγ)θ 回すが、E 場の BMT では (aγ + γ/(γ+1))θ で、差は θ/(γ+1)。基準の E×β の係数をその比倍にすると残りが 57〜78% 減る (7.8e-6 → 1.7e-6、1.4e-5 → 5.9e-6)。端 (tcavfrin) の模型の寄与ではない (DISFRIN=1・E_r なしで 6e-6 のまま)。γ ≳ 1000 の電子では無視できる (θ/(γ+1) ≲ 1e-3 θ)。直すには RF の向きの変化を磁場の曲げから分ける必要がある。RF つきの MULT (SOL の外) の POL + TRPT は SADError のまま。**判断: 直さない** (理由は9.1 の表の B238 の行)。
