09. Emittance[] / EMIT — SAD の temit と pysad の emit6d.py

この文書で分かること: リングの平衡エミッタンス、エネルギー広がり、バンチ長、放射減衰、RF の量 (同期位相・バケット高さ・シンクロトロンチューン) を、放射の量子励起と減衰から求める Emittance[] (台本の関数) と EMIT (FFS のコマンド) の使い方と結果の読み方。計算の流れ、要素ごとの扱い、v2 モードの動作、使える範囲と限界。 前提: CELL の CALC (docs/07_calc_optics.md)。放射積分 (RADINT) は docs/23_physics_guide.md を参照。 読む順: §0 (動かして数字を読む) → §1 (戻り値の規則) → §5 (注意点) → §4b の範囲・限界の表。§2〜§4 (計算の流れと pysad の構造) は開発者向け。

照合先: Packages/emit.n, src/tfemit.f, temit.f, tcod.f, tturne.f, tquade.f, tbende.f, tthine.f, tcave.f, tmulte.f, photons.f (tradke), tffs.f (module temw), tnorm.f, tdrife.f と pysad/emit6d.py, pysad/ffscmd.py (print_emit)。

0. 使い方と結果の読み方

用語: 平衡エミッタンスは、放射の量子励起 (エミッタンスを増やす) と放射減衰 (減らす) がつり合う値。RFSW は RF 空洞の電圧を計算に入れるスイッチ、RADCOD は放射による閉軌道のエネルギー損失を入れるスイッチ。

  1. 次のスクリプトを ffs_emit.sad として保存する (docs/07_calc_optics.md の §0 と同じ 24 セルの FODO リング、3 GeV、周長 105.6 m。RF 空洞の電圧だけ 4 MV に上げた)。
MOMENTUM = 3GEV;
DRIFT D1 = (L=1.0) D2 = (L=0.5) DS = (L=0.1);
QUAD  QF = (L=0.3 K1=0.7) QD = (L=0.3 K1=-0.6);
SEXT  SF = (L=0.2 K2=0) SD = (L=0.2 K2=0);
BEND  B  = (L=1.2 ANGLE=0.2617993877991494 E1=0.1308996938995747 E2=0.1308996938995747);
MARK  ORIGIN = ();
CAVI RF = (L=0 VOLT=4.0E6 FREQ=5.0E8 PHI=0);
LINE CELL = (SF DS QF D2 B D2 QD DS SD D1);
LINE RING = (ORIGIN RF 24*CELL);
FFS;
$FORM = "10.6";
USE RING;
CELL;

2. 計算の流れ (temit.f)

  1. tcod (CELL かつ calcod): 6D 閉軌道。RFSW なら先に RFSW を切った 4D 解 (δ 固定) を求め、cod(5)=asinz((u0·pgev−vcacc)/vceff)/wrfeff−trf0 を初期値に 6D Newton。各反復は tturne(update=.true.) で、末尾が trf0 = asin(U0/Vc)/wrfeff (trans(5,6)<0 なら π−asin) を決め直す。RADCOD では z のずれを trf0 へ移す (trf0 += dz/v0)。重み codw0=(1e-6,1e-7,1e-7,1e-8,1e-5,1e-6)、収束 1e-4。 RFSW OFF でも RADCOD ON なら放射込みの閉軌道を使う (tcod の rfsw=F 枝、出口 δ=−U0/P0、z のずれは trf0 へ。docs/29 A32)。
  2. irad=12、tinitr12、tsetr0 の後 tturne で一周。trans(6,12) の 1:6 列 = シンプレクティック部 T、7:12 列 = 放射減衰 D (tmuld6: D += tr1·(T+D))。beam(1:21) = 量子励起の 2 次モーメント。
  3. tecalc で固有値分解と平衡解。4. lfno>0 なら temitprint (FFS の EMIT)。

2-2. 放射 tradke (photons.f)

基準点 (codr0, transr) から現在点までの運動量ベクトルの角度 θ を外積 xpa から求め

anp = anrad·h1·θ,  uc = cuc·h1³/p0/al1·θ,  dg = −cave·anp·uc (cave=8/(15√3)),  u0 −= dg
dee = anp·uc²·cuu (cuu=11/27)      ← beam の (px,px),(py,py),(δ,·) に加算

crad = r_e(c/amass)²/p0/1.5, cuc = 1.5 r_e/rcratio, anrad = 5/(2√3)·rcratio (tphyzp)。xpa=0 (軸上の四極) なら何も更新しない。RADCOD ON のときだけ cod を更新し tesetdv を取り直す。

2-3. tecalc

  • RFSW OFF なら rx(6,1:5)=0, rx(6,6)=1。
  • teigenc (= teigen.f: tbal の vx, thess の高速 Givens, tqr の二重シフト QR; pysad は pysad/teigen.py に直訳) → tnorm: 各モードのシンプレクティック積 s を 1 に正規化 (s<0 なら固有値を共役に)、z 成分最大のモードを 5,6 列、x 成分の大きい方を 1,2 列に並べ替え、r(i,i+1)=0, r(i,i)>0 に回転。r=tsymp(r), ri=tinv6(r)。
  • synchm = rfsw ∧ Im(log λz)≠0。真: alphap = −Im(cd6)|Im(cd6)|/(c·2π/ω0)/(dvcacc/pgev), ωz = |Im cd6|ω0/2π。偽: alphap = −rx(5,6)/2π/c/p0·h0·ω0, ωz = sqrt|αp·2π·heff·Vc/pgev·cos φrf|·ω0/2π。
  • φrf = asin(U0/Vc), bh = sqrt|Vc/(π|αp| heff pgev)·(2cos φrf − (π−2φrf)U0/Vc)|。
  • rd = ri·D·r, 2×2 ブロックから cd = ((rd_ii+rd_jj)/2 + i(rd_ij−rd_ji)/2)/λ: Re = 減衰率、Im = チューンシフト、J = 4·Re cd/ΣRe cd。
  • 平衡: beam を ri で正規座標へ (synchm でなければ z 行・列を 0)、rdb (rd + モード回転) から 21×21 の btr を組み、(Σ11±Σ22)/√2 の基底変換とスケーリングの後 tsolva(btr, beam, emitn, 1e-8) (SVD) で Σ = MΣMᵀ+B を解く。
  • εx = sign(sqrt|e11e22−e12²|, e22·charge)、emitp = r·emitn·rᵀ、σE = sqrt|emitp(6,6)|。synchm なら σz = sqrt|emitp(5,5)|、εz も行列式。そうでなければ σz = |αp| σE c p0/h0/ωz, εz = σz σE。
  • rsetgl1 で EMITX/EMITY/EMITZ/SIGE/SIGZ に格納。
  • 不安定な光学 (docs/history/work_emit_unstable.md A): 固有値が実数 (λ, 1/λ) でも teigen/tnorm はそのまま通り、stab=(|Re cd(4:6)|<1e-6) ∧ fndcod は戻り値 (Emittance[] の Stable) にしか効かない (INTRA ON のとき Skip intrabeam because of unstable.)。Emittance は不安定でも計算・格納され、temitprint は一周行列の偏差 Σ|rx·tinv6(rx)−1|>1e-8 を *** Deviation from symplectic matrix = で出す。 実固有値の対の並び (λ と 1/λ のどちらが先か) は teigen の返す順で、始点が鏡映対称 (a=d) のときは丸め雑音の符号で決まる (pysad _order_real_pairs は雑音のとき増大側が先)。

2-4. 報告 (temitprint / FFS.print_emit)

SAD の EMIT (temitprint) の行: Closed orbit (Entrance/Exit)、Extended Twiss、P0, f0, U0 [MV], Vc [MV], dz [mm], alpha, dl, h, dV/P0, fs、Imag./Real tune、Damping (一周・時間・チューンシフト・分配数)、Emittance X/Y/Z, Energy spread, Bunch Length [mm], Beam tilt, Beam size。 pysad FFS.print_emit はこの全行を同じ書式で出す (docs/history/work_emit_report.md):

  • Closed orbit (Entrance と Exit。値は ' '//autofg(v,'9.6'))、Extended Twiss (EPX の欄は SAD の癖で EY の値、docs/29 A30)。
  • P0/f0 (f0 は c·β/C、β=p/h)、U0/Vc、dz/alpha、Orbit dilation dl = -FSHIFT·周長 (RFSW ON のとき dvfs=FSHIFT が全要素の dv に入る: _Phys.dvfs)、h = wrfeff c/ω0、Bucket height、fs = omegaz/2π。
  • Imag.tune = Re log λ/2π、Real tune、Damping (一周あたり Re cd、Damping time = -2π/ω0/Re cd、Tune shift = Im cd/2π、分配数 J = Re cd · 4/Σ Re cd)。
  • Emittance X/Y/Z、Energy spread、Bunch Length、Beam tilt、Beam size xi/eta。Beam tilt = atan2(−2σxy, σxx−σyy)/2、xi/eta = 主軸方向の rms (temit.f:1126-1141、emit6d.beam_tilt_sizes)。
  • Nominal spin tune = h0·GSPIN、Polarization time (POL OFF は 0)。POL ON のスピンの行・表は 4b 節 (POL OFF の形は SAD と同じ)。

書式: 実数は fmt_real (autofg 直訳)。vout は autofg(x,'10.7')(1:10) なので 7 桁目が切り捨てに見える (dz=20.61866962 mm → 20.618669、f0=497069.3289 → 497069.32) — fmt_real(x,'10.7')。 Damping 系は gfortran の 1p g14.6 (sadscript.fmt_g(v,14,6))、tune は 3(f10.7,10x) (行末の X 編集は出力されない)。NaN の報告 (閉軌道なし) は幅に右詰めの NaN。

3. 内部の座標・変数

  • 座標 (x, px/p0, y, py/p0, z, δ)。tesetdv(δ): dvemit = −(p1+p0)/h1/(p0h1+p1h0)·δ + dvfs、dvfs = FSHIFT (RFSW のときのみ)。ドリフトは tgetdv の同じ式で z −= L·dv。
  • trf0 = 同期位置 [m]、空洞位相 phis = trf0·w。PHICAV, DTSYNCH, EFFVC, EFFRFFREQ に書き出される。
  • temw の r (正規→物理), ri (物理→正規) を tecalc が更新。

解析ヤコビアンの対象と理由

  • 対象: ドリフト、薄い多極 (SEXT〜DODECA、ずれ・ロールは tchge の行列)、四極 (ずれ・ロール付き tsolrote、ハードエッジ tqfrie、線形フリンジ FRINGE=1,2,3 の tqlfre、K1<0 の −π/2 回転、tsolque 本体: _jac_quad_full/_jac_tqlfre)、BEND (K1=0 の lattice._tbendebody0_mat と K1≠0 の _tbendecorr/_tbendebody、エッジ)。lattice の CALC 経路と同じ関数を使う (docs/07 §2)。
  • まだ数値微分: MULT、ANGLE=0 の BEND、DROTATE≠0 の BEND、空洞 (history/work_emit_report.md §5)。F1 付き BEND の本体は emit6d._tbende_core (tblfre・tbendal・断片のループ) として実装している (微分の方式は未確認)。
  • 理由 1 (桁落ち): K1=0 の BEND 本体の数値ヤコビアンは rhob≈20 倍の桁落ちで相対 1e-8〜1e-7 の雑音が出る (刻みを小さくすると悪化、1e-5 で 2e-10)。この雑音は量子励起の分割数 int() を跨ぐ形で効く。解析式にすると雑音が消え、RADCOD ON も SAD と 2e-11 以内になる。
  • 理由 2 (分岐境界): 数値微分の刻み 1e-6 は K1=0 BEND の式の分岐境界に当たり (1,6) に 5.6e-7 の誤差が出るため、残る数値微分の刻みは 1e-7。
  • 理由 3 (フリンジ四極): tqlfre を含む四極を数値微分にすると ε・チューンに 1e-5〜2.7e-7 の差が出る (bench_level26b)。解析式で 1.3e-9。
  • z 行のシンプレクティック性: 数値微分の z 行をそのまま使うと T の誤差 6.6e-5、εy が 2% ずれる (Level 3C)。そのため z 行 (5,1..4) はシンプレクティック条件で組み直す (_State.piece)。

POL のスピン (docs/16_spin_pol.md)

POL; を付けた Emittance[]/EMIT は、偏極時間 (PolarizationTime)・スピンチューン・偏極ベクトル・スピン歳差行列・1 周の脱偏極ベクトル (表) を出す (pysad/spin.py の tradke_spin、spnorm、srequpol)。 放射の 1 ステップ (tradke) ごとに srot を回して積算し、tchge の回転 (ROTATE 付き偏向) でも回す。POL のとき BEND の分割数は 1+int(|φ|·h0·a/0.01) 以上になる (K64 も同じ)。

  • 平面リング・縦ずれ・傾き・6 極つきのリングで、偏極時間・スピンチューン・偏極ベクトルを K64 と 10〜13 桁で確認した (エネルギー 3.0〜3.08 GeV、aγ=6.8〜6.99 の格子の範囲。§6)。

5. 注意点 (仕様と落とし穴)

  1. Cavity PHI の既定は 0。phic = PHI·sign(charge)、同期位相は trf0 で入る。
  2. 4D CALC では空洞は RFSW に依らずドリフト (bench_level14a_dbg)。空洞が効くのは Emittance[] と追跡。
  3. 薄い多極の dv 項: tthine 内のドリフトにも z −= L·dv(δ) が付く (2-1 節)。表示桁 (εx 5 桁、Level 12) の照合ではこの差は見えないので、照合は全桁 ($FORM="18.14"、16b/16e) で行う。
  4. 閉軌道の δ: SAD の tcod は周長変化で δ≠0 を選ぶ (3C: δ=−4.85e-8)。close_z がないと U0・εx がずれる。
  5. RADCOD ON の z と trf0 (Equilibrium dz): tcod は一周ごとに z を trf0 に移し、収束判定が緩い (z は 1e-7 まで) ので、分け方は反復の履歴で決まる。_tcod_radcod が tcod を直訳しているので trf0 は 実ラティス で 12 桁一致する (trf0 固定の厳密な Newton では dz が 8e-4 mm ずれる)。 逆に言うと cod と trf0 の「和」だけが物理で、SAD の cod 自体は 1e-9 (dp) 程度しか収束していない (出口と入口がその分違う) — それでも emittance 等は 1e-11 で一致する。
  6. RFSW OFF の RADCOD: SAD の tcod は RFSW OFF でも RADCOD ON なら放射込みの閉軌道を使う (_tcod_radcod の RFSW OFF 枝)。RFSW OFF を RADCOD OFF と同一視すると 実ラティス で U0 が 7e-5、α_c が 1e-4 ずれる。
  7. RFSW OFF の RF の量: tturneg/tecalc は RFSW に関係なく空洞の積算量から Vc, wrfeff を作る (Vc, bh, dz, εz, σz は RFSW OFF でも 0 ではない)。
  8. 解析ヤコビアンの落とし穴: (a) lattice._tbendebody0_mat の z 行 (5,6) (xsn=sn−phi0) は 4D の CALC では使われないので、z 行の検証は emit 側の照合 (tests/test_emit_jac.py) に依る。 (b) Newton 法のヤコビアンを使い回す (chord) と軌道が 1.7e-14 変わるだけで εx が 2e-8 変わる — 量子励起の分割数 (nq, ndiv の int()) の境界。 (c) tecalc の tsolva (= tsvd、特異値 1e-8 の打ち切り) を numpy の SVD で代用すると y 方向に εy~1e-21 の雑音が出る (SAD は ~1e-38) → pysad/tsvd.py (SAD の直訳) を使う。 emit の結果は軌道の連続関数ではない (1e-8 のレベル) ので、SAD との照合では軌道の差 1e-9 の影響を見分けられない場合がある (解析式で SAD と同じ分割になっている)。

6. 検証

  • 実ラティス (3563 要素) の Emittance[] (RFSW × RADCOD の 4 通りと Matrix->True) の εx・εz・σE・σz・チューン・減衰率・U0・trf0 が、K64 (gs) と 1e-11〜1e-12 (全桁表示) で一致する。FODO・結合・強さ誤差・ROTATE・MULT・FRINGE・不安定な光学・FSHIFT・EMIT の報告 (全行) の各ベンチも 1e-6〜1e-12 で一致する (不安定な光学の水平側は K64 の T の悪条件の範囲 3e-5)。比較の表は docs/history/09_emittance_validation.md。
  • 例外 (一致しない): th≠0 かつずれ≠0 の要素 (K64 の tchge の癖) を含むリングでは、K64 の 6D 閉軌道が閉じず、Emittance[] の δ・チューンは K64 と一致しない (§2-1)。
  • PYSAD_COMPAT=k64 で K64 と同じ動作になる (v2 との違いは §4b の表と docs/28_v2_vs_k64.md)。
