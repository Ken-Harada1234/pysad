03. FFS のコマンド解釈 (src/tffsa.f) と pysad の ffscmd.py

この文書で分かること: SAD の対話コマンド層 FFS が 1 文をどの順に解釈するか (§1)、フラグ (§2)、マッチング (FIT・FREE・GO、§3)、要素値と誤差のコマンド (§4)、USE・CALC・EMIT・DISP などの主なコマンド (§5)、SADScript 側の組み込み関数 (§7)、pysad の対応表 (§8)、実行上の注意 (§9)。 前提: 02_lattice_main.md (ラティスの定義) を読んでいること。FFS は FFS; と書いた後に使えるコマンド群で、USE RING; CELL; CALC; のように 1 文ずつ実行する。 読む順: コマンドを使いたいだけなら §5 (USE・CALC・GO・EMIT・DISP) → §3 (FIT) → §2 (フラグ)。動作の細部 (K64 の仕様) が要るときに §1・§4・§7・§9。小さなコマンド (VARIABLES・MATRIX・DUMP など) と DELCOR は 04_ffs_small_commands.md。

用語: K64 = 本プロジェクトが翻訳の元にした SAD (Fortran)、gs = その実行ファイル。k64 モード = PYSAD_COMPAT=k64 で K64 と同じ動作、v2 モード = pysad の既定 (K64 の誤りを直した動作)。CELL / INS = 周期解 (リング) か、先頭 MARK の初期 Twiss からの伝搬 (輸送路) か。

対象: SAD K64 (\src) と pysad (\pysad)。すべて Fortran ソースと pysad のコードで確認した内容。行番号は 2026-10 時点のもの。

3. FIT 条件 (tgetfv.f)、FREE/FIX (tffsfreefix.f)、GO の解法とフック

3.1 位置: FIT [loc [loc1]] (tffsa.f)

  • FIT ALL → mfpnt=1, mfpnt1=nlat。
  • FIT loc → mfpnt=mfpnt1=ielme(loc)。FIT loc loc1 → 区間 (ifitp=min, ifitp1=max は tgetfv で正規化)。
  • 位置が解決できない語 (FIT NX 7.5 の NX、FIT; の空語) は ielmf が nlat ($$$) を返すので FIT; は位置を末尾 $$$ に戻すだけで条件は消さない (消すのは REJECT TOTAL)。位置は次の FIT まで保持され、以後の NX … はその位置に付く。
  • ielmf (ielm.f): $$$/*** → nlat、^^^ → 1、NAME.n (n は式も可)、NAME+k/NAME-k (k は式、小数部は要素内の割合)。fit QF のようにファミリー名だけなら ielmh(name,0) = 単独要素か多重要素の 先頭 (代表)。

3.2 関数: FUN value [npoints]

  • FUN は nlist (tffs.f:1622) の 64 個: AX BX NX AY BY NY EX EPX EY EPY R1 R2 R3 R4 DETR DX DPX DY DPY DZ DDP AZ BZ NZ ZX ZPX ZY ZPY PEX PEPX PEY PEPY PZX PZPX PZY PZPY GMX GMY GMZ BMAGX BMAGY BMAGZ TRX TRY TRZ LENG GX GY GZ CHI1 CHI2 CHI3 DEX DEPX DEY DEPY DDX DDPX DDY DDPY PDEX PDEPX PDEY PDEPY。mfit までが FIT 可能 (TRX/TRY は末尾のみ、区間 FIT は mfit 以下で TRX/TRY 以外)。GX/GY/GZ/CHI1-3 の fit は、pysad では値を geo.py の幾何から取り、微分は数値微分、CHI の scale は π/180 (docs/history/work_geo_sig.md)。
  • value: 実数、{min,max} (不等式。両端が同じなら実数扱い)、{v}、* (登録済みの値を保つ: 無ければ No default value of)、@/@-/@* (位置の MARK 要素の保存値、@- は符号反転、@* は進行方向 direlc で AX/EPX/R2 等を反転)。: を前置すると scale を掛けない (NX/NY/NZ は 2π、CHI1-3 は π/180 が scale)。
  • npoints: mfitp = n+1。省略 (または 0) は既存値を保ち未設定なら 2。-1 で無効 (mfitp=0)。FUNM (末尾 M) は最大/最小フィット (mfitp を負)。BX/BY に 0 以下を与えると Non-positive value for。
  • FUNI v (BXI 1.0) は先頭要素 (MARK) の初期 Twiss rlist(latt(1)+i) を設定。FUNSCALE v は scale(i) を変更。
  • FITP_OINTS n (tffsa.f): |mfitp|>2 の条件だけ sign(|n|+1, mfitp) に一括変更。オフモメンタム点数 nfr=max((|mfitp|-1)/2) が 1 以上なら DP (dpmax) が必要 (?No momentum bandwidth.)。
  • FITP>1 のとき MatchingAmplitude = {{dp, xamp, yamp}, …} と NFAMP で有限振幅ファミリー (tffamsetup) を足す: 各 dp 点の軌道 + 正規モード振幅の軌道のまわりの周期解 (閉軌道は探さない) で条件を評価する。FitValue の {id, dp} の id は kfam (x: 1..NFAMP、y: −1..−NFAMP)。pysad に実装はあるが SAD との照合はない (自己検証のみ。§9 のとおり FITP>1 の参照値が取れない)。
  • REJ_ECT (tfrej.f): TOTAL は全条件 mfitp=0 + tfinitcalc、TOTALFIT は mfitp=0 のみ、関数名 (パターン可、…M も) は現在位置 (mfpnt,mfpnt1) の該当条件だけ mfitp=0。
  • CAL_CULATE [FUN|FUN-]… (tfcalc.f): 表示に関数を追加/削除 (txcalc) してから計算。

3.3 FREE / FIX (tffsfreefix.f)

FREE pat [KEY] pat …: tfgetlineps(mode 0) で要素位置を集め、. を含まない名前は ファミリー先頭 (klp==k) だけ を変数にする。KEY (次の語) が要素型のキーワード (tfkwrd) なら ivvar にそれを、無ければ既定キーワード nelvx%ival (tfinit.f: DRIFT は L (ival=1, 下限 vlim(1)=0.1)、BEND/QUAD/SEXT/OCT/DECA/DODECA/SOL/CAVI/TCAV は 2 番目のキーワード (ANGLE/K1/K2/K3/…/BZ/VOLT)、MULT は K1、MARK/MONI は 0 → Can't use as variable)。BXI 等の nlistI は先頭 MARK の初期値を変数にする (it=41)。QF.2 のように成分を指定すると ivcomp 付き (Info-Component … is coupled to)。valvar = 値/errk で保持。成分ごとの FREE (tffsfreefix.f・tfsetv.f・tffsa.f の tfvcomp と gs の実測。両モード): 語に . があれば成分の変数。(a) 既定のキー (QUAD の K1 など) の変数は要素全体の値で、成分は先頭の成分に結合する。先頭の成分 (QF.1) は要素全体と同じ (結合先を ???-FFS-Info-Component QF.2 is coupled to QF.1 . で知らせる)。先頭でない成分 (QF.3) の既定のキーの変数は値を持たず効かない (K1 は動かない。gs は変数の数に数え、pysad は作らない: 反復の行の最後の数が 1 つ違い、その変数だけで GO すると pysad は ?No variable.)。(b) 既定でないキー (BEND の K1、ROTATE) の変数は、その成分だけの値 (tfsetv の ievar2)。(c) 同じ要素の変数は、後から FREE したものが先 (LOOP_I_2)。(d) 要素全体の変数がある所へ成分、成分がある所へ要素全体を FREE するとエラー (A component has been already used as variable: B.6)。(e) tfvcomp は (b) の変数があれば真で、NOKEEPEXP の CALC・GO は展開しない (NOCALEXP)。(f) FIX: FIX B.3 は成分、FIX B は成分に触れない、FIX B*・FIX * は成分も消す。VAR の Couple の欄は既定のキーだけ <--、制限値は既定のキー ±1e10、ほかは ±1e99。gs と一致を確認している (小さな FODO、大きなリング A。検証の節)。未確認: COUPLE で結合した要素の成分、USE NOEXPAND の展開済みの成分の値の保存。例 example/03_matching/flag_FREE_component.sad。FIX pat [KEY] は一致する変数を削除。ワイルドカード (%*<{|) があれば複数語を続けて読む。

3.4 GO の解法・微分・フック (tffsmatch.f)

  • tsvd (tfsolv → tsolva): 2 重対角化の後、対角の最小値 > anorm*eps なら特異値を落とさず直接解く (quick path)。そうでなければ暗黙 QR + 滑らかな減衰。pysad は pysad/tsvd.py (直訳)。J の条件数が 1e6 以上のとき (INS のフィット) numpy の硬い打ち切りと解が大きく違う。PYSAD_TSVD_NUMPY=1 で numpy 版に切り替え。
  • INS のフィットの微分: SAD は INS でも解析微分 (tffsqu→qdcell→qdtwis、cell=False)。FFS$NumericalDerivative のときだけ数値微分。pysad も match6d の解析微分を INS で使う (PYSAD_INS_NUMERIC=1 で数値微分)。未対応の条件・状況は中心差分に自動フォールバック (Matcher._analytic_unsupported)。
  • FitValue / FitWeight のフック: FitValue[comp, fn, {id_,dp_}, goal_, now_] (2 点条件は FitValue[c1,c2,fn,{id,dp},goal,now1,now2])、FitWeight[comp, fn, {id_,dp_}, w_]。pysad は {id, dp} を {0, dp} のリストで渡す (裸の実数では {_,dp_} に一致しない)。
  • VariableRange / VariableWeight (tffsvarfun、tffsmatch.f:717): VariableRange が実数を返せば dlim、0 なら変更前の値、{min,max} で範囲を狭める。VariableWeight は変数の重み gw を置換。pysad は Matcher.var_range/var_weight (_vlimit/_tweigh)。
  • OpticsProlog / OpticsEpilog: OpticsProlog := … / OpticsEpilog := … を定義すると CALC (と fit の各評価) の前後で呼ばれる。=. で外す。

4. 要素値コマンド (tfgetv.f) と誤差コマンド (terror.f)

4.1 NAME [KEY|R|MAX|MIN|MAXABS] value …

tfgetlineps(mode 1) でファミリーを列挙し、次の語が R_ELATIVE (相対: v*(1+x))、MAX/MIN/MAXABS|ABSMAX|MAXMIN|MINMAX (変数の上下限 nelvx%vlim を設定し、現在値をその範囲に丸める)、要素型のキーワード (itftypekey)、または値。キーワードなしは既定キーワード (?No default keyword for は MARK など)。パターンで型が混ざると Info-Different types of elements match。既定キーワードの代入は cmpd%value(iv)=vx*errk(1,ii) (誤差係数を掛けた実効値)。それ以外は tftouch。S* 0, SDA MAX 0, QF K1 0.5, QF R 0.01 が典型。QF.3 K1 v (. 入り) は成分だけ。

LINE[key,name]= で触ったキーは USE まで残り、CALC のたびに代表の値に揃える (tftouch)。

4.2 誤差: DELX/DELY/DTHETA/DL/DK/DDK/DBEAM sigma [opts] pat …、DUMP [pat]

  • sigma の前後に U_NIFORM/R_ANDOM (uni)、C_OHERENT/INC_OHERENT (cohe)、A_DD/P_UT (add) を置ける。既定は RANDOM・INCOHERENT・PUT。
  • 各要素 (パターン一致、DRFT 以外は master(i) の先頭から成分列) に errg = sigma*tgauss() (uni なら sigma、coherent なら 1 回だけ引いた値を共用) を加える。乱数は要素ごとに 1 回引く (tgauss は GCUT で切る正規乱数、追跡と同じ乱数列)。
  • master グループ (tmast.f): 同じ要素の分割片 (間にゼロ長要素のみ) はグループの先頭ごとに乱数を 1 回引き、同じ誤差を共有する。pysad は _master_array。
  • 代入先: DELX→DX、DELY→DY、DTHETA→DROT (無ければ ROT)、DL→L (max(0, …))、DDK→K0、DK→errk(1,j)=1+errg (ADD なら errk+errg) で、既定キーワードの実効値 = 設計値/er*errk*couple(j)。PUT の基準は設計値 idval (SAVE で更新)、ADD は現在値。DK は主強さだけに掛ける。LINE["K1"/"ANGLE", …] は DK 込みの値を返し、Element[] は設計値を返す。
  • DBEAM は先頭の Twiss を揺らす。DUMP pat は element DL(mm) DK DDK DTHETA(mrad) DELX(mm) DELY(mm) を (1x,a,3p,f10.5,1p,2g12.5,3p,3f10.5) で、ずれのある要素だけ表示。DK・DDK 列は Fortran の 1p g12.5 (0 → 0.0000、小さい値 → 4.22829E-04) に合わせる (ffscmd._gwd。誤差入りリングで gs と値・書式が一致。test_ffsextra.py::test_dump_format_matches_gs)。
  • uni でなければ最後に tfadjst (tfadjst.f): 隙間なく並ぶ磁石の鎖は先頭磁石の DX/DY のずれを共有する。pysad は _tfadjst。

6. 線形加速器 (TRPT) の加速と MARK の OFFSET

FFS; と MAIN の代入の残した違い: FFS (; なし) の次の行が USE 以外の文のとき gs はエラーにして行の残りを捨てるが pysad は FFS 部として実行する、A = 3 B = 4; は gs では A = 3 (エラーつき) だが pysad は代入しない、gs が構文エラーにするが pysad が受ける形 (45DEG・SIN[0.1]・未定義の名前 L=A)、gs が受けるが pysad が構文エラーにする形 (末尾の 1+)、MAIN の変数を E・Pi・Degree で代入しても要素定義の式の E は SADScript の定数 (gs は利用者の値)、LINE[{"EMITY",…},1] は gs が MAIN の値、pysad が MARK に書いた値 (0)。k64 モードでも MAIN で PBUNCH・EMITX・MASS などを代入している TRACK なしの台本は、その値が効く (gs と同じ向き)。

9. この SAD ビルド (WSL, K64) で分かった注意

  • NPARA の既定は 4 (Packages/init.n:219 NPARA=4;。initb1.f の RsetGL('NPARA',1) を init.n が上書き)。TrackParticles は粒子 9 個以上 (有効な並列数 = min(NPARA, np/9 + 1, ne·np/3000 + 1)。np ≥ 13 で実際に分かれる) で fork するため乱数列が分岐する。pysad の既定は NPARA=1。gs と比較するには NPARA=1; をスクリプトに入れるか、NPARA=n; を FFS で設定して同じ分け方を再現する (子の乱数の種 = 親の種 + 2k。RAD + FLUC の追跡だけ。gs の NPARA=1 と 4 の rms dp・最終の種と全桁一致: docs/10)。
  • FITP>1 の GO で SAD が再起動することがある (*** Run time Environment バナーが再び出る)。NPARA=1 でも起きるので、オフモメンタム条件の参照値は得られていない。確認: example/03_matching/FFS_FITPOINTS.sad (24 セル FODO、δ = −1%・0・+1% の 3 点で NX = 6.7・NY = 4.9) は今の gs は再起動せず完走し、最小値の手前で止まった (K1 (QF, QD) = (0.700211, −0.599628)、K2 (SF, SD) = (1.695226, −2.439058)、残差 6.3321e-6 が独立な最小値 6.33178e-6 より相対 5e-5 大きい。Overflow & closed orbit not found の試行点での打ち切り)。pysad の GO の最終解は独立な最小化 (残差の定義 Σ w (f − goal)² scale² の scipy の最小二乗) と 5e-8 以内で一致。
  • NPARA>1 では出力が子プロセスで重複する (tffsmatch の fork)。参照出力は NPARA=1 で取る。
  • FFS["…"] の unit 省略は非表示 (outfl=0)。画面に出すには FFS["…", 6] か -1。
  • MAXITERATION はこのビルドでは GO の反復数に効かない (MAXITERATION 1 でも 7 反復)。pysad はコマンドを受理する。
  • EMIT は codin=twiss(1,0,DX:DDP) を初期軌道にし、終了後 gauss=.true.。DISP/TYPE の前には tfsetparam が呼ばれる。
  • MOMENTUM の初期値は 30 GeV (K64 initb1.f の RsetGL('MOMENTUM',30.d9))。MAIN で書かなければ FFS も 30 GeV で計算する (pysad の ffscmd も同じ既定)。
  • 旧 WAKE コマンド: K64 の tffsa.f は tfwake.f を呼ばず WAKECOMMAND[] (init.n の AutoLoad。Packages/WAKECOMMAND.n は配布に無い) を評価する。gs は fileopen のエラーを出して行の残りを捨てる。k64 モードの pysad も同じ経路 (エラー文の表示だけ未再現)。v2 モードは tfwake.f の構文 WAKE L|T 要素 s1 w1 … ENDWAKE を WakeFunction の表として登録する (CAVI だけ。docs/13)。
  • Skip・Read の型 (Character・Real・Word の読み方、数でない語の Real は式の値) は gs に合わせた (test_evalfixes.py)。MessageName[f,"usage"] の関数形は、gs は f を無視して Undefined MessageName General::"usage" を出す (B70)。v2 モードは f の本文を返す (f::usage と同じ。無ければ General::tag の本文)。k64 モードの pysad も f を見る (General::tag へ継承する)。
  • MEASURE は INS; CALC のあとでも gs は何も出力しない。TRCOD は SIGSEGV (B42)。v2 モードの pysad は K64 のソースの読みで実装した (上の「v2 モードの MEASURE・TRCOD」)。
  • SOL (BOUND≠0) の長さは周長に入れない (K64。emit6d._emit_circ、追跡の circ も)。GEO の無い SOL では K64 の S 座標が途切れて周長が狂うが pysad は再現しない (docs/17)。

  • マッチング (FIT・FREE・GO): UNIPOL・RELW・既定の 3 通り、成分ごとの FREE (小さな FODO、大きなリング A) の反復の行・チューン・K1 が gs と一致する。
  • EMIT の後の USE で RF の位相の基準が変わらない動作は、小リング・大きなリング A・PF リングで gs と一致する。

  • MEASURE・TRCOD・LOGMEASURE は K64 が無出力・SIGSEGV のため、gs との数値比較は無い (§8 の「v2 モードの MEASURE・TRCOD」)。
