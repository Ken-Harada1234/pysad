# v2.3.0 U2: B160 の K1 の定義のオプション ('log' | 'lin') と B161 (CALC の dk) の修正

2026-11-21。担当 U2。U1 (`v23_U1.md`) の結論 (K64 の BEND の K1 は (1 + hx)∂b/∂x 一様の 'log' 場) を受けて、B' が x に一様な定義 ('lin'、elegant CSBEND K2 = 0・MAD SBEND と同じ) を v2 のオプションとして実装した。あわせて B161 を測って v2 で直した。
結果の表と条件は `example/v2_3/U2_README.md`、検証の出力は `U2_verify.out.txt`・`U2_astrid2_chrom.out.txt`・`U2_lma_astrid2.out.txt`。試験は `pysad/tests/test_v23_U2_bend_k1_def.py` (14 本)。

## 2. 'lin' の導出と実装

U1 §4 のとおり、中央面の磁場 g(r) = B_y(r, 0) が決まれば B_y = g − (y²/2)(g'' + g'/r) + …、B_r = y g' − (y³/6)(g'' + g'/r)' + …。'lin' は g = h + K1 (r − ρ0)。曲線座標の力の項 (1 + hx) b (b = B/Bρ0 を p で割る):
- x 方向: (1 + hx)(h + K1 x) の K1 の部分 = K1 x + K1 h x² (級数なし、'log' は K1 x (u/2 − u²/6 + u³/12 − …) の u = hx の級数)。
- y² の項: B_y ⊃ −K1 y²/(2r)。(1 + hx)/r = h なので、px' ⊃ +K1 h y²/2 (x に依らない)。
- py 方向: (1 + hx) B_r = K1 y (1 + hx) + K1 h² y³/(6(1 + hx))。K1 y は線形の本体、K1 h x y が増える。y³ の項 (4 次のポテンシャル) は入れていない (§7)。

kick (スライスごと。ak1 = スライスの K1 の積分値、p = 1 + δ、`tbendicorr` の中。幾何の補正のあと):
 px −= ak1 h (x² − y²/2) / p、py += ak1 h x y / p。
ポテンシャル V = ak1 h (x³/3 − x y²/2)/p から −∂V/∂x、−∂V/∂y に等しく、シンプレクティック。**K64 の kick (px −= ak1 x (u/2 − u²/6 + u³/12)/p) を置き換える** ('log' + 6 極の厳密な和ではなく、x の級数は使わない)。

解析行列 (`bendecorr(..., flags)`、bit0 = 'lin'): 幾何の行列を dk = 0 で作り (z の行も幾何だけから作る: 位置だけの kick は z を変えないので厳密)、そのあとで kick の行列を左からかける: 行 px: dkx = −2 hk x、dky = +hk y、行 py: hk y (∂/∂x)、hk x (∂/∂y) (hk = ak1/ρ0、正準運動量なので p は消える)。数値微分との差は 1e-9 以内 (試験)。これで y・x–y の要素まで入る。K64 の行列 (flags 0) は z の行に kick の dk が混ざる (1e-11) が、そのまま。

numba のカーネル: `track6n.py` `k_bendi` (rs[3] = 'lin' の印、`make_rs` が載せる。2 か所の補正)、`perfkern_bend.py` `bendecorr`、`elkern.py` `k_bend`・`_bend_core` (引数 `klin`)、`turnkern.py` `turn4` (引数 `klin`)。旗は `compat.bend_ecorr_flags()` (bit0 = 'lin'、bit1 = B161 の修正)。呼び出し側: `emit6d.py` (`_tbendecorr`、`_bende_fast`)、`lattice.py` (`_bend_k1_cod_matrix` 経由と `_one_turn_cod_matrix` の turn4、k_bend の直呼び)。`py -3.12 -m pysad.nbcache` 済み。
並列の worker (freqmap・lma。spawn で別プロセス) には `TrackSetup.__setstate__` で設定を引き継ぐ (`TrackSetup.bend_k1_def`)。`lma.py` は触っていない (LMA の試験で 'lin' が効くことを確認した: §1)。

## 5. ∂²ν/∂δ² の y の 3 倍の差: 'lin' で解消するか

**解消しない** (6 極つき: pysad / elegant の y の比は 'log' 2.66、'lin' 2.90。自然なリングは 1.90、1.80)。原因の切り分け:

1. **elegant の `dnux/dp2`・`dnuy/dp2` 自体が不正確**。elegant の値は N_KICKS (32 → 128)、INTEGRATION_ORDER (2・4)、`higher_order_chromaticity_range` (1e-3〜1e-2)、`default_order` (3・4)、EDGE_ORDER (2・3) を変えても 1 桁目まで同じで、追跡から出していない (行列の合成から出している) 値と見られる。そのうえ K1 の偏向磁石のない FODO リング (16 セル、sector 偏向磁石 + 厚い四極、フリンジなし) の独立な積分 (5.91、5.83) に対し、pysad (DISFRIN=1) は (5.92、5.90)、elegant は (5.60、4.51) で y が 23% 外れる。K1 ≠ 0 の n = 0.4 の扇形リング ('lin') でも elegant (−5.01、2.10) に対し独立な積分 (−2.60、1.763)・pysad (−2.611、1.763) が一致する。pysad の CALC の ∂²ν/∂δ² はこれらの独立な積分と合う。
2. **pysad は K64 の四極・偏向磁石の端のフリンジを含む**。ASTRID2 の 6 極つきで DISFRIN=1 (四極・偏向磁石・6 極のフリンジなし) にすると pysad の y は (log) 88.2 → 72.4、x は 76.3 → 68.4 (elegant にはフリンジがない)。FODO (K1 = 0) では四極のフリンジだけで y の ∂²ν/∂δ² が 38.8 → 5.9 になる。
3. ASTRID2 の自然なリングを、ドリフト・厚い四極・複合機能の扇形磁石 (硬い端 + 標準の縦方向の集束: 軌道の傾きでの端面の通過) の独立な積分 (`pysad/tests/_u2_indep.py`) で解いた (フリンジなし、6 極なし): ξ は 'log' (−6.2181、−11.8060)、'lin' (−6.2486、−11.0336) で pysad (DISFRIN=1) と 6 桁で一致。∂²ν/∂δ² は 'log' で積分 (44.22、106.44) / pysad (44.25、101.74)、'lin' で積分 (43.09、107.65) / pysad (43.14、102.94)。y に残る 4.5% は、積分側の端の縦集束を y の 1 次・軌道の傾きの厳密な式で入れたこと (pysad は SAD の厳密な `tbedge`) の差と見られる (未確認)。elegant (自然、EDGE_ORDER = 2) は (46.42、61.82) / (45.13、65.89) で y が積分の 6 割。

したがって T1 の「y で 3 倍」は B160 の定義の問題ではなく、pysad 側の K64 のフリンジの 2 割弱と、elegant の ∂²ν/∂δ² の精度の問題。**∂²ν/∂δ² の基準には elegant の `dnu/dp2` を使えない** (1 次の ξ は一致するので使える)。独立な積分があるのは ASTRID2 の自然なリング (6 極なし、フリンジなし) まで。6 極つき・フリンジつきの ∂²ν/∂δ² の独立な基準は未了。

## 6. B161 (`tbendecorr` の dk)

K64 の dk = −K1 xr (1 − xr (1 − 2 xr)) は、同じ関数の kick の導関数 −K1 xr (1 − xr/2 + xr²/3) と xr の 2 次の項が違う (U1 §8)。`bendecorr` の戻りの行列を出口 cod の数値微分と比べると、K64 の dk では xr = 0.1 で 1e-5 以上ずれる。v2 では導関数に直した (`compat.bend_dk_fix()`、v2 で既定 True、k64 は常に False。`set_bend_dk_fix(False)` で測定用に K64 の dk に戻せる)。

| 場合 | K64 の dk | 修正 |
|---|---|---|
| n = 0.4 の扇形磁石 16 台のリング (3 GeV 相当、xc/ρ0 ≈ 0.04 まで) の ν_x(δ) − 独立な積分 | δ = 1%: 3.5e-5、2%: 1.3e-4、4%: 4.8e-4、6%: 9.5e-4 | 1.2e-8、7.5e-8、1.4e-6、7.2e-6 (残りは 'log' の kick の級数 u⁴ 以降) |
| ASTRID2 (0.58 GeV): ξ・∂²ν/∂δ²・ν(δ = 2%)・EMITX・SIGE | — | ξ は 1e-6、∂²ν/∂δ² は 0.002、ν は 5e-7、EMITX・SIGE は 1e-9 (相対) 以内の変化 |
| 大きなリング A (`kek-ls_v03_12.lat`、3 GeV、603 m) | — | ξ は 4e-6、∂²ν/∂δ² は 0.007、ν は 1e-9 以内、EMITX・SIGE は 1e-9 以内の変化 |

追跡は kick を使うので影響を受けない。実際のリングへの影響は小さいが、強い複合機能偏向磁石で大きな軌道のずれ (δ ≳ 1%) の CALC の ν(δ) は、K64 の dk では追跡と 1e-4 ずれる。**k64 は K64 のまま、v2 で直した理由**: 行列と写像の不整合で、直すと CALC が追跡・独立な積分と合う。v2 の既定の結果が変わるが、既存の試験・回帰への影響はなかった (§8)。

## 7. 限界・未確認

- 'lin' の kick はポテンシャルの 3 次まで。B' 一様の実際の場の 4 次の項 (px: K1 h³ y⁴/(24 (1+u)²) の力、py: K1 h² y³/(6 (1 + u)) の力) は入れていない: 16 台、y = 7.5 mm で追跡の写像が独立な積分と 2.9e-8 ずれる (y 0.15 mm で 2e-10)。'log' の kick も u³ で打ち切り (K64 と同じ)。ADTS・DA の 4 次の項は 'lin' で厳密ではない。
- 端のフリンジ (K1 の Maxwell フリンジ `ttfrin` など。DISFRIN=0 の既定) は 'lin' でも K64 のまま (K1 の定義に依らない形)。DISFRIN=0 のときの 'lin' の端の K1 の項は B' 一様のときの値と同じかを未確認 (追跡の比較は DISFRIN=1 の本体だけ)。
- 大きなリング A (kek-ls) と ASTRID2 以外の複合機能の磁石、複数の E1・E2≠0 の複合機能 (長方形磁石) の 'lin' と独立な積分の比較は未了 (δ = 0 の不変性だけ確認)。
- `bendnl.py` (R3・R6 が編集中) は追跡の写像から 3 次の生成関数を取り出すので 'lin' に**自動で追従する** (キャッシュを消すと x³: −2.52e-4 → −5.05e-4 (2 倍)、x y²: 1.5e-8 → 7.6e-4、K1 h/6 → K1 h/3、−K1 h/2 の比と一致)。**ただし `bendnl._mode_key()` が `(compat.v2(), compat.bend_k1_edge())` のままなので、同じ磁石を 'log' → 'lin' に切り替えるとキャッシュ (`_CACHE`) が古いまま返る。`compat.bend_k1_def()` をキーに足す必要がある (R6 担当への依頼: `return (compat.v2(), compat.bend_k1_edge(), compat.bend_k1_def())`)。** `resdrive.chromaticity_bend` など、キャッシュを持つほかの関数は確認していない。
- δ = 0 以外の設計の確認 (`Emittance[]` の閉軌道が δ≠0 のとき 'lin' で EMITX が 1e-4、SIGE が 2e-3 変わる) は 3 GeV の試験用リングだけ。ASTRID2・大きなリング A の Emittance[] での 'lin' の変化は測っていない。
- gs は走らせていない ('lin' は K64 にない定義)。'log' の既定は既存の試験 (k64 の gs 一致) で変わっていないことを確認した (§8)。

## 8. 試験

既存の試験 (`test_elkern`・`test_perf_kernels`・`test_v23_U1_bend_k1_field`・`test_bend*` (feeddown を除く)・`test_emit*`・`test_v2_*` の BEND 関連) は 158 通過・2 skip・失敗 0 (B161 の修正を含む v2 の既定で。k64 の gs 一致の試験を含み、'log' の既定が変わっていない)。全試験・回帰は走らせていない (最後にまとめて)。
