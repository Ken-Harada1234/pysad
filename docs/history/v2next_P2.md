## 2. 項目 1: SynchroBetaEmittance (B128、大きなリング A で 40 倍)

### 2.1 状況と調べたこと

大きなリング A (3 GeV、603 m、νs = 0.004075、RF 1.4 MV) で、SB は 6.178e-9 (AzimuthalModes 3〜8 で一定、12・20・30・32 で 3.19e-9・1.46e-9・8.5e-10・7.9e-10 と動き続ける)、
独立な 6x6 の平衡 1.517e-10・Emittance[] 1.549e-10・追跡 1.6e-10。gs も pysad k64 も同じ 6.178294e-9 (今回の gs: modes 3 は 6.178294026e-9・modes 12 は 3.18594988e-9、k64 と 2e-7・6e-6)。
D1 までに原因でないと確かめたもの: 閉軌道の探索、二次の分散、クロマティシティ、RF の位置の分散。

### 2.2 K64 の式 (temits.f) の読み

`temits1` は、δ ごと (2·ndims+1 点) の閉軌道 c(δ)・1 周写像 T(δ)・放射の減衰行列 trads・拡散行列 beams を作り、(作用 J、シンクロトロンの位相 φ) の空間で、
条件つきの 1 次のモーメント h = ⟨X | J, φ⟩ と 2 次のモーメント B = ⟨X Xᵀ | J, φ⟩ の定常解を、拡散の演算子 (tevdif・tesolvd) と位相の回転 (cmu・smu) で解く。
`tefsetup` は **1 周の写像を X' = tr1 X + h1** (tr1 = T(δ)、`teintp1`: ri · T⁻¹ から作った Twiss を T(δ) = A_δ R(μ_δ) A_0⁻¹ に戻したもの、h1 = `tws(mfitdx..)` = 閉軌道 c(δ)) と書き、
`tesumb` は x の 2 次のモーメントに η η σδ² を足して `ri` で分散を引く。

### 2.3 原因 (特定)

| 検証した候補 | 方法 | 結果 |
|---|---|---|
| 放射減衰の分配 Jx・Jy・Je の取り扱い | `trads` と `beams` を δ に依らない (δ = 0 の値) にして SB を解く (他は同じ) | 2.96e-10 (SB は 6.18e-9 のまま動かない)。減衰の分配は原因でない |
| シンクロ・ベータ共鳴の側帯の和 (モード数の収束) | AzimuthalModes 3〜8 で一定、12 以上で動く | 原因でない (v2 の修正後は 1.0084 (3)・1.0043 (12)・1.0020 (20)・1.0011 (32) と Emittance[] に収束する)。K64 の値が 12 で動くのは誤差の 40 倍の値が小さなモード数の切り捨てに敏感なため |
| νs との位置関係 | νs の入力を 0.002〜0.010 に変える (D1) | 値は動かない (6.1792e-9〜6.1806e-9)。原因でない |
| 周期 (リングの対称性・始点) の取り方 | **FODO の始点を変える** (QF から: η = 0.70 m、BEND から: η = 0.57 m、BEND の途中から: 0.45 m) | **SB/Emittance[] が 6.54・6.54・4.74 倍で、始点に依る** (K64、gs でも同じ: `example/v2_next/P2_sb_dispersion_start.sad`)。Emittance[] は始点に依らない。始点の分散 η が小さい ASTRID2 (η = −0.0008 m)・PF (0.0023 m) では 1% で合っていた |
| 平均 ⟨X⟩ の源泉 | 大きなリング A の h = ⟨X | J, φ⟩ を調べる | **hc (定常解) = hb (源泉) の 1/2** (η δ に対して hc[2] ≈ 0.25 η p、hb[2] = 0.5 η p。物理的には ⟨x⟩ = η δ のはず) |

**原因**: K64 の定式化は、X を η を引いたベータトロン座標にして (`rm = rx·D·rxi`、`beams = rxi B rxiᵀ`)、1 周の写像を X' = T X + h1 と書くが、
(a) 源泉 h1 に **閉軌道 c(δ) をそのまま** 使う (物理座標の軌道で、1 次の分散 η δ が入っている)。X' = T X + c の固定点は (1 − T)⁻¹ c で、c にならない
(2 次元の回転 T = R(μ) では (1 − R)⁻¹ の実部が常に 1/2 なので、平均が c の半分になる)。正しい源泉は (1 − T) c_b (c_b = c − η δ はベータトロン座標の軌道)。
(b) `tesumb` は x_b の 2 次のモーメント bc に η η σδ² だけを足し、x_b と δ の相関 η σδ² (`beam(16:19)`) を入れない。`ri` の変換 (x_b = x − η δ) で分散が引き切れず、
始点の分散が大きいほど (η σδ が betatron サイズ √(εβ) に近づくほど) 誤差が大きい。大きなリング A は始点 (RF の位置) の η = 0.0445 m、η σδ = 3.1e-5 m、√(εβ) = 2.7e-5 m。
(2) の変更は (a)(b) の両方を直さないと直らない: (b) だけ直すと FODO で 1.475 倍、(a) だけ直すと 20 倍。

### 2.4 v2 の動作

1. 源泉の軌道から 1 次の分散を引く: c_b(δ) = c(δ) − η δ (η = 6D の正規形の分散 `r[:, 5]`)。
2. 平均を解かない (h1 = 0)。(1 − T) c_b にして平均を解く方法は、平均の数値誤差 (J の格子・φ のモードで 1e-3) が 2 次のモーメントの源泉に入り、
   減衰時間の逆数 (1/α ~ 1e4) 倍に増幅される (合成のトイで確認: c(δ) = a δ、a = 0.1 m で励起が +8.7% (MC は +2.9%)、μ に依る)。
3. c_b(δ) の効果を 2 つの解析的な項に分ける (`tefsetup(jump=)`): (a) 光子の放出で δ が跳ぶと軌道が c_b'(δ) du だけ跳び、betatron の振動が励起される: 2 次のモーメントの源泉 c_b' c_b'ᵀ D_δ (D_δ = 4|α_z| σδ²: 1 周の δ の跳びの分散)、
   (b) 静的な広がり ⟨c_b c_bᵀ⟩・⟨c_b δ⟩ (φ の平均)。
4. `tesumb_v2`: ベータトロン座標のモーメントを物理座標 (x = x_b + η δ) に組み立て直す。

根拠 (合成のトイ、`test_synchrobeta_orbit_jump_excitation_matches_analytic_toy`): SB のソルバーに、回転 (位相 μ) + 減衰 + 拡散の写像と軌道 c(δ) = a δ (a = 0.1 m) を入れる。
投影エミッタンス比の解析式 1.02499 (x に λ = a² e α_z/α_x、静的な広がり a² e) に v2 は 4 つの μ (−2.64・0.3・1.0・2.5) で 1.0e-3 以内で一致し (μ に依らない)、
モンテカルロ (8000 粒子 × 9000 周) は 1.025〜1.029 (統計 0.5%)。K64 の式 (平均を解く) は μ = 0.3 で 1.0265、μ = 2.5 で 1.0856 と μ に依る。

### 2.6 使える範囲と条件・使えない範囲

使える: 始点の η に依らず、Emittance[] (線形) と 1% 以内で一致する (FODO・A・B・PF・ASTRID2)。軌道の δ 依存 c(δ) の効果は断熱近似 (ベータトロンの応答が軌道の動き 2π νs c' より十分速い: |1 − e^{iμ}| ≫ 2π νs の δ 振幅 3.5σ まで)。
使えない・未確認: 平均の非断熱な部分 (νs が大きい・ベータトロンチューンが整数に近い) は入れていない。結合のあるリング (SQ・SOL) で始点の分散 η_y ≠ 0 の確認は FODO + skew 四極 (C の例) の走行だけ。
SB が示すシンクロ・ベータ共鳴の効果 (νx ± m νs = 整数の近く) は、この修正で変わっていない K64 のソルバーの部分で、独立な基準 (長時間の 6 次元追跡) との比較は未取得 (CPU が必要)。
大きなリング A で AzimuthalModes 3 の 1.0084 が 32 で 1.0011 に減るのは、モード数の切り捨ての影響と見ている (差が物理的な効果なら一定のはず)。D1 の警告 (モード数 m と 1.5 m の SB が 20% 以上違うと警告) は残した (v2 は大きなリング A で出さなくなった)。

### 2.7 K64 の新しい誤りの候補 (B 番号は親が付ける)

- **SynchroBetaEmittance (temits.f の tefsetup・tesumb)**: 1 周の写像 X' = T X + h1 の源泉 h1 が閉軌道 c(δ) (物理座標、1 次の分散を含む) のまま。(1 − T) c_b と書くべき (固定点が c にならない)。
  `tesumb` は x_b の 2 次のモーメントに η η σδ² だけを足し、相関 η σδ² を入れない。リングの始点の分散 η ≠ 0 で εx が始点に依り数倍〜40 倍過大になる
  (24 セル FODO 6.54 倍、大きなリング A 40 倍)。確度: 確定 (gs で再現。η = 0 に近い始点では 1% で合う。始点を変えた同じリングの値の比較と、v2 の式が Emittance[] と 1e-3〜1e-2 で一致)。

- 厳密な積分の 1 刻み (放射を刻みの終わりに入れる K64 の形) への分解: ddpx_exact = px_end − px_cons(1 + dg/pr) は **−0.5·dpx·dg × 0.99989** (θ = 0.05 rad)・1.00007 (0.02 rad)・0.9886 (0.36 rad、O(θ²))。
  位置の変化は ddpx × c1 (c1 = al1/(3 pr)) と 1.0004〜1.002。つまり **追跡 (tradkn) の ddpx = −0.5 dpx dg が正しく、Emittance[] (tradke) の +0.5 dpx dg は符号が逆**。
  エネルギーを失う間は同じ磁場が運動量の小さい粒子をより強く曲げるので、偏向の向きに偏向が増える (dg < 0、dpx は偏向の向き)。
- 刻みが細かいと ddpx の分は ∝ 1/N で消えるので、k64 の誤差は **既定の分割 (EMITDIV = 1) で効く** (1 台の偏向磁石で 9%、EMITDIV = 20 で 2e-4)。
- v2 (A1 が閉軌道が追跡で閉じることを根拠に反転した) が**独立な基準で正しいと確定**した。k64 は K64 のまま。試験: `test_tradke_sign_agrees_with_exact_radiation_reaction_in_v2_not_k64`。
- **v2 の Emittance[] (RADCOD) が gs と 1e-4〜1e-3 ずれるのは K64 の誤差**: A1 の記録の「gs と v2 のずれ」(要判断) は、v2 側が正しい。

### 4.2 RADTAPER の追跡の重み

K64 の tturne は BEND の係数に (3 δ_l + δ_l+1)/4 + dptaper、追跡 (tturn) は (δ_l + δ_l+1)/2 + dptaper (A1 は v2 の追跡を tturne の重みにした)。

- 連続な放射で、要素の中の損失が線形 (δ(s) = δ_l + Δ s/L) のとき、磁場一定の要素の曲げ角 θ = B ∫ ds/p(s) を設計値にする係数は p の**調和平均** = (δ_l + δ_l+1)/2 + O(Δ²/12)。したがって**物理的な係数は 1/2**。
  3/4 は、K64 の tradke が損失を刻みの終わりに入れる (刻みの中では運動量が刻みの始めの値) 粗い離散化 (2 刻み: 平均エネルギーが δ_l + Δ/4) に合わせた係数。
- ただし係数は「磁石の強さの設定」で、同じ係数を Emittance[] (閉軌道) と追跡の両方に使えば閉軌道は追跡で閉じる。大きなリング B (8 GeV、周長 1.4 km、U0/E = 1.2e-3) で確かめた:
  Emittance[] の出口の軌道 x = −7.3347e-7 m (3/4) と −7.3369e-7 m (1/2)、1 周の追跡の閉じ方 x −2.05e-9 m と −2.06e-9 m (差 1e-11 m)。係数の違いで軌道は 2e-10 m しか変わらない。
  K64 のように Emittance[] だけ 3/4、追跡だけ 1/2 にすると z が 7e-7 m 閉じない (4e-10 m と比べて)。
- **v2 の動作**: Emittance[]・EMIT・追跡とも BEND を (δ_l + δ_l+1)/2 + dptaper にする (A1 の「追跡を tturne の重み 3/4 に」を「両方を 1/2 に」に変えた)。k64 は K64 のまま (tturne 3/4、追跡 1/2)。
  効果は小さい (軌道 2e-10 m、チューン・U0 は 1e-6 の桁)。既存の試験の変更 1 件 (§8)。

## 5. 項目 4: RADCOD の 1 周の解析 T + D と写像の数値微分

方法: 4 次の中心差分 (刻み 2e-5。刻みに依らない: 5e-6〜1e-4 で同じ) で写像 (tturne、RADCOD ON、RFSW OFF) の 6x6 の微分を作り、解析の T + D と比べた (`example/v2_next/P2_radcod_derivative.py`)。
軌道 (x, px, δ) = (1e-4, 1e-5, −1e-4)、24 セルの FODO (3 GeV、矩形 E = 0.13·ANGLE)。

K64 の `tradke` (photons.f 1417〜) の微分で、v2 が直した 4 点 (`perfkern.tradke_db` の `exactd`):

| # | K64 の式 | 誤り | 大きさ |
|---|---|---|---|
| 1 | `tr1` (区間の始点の座標 j に関する微分: `tr2 = trans·tinv6(transr)` の列 j は始点の座標) を、D・B の更新 `D += tr1·(T + D)`・`B = (I+tr1) B (I+tr1)ᵀ` にそのまま使う | この更新は終点の座標に関する微分を要する (T + D は終点までの行列)。正しくは tr1 ← tr1·tr2⁻¹ (スピンの更新 `srot += dg·transr` は始点の行列を掛けていて正しい) | y 面 (BEND 1 台) の誤り 5e-7 の主因 (この修正だけで y 面の差が 1e-15 になった)。区間が粗い (長い) ほど大きい |
| 2 | `dddpx = 0.5((tr2(2,:) − dpxr0)·dg + ddpx·ddg)` | 2 項目は dpx·ddg (ddpx = 0.5 dpx dg を微分する) なのに ddpx·ddg (dg 倍だけ小さい) | (px, δ) の BEND 1 台で 5e-7 |
| 3 | `tr1(1,:) = c1·dddpx`、`tr1(1,6) −= ddpx/pr` | x' = x + ddpx·c1 の c1 = al1/(3 pr) の微分が無い (dc1 = dal/(3 pr))。δ の項は c1 を掛けず (角度の次元になっている) | (x, δ) の BEND 1 台で 4e-7 |
| 4 | `dxpa = (xp·dxp)/xpa/pr²` | xpa = \|xp\|/pr² の微分は (xp·dxp)/(xpa pr⁴)。δ ≠ 0 の軌道で 2δ の相対誤差 | δ = −1e-4 で (δ, δ) の相対 2e-4 |

結果 (最大の \|T + D − 数値微分\|):

| 対象 | k64 | v2 |
|---|---|---|
| QF 1 台 | 1.1e-8 | 6.7e-16 |
| BEND 1 台 | 5.1e-7 | 1.7e-10 |
| QF + D + BEND | 5.1e-7 | 6.4e-9 |
| 1 セル | 1.9e-6 | 6.4e-9 |
| 24 セルのリング全体 | 4.3e-6 | 1.9e-7 |

残る 6.4e-9 (QF + BEND 以降) と 1.9e-7 (24 セル) は **(z, δ) 成分 [4, 5] だけ**で、BEND の T[z, δ] (tbendebody0 の (5,6) の近似: px² に比例し、px = −5.9e-5 で 6.5e-9、px = 1e-5 で 1.5e-10) による。
RADCOD OFF の T だけでも 1.2e-7 ずれる (同じ項。放射の微分ではない)。K64 の仕様として直していない。
Emittance[] への影響 (v2): 放射による D 行列が変わり、放射のチューンシフト (1e-5 の桁) が変わる。WSPAC の Emittance[] のチューンシフトで 2e-3 (相対、−4.1386e-3 → −4.1295e-3)、RADTAPER つきのチューンで 1e-5 の桁 (§8 の試験の変更)。大きなリング B の εx は収束値で 6.955407e-9 → 6.955375e-9 (5e-6)。

### 5.1 K64 の新しい誤りの候補 (B 番号は親が付ける)

- **tradke の微分 (photons.f tradke の `irad > 6` の節)**: 上の 4 点。確度: 確定 (写像の 4 次の中心差分と v2 で 1e-10 以内で一致。K64 の式のままだと 5e-7)。
  影響: 放射の減衰行列 D と拡散行列 B (Emittance[]・EMIT の減衰率・エミッタンス・チューンシフト) が、区間が粗いときに 1e-3 程度ずれる。

## 6. 項目 5: K1≠0 の BEND の端の模型 (オプション)

- K64 の `tbende`・`tbendi` は、K1≠0 の BEND の双極磁場を端面 (半径方向から e 回った平面) から、四極 (K1) の磁場を半径方向の入口・出口の面から始める (B1 が厳密な写像 `_exact_map` で確定: CALC は 1e-11 で一致)。
  端面から四極も始まる硬い端の磁石とは、2 つの面の間の楔形の領域 (厚さ x tan e) の四極の蹴りが違う。
- **v2 のオプション `face`**: `compat.set_bend_k1_edge('face')` または環境変数 `PYSAD_BEND_K1_EDGE=face` (v2 だけ。k64 は設定しても常に `radial`)。
  半径方向の入口の面 (入口の端の後)・出口の面 (出口の端の前) に薄い蹴り **Δpx = +K1 tan(e) x²、Δpy = −K1 tan(e) x y** (px は p0 で割った量) を入れる
  (e > 0 では端面が半径方向の面の下流 (入口) にあり、半径方向の模型はこの楔形の領域に双極磁場なしで四極だけを置く。端面から始まる模型はそれを取り除く)。
  実装: `lattice._face_kt` (係数)・`_face_kick_cod`・`_face_kick_jac`、`lattice._bend_k1_cod_matrix` (CALC)、`emit6d._tbende_core` (Emittance[]・CALC の Python の経路)、
  `track6n.k_bendi` (numba の追跡。`rs[2]` = 1 の印)・`track6._tbendi` (Python の追跡)。`face` のときは numba の高速な経路 (`lattice._bend_step_fast`・`emit6d._bende_fast`) を使わない。
- 根拠: ローレンツ力の厳密な写像 (`_p2_indep.exact_map(quad='radial'|'face')`) と、E = 0.5・0.25、K1 = −0.05・0.3、軌道 (x0, px0, δ) の 5 通り (x0 ≤ 3 mm) で、
  `face` は CALC 3e-10 (実測 1.2e-11〜1e-10)・追跡 1e-9 (5e-11〜6e-10)、`radial` は同じ精度で `radial` の厳密な写像と合う。2 つの模型の差は x0 = 1 mm で 1.1e-8、3 mm で 1e-7、K1 = 0.3 で 4.5e-7。
  CALC の行列は厳密な写像の数値微分と 1.5e-7〜2.6e-7 (数値微分の精度) で合う。
- 蹴りは x² に比例するので、**軌道が中心 (x = 0) のリングでは 2 つの模型の Emittance[]・チューンは完全に同じ** (εx が 1e-10 で同じ)。違いが出るのは、軌道がずれた BEND (ステアリング・ずれ・δ ≠ 0 の分散軌道) の写像の x0 tan e の項。
- 使える範囲: K1≠0 かつ ANGLE≠0 の BEND、E1・E2 ≠ 0、DISFRIN=0 (厳密な tbedge を使う v2 の経路)。ずれ・ロールつきの BEND は tchge の内側で効く。
  使えない・未確認: DISFRIN=1 (K64 の薄い端のまま)、K1≠0 かつ ANGLE=0 の BEND・MULT の端、SOL 領域内、RADINT (K1≠0 の BEND の勾配の項に楔形の領域を入れていない)、F1・FB の端 (楔形の領域の蹴りは F1 の断片の外側)。
  放射 (tradke) は楔形の蹴りを偏向角に入れない (蹴りは 1e-9 の量)。
