# v2.3.0 担当 R3: 偏向磁石の 3 次の項 (曲率・硬い端・複合機能の本体・E1/E2) と 6 極の交差項を解析の ADTS に入れる (2026-11-20)

依頼 (ユーザー): 「ADTS は追跡 + FFT の結果と比べて正しさを検証し、未確認の部分で大きくおかしい部分はきちんと追求する。」
R2 は、解析の ADTS (6 極 2 次 + 8 極 1 次 + 運動学的な項 + 四極の端部のフリンジ) が追跡と ASTRID2 で 10〜13%、大きなリング A (kek-ls_v03_12.lat) で 1〜4%、FODO で 3〜9% 違うことを示し、原因を **6 極 × 偏向磁石の曲率 (h/2)x(px²+py²) と硬い端 ±(h/2)px y² の交差項** と特定したが、実装を見送った。R3 でこれを実装し、追跡と比べた。

**結論 (要点)**
1. **偏向磁石の 3 次のハミルトニアン項を、K64 の追跡の写像から取り出して 2 次の摂動に入れた**。`resdrive.adts(bend_cubic=True)` (既定 ON、台本 `AmplitudeTuneShift[BendCubic->…]`)。入れたのは (a) 偏向磁石の 3 次どうしの対の項 `.bend`、(b) 6 極との交差項 `.cross` (6 極の強さに比例)。曲率の項・硬い端・複合機能の本体の K1 h x³/6・E1/E2≠0 の端の 3 次の項をすべて含む。
2. **追跡 (pysad k64 の直接のフィット、70 粒子、1024 周) との相対差 (解析 − 追跡)/追跡 (6 極の強さ ×1、xx / xy / yy)**: FODO −2.7%・+1.6%・+9.5% → **−0.04%・−0.04%・−0.03%**、ASTRID2 +10.9%・+15.3%・−6.5% → **−0.24%・−0.08%・−0.19%**、ASTRID2 MPW +10.9%・+15.1%・−7.8% → **−0.25%・−0.08%・−0.22%**、大きなリング A (kek-ls_v03_12.lat) +0.19%・+1.2%・+3.6% → **−0.014%・−0.017%・−0.26%**。
3. 6 極の強さの走査 (×0、×0.5、×1、×2) で、奇数次 (交差項) と偶数次 (6 極 2 次 + 8 極 + 運動学・フリンジ + 偏向磁石の 3 次どうし) の両方が合う。**残りの差は 6 極の強さに依らない定数** (FODO 0.11〜0.18、ASTRID2 1.1・1.1・2.6、大きなリング A 7.0・6.9・17 [1/(m rad)]) で、四極・複合機能偏向磁石の本体の 4 次の項 (R2 が 6 極なしの追跡で見た差と同じもの) と推定する (未解決。下)。
4. gs (`NORFSW;`) で 3 例 (ASTRID2 ×0.5、FODO ×2、大きなリング A ×2) を追加確認し、gs と pysad k64 は 1e-9 以内 (粒子ごとの同じ追跡)。K64 の誤りは見つからなかった (B 番号の追加なし)。K64 の複合機能偏向磁石の本体の 3 次の項が Maxwell 方程式を満たす形と違う (要判断、下)。

## 1. 方法 (`pysad/bendnl.py`、`resdrive.bend_cubic_adts`)

**考え方**: 1 要素の追跡の写像 M(z) = R z + T(z,z) + … (z = (x, px, y, py)、δ=0、放射なし) の 2 次の部分 T から、薄い kick の 3 次の生成関数 f を求める。kick z → z + τ(z) (τ = T の kick 化) は S∇f = τ (S = [[0,1],[−1,0]] の直和) なので ∇f = −Sτ、f = (1/3) z·∇f (同次式のオイラーの式)。f を位置 s での w = (wx, wpx, wy, wpy) (w = √β e^{iμ}、wp = (i − α)/√β e^{iμ}) で角度・作用の単項式 z^j z̄^k v^l v̄^m (z = √(2Jx) e^{iφx}、v = √(2Jy) e^{iφy}) に展開した振幅 A_jklm を、6 極の厚い要素の `a_all` と同じ規格化 (2^{3/2} を含む) で並べ、**6 極と同じ 2 次の対の項の式 (`_second_order`)** にかける。素子内の位置は線形写像で伝播する。
**T の取り出し**: 追跡 (`track6n.track_particles_fast`、k64 または v2 の現在のモード) の出力を ±z の平均 (偶数次だけが残る) の Richardson 外挿 (振幅 5e-3 と 1e-2、誤差 ~ A⁶) で取る。R は中心差分 (Richardson)。
**偏向磁石の分解**: 全体 = Edge(E2) ∘ B_n ∘ … ∘ B_1 ∘ Edge(E1) (n = `bend_nslice`、既定 16 の等分の本体)。K64 の追跡は E=0 の端でも硬いフリンジ (Maxwell の項、H = ±(h/2) px y² の流れ: 入口 Δx = +y²/(2ρ)、Δpy = −px y/ρ) を持つので、長さ L/n・E=0 の偏向磁石 S = A_out ∘ B ∘ A_in から本体 B = A_in ∘ S ∘ A_out を取り、端は Edge(E1) = A_in ∘ elem(ε, E1, 0)、Edge(E2) = elem(ε, 0, E2) ∘ A_out (ε = 1e-8 m の極薄い偏向磁石) で取る。**n 個の部分偏向磁石の連続は 1 つの偏向磁石と 1e-9 (相対、振幅 1e-3) で一致する** (FODO・ASTRID2・大きなリング A の 3 種、`test_sub_bend_chain_equals_whole_bend`)。スライスの生成関数は中央の座標 (半分の線形写像 R_h を掛けた座標) で表し (対称な分割、誤差 O(ds²))、端の kick は線形部分 R_e の前に置く。
**取り出した結果が解析式と一致する**: E1=E2=0・K1=0 の偏向磁石で、スライスの生成関数は (h/2) ds (x px² + x py²) と一致 (1e-4)、端は ±(h/2) px y² (1e-9)、他の係数は 1e-5 h ds 未満 (R2 が追跡の奇数次から推定した 2 項と同じ)。K1≠0 の本体は (h/2) x (px²+py²) + (K1 h/6) x³ (ASTRID2 の BH で 2e-3 以内。K64 の `bendecorr` の kick Δpx = −K1 h x²/2 と一致)。E1・E2≠0 の端は追加の項 (px²・x px py など、h tan E に比例) と線形の端の写像 R_e を与える。
**DISFRIN**: K1≠0 の偏向磁石 (K64 の tbendi) では DISFRIN=1 で硬い端のフリンジ (Maxwell の項) も切れる (`af`)。K1=0 の偏向磁石 (tbendcore) は常に ON。分解はそれに従う (`test_disfrin_changes_hard_edge_of_k1_bend`: ASTRID2 で DISFRIN=1 の追跡と 6 極 ×1 で xx −0.28%・xy −0.09%・yy −0.25%)。
**採用した理由**: 偏向磁石の解析式 (曲率・E1/E2・複合機能・端) を個別に導くより、追跡の写像から取り出す方が K64 の動作そのもの (K64 の複合機能偏向磁石の本体、E1/E2 の端の非線形) を含み、**追跡との比較が実装の検証になる** (k64 と v2 のモードでそれぞれの追跡から取り出す)。素子の種類ごとに 1 回 (キャッシュ) で、大きなリング A (偏向磁石 800 台) でも `adts()` は約 3 秒。解析式の要素 (厚い 6 極の `_EP` の指数・多項式) とは混ぜずに、偏向磁石は nslice + 2 個の薄い kick の列として s の順に並べる。

## 3. 残った差と原因

- **6 極に依らない定数のずれ**: 追跡 − 解析 R3 (λ = 0, 0.5, 1, 2): FODO (0.11, 0.17, 0.12)・(0.12, 0.17, 0.13)・(0.15, 0.17, 0.18)・(0.25, 0.14, 0.36)、ASTRID2 (1.11, 1.10, 2.55)・(1.11, 1.09, 2.62)・(1.13, 1.07, 2.82)・(1.19, 1.01, 3.63)、大きなリング A (6.98, 6.92, 17.09)・(7.00, 6.95, 17.11)・(7.02, 6.99, 17.14)・(10.0, 5.7, 17.3) [1/(m rad)]。6 極の強さ λ にほとんど依らない (λ=2 の ASTRID2・大きなリング A の増加は追跡のフィットの J の高次)。したがって **6 極と無関係の 4 次以上の項**: 四極本体の写像の 4 次の項 (R2: 6 極・偏向磁石・端部のフリンジなしの FODO で yy が 14% 残る (絶対 0.1〜0.6)) と、複合機能偏向磁石の本体の 4 次の項 (ASTRID2 の 1.1, 1.1, 2.6。DISFRIN=1 でも同じ定数) が候補。**これを解析に入れていない**。ASTRID2 は ADTS の 0.2〜1.3% (6 極 ×1 で 0.1〜0.24%)、大きなリング A は yy の 0.15〜0.37% (絶対 17、xx・xy は 0.02% 以下)。
  四極本体の運動学的な項を K64 の `tqente` のように入口に集約 (または入口・出口の半々) した 1 次の式 (γ の入口の値 × L) も試したが、6 極・偏向磁石・フリンジなしの FODO で追跡 (5.78, 3.25, 4.15) に対して、分布させた式 (5.59, 3.06, 3.90) の差 (0.19, 0.18, 0.25) が入口集約 (5.99, 3.35, 4.23) では (−0.21, −0.11, −0.08) に変わるだけで、どちらも合わない。**四極・K1 つき偏向磁石の本体の 4 次の項は未解決**。
- 偏向磁石の 3 次の項は **δ=0 の写像**から作る。δ≠0 の `adts(delta=δ)` は 3 次の項を入れない (警告)。δ 微分は追跡で求める (R2 の結論のまま)。
- 取り出しは K64 の追跡に対して行うので、モード (k64・v2) ごとに結果が違い得る (K1≠0 の偏向磁石の端 `compat.set_bend_k1_edge('face')` など)。**検証は k64 の追跡とだけ** (gs と一致するモード)。v2 の既定のモードの追跡との比較は ASTRID2 の DISFRIN=1 のテスト (conftest の k64) だけで、v2 の追跡のフィットは未確認。
- K0≠0 の偏向磁石 (挿入光源、ASTRID2 MPW の BMPW 23 台) の内部の軌道の振動・端の非線形は入れていない (警告)。MPW の線形の光学は CALC で入る。λ=1 の MPW は 0.08〜0.25% で合う (R2 の「MPW 内部の非線形 2〜3%」は、実際は偏向磁石の曲率・端の交差項と同じ原因が大半だった)。
- ROTATE・ROTATION≠0 の偏向磁石は入れない (警告)。DX・DY は無視 (誤差なしの設計光学を想定)。F1・F2・FRINGE の指定は取り出しの写像には引き継がない (警告)。
- E1・E2≠0 の端の非線形は FODO (E = 0.0343 rad)、長方形 (E = 0.1309 rad)、非対称 (E1 = 0.21 rad、E2 = −0.079 rad) で 0.1% 以内。端の高次 (4 次) と大きな端角 (E > 0.3 rad) は未確認。
- **K64 の複合機能偏向磁石の本体の 3 次の項 (要判断、B 番号は付けない)**: K1≠0 の偏向磁石の本体は (h/2) x (px²+py²) + (K1 h/6) x³ で、x y² の項はない。By(x, 0) = B0 + B1 x の磁場を曲線座標で Maxwell の方程式 (∂x((1+hx)∂xψ) + (1+hx)∂y²ψ = 0) から導いたポテンシャルは K1 h x³/3 − K1 h x y²/2 (私の導出、未確認)。K64 の `bendecorr` は kick Δpx = −K1 h x²/2 (x³ の係数が半分) だけで y 方向の項もない。SAD の複合機能磁石の場の模型 (K1 の定義、By(x) の x の次数) の仕様が分からないため、誤りとは断定しない。追跡 (K64) と解析 R3 は同じ模型で比べているので ADTS の比較には影響しない。物理の正しさが要る場合は、SAD の複合機能磁石の場の定義を確かめてから、この項を v2 の修正として扱う。
