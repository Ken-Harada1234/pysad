# v2.3.0 担当 R4: 共鳴駆動項 (RDT) の追跡による検証と、偏向磁石の 3 次の項の追加 (2026-11-20)

依頼 (ユーザー): 「ADTS はトラッキング + FFT で求めた結果と比較して、正しさを検証して。未確認の部分で大きくおかしい部分はきちんと追求して」に続き、「RDT (共鳴駆動項) については?」。RDT も ADTS と同じ水準まで検証する。
R2・R3 は ADTS を追跡の直接のフィットと比べて偏向磁石の 3 次の項を入れた。RDT (`resdrive.resonance_terms`) は FODO の 1 周の ΔJ (0.5%)・文献の薄い 6 極の式・3νx = 20 の近くの周期点 (0.15〜1.3%) だけで検証されていて、ASTRID2・大きなリング A・挿入光源つきのリングは未確認、偏向磁石の 3 次の項は h に入っていなかった。

**結論 (要点)**
1. **追跡から RDT を取り出す方法を作った** (`pysad/rdttrack.py`)。リング 1 周の追跡の写像 M(z) = R z + T(z, z) の 2 次の部分 T は各要素の kick の 2 次の部分の和そのもの (2 つの kick の積は 3 次以上) なので、正規化座標で T を有限差分 (±z の平均の Richardson、振幅 1e-5 √m) で取り出すと、1 周の kick の生成関数 f_eff = Σ f_i(R_{0→i} z) が得られ、角度・作用の単項式の係数がそのまま全周の和 h_jklm になる (1 次の摂動で厳密)。δ の項は閉軌道のヤコビ行列の δ 微分 (p=1) と 2 次の閉軌道 (h10002) から取り出す。
2. **6 極の分は追跡と 1e-6 以内で一致した** (FODO・FODO 長方形・非対称・ASTRID2・ASTRID2 MPW・大きなリング A の 6 リング、h21000・h30000・h10110・h10020・h10200 と h11001・h00111・h20001・h00201・h10002、強さ ×1 − ×0 の差)。位相・符号・厚いレンズの積分・規格化は正しい (最悪 2.3e-7)。
3. **偏向磁石の 3 次の項は h の 1.4〜3.4% (FODO)、0.8〜11% (ASTRID2)、MPW で最大 22%、大きなリング A で 0.005〜0.3% あり、6 極のみの解析は追跡と最大これだけ違っていた**。K64 の追跡の写像から取り出した偏向磁石の生成関数 (R3 の `bendnl.py`) を、h に足した (`resonance_terms(bend_cubic=True)`、既定 ON、δ の項 p ≥ 1 は分散による軌道のずれ x → x + ηδ、px → px + η'δ の展開)。足すと追跡 (6 極 ×1 の全体) と **FODO・長方形・非対称・ASTRID2 で 1e-8 以内、大きなリング A で 4e-7 以内、MPW で 5e-5 以内** (MPW の差は K0≠0 の偏向磁石の内部で、入れていない)。
4. **δ の項**: 6 極の分 (h11001・h00111・h20001・h00201・h10002) は追跡 (閉軌道のヤコビ行列の δ 微分、2 次の閉軌道) と 1e-7 以内 (最悪 FODO 4.8e-9、ASTRID2 9.1e-8、大きなリング A 8.9e-8)。薄い 6 極の閉じた式 (導出は docs/49 §9) と `resonance_terms` は 1e-14 で一致。偏向磁石の分 (h11001・h00111 は ξ の偏向磁石の寄与) は、**自然クロマティシティの解析式 (`chromaticity_natural`) + 偏向磁石の分 (`chromaticity_bend`) が CALC の 6 極なしの ξ と一致する**ことで検証した (FODO 3e-3・2e-5、ASTRID2 6e-4・3e-4、大きなリング A 1.4e-5・5.7e-5。偏向磁石の分を入れないと 0.3・0.1 (FODO)、0.08・3.5 (ASTRID2) ずれる)。
5. **3νx = 整数の近くの 3 周写像の不動点**から |h30000| を求めた (FODO・ASTRID2・大きなリング A): 24 セル (または対称性のあるリング) では共鳴は駆動されず (h30000 ∝ ε)、不動点は 6 点でなく曲線になる。J(φ) の 3φ 成分 (正規形の 1 次のリー変換から振幅 2|h|u0/(π a)) から求めた |h30000| は解析 (6 極 + 偏向磁石) と FODO で −0.07〜−0.10%、ASTRID2 で −0.2〜−0.4% (6 極のみは FODO +1.6%、ASTRID2 +8%)。位相は解析と 3π|ε| (正規形のリー変換の位相) の程度の差。
6. **gs (`NORFSW;`) の 1 周の追跡から同じ取り出しをした**: FODO・ASTRID2・大きなリング A で gs の h は pysad k64 の h と 6e-10 以内、解析と 2e-9 (大きなリング A 4.4e-7) 以内。K64 の誤りは見つからなかった (B 番号の追加なし)。
7. **`ref=i` の意味を明確にした**: `resonance_terms(ref=i)` は全要素の位相の基準を変えるだけ (h × 位相)。素子 i から始めた 1 周の写像の h は、i より前の要素の位相に 1 周分の e^{2πi((j−k)νx+(l−m)νy)} がつく (試験で確認)。
8. **偏向磁石の項は h の p=0 だけでなく ξ にも効く**: 自然クロマティシティ ξ_nat = −(1/4π)∮(K1 + h²)β ds + (1/4π)Σ h tanE β (x。y は符号反転で K1 → −K1、h² なし) に偏向磁石の曲率・端の分散の分 (h11001/π) を足すと CALC と一致する。

## 1. 方法

### 1.1 (a) 1 周の写像の 2 次のテイラー展開 (`rdttrack.ring_map`、`rdt_from_map`)
追跡 `track6n.track_particles_fast` (RF・放射なし、δ 一定) の 1 周の写像を、リング先頭の Twiss で規格化した座標 z_n = A⁻¹ z (z_n = (x/√β, (αx + βpx)/√β, y/√β_y, (α_y y + β_y py)/√β_y)) で `bendnl.extract_map` (R: 中心差分の Richardson、T: ±z の平均の Richardson、振幅 amp と 2·amp、誤差 ~ amp⁴) に渡す。1 周の写像は M = R(z + τ_eff(z)) (τ_eff の 2 次の部分 = R⁻¹T) で、`cubic_from_kick` が f_eff を、`harmonic_amplitudes` (w_n = (1, i, 1, i): ζ = x_n − i p_n) が h_jklm を与える。
**振幅**: 大きなリング A (603 m) で amp = 1e-4 は誤差 8e-4、3e-5 で 6e-6、1e-5 で 4e-7 (amp⁴ で減る)。既定は amp = 1e-5 √m (J = 5e-11 m·rad)。FODO は amp 2 倍で 1e-5 以内 (試験)。
**6 極だけの分**: T は kick の和 (線形) なので、6 極の強さ ×1 − ×0 が 6 極だけ、×0 が偏向磁石 (とその他の 2 次の kick)。
**四極端部のフリンジ・運動学的な項 p⁴/8 は h に入らない**: これらは 4 次のハミルトニアン (写像の 3 次) で 2 次のテイラー係数に現れない。実際、追跡の全体 − (6 極 + 偏向磁石の解析) は 1e-9 (FODO)。δ の項でも p=1 の 2 次形式・p=2 の 1 次形式は 3 次のハミルトニアンだけから出る (4 次は p=1 で 3 次形式、p=2 で 2 次形式になる = h21001・h11002 など。入れていない)。
**位相の基準**: リング先頭 (μ = 0)。素子 i から始めた 1 周の写像と比べるときは上の 7 を参照 (`ring_map` に素子を回転した列と rows[i] を渡す)。

### 1.2 δ の項 (`delta_quadratic_total`、`delta2_orbit_h10002`)
閉軌道 z_co(δ) (Newton 法、δ = ±1e-4・±2e-4) でのヤコビ行列 J(z_co; δ) の δ 微分 (中心差分、δ = d と 2d の Richardson) から R0⁻¹ ∂J/∂δ = S Q、g2 = ½ zᵀ Q z (S = [[0,1],[−1,0]] の直和)。**全体** = 四極・偏向磁石の自然なクロマティックな項 + 6 極 + 偏向磁石の曲率・端の分散による分なので、6 極の分は強さ ×1 − ×0。h10002 は 2 次の閉軌道の係数 c2 = ½ ∂²z_co/∂δ² から固定点の式 z* = (1 − R)⁻¹ R S∇g δ² で線形項 g を求める (同様に全体)。
**偏向磁石の分 (p ≥ 1) は追跡だけでは自然な項と分離できない** (J(0; δ) は原点の軌道が分散を持つ (= 6 極なしの ×0 でも偏向磁石の曲率の項を含む)。分散による軌道のずれの分は、K64 の追跡から取り出した偏向磁石の生成関数 f を、分散ベクトル e(s) = (η, η', 0, 0) での展開 (e·∇)^p f / p! にする解析式 (`bendnl.harmonic_amplitudes_shift`、`bend_atoms_rdt`)。分散は入口の Twiss と、スライスの線形写像 + 生成される分散 d_h・d_b (追跡の z=0、δ = ±1e-6 の応答) で伝播し、出口の Twiss と 1e-4 以内で合うことを警告で確認する)。検証は (i) 自然クロマティシティの解析式 + 偏向磁石の分 = CALC の ξ (6 極なし)、(ii) 扇型の偏向磁石 (E=0・K1=0) の曲率の項 (h/2)x(px²+py²) と硬い端 ±(h/2)px y² の、cos/sin の解析的な w・η・η' での中点則の積分 (独立) と原子の和が p=0 で 2e-3、p ≥ 1 で 5e-3 以内 (試験 `test_sector_bend_atoms_equal_independent_integral_of_curvature_and_hard_edge`)。

### 1.3 (b) 共鳴線の近くの不動点 (`periodic_points`、`predict_periodic_J`、`R4_rdt_tracking.py res`)
K1>0 の四極を f 倍して νx = n/3 + ε (3νx = n + 3ε、ε = −2e-3〜−2e-4) にし (その格子で h と ADTS を作り直す)、y=0 の 3 周写像の不動点を Newton 法 (位相 24 通り × 予測の J の 2 つ) で探す。1 周の生成関数 G = 2π[νJ + aJ²/2] + 2|h|(2J)^{3/2} cos(3φ + θ) (θ = arg h30000、a = 共鳴に依らない ∂νx/∂Jx = 解析の合計 − 共鳴の特異部分 −12|h30000|²/(π² ε) (共鳴の項 k = ±(3,0)、n = 3νx に最も近い整数の 2 次の寄与)) から、**リングが k 回対称で 3νx = n が k の倍数でないとき (FODO は 24 セル、ASTRID2・大きなリング A も同様に h30000 ∝ ε)、共鳴は駆動されず 3 周写像の不動点は曲線**になる (6 点でなく 40 個以上が見つかる。R2 の「周期点の J の最小・最大」はこの曲線の J の幅だった)。この曲線 J(φ) の 3φ 成分は、正規形の 1 次のリー変換 W (W = h/(e^{i3μ} − 1)、|W| = |h|/(6π|ε|)) から、J − I = ∂W/∂φ の 3φ 成分の振幅 A = 6|W|(2J0)^{3/2} = 2|h| u0/(π a) (u0 = √(2J0)、J0 = |ε|/a)、位相 arg h30000 (+3π|ε|) になる (J(φ) を k = 1〜6 の高調波でフィットして 3φ 成分を取る)。以前の予測 (3|h|u0/(π a)、cos = ±1) は 2/3 倍だけ違う (観測の比が 0.667 で FODO・ASTRID2・全 ε で一致して気づいた)。非対称なリングの共鳴では 6 つの不動点が J_lo・J_hi を取る (予測式は `predict_periodic_J`)。

### 2.6 偏向磁石の分の独立な確認 (試験)
扇型 (E1=E2=0) の FODO の偏向磁石: 追跡の写像から取り出した原子の和と、曲率の項 (h/2)x(px²+py²) の ds の積分 + 硬い端 ±(h/2)px y² の (x → x+ηδ、px → px+η'δ の展開つきの) 独立な積分 (cos/sin の解析的な w・η・η') が p=0 で 2e-3、p=1・2 で 5e-3 以内で一致する。

## 3. 文献との照合 (δ の項) と導出
H = ½(px²+py²) + … + (K2/6)Re[(x+iy)³] = … + (K2/6)(x³ − 3xy²)、x = (wζ + w̄ζ̄)/2 (ζ = √(2J)e^{iφ})、x → x + ηδ から、薄い 6 極 (積分強さ K2L) で
 h11001 = ¼ΣK2L η βx、h00111 = −¼ΣK2L η βy、h20001 = ⅛ΣK2L η βx e^{2iμx}、h00201 = −⅛ΣK2L η βy e^{2iμy}、h10002 = ¼ΣK2L η² √βx e^{iμx}。
`resonance_terms` (解析・数値積分) と 1e-14 で一致 (FODO の SF・SD を `slice_thin(4)` した薄レンズ列。試験 `test_thin_sextupole_closed_forms_of_delta_terms`)。ξ(6 極) = h11001/π = (1/4π)ΣK2L ηβx は標準的な式 (CALC の 6 極あり − なしと R2 で 2e-3 以内、R4 で 3e-8 以内)。h20001・h00201・h10002 の文献の式 (Bengtsson の SLS の文書の記憶では h20001 = ⅛ΣK2L η βx e^{2iμx} の形) は**記憶に基づく**もので、文献を見て確認していない。符号と因子 1/(j!k!l!m!) は R2 で確認した h21000 などと同じ定義 (pysad の h = −文献の符号)。独立な数値計算は、追跡の 1 周の写像 (正規形ではなく、直接のテイラー展開) と上の閉じた式。

## 4. 残った差・限界・未確認
- **K0≠0 の偏向磁石 (挿入光源) の内部の非線形は入れていない**: MPW の h10020・h10200 が 4.6e-5・2.0e-5、ξy が 0.17 ずれる (MPW の K0≠0 の偏向磁石 23 台)。
- **δ≠0 の追跡の h の偏向磁石の項は入れていない** (警告)。p=2 の偏向磁石の分 (h10002 の偏向磁石の分) は追跡で自然な 2 次の分散と分離できず、独立な積分 (扇型) だけで確認。h20001・h00201 の偏向磁石の分も同様 (ξ の対角の項 h11001・h00111 は CALC と確認)。
- **四次以上の項** (h21001・h11002・h22000 など、運動学的な項 p⁴/8・四極端部のフリンジの分散による展開) は入れていない (6 極の 1 次の 3 次の項と、偏向磁石の 3 次の項だけ)。
- ξ の 2 次以降の解析式 (∂²ν/∂δ² など) と 6 極の 2 次 (K2² の δ 依存。ASTRID2 で ξ に 0.02〜0.03) は入れていない。λ=1 の ξ の解析と CALC の差はこの 2 次の項と、FODO の y 0.007。
- 結合・垂直分散・誤差のあるリングは対象外 (未検証)。v2 モードの追跡は FODO・ASTRID2 で k64 と同様に 1e-6 以内で一致 (取り出しは現在のモードの追跡から行う)。端の 4 次と大きな端角 (E > 0.3 rad) は未確認 (FODO 長方形は E = 0.131 rad)。
- 追跡 (a) の誤差は振幅 amp の 4 乗 (大きなリング A で amp = 1e-5 √m の 4e-7)。(b) は 3νx = n/3 の近くで共鳴の特異部分を引いた a (解析) を使うので、a の誤差 (0.01〜0.3%) と J の高次 (ASTRID2 で aJ ~ 2〜7e-3、大きなリング A で ~ 1e-3) の分、|h| の推定は 0.1〜0.6% 揺れる。非対称なリング (6 個の不動点) の |h| の検証は未実施 (MPW は J_lo・J_hi が 0.7〜3.3% 違う)。
- スペクトルの線 (NAFF) から h を求める方法は未実装 (docs/50 の「方法 3」)。
