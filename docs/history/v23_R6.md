## 2. 直したもの・分かったこと

- **偏向磁石の分解の一般化**: スライス = E=0 の部分偏向磁石の写像そのもの。T (写像の 2 次の部分) は 1 次の摂動で厳密な積分 (kick の和) なので、スライスの生成関数を中央の座標に引き戻した形の和は n に依らず、硬い端 (Maxwell) の対は S = A⁻¹BA = exp(ds·Ĥ) の内部に入る。R3 の A_in の解析式 (原点のまわりだけ) が不要になり、原子の和は R3 と 1e-14 で一致する。端の薄い kick は E1≠0 の極薄い偏向磁石 (1e-8 m) の写像。
- **δ の項の座標**: 追跡の px は正準運動量 (p0 で規格化)。要素ごとの δ の項は、スロープ座標 x' = px/(1+δ) で測らないとドリフトの 1/(1+δ) が入り、全素子の和は CALC の ξ と合うが自然クロマティシティの解析式 (K1/(1+δ)) と二重になる。スロープ座標で測ると四極 1 個が解析式と 4e-7、MPW の全素子の和が CALC と 4e-7・3e-5。
- **δ≠0 の 6 極**: 軌道がずれた 6 極は内部で K1 = K2 x0 の四極 (フィードダウン) として働く。素子内のドリフトの有効長は L/(1+δ) (追跡 x += px s/(1+δ))。
- **四極のフリンジ**は δ に依らない (δ 微分の追跡との比: 1/(1+δ) を掛けると ASTRID2 の xx 6193 に対し 6129、掛けないと 6193)。運動学的な項は /(1+δ)³。
