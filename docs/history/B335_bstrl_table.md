# v2.5.0 記録: ビームストラールングの光子エネルギーの逆引き表 (B335)

日付: 2026-11-23。試験 `pysad/tests/script_tests/test_v250_bstrl_table.py` (6 件)。gs の保存した出力 `pysad/tests/script_tests/scripts/v250_bstrl_table__big.{sad,gs.txt}`。

## 1. 症状

`bbstrhl.f` の `mkbesseltab` (871-903 行) は、光子数のスペクトル dN/dξ ∝ Sw(ξ) = ∫_ξ^∞ K_{5/3}(t) dt を格子 ξ_i = 1.1^40/1.02^i (i = 1..1000、ξ_min = 1.136e-7) で Simpson 積分し (Sw は正確)、累積 SwI(i) = SwI(i−1) + Sw(i)·(x0 − x) を作る。Sw(i) は区間 [ξ_i, ξ_{i−1}] の下端の値 (矩形則。Sw は ξ の減少関数なので各区間で過大)。そのあと SwI(1000) で規格化する (ξ_min より下の裾を捨てる)。`bbstrhl.f:394-410` が乱数 u = xx/rnbs を SwI の二分探索と ln ξ の線形補間で ξ に直し、光子のエネルギー cubs·ρ·ξ とする。

## 2. 確認

### 2.1 表のモーメント

理論値 (scipy の K_{5/3} の数値積分): ⟨ξ⟩ = 0.307920、⟨ξ²⟩ = 0.407407。表から (u 一様、ln ξ が SwI で区間ごとに線形、区間ごとに厳密に積分) 求めたモーメント:

| 表 | ⟨ξ⟩ | ⟨ξ²⟩ |
|---|---|---|
| K64 (矩形則 + 裾を捨てる) | 0.312849 (+1.601%) | 0.418069 (+2.617%) |
| 台形則 (裾は捨てる) | 0.309819 (+0.62%) | 0.410040 (+0.65%) |
| 厳密な CDF を格子の点で使う (裾は捨てる) | 0.309778 (+0.60%) | 0.409906 (+0.61%) |
| v2 (台形則 + 裾) | 0.307971 (+0.016%) | 0.407594 (+0.046%) |

台形則で残る +0.6% は、ξ < ξ_min の光子 (小 x の漸近形 Sw ≈ 2.15 ξ^(−2/3) から ∫_0^{ξ_min} Sw ≈ 3 ξ_min Sw(ξ_min) = 0.031。全体 5.2 の 0.6%) を捨てて規格化するため。

### 2.2 gs

BEAMBEAM (BX = 0.5、BY = 0.01、EMIX = 1e-8、EMIY = 1e-10、SIGZ = 0.005、DP = 1e-3、SLICE = 5、NP = 3e11、BSTRL = 1)、1.7 GeV、TRPT・INS・RAD・FLUC・PHOTONS、`SeedRandom[7]`、4000 粒子 × 7 周で PhotonList は 422 個。エネルギー [eV] が pysad の k64 (K64 の表の再実装) と相対 1.6e-7 以内で一致する (表のどの区間に入る光子も合う)。同じ乱数で v2 は光子の数が同じ (422)、エネルギーの総和が k64 の 0.9838 倍 (1/1.016 と一致)。

## 3. 修正 (v2 のみ)

`beambeam.besseltab()` が `compat.v2()` のとき `_besseltab_v2()` を返す。累積を台形則 (区間の両端の平均) で作り、裾 3·ξ_min·Sw(ξ_min) を全体に入れて規格化 (SwI(1000) = 0.99404)。1001 番目の点を ln ξ が 40 小さい点 (SwI = 1) に置き、u > SwI(1000) の光子は ξ → 0 (エネルギーはほぼ 0)。格子と Sw は K64 と同じ。

## 4. 限界・未確認

- 表のモーメントの厳密な積分と、光子 422 個の gs との一致で確かめた。gs の標本平均 (統計) は取っていない。
- 表の線形補間 (2% 刻みの ln ξ) の誤差は +0.02% 程度 (v2 の +0.016%・+0.046% に含まれる)。直していない。
- BSTRL つきのリングの Emittance・寿命への影響は確かめていない。
- 光子のスペクトルの偏光・角度分布は別 (`photons.f` の `tphotonconv`)。
