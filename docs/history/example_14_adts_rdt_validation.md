### 7.6 比較

- RFSW ON と OFF の差: ASTRID2 の ×0 で xx +11.7 (94.86 対 83.20、+14%)、kek-ls_v03_12.lat の ×0 で 35320 対 878 (40 倍)。
- `NORFSW;` の gs と pysad (RF なし) の ×0 の差: ASTRID2 で 2e-8 以内 (83.20202 対 83.20202)。kek-ls_v03_12.lat の ×0・8 極なしは gs 877.86、pysad 877 (整数まで転記した値)。
- C の解析との差 (gs `NORFSW;`、解析 − gs): FODO −0.012, +0.004, +0.115 (4e-5, 7e-6, 2e-4)、ASTRID2 −0.664, −1.432, +1.976 (1.5e-3, 1.1e-3, 1.8e-3)、kek-ls_v03_12.lat −1.350, −1.997, −1.796 (1.6e-5, 2.7e-5, 1.1e-3)。`NORFSW;` なし (RFSW ON) の ASTRID2 の C は解析より 2〜4% 大きい。
- チューンの 1.1e-5 の差 (kek-ls_v03_12.lat、`NORFSW;` なし) も同じ原因。
- **限界**: RF ON の gs と pysad の ADTS は、NAFF の窓が 1 周ずれる (pysad は初期値を含む) ため 2e-4 だけ違う。RF ON の ADTS はシンクロトロン振動の位相と周数に依るので ADTS の基準値には使えない。一致を確かめたのは k64、δ = 0 の初期条件、RF なし。食い違いは**K64 の誤りでも pysad の誤りでもなく、台本に `NORFSW;` を入れないこと**による。
