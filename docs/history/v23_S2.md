# v2.3.0 の記録: 担当 S2 (周波数マップを信頼して使える状態にする、2026-11-21)

目的: 周波数マップ (`pysad/freqmap.py`) を、(1) 解析・追跡・gs の比較が条件つきで揃い、(2) 既知の不一致に原因の説明があり、(3) 既定の設定で安全な値を返し、(4) 使えない条件で警告を出す、状態にする。
S1 が残した 7 項目 (誤差つき・MPW・RFSW ON/FLUC・v2/k64 の差・D の閾値と周回数・警告・gs との比較) を、複数の乱数の種・複数の強さ・要素の種類ごとの切り分けで調べた。
共鳴線の予想 (`ResonancePredictor` など、RDT・ADTS の部分) は S3 の担当で、触っていない。

コード: 新規 `pysad/fmapcheck.py`。変更: `pysad/freqmap.py` (警告・周回数の換算・スケーリング・K1 の設定の引き継ぎ)、`pysad/fmapres.py` の `apply_alignment_errors` (誤差の種類ごとの乱数の列 `streams='type'`、6 極のロール・8 極のずれ)、
`pysad/trksetup.py` の `from_ffs` (RAD OFF の同期位相、2 行)、`pysad/q1cmd.py` の `FrequencyMap[]` (既定のフラグ、警告の表示)。numba のカーネルは編集していない (`py -3.12 -m pysad.nbcache` は不要)。
試験: `pysad/tests/test_v23_S2_fmapcheck.py` (保存済みの出力を読むものを含む)。例: `example/v2_3/S2_*` (説明 `S2_README.md`、全数値 `example/v2_3/S2_data/*.jsonl`)。解説: `docs/48` §3.2・3.3・3.6・§10、`example/v2_3/FMAP_summary.md` §14。
使ったリング: ASTRID2 (`example/astrid/lattice/ASTRID2_v01_01.sad`、0.58 GeV、45.7 m)、MPW つき (`ASTRID2_v01_02_id.sad` の `RINGMPW`)、KEK-LS (`pysad/tests/kek-ls_v03_12.lat`、3 GeV、603 m、大きなリング A、ESRF 型の HMBA)。
条件: v2、RFSW・RAD OFF (3 項を除く)、LOSSAMPL = 0.1 m、NAFF の窓 Hann (p = 1)、規格化 = 標本の楕円、**小さな格子 21 × 16 = 336 点** (S1 の 41 × 31 の 1 つおき。ASTRID2: x = 0.5〜18 mm、y = 0.5〜14 mm、位置 2。KEK-LS: x = 0.2〜6 mm、y = 0.2〜8 mm、位置 3)、1024 周。
小さな格子の誤差なしの D > −5 の割合は ASTRID2 で 0.030 (41 × 31 では 0.038。336 点の二項分布の誤差 ±0.01)、KEK-LS で 0.142 (失われた点 125 / 336)。誤差の強さの標準 (k = 1): 四極・6 極・偏向磁石・(KEK-LS は 8 極も) の DX・DY 50 μm、四極のロール 0.2 mrad、偏向磁石のロール 0.1 mrad (補正なし。実機の許容値ではなく例)。
K64 の新しい誤り: **なし** (docs/21 に B 番号は付けていない。「`LINE["DX", n] = 値` は同じ名前の全部の実体に効く」は K64・gs の仕様で、誤りではない。§3.7)。

### 3.2 MPW (項目 2)

`S2_mpw.py`、`S2_mpw.out.txt`。MPW の強さ s = 偏向磁石の K0 の倍率。νy の調整は四極 QF3・QF2 の 2 家族の K1 の倍率の Newton 法 (νx は一定)。

|---|---|---|---|---|---|
| s = 0 (MPW なし) | (5.17999, 2.14018) | 0.110 | 0 | 0.030 | なし |
| s = 0.25 | (5.17999, 2.14919) | 0.101 | 8 | 0.384 | なし (y = 14 mm の列) |
| s = 0.5 | (5.17999, 2.17354) | 0.077 | 111 | 0.556 | 10.4 mm |
| s = 0.75 | (5.18000, 2.20816) | 0.042 | 212 | 0.323 | 6.8 mm |
| s = 1 | (5.18001, 2.24920) | 0.0008 | 245 | 0.176 | 5.0 mm |
| s = 1、νy = −0.05 | 2.1992 | 0.051 | 218 | 0.314 | 5.9 mm |
| s = 1、νy = −0.03 | 2.2192 | 0.031 | 244 | 0.272 | 5.0 mm |
| s = 1、νy = −0.01 | 2.2392 | 0.011 | 252 | 0.286 | 5.0 mm |
| s = 1、νy = +0.01 | 2.2592 | 0.009 | 233 | 0.447 | 5.0 mm |
| s = 1、νy = +0.03 | 2.2792 | 0.029 | 207 | 0.450 | 6.8 mm |
| s = 1、νy = +0.05 | 2.2992 | 0.049 | 234 | 0.225 | 5.9 mm |

- **4νy = 9 は原因ではない**: 共鳴の位置 (|4νy − 9|/4 = 0.0008) でも 0.05 離れても、失われる点は 207〜252 で同じ (νy の動かし方に依らず 62〜75%)。失われる点は共鳴の位置と一緒に動かない。
- **MPW の内部の非線形が原因**: MPW を弱めると y の限界が広がる (s = 1: 5.0〜5.9 mm → 0.75: 6.8 → 0.5: 10.4 → 0.25: 14 mm 以上)。MPW の強さを s = 1 のまま νx・νy を MPW なしの値に四極で戻しても 216 点 (64%) 失われる (s = 0.5 は 94 点、28%)。
  線形のずれ (νy が 0.109 動く) ではなく、K0 ≠ 0 の偏向磁石の内部の非線形が y の力学口径を決めている (この MPW の偏向磁石は ANGLE = 0 で、端の角 E1・E2 は ANGLE に掛かるので効かない: E1・E2 を 0 にしても作動点が変わらない (5.18001、2.24920 のまま)。端面のフリンジではなく本体・K0 の運動学)。追跡の ADTS (xx, xy, yy) は MPW なし 471, 1305, 1486、MPW つき 471, 1509, 1712 [1/(m rad)] (R2・R6、docs/49) で、xy・yy が +16% 増えるだけ。
  y の限界が 14 mm 以上から 5 mm に縮むことは、線形の ADTS では説明できず、高次 (K0 ≠ 0 の偏向磁石の端のフリンジ・運動学の高次) の非線形によると考えられる。この高次の項の大きさを解析式で出してはいない (未確認)。
- 実用上: MPW つきのリングは **y ≳ 5 mm で動力学的に不安定** (アパーチャ LOSSAMPL = 0.1 m の外で) で、x–y の周波数マップの y の範囲は 5 mm 以下 (s = 1) に取る。S1 の 41 × 31 の格子 (y = 0.5〜14 mm) の 75% が失われたのはこのため。

### 3.6 警告 (項目 6)

`fmapcheck.check_setup` (追跡の前)・`check_result` (追跡の後)。`frequency_map(warn=True)` が `FMapWarning` を出し、`FMapResult.warnings` ([(コード, 文)])・表の `# warning = `・条件の `warnings` に入る。
`warnings.simplefilter('ignore', FMapWarning)` か `warn=False` で消す。台本 `FrequencyMap[]` は ` FrequencyMap: WARNING [コード] …` を出力する。

| コード | 条件 | 理由 (測定) |
|---|---|---|
| `nturn_short` | nturn < 512 | NAFF の精度、閾値の換算が成り立たない (N = 256) |
| `window_none` | window = 0 | D の下限 −7.95、D > −5 が 5 倍 |
| `rfsw` | RFSW ON | D > −5 が 0.03 → 0.57 |
| `rad` | RAD ON | 0.03 → 0.99、RF なしは δ が下がる |
| `fluc` | FLUC ON | 乱数の種に依る |
| `tune_integer` | 作動点が整数・半整数共鳴の 0.03 以内 | 線形の運動が不安定に近い |
| `tune_lowres` | 2 次の和・差の共鳴の 0.02 以内、3 次の 0.01 以内 | 結合・低次の共鳴で D が大きい領域 |
| `errors` | 要素にずれ・ロールがある | 周期性なし・位置固有、D > −5 が誤差なしの 7〜12 倍 (§3.1) |
| `coupling` | \|c−\| の見積もり > 差の共鳴までの距離の半分 | νx・νy の対応が崩れる |
| `unstable` | 誤差つきの閉軌道まわりの行列が不安定、または閉軌道が求まらない | マップは意味を持たない (以降の判定を止める) |

| `lost_many`・`lost_all` | 失われた点が 20% 超・全部 | D の統計は残った点だけ (失われた点を D 大とみなした割合も出す) |

| `tune_edge` | チューンが 0・0.5 の 0.01 以内の点が 2% 超 | NAFF の分解能と同程度 |

### 3.7 gs との比較・誤差つき (項目 7)

`S2_gs_errors.py`、`S2_gs_errors.out.txt`。ASTRID2、誤差 all ×1、種 1 (`streams='type'`)、位置 2、6 点 (Q1 と同じ x, y)、512 周、NORFSW・NORAD。

- **gs の乱数の種は pysad に渡せない**。SAD の乱数 (`Random[]`・`GaussRandom[]`) は SAD 自身の乱数列、pysad の周波数マップの誤差は numpy の乱数なので、同じ種でも同じ配置にならない。代わりに、pysad で作った誤差の値を gs の台本に明示する。
- 台本に `LINE["DX", 番号] = 値;` と書いても、**同じ名前の全部の実体 (ASTRID2 の QF3 は 12 個) に効く** (gs でも pysad の台本でも同じ。`LINE["DX", 5]` を設定したあと `LINE["DX", i]` を読むと 5 番だけ値があるのに、追跡は 12 個全部がずれたとして走る。QF3 の 1 個に 1 mm で 1 周後の x が +4.1 mm、12 個全部で −15.6 mm)。
  実体ごとの値を書けないので、誤差のある 60 個の実体に固有の名前 (`E<番号>`) の要素定義を作り、全要素を並べた `LINE RINGERR` を台本に入れた (`error_ring`)。誤差を与えた要素 24 + 24 + 12 = 60。
- 結果: pysad の `TrackSetup.track` と台本の追跡は 0.0 (ビット一致)。gs と台本の座標の最大の差 (6 点): 1.6e-15・5.2e-15・3.0e-13・1.4e-12・5.0e-5 (D = −1.7)・1.9e-2 (D = −1.5) m。D は 4 桁一致 (−7.4800・−7.6993・−4.4444・−3.4510・−1.7098・−1.4651 に対し gs は最後だけ −1.4648)。
  カオス的な点の食い違いは、1e-13 m の摂動の増幅と同じ (S1)。閉軌道 (位置 2 の x, y): pysad の Newton 法 (0.29955, −0.24101) mm、台本の CALC (0.29990, −0.24089)、gs の CALC (0.29990, −0.24100)。CALC と Newton 法の 0.1% の差は、K64 の CALC (tsteee) が
  K1 = 0 の偏向磁石の DROTATE を使わず、追跡 (tsteer) は使うため。周波数マップの閉軌道は追跡の写像の不動点 (Newton 法) で、TrackParticles と同じ。gs の終了後に sad1.exe の残りなし。
