## 2. 項目 1: example/07 のスピン角 (500 周後 0.8794 rad 対 1.1516 rad) の原因

### 調べたこと

- 24 セル FODO (3 GeV、RF 4 MV、z=zeq から開始) の 1 周のスピン角: k64 −1.1940907 rad、v2 −1.1935299 rad、差 5.6e-4 rad/周 (500 周で 0.28 rad に積算。`.pysad.txt` と gs の 0.8794 と 1.1516 の差と同じ)。
  軌道は 1e-9 の差しか無い (x 3e-9、dp 3e-9)。つまり座標ではなくスピンの回転が違う。
- A の B56・B58・B64 と K1 つき BEND の修正は、この例では効かない。B56 は tbrote の srot (ずれ・ロールのある要素)、B58・B64 は端の縦磁場 ψ = y/ρ + k x y (y=0 の閉軌道では 0)、
  K1 つき BEND の修正は K1≠0 の要素だけ。この例の偏向磁石は K1=0 でずれもロールも無い。
- 原因は C2 の N8 (sprot の刻みの角): K64 の `sprot` は、運動量の向きの変化の外積 (大きさ sin θ) を中点の pz (≈ cos(θ/2)) で割るので、歳差の角が (1+aγ)·2 sin(θ/2)
  になる。放射の分割 (EPS で決まる刻み、既定では偏向磁石 1 台が少数の刻み) の 1 刻みの偏向角 θ について θ²/24 だけ小さい。v2 は厳密な θ。
- 確認 1 (刻みを細かくする): 偏向磁石に `EPS=1E-5` を付けると、gs (K64) −1.1935395510、v2 −1.1935395636 で、1e-8 で一致する。
  既定の刻みでは k64 −1.1940907 (誤差 5.5e-4)、v2 −1.1935299 (誤差 9.6e-6)。k64 の誤差は刻みを細かくすると 1e-8 まで消え、v2 のほうが 57 倍速く収束する。
  500 周では gs の既定 0.1212 に対し EPS=1E-5 で 0.3969、v2 は既定 0.3948・EPS=1E-5 で 0.3970 (走る例 `example/v2_next/A2_spin_turn.sad`)。
  **例 07 の保存値 0.8794 は K64 の刻みの誤差が 500 周に積算した値**で、物理の値ではない。
- 確認 2 (解析式、要素ごと、`test_v2_A2_spin.py`): 追跡のスピン角の 1 周の変化は、要素ごとの (スピンの回転 = aγ × 運動量の向きの変化 + (向きの変化 − 基準軌道の回転)) の和と合う
  (Thomas-BMT: スピンと運動量のなす角 = aγ × 偏向角、γ は要素の前後の δ の平均のエネルギー)。残差は v2 +9.8e-6 rad/周、k64 −5.5e-4 rad/周 (N8 の大きさ)。
  閉軌道の近くで 1 周の角は 2π aγ (mod 2π) にエネルギーの損失・加速の分 (δ の平均) を足したもの (この例は +0.0114 rad)。
- 確認 3 (K1 つき BEND と ソレノイド): K1 = ±0.05 (tbendi の経路) でも同じ残差が 5e-5 以内。K1 つき BEND と 1 m のソレノイド (BZ = 0、1、2.5 T) のある平面リング
  (0.5 GeV、aγ = 1.135) の 1 周のスピン行列の跡から cos(μ/2) = cos(π aγ) cos(φ/2) (φ = (1+a) bz L) の解析式と 5e-5 以内で一致する。
- 結論: **v2 が正しい。K64 の差は放射の分割の粗さに依る離散化誤差で、v2 に誤りは無い。**

### 使える範囲と条件 / 使えない範囲

- 使える: 偏向磁石・四極・K1 つき BEND の追跡のスピン (POL + RAD) の 1 周の角が、刻みの粗さによらず厳密な Thomas-BMT の角と 1e-5 rad/周で合う。
- 使えない・注意: K1=0 の BEND の追跡 (tbend + tradk) は放射の分割が粗く、刻みの前のエネルギーで歳差を計算するので、エネルギー損失の半分に当たる 2e-5 rad が残る (A の要判断のまま)。
  端の縦磁場 (B58・B64) の項は y≠0 の軌道でだけ効き、ここでは確かめていない (A の `test_v2_A_spin.py` が Emittance[] と追跡の一致 1e-5 を確かめている)。

### 3.2 (b) FLUC つきのスピン追跡との比較 (統計誤差つき)

リング: 12 セルの FODO (`test_v2_A_spin.py` の `_lat`、四極の縦ずれ ±3 mm、閉軌道 y 約 6 mm、RF 調和数 64)。スクリプトは `example/v2_next/A2_pol_fluc_tracking.py` (1 粒子 1 周 4.5 ms の Python 追跡)。
手順 (A の方法に 2 点足した): (1) 高速追跡 (FLUC、スピンなし) で 8000 周かけて平衡の分布を作る (A は閉軌道から始め、平衡に達する前の率を測っていた)、
(2) スピンを n(u) = n0 + N0 u (N0 は v2 の `spin_orbit`) で置き、FLUC つきスピン追跡を n1 = 1500 周 -> FLUC を切って 4500 周で軌道を閉軌道へ減衰 -> 1 − ⟨S·n0⟩ (不可逆な脱偏極 D) を測る、
(3) 同じ粒子で FLUC をさらに 1500 周 (計 3000 周) -> 同様に D を測る。**率は D(3000) − D(1500) から求める**ので、初期のスピンの置き方の誤差・減衰しきらなかった軌道の分 (可逆) は打ち消される。
粒子 120 個 × 2 本 (乱数の種 11・12) = 240 粒子。統計誤差は粒子間のばらつき (標準誤差)。

| エネルギー・RF | スピンチューン (端数) | 追跡で測った D(1500) | D(3000) | 脱偏極率 [/周] = (D(3000) − D(1500))/1500 | v2 の `depol_rate` | v2 / 追跡 |
|---|---|---|---|---|---|---|
| 4.2 GeV、12 MV (種 11) | −0.236 | (1.81 ± 0.25)e-4 | (3.31 ± 0.47)e-4 | (1.0 ± 0.36)e-7 | 2.32e-8 | 0.23 |
| 同 (種 12) | | (1.76 ± 0.22)e-4 | (3.04 ± 0.41)e-4 | (0.86 ± 0.31)e-7 | | 0.27 |
| 合計 240 粒子 | | (1.78 ± 0.17)e-4 | (3.16 ± 0.31)e-4 | **(9.2 ± 2.3)e-8** | 2.32e-8 | **0.25 ± 0.06** |

- 比較: A の記録 (16 粒子、閉軌道から開始、統計 ±25%) は 3 GeV・1.5 MV で v2/追跡 = 1.6、2.903 GeV で 1.2、4.2 GeV・12 MV で 0.53 だった。平衡から始めた今回の 4.2 GeV の測定は 0.25 ± 0.06 (A の 0.53 は 16 粒子・閉軌道から開始で、平衡に達する前の率を含んでいた可能性がある。確かめていない)。
- 結論: **v2 の脱偏極率 (線形のスピン軌道結合) は、低エネルギー (3 GeV 前後) では追跡と 0.5〜1.6 倍で合う (A の 3 例、16 粒子)が、4.2 GeV・12 MV (aγ = 9.5) では追跡の約 1/4 に過ぎない (240 粒子で 4σ)。**
  高エネルギー・大きな RF 電圧ではシンクロトロン側帯 (高次) の共鳴が効き、線形 (SLIM 相当) の式は脱偏極率を過小評価する。
  v2 の `Polarization` はこの領域では上限を与えない (P を実際より高く出す)。使える範囲の目安: 追跡で確かめたのは 3 GeV 前後だけ。ほかの条件は線形の見積もりとして扱い、
  `depol_rate` が小さいリング (P が ST の 92.4% に近い) では追跡 (FLUC) で確かめること。
- 統計: 率の標準誤差は 25% (D の差が 4σ)。本数を増やす (粒子数 ×4、計算 ×4) と ±12%。3 GeV の脱偏極率 (3.4e-11 /周) は 1 周あたりが小さすぎて、現実的な周回数では測れない (A も 4e-7 の 1−⟨S·n⟩ を 12000 周で測った)。

### 3.3 (c) 大きなリングでの妥当性

- τp は §3.1 の表のとおり 1e-6 のオーダーで式と一致 (誤差のないリング)。
- 大きなリング A (3 GeV、603 m、νs の端数 −0.19185) に、鉛直方向の四極のずれを rms 0.1・0.2・0.4 mm (60 台) 入れる:

| rms のずれ | P (v2) | 脱偏極率 [/周] | 脱偏極時間 [s] | n の広がり ½⟨\|Nu\|²⟩ |
|---|---|---|---|---|
| 0 | 0.923760 | 0 | — | 0 |
| 0.1 mm | 0.923357 | 8.8e-14 | 2.3e7 | 1.0e-9 |
| 0.2 mm | 0.922127 | 3.5e-13 | 5.7e6 | 3.8e-9 |
| 0.4 mm | 0.917626 | 1.3e-12 | 1.6e6 | 2.0e-8 |

  脱偏極率はずれの 2 乗に比例する (0.1 -> 0.2 mm で 4.0 倍、0.2 -> 0.4 mm で 3.7 倍。高次の項が入ってくる)。P は 92.376% からずれに応じて下がる (n の傾きによる sdamp の変化と脱偏極率の両方が効く)。
  追跡 (FLUC) の比較は計算が重く大きなリングでは行っていない (小さなリング §3.2 だけ)。

### 3.4 (d) 逆向きの磁場 (挿入光源) のあるリング (P1)

ASTRID2 + MPW (11 周期の K0 の極、K=32.7、B0=2 T) で、v2 に修正を入れる前は P = 92.376%・τ = 28842 s (K64 の追跡 RADPOL の増加率 PST·Σr(b·n) と同じ符号つきの率) だった。
独立な式は P = 0.70163、τ = 21886 s (偏向磁石 BH の ∮ρ^-3 = 2.386 に、MPW の極の ∮\|ρ\|^-3 = 0.755 が加わり、符号つきの和は 0 に近い)。
v2 の修正後: P = 0.70190、τ = 21915 s (3.9e-4、1.3e-3 の差は閉軌道の曲がりと勾配)。
K64 の追跡 (RADPOL、NOFLUC、`TrackParticles`) の緩和率で確かめた: 同じ軌道の上で、n に垂直なスピン (P=0) から立ち上がる率は PST·Σr(b·n) (符号つき) で Emittance[] の sdamp と一致 (3.2028e-5 /s、3.2058e-5 /s)、
n から (P=1) の緩和率は MPW あり 4.75e-5 /s、MPW なし (ASTRID2) 3.62e-5 /s で比 1.311 (v2 の Σr(b·n)² の比 1.315、式の比 1.317)。
追跡の P=1 からの緩和率の絶対値は、ST の式 (1 − PST)/τ より 1.58 倍大きい (ASTRID2 で −4.17e-6 /s 対 −2.65e-6 /s)。MPW あり・なしで共通の係数なので比には効かないが、
K64 の追跡の緩和の定数の意味は確かめていない (要判断)。

### 使える範囲と条件 / 使えない範囲

- 使える: 平面リングの P・τp (1e-5)、逆向きの曲げのあるリングの P・τp (2e-3)、誤差のあるリングの脱偏極率・n の広がり (線形、SLIM 相当。3 GeV 前後で追跡と 0.5〜1.6 倍)。
- 使えない・注意: 4.2 GeV・12 MV (§3.2) では脱偏極率を追跡の約 1/4 に過小評価する。
- 使えない: 高次のスピン軌道共鳴 (シンクロトロン側帯、νs が整数に近い)、運動論的偏極、SOL 領域内の MULT・BEND のスピン (元から)。
  軌道が鉛直方向に曲がる (垂直の偏向) リングや、n が y から大きく傾くリングで緩和率 Σr(b·n)² を使うのが最適かは確かめていない (n と b の成す角が大きい場合の ST の係数 (1 − 2/9 (n·v)²) の項は入れていない)。

## 4. 項目 3: RADINT・Emittance[]・追跡の整合 (大きなリング)

### 4.1 比較の方法

- 自前の計算 `pysad/tests/_a2_indep.py`: 要素表 (L、ANGLE、K1、E1・E2、四極の K1) から 3x3 行列 (x, x', δ) で、周期解の分散 η・Twiss を求め、偏向磁石をスライス (1 m あたり 80 と 160、Richardson) して
  I1 = ∮ηh ds、I2 = ∮h²、I3 = ∮\|h\|³、I4 = ∮η h(h²+2k) − Σ η h² tan e (端、係数 1: A の JX1 の結論)、I5 = ∮ H\|h\|³。六極・八極・ステアリングはドリフト (軌道 0)。平面リングを仮定。
  U0 = Cγ E⁴ I2/2π、Jx = 1 − I4/I2、Jy = 1、Je = 2 + I4/I2、τ = 2E T0/(J U0)、εx = Cq γ² I5/(Jx I2)、σδ = √(Cq γ² I3/(Je I2))、α = I1/C。
- RADINT: `radint.compute` の RI (I1〜I5、I4V) とその式。Emittance[]: `emit6d.emittance6d` (RFSW・RAD、EMITDIV = 1 と 20)。
- 追跡: RAD つき 6 次元追跡の閉軌道 (トラッカーで 6 次元ニュートン) の周りの一周写像 (数値微分) の固有値の減衰から分配数 J = 2E(1−\|λ\|)/U0 (固有値は Emittance[] のチューンの端数で対応づけ)。

## 5. 項目 4: ずれた BEND の CALC (tbende) と追跡 (tbend) の差

### 状況

- 再現: 矩形磁石 (E1=E2=0.5、15 度) 1 台の DX = 2 mm で、CALC のチューンが (νx, νy) = (5.3836953567, 4.2698645878) -> (5.3836683090, 4.2698448750)。
  gs も同じ値 (`example/v2_next/A2_dx_bend.gs.txt`)。追跡の一周写像のチューンは動かない。
- 1 要素で比べると、CALC と追跡の差は x-px・y-py の行列の「ドリフトの長さ」が 2 dx sin(θ/2) = 5.2e-4 m 違うことと、出口の z が +5.2e-4 m (追跡は 0) の違い。
- 原因: K64 の `tchge.f` の `tbrote` (出口): `dz1 = dz·c0 − dx·s0` (入口は `dz·c0 + dx·s0`)。tbende は出口に `phig − phi0 = −θ/2` を渡すので s0 = −sin(θ/2) で
  dz1 = +dx sin(θ/2) となり、`tdrife1(−dz1)` が −dx sin(θ/2) のドリフトになる。追跡の `tbshift` の出口は +dx sin(θ/2) のドリフト。
  厳密な幾何 (下) と合うのは後者。出口の (dx1, dz1) も、入口と同じ「中点の座標の (dx, dz) を出口の座標へ回す」R(phig)(dx, dz) = (dx c0 − dz s0, dz c0 + dx s0) にすれば直る (K64 の出口は両方の s0 の符号が逆)。
- 根拠 (追跡も SAD も使わない): 硬い端の厳密な幾何。磁石を、弦に垂直な方向 (中点の x 方向) に dx だけ平行移動した帯の中の円弧として、名目の出口の平面上の位置・傾きを求める。

## 6. 要判断・残した項目

| 項目 | 見つけたこと | 残した理由 |
|---|---|---|
| K1≠0 の BEND の CALC と追跡 | 軌道が x0 = 1 mm ずれると x-px 行列が 1e-5 (DX と無関係) | どちらが厳密か、K1 つき BEND の厳密な幾何の独立な計算を持っていない。tbendi と tbende の 2 次の項を追う必要がある |
| v2 の脱偏極率が追跡より小さい (高エネルギー・大きな RF 電圧) | 4.2 GeV・12 MV で追跡の 1/4 (§3.2)。高次の側帯共鳴 | 線形理論の外。シンクロトロン側帯の項を入れるには、K64 の spdepol の式の導出か、側帯の高次の摂動が要る |
| 追跡の ST の緩和率 | P=1 からの緩和が、立ち上がりの率から期待される (1−PST)/τ より 1.58 倍速い (ASTRID2、NOFLUC、n に垂直な始点からの立ち上がりは式どおり) | K64 の追跡の dst の式の意味 (定数) を確かめていない。Polarization (Emittance[]) には使っていない |
| RADINT の K0 の極 (R4) の εx・Jx | Emittance[]・追跡と 3.5%・0.7% 違う | 極の中の分散の伝搬の近似 (扇形の行列)。基準軌道を曲げない K0 の場の正確な積分は、CALC の Twiss の行列の取り方を変える必要がある |
| 結合リングで νy ≈ νs のときの J | 追跡・Emittance[] の Jy・Je と RADINT が 0.015 ずれる | モードが混ざり分配数が定義できない条件 (νs・放射を変えると追跡の J が変わる)。RADINT の誤りではない |
| Polarization の緩和率 (P1) | n が y から傾く・非平面のリングで Σ r(b·n)² が最適か | ST の厳密式 (1 − 2/9(n·v)²) の項を入れていない |
