# v2.3.0 の記録: 担当 T2 (Touschek 寿命の式: どちらが正確か。独立な第三の方法での確定、2026-11-21)

依頼: T1 で「pysad (SAD K64 の `touschek_f` の式) と elegant (`touschekLifetime`、Piwinski の式) が −4.3〜+2.4% 違う (結合と δ で変わり、比 0.89〜1.18)。どちらが正確かは第三の独立な方法で確かめていない」とした課題を**解決**する。
結論を先に書く。

| 問い | 答え |
|---|---|
| どちらが正確か | **elegant (Piwinski) が正確。pysad (K64 の式) が不正確** (結合 1% で +0.1〜+6%、10% で +1〜+14%、丸いビームで −14〜+21%。寿命が長すぎる・短すぎる両方向)。独立な式 (§2) は、3 次元の一般の積分と、厳密な相対論の運動学の対のモンテカルロに 0.3% 以内で一致し、**elegant とは −1.6〜+0.3% (elegant の損失率が少し大きい。標本化を細かくしたとき) で一致**、K64 だけが違う |
| K64 の式の何が違うのか | 損失率の関数 `touschek_f` の当てはめ (±1%) ではなく、**x-y 面の運動量の広がりを「平坦ビームの 1 次元の関数に、固有値の和 ptrans² = tr(P) を入れる」近似** (§4)。結合が小さければ小さい誤り (λ2/λ1 ≈ 2% で寿命 +4〜+6%)、結合が大きいと大きい誤り |
| elegant 側の近似 | **要素の出口だけで局所の損失率を標本化し台形則で積分する**ため、要素が粗いリングで寿命が長めに出る (ASTRID2 で +2.0〜+4.8%、KEK-LS で +0.7%)。要素を 8 分割して標本化すると収束する (32 分割と 0.04%)。残る −0.3〜−1.3% (elegant の損失率が大きい。大きい a・丸いビームで大きい) の原因は未特定 |
| 直したもの | 新しい関数 `touschek.touschek_piwinski` (v2 の `TouschekLifetime[INF, INF, nz]`・`TouschekLifetimeLMA[]` の**既定**。`Formula->"K64"` と `PYSAD_COMPAT=k64` は K64 の式) |
| B 番号 | **B162** (`docs/21`) |

## 1. 比べたもの (同じビーム・同じ光学・同じ一様な受容)

- ビーム: pysad の IBS 込みの収束値 (`Emittance[]`、`INTRA`、`PBUNCH`、`MINCOUP`)。elegant には εx (EMITXC)・εy (EMITYC)・σδ (SIGE)・σz (SIGZ) を渡す (T1 と同じ)。pysad の 6 次元のビーム行列の不変量 (エミッタンス・σδ・σz) は、この値と 4 桁で一致する (6 スライスで確認)。
- ラティス: ASTRID2 (`example/astrid/lattice/ASTRID2_v01_01.sad`、0.58 GeV、周長 45.704 m、RF バケット δ_rf = 1.618%)、KEK-LS (`pysad/tests/kek-ls_v03_12.lat`、大きなリング A。ESRF 型の HMBA、3 GeV、周長 603 m、δ_rf = 2.994%)。誤差なし、RFSW・RAD ON。
- 受容: 一様な δ = ±a (ASTRID2: 0.4・0.6・1.0・1.6%、KEK-LS: 0.4・0.6・1.0・2.0%)。結合: MINCOUP = 0.01・0.1・1 (εy/εx = 1%・10%・100%)。電流: PBUNCH = 1e6・1e9・3e10。
- 3 つの方法: (1) pysad の K64 の式 (`TouschekTable`、`touschek_lifetime(table, None, None, a/σδ, σδ)`、表の点なので補間誤差なし)、(2) elegant 2026.4.0 の `touschekLifetime` (WSL。光学は全要素を 8 分割、§3.2)、(3) 独立な式 (§2、`touschek_piwinski`)、その検証に 3 次元の一般の積分 (`T2_check3d.py`) と実験室系の対のモンテカルロ (`T2_mc.py`)。

## 2. 独立な式の導出

ビームの 6 次元ガウス分布 (実験室系の共分散 Σ。位置 s のスライス中心の値) から出発する。

1. **静止系へ**: x* = x、y* = y、z* = γz (ビームの重心系で z が γ 倍)、運動量 p* [mc 単位]: px* = px p0、py* = py p0、ps* = δ p0/γ = βδ。K64 の `trans2` と同じ写像 (自分で導いて確かめた: `twissbuild.rest_from_lab`、K64 の xx・pl と一致)。
2. **同じ位置の 2 粒子**: 粒子 1・2 の位相空間の点 w1, w2 が独立に N(0, Σ)。重心 c = (w1 + w2)/2 と相対 r = w1 − w2 は独立 (cov(c, r) = (Σ − Σ)/2 = 0)。衝突には相対位置 x_rel = 0 が要る。このとき相対運動量 q = p1 − p2 の分布は N(0, 2P)、P = Σ_pp − Σ_px Σ_xx⁻¹ Σ_xp (**位置を固定したときの運動量の共分散**。分散の傾き η'・x-y 結合・z-δ の相関はすべてここに入る)。重心の δ は N(0, σδ²/2)。位置の積分は ∫n² d³x = N²/V*、V* = (4π)^{3/2} √det(xx*)。
3. **散乱**: 質量中心系で非相対論的な Møller 断面積 (スピン平均)
   dσ/dΩ = (r0²/(4β*⁴)) (4/sin⁴θ − 3/sin²θ) = (4 r0²/k⁴) K(θ)、k = |q| (mc 単位、β* = k/2)
   (Rutherford + 交換 + 干渉項。同種粒子なので、事象は半球にだけ数える)。静止系の時間の 1/γ で実験室系の率になる。
4. **損失**: 受容 a+・a− に対し、散乱で δ が a+ より増える、または −a− より減る (**kick の基準**: 粒子のもとの δ を 0 と見る。Piwinski・elegant・K64 も同じ。最も近い粒子の対応で、前方散乱の発散を避ける)。1 事象で失われる粒子の数 = L1 + L2。
   1/τ_inst = (r0² c N/(γ V*)) 2 ⟨k⁻³ ∫_半球 K(θ) [I(k|g| > 2β a+) + I(k|g| > 2β a−)] dΩ'⟩_{q ~ N(0,2P)},  g = n'_s − û_s (û = q/k)
   (3 次元の一般の式。`T2_check3d.py`)。
5. **1 次元の式** (q_s = 0、すなわち ps* の広がり βσδ が x-y の広がり √λ より十分小さい極限。KEK-LS・ASTRID2 で 3 次元と 1e-3 以内): n' の方位角の積分は閉じた形 (∫dφ K = 4π/μ³ − 2π/μ、μ = n'_s) で、散乱後の s 成分が μ k/2 ≥ βa を満たす分の立体角が
   W(κ) = 2π [κ² − 1 − ln κ] (κ = k/(2βa) ≥ 1)
   動径の積分以外は x-y 面の方位角の積分だけで、P の x-y ブロックの固有値 λ1 ≥ λ2 (mc² 単位) と α_i = 1/(4λ_i) で Bessel I0 になる:
   1/τ_inst = r0² c N / (γ V* √(λ1 λ2)) Σ_± J(2β a±),  J(c) = ∫_c^∞ dk k⁻² W(k/c) e^{−k²α1} I0e(k²(α2 − α1)/2),  I0e(z) = e^{−z} I0(z)
   リング全体: 1/τ = Σ_スライス (al/C) · 1/τ_inst (スライスは K64 の tintrb の分割。`touschek_table(record_rest=True)` が各スライスの xx・pl・Σ を記録する)。
   実装: `touschek.touschek_piwinski` (k の対数を 40 区間 × 16 点の Gauss-Legendre。`scipy.special.ive` は z ≳ 1e10 で nan を返すので漸近展開を併用)。

近似・仮定 (限界は §7): 非相対論的な Møller (CM 系の β* ≲ 0.03、補正 O(β*²) ≈ 1e-3 以下)、kick の基準 (δ_old = 0)、q_s = 0。

## 3. 結果

### 3.1 式の検証 (独立な 2 つの数値積分)

`T2_validate.py` (`T2_validate_astrid2.out.txt`・`T2_validate_kekls.out.txt`): ASTRID2・KEK-LS、結合 1%・100%、各 3 スライス、受容 2 点。
- **3 次元の一般の積分 / 1 次元の式 = 0.9993〜1.0003** (準モンテカルロの統計誤差 1e-3 以内)。q_s ≠ 0 (σδ/γ)・x-y-s の非対角・位置の依存をすべて入れても変わらない (KEK-LS で σδ/a = 0.19 でも 1e-3 以内)。
- **実験室系の対のモンテカルロ (厳密な相対論の運動学) / 1 次元の式 = 0.9969〜1.0003** (ほとんど 0.998〜0.999。受容が大きい (δ_rf 付近) ほど −0.2〜−0.3%、静止系の非相対論的な近似の補正)。このモンテカルロは z* = γz・ps* = δ/γ の写像、q_s = 0、非相対論的近似を使わない。
- elegant のスライスごとの局所の損失率 (FP) と、Twiss から作った Σ での独立な式の比 (ASTRID2、一様 0.4%、全 1407 点): 0.973〜0.998、平均 0.995 (elegant が 0.5% 大きい)。

### 3.4 解析式との比較

`T2_limits.py` (`T2_limits.out.txt`):
- **平坦ビームの極限** (λ2 → 0): 1 次元の式 J(c) √(π α2) c² は、Bruck・Piwinski の関数 π D(ε)/√ε (ε = x = c² α1。D(ε) = √ε [−3/2 e^{−ε} + ε/2 ∫_ε^∞ (ln u/u) e^{−u} du + 1/2 (3ε − ε ln ε + 2) ∫_ε^∞ e^{−u}/u du]。**D の式は記憶に基づく** (Handbook of Accelerator Physics の Touschek の節。出典の原文は未確認)) と 6 桁で一致 (x = 1e-5〜3)。独立に導いた式が文献の関数に一致したことは、数値積分との一致とは別の確認。
- **K64 の当てはめ `touschek_f`**: f(x) π x / g(x) − 1 (g = π D/√x) = −0.002 (x = 1e-2)、+0.004 (0.1)、−0.007 (1)、+0.010 (10)。x = 1e-6〜10 で ±1%。**当てはめの誤りは寿命の差の主因ではない**。
- 丸いビーム・弱い結合の解析式 (Le Duff・Bruck の別の式) は、記憶に頼れず比べていない (数値積分との一致だけ)。非相対論的な極限は式に入っている (§2 の仮定)。

## 4. K64 の式の差の原因 (近似を 1 つずつ置き換える)

`T2_cause.py` (`T2_cause_astrid2.out.txt`・`T2_cause_kekls.out.txt`)。ASTRID2・KEK-LS のスライスごとの損失率を次の式で作り、寿命を比べる (E3 は TouschekTable の値と 1e-4 以内で一致 = 再現が正しい):

| 式 | 内容 |

| E0 | 独立な式 (x-y の 2 固有値 λ1 ≥ λ2) |
| E1 | 平坦ビームの極限の厳密な関数 (D(ε))、λ1 だけ |
| E2 | E1 と同じ関数、**K64 と同じ ptrans² = tr(P)** |
| E3 | **K64 の当てはめ** `touschek_f`、ptrans² = tr(P) (K64 の式の再現) |
| E4 | K64 の当てはめ、λ1 だけ |

| 100% (1.6%) | 161723 | +14.3% | +15.7% | +15.8% | +14.3% |

- **E2 ≈ E3 (0.2% 以内)**: 当てはめの関数は厳密な平坦ビームの関数と同じ (§3.4)。差の原因は**関数ではなく、x-y 面の運動量の分布の扱い**。
- **E1・E2・E3・E4 が E0 から違う**: K64 は運動量の相対分布を 1 次元 (平坦ビームの関数) とし、小さい方の広がり λ2 を ptrans² = tr(P) = λ1 + λ2 + λ3 を通してしか入れない。厳密には q の x-y 面の分布は 2 次元ガウス分布 (固有値 λ1, λ2) で、Bessel I0 を含む式になる。結合 1% でも λ2/λ1 は ASTRID2 で 2% 程度あり、λ2 の効きが +4〜+6% の寿命の差になる。丸いビーム (λ2 = λ1) では 1 次元の関数が成り立たず、受容が小さいと −14%、大きいと +16% (a が大きいと、散乱角の大きい高いエネルギーの末が効いて、2 次元の分布の裾の形に敏感)。
- そのほかの近似は効かない: **分散の傾き η'・x-y 結合・z-δ の相関** (K64 も位置を固定した運動量の共分散 P を使う。独立な式も同じ P を使い、3 次元の積分で q_s・非対角を入れても 1e-3)、**s 方向の運動量の広がり** (σδ/γ。3 次元の積分で 1e-3 以内)、**IBS の取り込み** (K64 も独立な式も同じ IBS 込みの 6 次元のビーム行列を使う。IBS の電流を 1e6〜3e10 で変えても差が変わらない)、**ビーム行列の違い** (pysad のビーム行列と Twiss から作った Σ の寿命の差は 0.2%)。
- **elegant 側の近似**: (1) 要素の出口だけの標本化と台形則 (§3.2、+0.7〜+4.8%)。(2) 8 分割した標本化でも残る −0.1〜−1.3% (elegant の損失率が大きい)。受容が大きい・丸いビームで大きい。原因は特定していない (Piwinski の式の導出での相対論的な近似の違いが候補。式の中身は確かめていない)。(3) ビームの分布は x-y 非結合のガウス分布 (εx, εy, σδ, σz、局所の β・α・η・η' から Σ を作る) で、pysad のビーム行列と寿命で 0.2% 以内。

## 5. 判定と修正

**判定**: K64 の式 (pysad) は、結合 1% のリングで寿命が +0〜+6% 長く、結合が大きいと ±20% ずれる。**elegant の式 (Piwinski) が正確** (独立な式と標本化を細かくして −1.25〜+0.1%)。pysad の式を直す。

**実装** (`pysad/touschek.py`):
- `touschek_table(..., record_rest=True)`: 最終パスの各スライスの静止系のビーム (`xx`・`pl`・`pp`・実験室系 Σ・`al`・`l`) を `result['rest']` に記録 (FFS の INTRA ON の `Emittance[]` は常に記録。K64 の表・値は変えない)。
- `touschek_piwinski(result, a=None, ap=None, am=None)`: 一様な a、または要素ごと (長さ nlat の配列) の δ+・δ− の寿命。`piwinski_slice_rate`、`_piw_J`。
- `lma.touschek_lifetime_local_piwinski(tt, lma, ...)`: 局所の LMA (`touschek_lifetime_local` と同じ補間)。
- 台本: `TouschekLifetime[INF, INF, nz, Formula->"K64"|"Piwinski"]`、`TouschekLifetimeLMA[Formula->...]`。

**既定の決定: v2 の既定を Piwinski 型にする。k64 は K64 の式 (gs と同じ)**。理由: (1) 式の差が最大 ±20% で、v2 の方針 (正しい物理が既定、K64 の再現は k64) に当てはまる。(2) 検証が 3 つの独立な方法 (解析式の極限・3 次元積分・厳密な運動学のモンテカルロ) と elegant で一致し、K64 だけが違う。(3) 局所の LMA の寿命も同じ式で出せる。**範囲**: v2 の既定になるのは運動量の受容だけ (nx = ny = INF) の寿命。**横の振幅の受容 (nx か ny が有限) と EMIT の報告 (`TouschekTable` の寿命の表) は K64 の表のまま** (新しい式は運動量の受容のみ)。
`Formula->"K64"` で表に戻せる。既存の試験 (k64 が既定) は変わらない。Q1・T1 の記録の値 (局所の LMA の寿命 ASTRID2 9502 s・KEK-LS 26876 s) は K64 の表の値で、v2 の既定の台本では変わる: Piwinski 型は ASTRID2 9327 s (−1.8%)、KEK-LS 26862 s (−0.05%) (`T2_lma_lifetime.py`、LMA の表は Q1・T1 の保存済み。T1 の elegant の局所の LMA の寿命 9069 s・27117 s は粗い標本化の値なので、細かくすると短くなる)。

## 7. 未確認・限界・要判断

- **kick の基準** (粒子のもとの δ を 0 と見る) は、Piwinski・elegant・K64・独立な式のすべてが共通。バンチ内の δ の分布 (σδ) を入れる (受容を a − δ_old に変えて平均する) と損失率は増える。概算 (`T2_limits.py`、δ_old ~ N(0, σδ²) を q_s と無相関に入れた値): ASTRID2 a/σδ = 9・14・23・36 で +5.4・+2.5・+1.0・+0.4%、KEK-LS a/σδ = 5・8・13・27 で +21・+8.6・+3.3・+1.0%。小さい受容 (a/σδ ≲ 10) では 5〜20% 損失率が増える可能性がある。厳密には、「もとの δ が受容の近くの粒子の小角散乱」は IBS (拡散) と区別できず (前方の発散)、Touschek の定義の問題。**4 つの式とも入れていないので、比較には影響しないが、絶対値の限界**。要判断 (入れるなら δ_old と q_s の相関を入れた定義が要る)。
- 1 次元の式は q_s = 0 の極限。σδ/γ が x-y の広がりに近づく低エネルギー・大きいエミッタンスでは 3 次元の積分 (`T2_check3d.py`) で確かめる (KEK-LS・ASTRID2 では 1e-3 以内)。非相対論的な Møller の近似は β* ≲ 0.03 (受容 3% 以内) で 0.3% (モンテカルロ)。
- elegant の残る差 (−0.1〜−1.3%、elegant の損失率が大きい) の原因は未特定。elegant の式の中身 (Piwinski の B1・B2・τ の定義) は読んでいない。
- 新しい式は誤差なし・結合の小さいリングで確かめた (ASTRID2・KEK-LS、結合 1・10・100%)。誤差・挿入光源・SOL つきのリング、陽子の `MASS`・`CHARGE` (古典半径の扱い、B112) は確かめていない。偏極 (elegant の `-polarization`) は入れない。
- 損失率の積分の標本化は K64 の tintrb のスライス (ドリフトは 1/4・1/2 に分割、磁石は要素の中央)。elegant の粗い標本化の誤差 (§3.2) と同様の離散化誤差が pysad にもあるはずだが、ASTRID2 で pysad (229 スライス) 427.07 s と elegant の細かい標本化 (1407 点) の Twiss から作った独立な式 427.83 s が 0.2% で一致 (標本化の差は 0.2% 以下)。
- K64 の `TouschekTable` の他の使い道 (横の振幅の受容 nx・ny、EMIT の報告) は K64 の式のまま。
- 近似の精度: 一様な a の局所の寿命の計算は、a/σδ ≳ 10 で独立な式の精度 0.3%。
