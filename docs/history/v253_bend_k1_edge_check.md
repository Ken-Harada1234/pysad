# K1≠0 かつ E≠0 の偏向磁石の閉形式の確認 (2026-11-28)

- 目的: docs/25 §11.8 の未確認「端の閉形式は K1≠0 かつ E≠0 は未確認」を確かめる。
- 方法: FODO (3 GeV) の B に K1・E1・E2 を足し、`bendnl.bend_analytic_h3` (閉形式) と `bendnl.bend_atoms` (追跡の写像から取り出した原子の和) を比べた (3 次の全単項式の最大の相対差)。計算は 2 スレッド、低優先度。
- 結果: v2 は 1e-6 以内 (最大 6e-7)。k64 は E1≠0 で 5.6e-3、E2≠0 で 6.3e-4 (K1 = 0.1)。k64 の薄い端 (track6.py の `v2edge` が v2 だけ厳密な端) による。
- 試験: `pysad/tests/script_tests/test_v253_bend_k1_edge_closed_form.py` (6 件)。R6 の試験とあわせて 21 件通過。
- 未確認: K1 が大きい場合 (ASTRID2 の 1e-5 の原因)、積分器の式との照合、k64 の薄い端の閉形式。
- 追加 (同日): 解析の ADTS (`adts(fourth='r6')`) と追跡 + NAFF + フィットの直接値の比較。FODO + 6 極で v2 は 1e-4 以内、k64 も 1.2e-4 以内。K1 = 0.2・E = 0 の Jmax = 1e-7 の 6.9e-3 の差は追跡の J² の寄与 (Jmax を下げると収束)。試験は同じファイルの 3 件 (合計 8 件)。
