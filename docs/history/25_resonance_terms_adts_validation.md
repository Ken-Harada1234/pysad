# 共鳴駆動項・ADTS・クロマティシティの検証の詳細 (K64 (gs) との比較)

本文 [../25_resonance_terms_adts.md](../25_resonance_terms_adts.md) から移した、K64 (gs) との比較の記述。元の文書: 49_resonance_terms_adts.md。見出しは元の節。

## §6 FODO の項

- 小さな FODO (3 GeV、105.6 m、νx = 6.696329、νy = 4.906056、SF・SD の K2L = 4, −6): 解析 (323.410、−474.023、496.072 [1/(m rad)]) と pysad の追跡 (k64) の C が 4e-5・7e-6・2e-4 以内。**gs (SAD K64) の追跡の C も 4e-5・7e-6・2e-4 以内** (1024 周、[`example/v2_3/Q2_adts_gs_fodo.txt`](../../example/v2_3/Q2_adts_gs_fodo.txt))。

## §6 ASTRID2 の項

- ASTRID2 (0.58 GeV、45.7 m、νx = 5.179990、νy = 2.140178): 解析と pysad の追跡の C が 1.5e-3・1.1e-3・1.7e-3 以内 (J = 2e-8。J → 0 で解析値に近づく: J = 2e-9 で 5e-4)。gs (台本に `NORFSW;`、1024 周) の C (440.97、1296.00、1125.57) も解析と 1.5e-3・1.2e-3・1.8e-3 以内、×0 の ADTS は gs 83.2020、pysad 83.2020。(`NORFSW;` なしだと gs の空洞が働き、×0 は 94.9、C は解析より 2〜4% 大きい。§5 の注意)

## §6 大きなリング A の項

- 大きなリング A (kek-ls_v03_12.lat、3 GeV、603 m、νx = 47.580034、νy = 17.620044、J = 2e-10): 6 極 2 次 (86841、−75099、−1610) と 8 極 1 次 (−36905、32480、−7154) が pysad の追跡の C・B と 2e-5・3e-5・1e-3 (6 極)、4e-6・8e-6・2e-5 (8 極)。gs の 8 極の B (−36890、32480、−7154) は解析と 4e-4・1e-5・2e-5、gs の全部入り (×1) は pysad と 3e-4・4e-6・0。gs (`NORFSW;`、1024 周) の 6 極の C (86842、−75097、−1608) は解析と 2e-5・3e-5・1e-3、×0・8 極なしの ADTS は gs (877.9、2073.7、2484.8) と pysad (877、2074、2485) が一致。(`NORFSW;` なしの gs は ×0 で 35320 など別の値になる。追跡の周数にも依る)

## §7 表の下

gs の直接のフィットは pysad と 1e-10 (ASTRID2 MPW は 1e-5)。運動学・フリンジを含まない (6 極 2 次 + 8 極 1 次) との差は FODO +26%・−13%・+5%、ASTRID2 +7%・+1%・−24%、大きなリング A +1.5%・−3.7%・−34%。

## §8 6 極の強さの走査の後

gs (`NORFSW;`) との確認 (ASTRID2 ×0.5、FODO ×2、大きなリング A ×2): gs と pysad k64 は 1e-9 以内、解析 − gs は ASTRID2 −0.67%・−0.24%・−0.45%、FODO −0.018%・−0.008%・−0.019%、大きなリング A −0.003%・−0.002%・−0.15%。

## §9

**gs**: gs の 1 周の追跡 72 点 (`NORFSW;`) から同じ取り出しをした h は pysad k64 と 6e-10 以内 (FODO・ASTRID2・大きなリング A)、解析と 2e-9 (大きなリング A 4.4e-7) 以内。

## §10.5

- gs の 1 周の追跡 (360 点、`NORFSW;`) から取り出した $h_4$ は pysad k64 と FODO で 1e-8 以内 (最悪 7.6e-9)、ASTRID2 で 2e-8 以内 (最悪 1.75e-8、h20200)、解析との差は FODO 1e-4〜、ASTRID2 1e-4〜1.3e-3 (`R5_gs_map_{fodo,astrid}.gs.txt`)。
