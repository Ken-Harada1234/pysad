# v2.3.0 U1: B160 (K1≠0 の BEND の本体の K1 の定義) の切り分け

2026-11-20。担当 U1。読み取りと独立な数値計算だけで、pysad のコードは変えていない。T1 (`v23_T1.md` §6) が「K64 の誤りの候補 B160」とした
「K1≠0 の BEND で、勾配の力に曲率の因子 (1 + h x) が掛からない」を、K64 のソース・SADHelp・導出・独立な数値積分で調べた。

## 1. 結論

| 項目 | 結果 |
|---|---|
| K64 の BEND (K1≠0, ANGLE≠0) の本体は何を実装しているか | 中央面の磁場 B_y(r, 0) = B0 + (K1/h) ln(r/ρ0)、B_r = K1 y ρ0/r (h = 1/ρ0, r = ρ0 + x) の中の運動の写像 (x の級数は u³ の項まで)。すなわち (1 + h x) ∂b/∂x が一様 (r ∂B/∂r が一様)。これは ∇×B = 0 と ∇·B = 0 を厳密に満たす 2 次元調和場で、x y² の項を持たない |
| 勾配の定義 | 「磁場の x 微分が一様 (B' 一様)」ではなく、「曲線座標の勾配 (1 + hx)·∂b/∂x が一様」。B''(ρ0) = −h B'(ρ0) (elegant の K2 = −h K1 に相当) |
| 独立な数値積分との一致 | K64 (pysad の追跡、gs と 1e-13 で同じ) の 16 台の写像が、'log' 場のローレンツ力の厳密な積分と 1e-10 (振幅 5 mm、δ = 0・±0.4%、DISFRIN=1) で一致。'lin' (B' 一様) とは 1e-5〜1e-4 違う |
| 判定 | **誤りではなく K1 の定義の違い** (B' 一様ではなく (1 + hx)∂b/∂x 一様)。実装は自分の定義の中で厳密 (内部の不整合はない)。T1 の「(1 + hx) が掛からない誤り」は、定義を (a) B' 一様と取ったときの見え方だった |
| 確度 | 実装の同定 (K64 = 'log' 場): **確定** (ソース・導出・独立な積分 1e-10・MULT (ANGLE) の別経路が同じ値)。「定義であって誤りではない」: **中〜高** (SADHelp の BEND の K1 は B' L/Bρ としか書かず B'' を決めていないが、MULT (ANGLE≠0) の K1 は A_s の展開で明示され、独立な実装 (tbendcore + 多極キック) が BEND の K1 の本体と 1e-12 で同じ dν/dδ を与える) |
| v2 の扱い | 既定は変えない (K64 の定義が仕様)。elegant・MAD 系との変換には K2 = −h K1 が要る (§6)。「B' 一様」の定義が要るなら、新しいオプション (§7、要判断) |

## 3. SADHelp の記述

ローカルの `Documents/SADHelp.html` (BEND の K1 の項) と同じ内容の CERN の SADHelp:

- BEND の K1: 「The normal quadrupole magnetic field component (times the length L)」。式は K1 = B' L/Bρ、「L はアーク長に沿う有効長、正は水平収束」。**B' が x に一様か曲線座標か、B''(ρ0) は何かは書いていない**。BEND の変換の節は、K1≠0 では E1・E2 を薄い四極で近似し、本体を細かく割って K1 のキックを交互に当てると書く (古い記述で、実際の tbendi は上記の補正つきの本体)。
- MULT (ANGLE≠0): 「multipole_with_nonzero_ANGLE」の節に、多極の定義が A_s(x, y) = Σ g_kn (Kn + i SKn)/(n + 1)! (ρ + x)^{1/2−k} (x + iy)^{n+k}/√ρ、g_kn = −(2k−1)!!(2k−3)!!(n+1)!/(8^k (n+k+1)! k!) として明示されている (ρ = L/ANGLE)。「MULT の K0・K1 は BEND と違う」とも書く。**この展開から K1 の中央面の磁場を解析的に導いて 'log' 場と照合することは、式の指数 (x + iy)^{n+k} の読み (印刷が n+k+1 の可能性) が確定せず、していない**。照合は数値 (§5.5) だけ。
- 「K1 = B'」を曲線座標の B' 一様と明示する記述はない。

## 4. 導出

規約: x は外向き、h = 1/ρ0、b(x, y) = B/Bρ0 (規格化した磁場、運動量 p = 1 + δ の粒子)、px・py は方向余弦、中央面の b(x, 0) = h + K x + ...。扇形磁石で E1 = E2 = 0。

**運動方程式** (曲線座標の厳密な式、傾きは小さくない): px' = h pz − (1 + hx) b/p、x' = (1 + hx) px/pz。
(1 + hx) b が力の項である (弧長の因子 (1 + hx) と、磁場の項 b そのものの積)。

**磁場の 3 通りの定義**。静磁場・軸対称・∇×B = 0 から、中央面の g(r) = B_y(r, 0) が決まれば B_y = g − (y²/2)(g'' + g'/r) + ...、B_r = y g' − (y³/6)(g'' + g'/r)' + ... (ラプラス方程式 φ_rr + φ_r/r + φ_yy = 0)。K1 = g'(ρ0)/Bρ0 は共通で、g''(ρ0) だけが違う:

| 模型 | g(r) | g''(ρ0) | (1 + hx) b の x の 2 次 | y の依存 |
|---|---|---|---|---|
| 'lin' (B の勾配が x に一様。elegant CSBEND K2 = 0) | h + K1 (r − ρ0) | 0 | K1 h x² | B_y に −(K1/2r) y²: **x y² の項あり** |
| 'log' ((1 + hx) ∂b/∂x が一様。r ∂B/∂r が一様) | h + (K1/h) ln(r/ρ0) | −h K1 | K1 h x²/2 | g'' + g'/r = 0 なので y² の項なし |
| 'pow' (磁場指数 n が一様。B ∝ r^−n) | h (ρ0/r)^n | −(n+1) h K1 | | |

(1 + hx) b の展開: 'log' は K1 x (1 + u/2 − u²/6 + u³/12 − u⁴/20 …) (u = hx)、'lin' は K1 x + K1 h x²。

**3 次の項** (ハミルトニアンの位置エネルギー Φ(x, y)。Φ_x = −(1 + hx) b、Φ_y = (1 + hx) b_x (b_x = B_x/Bρ0 = B_r/Bρ0)):
- 'lin': B_r = K1 y、B_y ⊃ −(K1 h/2) y² → Φ の 3 次 = −K1 h (x³/3 − x y²/2) (符号は H = −Φ に依る)。T1 の「K1 h x³/3 − K1 h x y²/2」と一致。
- 'log': B_r = K1 y/(1 + hx) → Φ_y = K1 y (x に依らない)、B_y に y² なし → Φ の 3 次 = −K1 h x³/6 だけ。K64 (R3 の bendnl が追跡の写像から取り出した生成関数) の「(K1 h/6) x³ のみ、x y² なし」と一致。
- 差 'lin' − 'log' = K1 h (x³/6 − x y²/2) = 強さ K2 = h K1 の6 極 ((K2/6)(x³ − 3 x y²))。**CSBEND に K2 = −h K1 を足すと K64 に一致する**という T1 の観察の理由。

### 5.5 MULT (ANGLE≠0) の K1 との比較

同じリングで BEND を MULT (L = 1、ANGLE、K1、K0 なし) に置き換えると、pysad の dν/dδ は (−0.1721326, +0.2108185) で、BEND と 1e-12 以内に一致 (本体の道が違う: MULT は tbendcore の純粋な偏向 + 曲率つきの多極キック)。SADHelp が A_s で明示的に定義する MULT の K1 が BEND の K1 の本体と同じ磁場であることを示す。δ = 0 のチューンも同じ。

## 6. 判定

- (a) B' が曲線座標の x に一様 ('lin') なら K64 は「定義とずれる」: **×**。独立な積分は K64 と −0.17213・+0.21082 に対し −0.60251・+0.73789 で違う。
- (b) 曲線座標の勾配 (1 + hx)∂b/∂x (= r ∂B/∂r) が一様 ('log') なら K64 は正しい: **○**。dν/dδ・非線形の写像・3 次の項のすべてが 1e-10 〜 1e-8 で一致。
- K64 の実装に内部の矛盾はない (y の x への結合、運動量依存、δ = ±0.4% まで)。SADHelp は BEND の K1 を B' L/Bρ としか言わず B''(ρ0) を指定しない。MULT (ANGLE) の K1 は A_s の展開で定義され、BEND の K1 の本体と一致する。以上から **B160 は「K64 の誤り」ではなく「K1 の暗黙の定義 (B'' = −h B')」**。elegant・MAD 系の CSBEND/SBEND の K1 (B' 一様) と同じ記号でも同じ磁石ではなく、**SAD → elegant の変換は K2 = −h K1 を足す** (T1 が使った)。
- 物理として正しいかは、実際の磁石の B''(ρ0) 次第 ('lin' が理想的な直線勾配の極、'pow' は磁場指数一定の極、'log' は K64 の調和場。B'' の違いは hB' x²/2 の大きさ)。**K1 だけでは B'' が決まらない**のが本質で、設計値の入力が B' (K1) だけなら、SAD は B'' = −h B'、elegant は 0 を暗黙に選んでいる。
- 確度は §1 の表。

## 7. v2 で直す場合 (要判断) の方針案

直すのではなく**定義のオプション**になる。推奨: 既定は K64 のまま、文書化 (docs/11 に定義を追記) だけ。「B' 一様」の BEND が要るときのためのオプション案:

| 項目 | 内容 |
|---|---|
| 'lin' の実装 (本体のカーネル) | 'lin' = 'log' + 6 極 K2 = +h K1 の補正。`tbendicorr` (`track6.py`・`track6n.py` `k_bendi`) の x の kick の級数 K1 x² h (½ − u/6 + u²/12) を K1 h x² (1 の係数 1、級数なし) に変え、y の項を足す: px −= K1 h (x² − y²/2)/p 相当、py += K1 h x y/p 相当 (積分値を L で割らずに単位を揃える。差の kick は −(K1 h/2)(x² − y²) と +K1 h x y。§5.3 の係数と整合) |
| 解析行列 | `tbende.f` の `tbendecorr` の dk を 'lin' の導関数に (xr に比例する項)、y・x–y の行列要素 (行 px–y、行 py–x・y) を足す。`perfkern_bend.py` `bendecorr`、`lattice._bend_k1_cod_matrix`、emit6d の呼び出し |
| MULT (ANGLE≠0) | A_s の K1 の定義はそのまま (SADHelp の仕様) |
| オプション | `compat.set_bend_k1_def('log' | 'lin')` の形 (既定 'log' = K64、k64・v2 とも既定は変えない)。elegant の K2 の対応は変換スクリプト (`T1_sad2ele.py`) の K2 = −h K1 の注記 |
| 影響範囲 ('lin' を選んだとき) | δ≠0 のチューン (色収差 ξ、∂²ν/∂δ²): 0.4 の複合機能で ξ が 3.5 倍違う、ASTRID2 の自然な ξy は 'log' −11.8 に対し elegant −8.2。LMA・DA・クロマティック ADTS (追跡・NAFF): 変わる。ASTRID2 の LMA は T1 で影響なし。δ = 0 の光学・エミッタンス・放射積分: 変わらない。`bendnl.py` (R3) は追跡の写像から 3 次の生成関数を取り出すので、追跡を変えれば自動で追従 (K1 h x³/6 → 3 次の項が変わる)。R4 の `resdrive.chromaticity_bend` (分散による軌道のずれの展開) も同様 |
| 試験 | `test_v23_U1_bend_k1_field.py` の 'lin'・'log' の独立な積分が基準 |

## 8. 副次の発見 (小さい)

- `tbende.f` の `tbendecorr` (87 行、`perfkern_bend.py` 83 行) の行列の dk = −K1 xr (1 − xr (1 − 2 xr)) は、同じ関数の kick (86 行) の導関数 −K1 xr (1 − xr/2 + xr²/3) と **xr の 2 次の項が違う** (xr = 0.001 で −0.05%、xr = 0.1 で −3.5%、xr = 0.3 でたまたま一致)。写像と行列の不整合 (CALC・Emittance[] の転送行列だけ。追跡は影響を受けない)。影響は、スライス 1 cm、K1 = −0.06 /m²、xr = 1e-3 で 3e-10 (t[1,0]) と小さく、リングのチューンで 1e-8 程度以下と見積もる (全体の量は見ていない)。B 番号を付けるほど確かでも重要でもないので「B161 候補、低、未確認」とする。直していない。
