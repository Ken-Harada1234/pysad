# v2.4.0 記録: 放射・エミッタンス (DDBA_15 の差、極の RADINT、EMITDIV の既定)

2026-11-22。試験: `pysad/tests/test_k64_tcod_notfound.py`・`test_v24_rad_pole.py`、独立な計算 `pysad/tests/_rad_indep.py`。

## 1. DDBA_15 の εx の gs との 0.33% の差 (原因を特定して直した: B163)

- 条件: DDBA_15 (5 GeV、周長 731.4 m、RF 7 MV、6 極 600 台、等時セル + 逆曲げ BEND 80 台)、`ON RAD FLUC COD RFSW RADCOD; cell calc emit`。
- 切り分け: (1) 6 極を 0 にした同じリングは gs と全桁一致 (逆曲げ BEND は無関係。ANGLE を 0・1e-10・符号反転にしても一致)。(2) 6 極 ×1 で差が出る。ノーマルセルだけのリング (`RINGM`) でも出て、6 極の強さを 0.5 倍にすると出ない (0.8 倍から出る)。(3) gs の出力に `???-Emittance[]-closed orbit not found.` があり、gs の `Stable` は 0。pysad (k64) は出ていなかった。
- 原因: K64 の `tcod` は、RFSW ON の最初の Newton 法で運動量の誤差が大きい (`abs((dz-dtrf0*v0)*dvcacc/pgev)+abs(ddp) > dpthre`) と横方向の修正 `dcod(1:4)` を 0 にする。その `dcod` で r が下がらないと、`fact` を半分にしながら同じ `dcod` を使い回し、`fact < fmin` で `fndcod = .false.` のまま終わる (横方向の残り 28 σ が残る)。`temit` はメッセージを出して、その (ほとんど動いていない) cod から Emittance[] を計算する。pysad は `tcod` を直訳していて同じ所で止まるが、止まった後に 6D 固定点を Newton 法で解く別の経路に入り、本当の閉軌道の値 (9.632e-10) を出していた。gs の値は収束していない軌道での値 (9.6006e-10)。
- 確認: 収束した値は設計者のメモの値 9.6310e-10 と 0.01〜0.06% で合う (その SAD では収束している)。k64 に「収束しなければその cod から続行、メッセージを出す」を入れたら、εx・σE・αc・U0・減衰率が gs と全桁一致 (DDBA_15: 9.60063327e-10 対 9.60063327e-10。`RINGM`: 6.27329883e-10 対 同じ)。
- 変更: `emit6d.closed_orbit6d` (k64 で tcod が見つからなければ収束していない cod を返す)、`emit6d._emittance6d` (`cod_found`)、`ffscmd.run_emit` (メッセージ)。v2 は変えていない (固定点を解く。メッセージなし)。
- 未解決: gs の `tcod` のこの停止は K64 の設計上の限界 (再スタートがない)。v2 が固定点を解くのは、この停止を避けて物理的に意味のある値を返すため (gs と合わせない)。

## 2. v2 の Emittance[] と RADINT (極の εx・Jx、矩形磁石)

独立な計算 (SAD・pysad の光学を使わない): (a) 3x3 行列で I1〜I5 (極は直線の基準軌道の場: η'' + kη = h)、(b) (x, px, δ, z) の放射つき 1 周写像 (RK4、薄い空洞、端の角は 1 次) + 量子励起の Lyapunov 方程式。

- ASTRID2 + MPW (0.58 GeV、周長 45.7 m): 従来の RADINT の εx は 1.09305e-8、独立な積分は 1.07018e-8、RF なしの Emittance[] (EMITDIV = 20) は 1.07012e-8。RADINT が +2.1% 違った。原因は 2 つ: (1) 極の中の分散の伝搬を扇形磁石の行列 (幾何学的な収束 h²、I4 の h³ の項あり) で近似、(2) RADINT は CALC の分散 (rows) を各要素の初期値にするが、K64 の CALC は極の分散の発生 (η' += K0 δ) を入れない (`etpx` が極の出口で変わらない)。
- 修正 (v2、`radint.py`): 極は `bmag_pole` (直線の基準軌道の中の場: 水平 kx = k、η'' + kη = h。I4 の被積分は 2 K1 h η だけ)。極があるとき、1 周目で要素ごとの 4x4 行列と極の分散ベクトルを集め、周期解の補正 Δ = TΔ + V_pole を解いて、2 周目で各要素の分散の初期値に足す。結果: I1・I2・I3・I4・I5 が独立な積分と 5e-5 以内 (従来 I1 4e-3、I5 2.1e-2)、εx 1.07021e-8、Jx 1.29618 (独立な積分 1.29618)。k64 は変えていない (極を積分に入れない K64 の動作)。
- RF あり Emittance[] との差: RF あり (RFSW + RADCOD) の Emittance[] は Jx が +0.0092、εx が −1.4%。小リング (16 セル、1 GeV、K0 = 0.06・−0.12・0.06 rad の 3 極) で、RF なし Emittance[] = RADINT = 独立な積分、RF あり Emittance[] の Jx 0.7040 は独立な 4 次元の写像 (空洞つき) の 0.7038、チューン (x 0.38954、z 0.03404) も 1e-5 で一致。RF の位置の分散が効く物理的な効果 (K0 の極が RF の位置の η' を作る)。RADINT は RF の位置に依らない理論なので一致しないのが正しい。
- 矩形磁石 (SP8 型) の 1.4e-3 (v2.2.0 の P2): EMITDIV の既定 (1) の離散化の誤差で v2 の誤りではない (P2 で確定済み)。ここで独立な 4 次元の写像でも確認 (3 節)。

## 3. EMITDIV の既定と、RF が分散のある場所にある矩形リングの +1.7e-3

- 16 セルの小リング (1 GeV、QF D B D QD D、RF を先頭 = 分散のある場所、E1 = E2 = 0 と 0.5·ANGLE): v2 の Emittance[] (EMITDIV = 20) のビーム行列 (x, px, δ, z) が独立な 4 次元の写像 (RK4 + 空洞 + 量子励起の Lyapunov、端の角は 1 次の蹴りと行路の短縮) と、σxx・σδδ・σzz・σxδ で 3e-5〜1.6e-4 で一致 (扇形 0.99994、矩形 0.99997 (σxx))。EMITDIV = 1 では矩形の σxx が +1.36e-3。v2.2.0 の「独立な 6x6 (`_c3_indep.coupled_equilibrium`) と矩形で +1.7e-3」の差は、EMITDIV = 1 の離散化の誤差 (+1.4e-3 と同じ大きさ) と考えてよい (6x6 の側の近似は決められていないが、v2 の誤りでない)。
- EMITDIV の走査 (v2、RFSW + RADCOD、EMITDIV = 20 を基準): 大きなリング A (3 GeV、603 m) εx +2.17e-2 (1)・2.7e-3 (2)・2.2e-4 (4)・1.4e-5 (8)、PF +2.2e-3・1.4e-4・9e-6・6e-7、ASTRID2 は 1e-6 (差なし)、DDBA_28 +1.9e-4 (1・2)・6.5e-5 (4)。実行時間 (EMITDIV = 4): 0.1 s 以下。
- 判断: **v2 の既定を 1 から 4 にした** (`compat.emitdiv_default()`)。k64 は 1 のまま (gs と全桁一致のため)。台本が EMITDIV を与えればその値 (EMITDIVB・EMITDIVQ の既定は 1)。環境変数 `PYSAD_EMITDIV_DEFAULT=1` で戻せる。
- 例外: POL ON のスピンの計算は既定 16。線形の脱偏極率 (4.2 GeV・12 MV の 12 セル FODO) は EMITDIV = 1 で 2.314e-8、2 で同じ、4 で 2.249e-8、16 で 1.958e-8、64 で 1.868e-8、200 で 1.886e-8 で、偏向磁石の刻み (EMITDIV·EMITDIVB) だけに依り、EMITDIVQ には依らない。刻みの端の値で d ベクトルを積算する離散化で、収束値より EMITDIV = 1 は +24%。64 以上では εx が壊れる (200 で 2 倍。未調査)。RADTAPER ON の閉軌道は k64 でも収束した軌道 (`closed_orbit6d(k64_continue=False)`、tcod の直訳は RADTAPER OFF だけ)。
- 互換への影響: k64 の試験・回帰は変わらない。v2 の試験のうち EMITDIV = 1 を前提に数値を持つもの、`example/ddba/results_v2.json` などの v2 の記録値は、既定の変更で 1e-4〜1e-3 動く (全試験を通して確認)。

## 4. 未解決・限界

- AE のある極の放射の 2.7% (B143): 独立な 4 次元の写像 (端の角は 1 次) との比較で、v2 の ΔJx は AE = 0.1・0.3 rad で ±1.1% (符号が逆転) で一致した。1 次の模型の限界 (tan² e の 1〜10%) の範囲で、2.7% の有無を決められない。決めるには硬い端の厳密な幾何 (面との交点を求める積分) で独立な計算を作る必要がある。
- RF の位置の分散による Jx の変化は Emittance[] が正しく含む。CALC の分散 (Twiss の EX・EPX) が K0 の極の分散の発生を含まないのは K64 の動作で、v2 でも直していない (チューン・クロマティシティ・光学に波及するため。RADINT だけ補正)。

## 5. 第 2 弾 (追加方針の残り)

- B143 (AE のある極): 硬い端を実験室の直線座標で厳密に積分する独立な 4 次元写像で、v2 の ΔJx は厳密より AE = 0.1 で +1.0%、0.3 で +2.0%、チューンは 8e-5・9e-4 違う (AE² に比例)。放射の入れ方は正しく、原因は K64 の端の模型の AE の 2 次の違い。直さない。
- tbrote の srot・tbendebody の bsi2 (k64): gs で確認した (傾いた BEND は全桁一致、K1≠0 の BEND は PolarizationTime が 6.5e-9)。
- POL の EMITDIV: 偏向磁石の刻みの離散化誤差と特定し、POL ON の v2 の既定を 16 にした (1 節 3 の例外)。
- 実施していない (理由): B136 の B∥ (全要素の本体の改修。影響は py≠0 のスピンだけで、k64 は K64 を再現する)。BEAMBEAM の傾き (B34): 強ビームの x-y 結合の共分散を独立に作って 2 次元ガウスの場の数値積分と比べる必要があり未実施 (共変性の試験のみ)。SynchroBetaEmittance のシンクロ・ベータ共鳴、Polarization の追跡 (FLUC) との確認 (6 MV・24 MV・PF・大きなリング A): 6D FLUC 追跡で統計誤差 0.5% にするには 1 条件数時間〜十数時間の CPU が要り、この作業では走らせていない。
