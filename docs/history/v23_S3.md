## 0. 指示の経過 (途中で変わったこと)

1. 当初: R6 の道具で共鳴線の予想を作り直し、J² の項は「追跡から求めたチューンを使う方法」も可、判別力をスコアで評価、5 次以上の原因を特定、信頼度のフラグ。
2. 追加 1 (ユーザー): **追跡に合うように補正項をどんどん足すのは違う**。摂動論の定義された次数 (RDT は 3・4 次、ν(J) は ADTS、幅は振り子の式) から原理的に作り、当てはめの項・経験的な重みは足さない。改善しなければ「改善しなかった。理由は…」と書く。
   → **開発の途中で入れていた「追跡のチューンの規則的な点から J² の項を最小二乗で当てはめる `fit_tunes`」を削除した** (最初の実装。残していない)。追跡のチューンは `predict(nu=...)` の診断 (ν(J) の誤差の効果を測る) にだけ使う。
3. 追加 2 (ユーザー): 物理として有意な効果は足してよいが、0.1〜0.3% の端数合わせはしない。`adts()` の既定は V2 で物理的な項だけ (`fourth='r3'`・`optics='calc'`) に戻る予定 → S3 は `adts(fourth='r3', optics='calc')` を明示して呼ぶ。

足した項 (原理的な理由): 4 次の h の**非共鳴の 3 次の摂動の補正** (R6 の `rdt4_normal_form`、BCH から導かれる F4' = F4 + ½{R⁻¹W, W}。共鳴線の近くの実効的な駆動項は写像の係数 F4 ではなく F4' だから)。島の幅 W の J ごとの G0 (J² の項がないので定数)。
足さなかった項: ν(J) の J² (解析式が無い。追跡の当てはめは方針で足さない)、次数 5 以上の駆動項 (解析式が無い)、幅の経験的な係数 (R5 で c を絞る試験をしたが、予想には入れない)、重なり (カオス) の D の大きさの式。

## 2. 分かったこと・結論

- **改善したのは MPW (AUC 0.66 → 0.79) と ASTRID2 の AUC (S1 0.51 → 0.68) だが、振幅だけのスコアには及ばない (ASTRID2)**。ASTRID2 の cov は 0.40 → 0.42 で、領域の面積 25% の対照 (0.25±0.16) と有意に違わない (p = 0.23)。R5 と同じ「改善なし」。
- 非共鳴の補正 (R6 の原理的な項) は、ASTRID2・KEK-LS・MPW の AUC に ±0.03 以内の効果しかない。駆動項の値は変わる (h20110 は 4.6 → 91) が、D の大きい点の判別には効かない。つまり R5 の仮説 (補正の入れ漏れが主因) は**否定された**。
- 残る仮説のうち、データで支持されたのは (i) 次数 5 以上・どの線にも近くない点が D > −5 の半分前後 (ASTRID2 52%、MPW 69%) で、駆動項が入っていない、(ii) 島の中は規則的で、D の大きい点は島の縁・重なりにあり、島の位置・幅 (摂動論で予想できる) と D の大きさ (カオス) は別の量、(iii) KEK-LS は大振幅で ν(J) が外れ、共鳴が重なる。(iv) ν(J) の J² は FODO だけ主因。
- 帯が広い (νx−νy ≈ 3 の帯が格子の 30%) 仮説: 島の幅 W は 0.044 だが島の中の点の D は小さい。帯に入っていること自体は D の大きさを区別しない。

## 3. 使えない範囲・未確認

docs/49 §12.7 と FMAP_summary §13.8 のとおり。主なもの: δ ≠ 0、5 次以上の駆動項 (数値の正規形の拡張: 4 次のテイラー展開 + Dragt–Finn の次の段が必要、未実装)、J² の項、PF・SP8 への適用、評価に使った表が 4 つ (D > −5 は 44〜124 点) で AUC の誤差の見積もりをしていない。MPW はずらしの対照が不適切 (失われた点の穴)。

## 4. S2 の記録との整合

S2 は MPW の損失 (νy = 2.2492 が 4νy = 9 の 0.0008 以内) を調べている。S3 の MPW の予想は生き残り 321 点で評価し、(0,4) の島 (4νy = 9) の予想は D > −5 の cov 0.05 (面積 0.012) で有意でない。**4νy = 9 が失われる点の原因という S2 の記録を S3 の予想は区別できない** (予想は 4 次の h00400 の W = 0.068 の島を出すが、損失の大きさ・位置を決める量ではない)。
