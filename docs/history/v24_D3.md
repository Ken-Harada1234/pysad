# v2.4.0 D3 記録: スピン・放射・SOL の残り (B230〜B239)

2026-11-22。担当 D3 (前任 D の未着手・未完の項目)。k64 は変えない。試験: `pysad/tests/test_v24_D3_spin_bpar_magnets.py`・`test_v24_D3_rad_rf_sol.py`。独立な基準: `_spin_maxwell_indep2.py` (直線の磁石の Maxwell 場の Thomas-BMT)、`_rad_beta_indep.py` (Ring4B)。表は docs/21 の B230〜B239。

## 1. 磁石の本体の運動量の向きの磁場 (B165 の範囲拡大。B230・B231・B235)

- 基準: 直線の磁石 (QUAD・SEXT・MULT・ステアリング) の Maxwell 場 (スカラーポテンシャル Φ = Σ_j c_j G^(2j) r^(2j) P_n、c_(j+1) = −c_j/(4(j+1)(j+m+1))、G = f(z) f(L − z) のソフトな端、w = 8・4 mm の w² 外挿) の中の運動方程式と Thomas-BMT の数値積分。0.5 GeV・L = 0.4 m・入口の座標 (2, 3, 2, 3) mm。
- **原理 (和が 0)**: 静磁場の全 ∫B·dr (端 + 本体) は 0。K64 は QUAD・MULT・BEND で端の ψ (入口 +、出口 −) だけ足して本体を足さない → −Δψ が残る。SEXT (L ≠ 0)・ステアリングは K64 が端も本体も入れないので和が 0 で元から正しい (追跡の誤差 2e-8、確認済み)。
- QUAD: k = 1 で R01 の誤差 1.0e-5 → 3e-9 (追跡)、Emittance[] も 1e-8 以下。MULT (K1・K2、K0 つき) も 6.5〜9e-6 → 3e-9。実装: 追跡は `_tsolqur_ens` で刻みごとに `p.bpadd` = Δψ/(1+δ)、MULT は K64 の bsi を全次数の ψ (入口・刻みの途中・出口) に置き換え、Emittance[] は `st.bpot` を `_tquade`・`_tmulte` で設定 (BEND と同じ hook)。前任の「numba 核で入らない」は、POL の Emittance[] は Python の経路 (`fast = ... and not POL_MODE`) なので、実際は hook が効く (numba 核は POL で使われない)。
- **B231**: tsolqur の `bsi` は入口で `= akk x y`、最後の刻みで `= −akk x y` と代入するので、刻みが 1 つ (ndiv = 1) の四極は入口の +ψ を落とす。v2 は足す。
- **追跡の BEND の R12・R21 (1e-2)**: 前任は「端の ψ を刻みの中点の向きで分解する K64 の近似」と推定したが、実際は刻みに比例する 1 次誤差。刻みの偏向角 0.087 → 0.017 → 0.0035 rad (EPS = 1・0.2・0.05) で R12 が 1.2e-2 → 2.7e-3 → 5.4e-4、R21 −1.3e-2 → −2.9e-3 → −6.0e-4 と比例し、Emittance[] (EMITDIV = 256 → 1024 で 3e-4 → 1e-4) も同じ。スピンを回転ベクトルで回した後に座標系の回転を掛ける K64 の `sprot` の分け方 (回転と歳差の交換子) の 1 次誤差。座標系の回転を先に掛ける・歳差のベクトルを回す (交換する順序・角を変える) 変種を試したが 2 次精度の分け方は見つからず (どちらも誤差が一定の割合で動くだけ)、刻みを細かくする方法を採用: POL ON の追跡の `_ndivrad` で 1 刻みの偏向角を 5e-3 rad 以下にして R12・R21 を 6e-4 にした (v2 のみ)。a = 0 では一致の確認だけ (座標が小さいと区別できない)。
- 試験: `test_body_bpar_tracking_and_emittance` (quad1・quad8・mult・mult_k0)、`test_sext_steering_already_consistent`、`test_quad_single_slice_entrance_psi_not_overwritten`、`test_bend_default_slicing_converges`。
- 気づいたが直していない: Emittance[] の SEXT (L ≠ 0) は K64 の tthine が放射しないので spin も入らない (追跡は入る)。

## 2. SOL 領域内の四極の本体の B∥ (B234 = B146 の ψ の確定)

- 前任 (P4) の `test_v2_P4_sol_spin.py` は硬い端 (B_s なし) の磁場を基準にしていて座標が小さく (本体の Δψ が 1e-6 以下)、領域内の QUAD の本体の Δψ が欠けていたのに見えなかった。座標を 3 倍にすると DISFRIN=0 (端の ψ あり) は Maxwell 場の積分と 5.5e-6、DISFRIN=1 は硬い端の積分と 5.5e-6 ずれた (座標の 2 乗)。
- 修正: 追跡 (`_tsolqu_bz_ens`) は刻みごとに Δψ/(1+δ) を `p.bpar` に、Emittance[] (`solemit._quad_trk`) は刻みの中点の (bx, by) = (kq y, kq x) と勾配を hook に渡す (領域内の MULT は元から入っている)。結果: DISFRIN=0 は Maxwell と、DISFRIN=1 は硬い端と追跡 3.6e-7・1.6e-7、Emittance[] 1.7e-7・6.7e-8。**B146 の「DISFRIN=0 の ψ は物理的に正しい」ことが確定した (本体を足すと和が 0 になる Maxwell 場)**。
- 領域内の MULT (K0・K1・K2) は元から正しい (DISFRIN=0 は Maxwell に、DISFRIN=1 は硬い端に合う)。

## 3. B167 の残り (RF の β・PhotonList の β・独立な写像)

- **B232 RF の同期位相**: 空洞の kick (tcave) はエネルギー (Δp = ΔE/(βc))。同期位相の asin(U0/V) の U0 は運動量の損失 Σδ·p0 c で、β < 1 では損失のエネルギー β·Δp c と 1/β 違う。さらに空洞は z V を与える (v = VOLT/amass |z|) のに vcacc の比べ方は電荷を割らない。`emit6d._u0_energy` で U0·β/|z| (γ < 300 の B167 の係数が有効なとき、v2)。確認: 同期位相の追跡 1 周 (RF + RAD) の δ の残り/(U0/pc) が 3 GeV/c の陽子 (z = 1000、V = 20 V) で 1e-6 以下 (β を入れない場合 0.05、K64 の式は 1e3)。
- **B233 PhotonList**: 光子のエネルギー列は dp·m·γ (K64 は βγ)。エネルギー保存 (光子の総和 = 粒子の失ったエネルギー) から dp·β p0 m。以前は 1/β² 倍 (6 GeV/c で 2.5%)。確認: 6 GeV/c・z = 100 で 1.000、3 GeV/c・z = 20 で 0.998。低 γ では軟らかい光子の放射角 σ/γ が 1 rad を超えて px² + py² ≥ 1 になり pz が決まらない (K64 の radangle1 は γ ≫ 1 の近似、k64 の陽子は math domain error) ので、v2 は方向を単位球に載せる。
- **独立な写像との比較 (B167)**: 陽子の減衰が弱く条件が悪い問題は、(1) Emittance[] を z = 1000 (古典半径 ∝ z²) で走らせる (減衰 1e-11/周でも Emittance[] は解析的な D・B を使うので問題ない)、(2) 独立な写像 (Ring4B) は z_I = 1.7e5 (減衰 1.4e-6/周) まで強めて解く (平衡の εx・σδ は z に依らない)、(3) RF は z V = 1e5 U0 (同期位相ほぼ 0)・PHI = π (安定な側)、(4) 扇形 (E1 = E2 = 0) の FODO、で成立した。独立な写像の空洞はエネルギー kick (`_cavity`)。εx は条件つき共分散 (δ・z との相関を引く。病的な逆行列) でなくモード分解 (`mode_emittance`) で求める。刻み 0.0125 m で εx 4e-5・σδ 8e-6、0.02 m で 1e-3・3e-4、0.03 m で 8e-3 (独立な写像の刻みの収束)。σz は Qs の違い (同期位相 sinφ の違い) で 2%。1.5 GeV/c (γ = 1.89、β = 0.848) も、刻み 0.0125 m で εx 6e-5・σδ 4e-4、0.02 m で εx 6.6e-3・σδ 1.3e-3 の一致。
- 気づいたこと: RF を PHI = 0 に置くと、この FODO (η < 0 = 遷移エネルギーより下) では K64 の同期位相の自動選択 (T[4,5] の符号) が不安定側になり縦の 2×2 が双曲的 (Qs = 0) になる。SAD の仕様 (ユーザーが PHI を与える)。
- 気づいたこと: RF なし (rfsw = False) の `momentum_spread` は z の閉じ方 (δ の割線法) で決まり、陽子では z⁴ に比例する値になる (独立な計算とは比べていない)。

## 4. B145・`Bend.transfer_matrix`

- **B145 は誤りではなく基準軌道の取り方**: 厳密な Maxwell 場の運動 (`_p3_indep.maxwell_steer`) との差は δ に依らない定数 (K0/al)(fb1² − fb2²)/24。厳密な入口の変位は −dxfr1/(1+δ) = dxfr1 δ/(1+δ) − dxfr1 で、K64 は第 1 項だけ (δ = 0 の粒子を動かさない = 設計軌道をフリンジが動かさない)。差は設計軌道の変位 dxfr1 そのもの。リングの幾何 (硬い端の模型) と一致させる定義なので変えない。px と δ 依存の部分は 1e-10。大きさは実機 (K0/al ≤ 0.01 1/m、fb ≤ 0.1 m) で 2e-6 m 以下。
- **`Bend.transfer_matrix` (B237)**: h = ANGLE/L のまま K0 を無視していた (pysad 自身の古い式)。追跡の写像の COD = 0 での微分と比べると、K0 = 0.004・ANGLE = 0.1 で分散が 4%、4×4 が 4e-4 ずれた。v2 は CALC の `_bend_element_cod_matrix` を返す (追跡のヤコビアンと 1e-12)。ANGLE = 0 のステアリングと k64 は旧式のまま。

## 5. SOL 内の加速 (B238)

- 以前は POL + TRPT + RFSW + SOL 内の CAVI が SADError (track6 の経路は空洞の後の基準運動量を更新しない)。v2 は `sol_mult_full` に TRPT を渡し (track6n の高速追跡と同じ関数)、返った新しい ph を全粒子に設定し、後続の要素の bz に p0_ref/p0 を掛ける (`track6n_ext.step_kind` と同じ)。ffscmd の SADError の条件から「v2 で Solenoid を含む」を外した (RF つき MULT・TCAVI の SADError は残る)。
- 基準: 一様な E_z (ソフトな端、Maxwell: E_r = −r E'/2、E_z の r² 項) + 一様な B_z の中の運動方程式と Thomas-BMT (E×β の項を含む) の積分。0.02 GeV の電子 (γ = 39.2)・BZ = 0.1 T・L = 0.4 m・FREQ = 1 MHz で V = 3 MV (γ → 45.0): 積分との差 7.8e-6 (V = 1 V で 4e-8、V = 6 MV (γ → 50.9) で 1.4e-5)。E×β の項を落とした基準は 3.4e-4 ずれる (物理的に効く項で、K64 のモデルは向きの変化の中に取り込んでいる)。残りの加速に比例する差の原因は未確認。

## 6. 低 γ の硬い端の磁石の端放射 (B239、閉じた: 直さない)

- 3 GeV/c の陽子で 1 台の 15° の扇形は θγ = 0.87、1.5 GeV/c で 0.49: 1 台の磁石が放射の円錐より短い。U0 は Larmor の積分で端に依らず厳密 (B167)。2 次モーメントは硬い端で対数発散し、有限の立ち上がり幅の模型に依る。独立な基準が取れない (一意でない) ので限界として docs/46 に書いた。

## 8. 続き (統括からの 5 項目)

- **Emittance[] の SEXT (B240)**: `emit6d._tthine(enarad=True)` が setr0 + tradke(L) を入れる (v2、L ≠ 0・ak ≠ 0・RAD = 0)。numba の `k_thin` は放射なしなので `_thine_fast` は v2 のこの場合 1 を返して Python の経路に落とす。CALC・emit_extra・touschek の呼び出しは放射なしのまま。結果: Maxwell 場の Thomas-BMT と spin 回転行列が 3.5e-4 → 2e-6 (6 極のフリンジ ttfrin は Emittance[] に入らない K64 の動作のぶん軌道が 1e-6 違う)。U0 は追跡の 1 刻みと 4e-6。k64 不変。閉軌道が 6 極の中心を通る理想のリングでは効果 0、軌道のずれのあるリングで効く。
- **本体の B∥ の範囲 (項目 2)**: 基準 `_spin_maxwell_indep2.maxwell_R` に dx・dy・rot を足した。QUAD の DX・DY、ROTATE = 0.3、K1 < 0、F1 = 0.03・FRINGE = 3、MULT の DX + ROTATE、F1 + FRINGE で、追跡・Emittance[] とも R01 が基準と 1.5e-7 以内 (B165 を切ると 4〜6e-6)。**追跡の MULT の ROTATE だけスピンを回していなかった (B241)** ので v2 で直した (全体が 5.7e-4 → 4.5e-7)。
- **B238 の残りの原因 (項目 3)**: 切り分け。端の寄与ではない (CAVI の DISFRIN = 1 + 基準の E_r なしでも 6e-6)。E×β の項を落とすと 3e-4。K64 の向きの変化 → (1+aγ)θ と、E 場の BMT の (aγ + γ/(γ+1))θ の差 θ/(γ+1) (γ = 40 で 2.4%) を基準の E×β の係数の比 (1+aγ)/(aγ+γ/(γ+1)) 倍で入れると 7.8e-6 → 1.7e-6 (15% 加速)、1.4e-5 → 5.9e-6 (30%): 残りの 78%・57% を説明。残りは γ が加速中に動く (比を 1 点の γ で入れた) 近似など。直していない。
- **B239 の誤差の目安 (項目 4)**: docs/46 に明記 (θγ = 0.5〜1 で 10〜50% のオーダー、θγ ≈ 3 で数 % 以下、θγ ≳ 10 で 1% 以下。計算で確かめていない見積りと明記)。
- **試験の完走 (項目 5)**: 全試験 (176 ファイル、4 分割の並列) を回し、失敗した 6 件は下の更新 (7. 参照) で解消。
- **B242** (本節の最後に追加): 端の ψ の (1+δ) の規格化。下の項。
