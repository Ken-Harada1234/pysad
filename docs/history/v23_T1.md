### 3.2 K1≠0 の BEND の変換: K2 = −K1·ANGLE/L と EDGE_ORDER = 2

最初の変換 (CSBEND、K1 のみ、既定の端の効果) では、δ = 0 の光学は全部合ったが、**色収差が違った**: ASTRID2 は ξy = +4.40 (pysad・SAD 0)、自然な色収差 (6 極なし) は elegant (−6.249、−7.437)・pysad (−6.218、−11.806)・pyAT (−6.300、−8.293)。調べた順:

1. 磁石が 1 種類だけのリングでは差が出ない (ANGLE = 0 の BEND は pysad・AT・elegant が 6 桁で一致)。差は ANGLE ≠ 0 かつ K1 ≠ 0 の BEND のオフモメンタムの運動 (曲率 h と K1 の結合) にある。
2. **一様な磁場指数 n = 0.4 の扇形磁石 16 台のリング (3 GeV、RF なし) を、gs・pysad・elegant で比べた** (`T1_gs_bend_k1.py`・`T1_bend_k1_elegant.py`): 閉軌道の周りの 1e-6 m の振動のチューンを δ = −0.4〜+0.4% で追跡 + NAFF。
   - gs と pysad (k64・v2 とも): 追跡のチューンが 1e-12 で一致。dν/dδ = (−0.17213、+0.21082)。
   - 解析式 (B_y = B0 + G x が曲線座標の半径方向に厳密に直線、K1 = G/Bρ が一定): 閉軌道の半径が δ で変わり、磁場指数が n_eff = n (1 + x/R0)/(1 − n x/R0)、x = R0 δ/(1−n)。ν_y² = n_eff、ν_x² = 1 − n_eff から dν/dδ = (−n(1+n)/(2ν_x(1−n))、ν_y(1+n)/(2(1−n))) = **(−0.60246、+0.73786)**。elegant の CSBEND (K2 = 0) は **(−0.60246、+0.73786)** (5 桁以上一致)。
   - pysad の値は、解析式で (1 + n) → n と置いた (−n²/(2ν_x(1−n))、ν_y n/(2(1−n))) = (−0.17213、+0.21082) と一致する。差は x/R0 = h η δ に当たる: **勾配の力に曲率の因子 (1 + h x) が掛かっていない**、すなわち本体に K2 = −h K1 の6 極成分があるのと同じ。
   - elegant の CSBEND に **K2 = −h K1 を足すと**、dν/dδ = (−0.17213、+0.21082) で pysad・gs と 5 桁一致 (`T1_bend_k1_elegant.out.txt`。K2 = −2 h K1 は (+0.258、−0.316) で合わない)。
3. 周期的な格子 (ドリフトあり) では、さらに ξy が 0.76 (toy) 〜 3.6 (ASTRID2) 合わなかった。elegant の端の効果の次数 (EDGE_ORDER 既定 1 = 線形の端) を 2 にすると合った (EDGE_ORDER = 2 で ξ = (−1.884、−2.0588) が pysad (−1.884、−2.0588) と 6 桁で一致): SAD は硬い端の x' の 1 次の項 (オフモメンタムの軌道が端面を斜めに横切ることによる垂直方向の集束) を入れている。これは SAD の欠陥ではない (elegant の既定の方が粗い)。

変換 (`T1_sad2ele.py`): `CSBEND ... K2 = −K1·ANGLE/L, EDGE_ORDER = 2` (K1≠0 の BEND だけ。純粋な偏向磁石には K2 を足さない)。`--exact-k1` で K2 を足さない版 (厳密な勾配) も作れる。これで ASTRID2 は ξ = (0.023、0.035)、kek-ls は (−0.059、0.056) (pysad: ほぼ 0、(−0.049、0.067))。

**LMA への感度**: ASTRID2 で K2 を足さない版 (厳密な勾配、ξy = +4.4 の光学) の elegant の LMA は、K2 を足した版と 33 位置全部で δ± が同じ (差 0、刻み 7.8e-5 以内。`T1_elegant_astrid2_exactk1.lma.txt`)。ASTRID2 の LMA はこの違いに鈍感 (限界が分散 η = 0.58 m の水平アパーチャと RF バケットで決まり、ξy・端の光学に依らない)。

### 4.2 kek-ls_v03_12.lat (3 GeV、周長 603 m、δ_rf = 2.994%)

`T1_lma_compare.py kekls`、表 `T1_lma_kekls.table.txt`、図 `T1_lma_kekls.png`。pysad: 52 位置 (最初のセルの 43 位置 + 別の 3 セル × 3 位置、check_every = 1、491 周、2 並列 1378 s、追跡した粒子 2236)。elegant: 14 位置 (最初のセルの pysad の位置の 4 つおき 11 点 + 9 番目のセルの 3 点、**1500 周**、serial の elegant を位置ごとに 4 本同時、1810 s)。

| 位置 | 限界の種類 | δ+ pysad / elegant | 相対差 | δ− pysad / elegant | 相対差 |
|---|---|---|---|---|---|
| 最初のセルの 11 点 (s = 0〜26.6 m) | **RF バケット** (|δ| ≥ 0.97 δ_rf) | 0.03021〜0.03026 / 0.030156 | −0.28% (−0.35〜−0.19) | −0.03007〜−0.03021 / −0.03016〜−0.03023 | +0.08% (−0.03〜+0.30) |

- 最大の差 |Δδ+| = 1.05e-4、|Δδ−| = 8.95e-5 (elegant の最終刻み 7.8e-5、pysad の tol 1e-4 の範囲)。elegant の周期性: 9 番目のセルの 3 点と最初のセルの差は δ+ が 0、δ− が最大 7.8e-5 (刻み 1 つ)。
- **elegant は周回数が違う (1500 周 = 約 6 周期。pysad は 491 周 = 2 周期)**。理由: elegant はバケットから出ただけでは損失にしないので、**スリップした粒子がアパーチャに届くまで追跡を続ける必要がある**。kek-ls は 1 周のエネルギー損失が 1e-4 で、491 周 (4.9%) では δ+ = +3.1% の粒子が δ = −1.8% までしか下がらず (水平アパーチャに届くには ηx = 0.15 m で δ ≈ −6.6%)、δ+ の限界が見つからなかった (走査の上限 5% まで落ちない)。elegant の損失の周は 327〜909 周 (シンクロトロン振動 245 周の 1.3〜3.7 周期) で、500 周より長い点が多い。
- 試した方法 (うまくいかなかったもの): (a) 491 周のまま `soft_failure = 1` — 限界が見つからないと探索が終わらない (上限を超えて δ を増やし続ける。Pelegant で 90 分、serial で 45 分以上)。(b) CLEAN (MODE = absvalue、TLIMIT = バケットの |z|/c) でバケットの判定を入れる — t が周回で増える絶対時間なので、fiducial 粒子が落ちて使えない。
- pysad の 52 位置のうち、elegant と同じ位置は 11 点 (別のセルの 3 点は pysad の位置と違う)。pysad 自身の周期性 (別のセルとの差) は Q1 で確認済み (最大 4.9e-5)。

### 5.1 差の原因の切り分け

| 調べたこと | 結果 |
|---|---|
| elegant の積分 | `-method=0` (直接) と `1` (変数変換) で ASTRID2 (δ = 1%) 1.368743 h と 1.368784 h (3e-5)。elegant の積分は収束 |
| 入力の取り違え | 垂直エミッタンス: pysad の Touschek は MINCOUP の下限 εy = 0.01 (εx + εy) を使う (`EMITYC`)。elegant にもこの値を渡した (生の最終パスの EMITY = 1.2e-14 を渡すと桁違いになる)。σδ・σz も IBS 込みを渡した |
| 分散・β の位置依存、バンチ長 | 両方とも要素ごとの局所の β・η・η'・α とビーム行列 (pysad は 6 次元のビーム行列、elegant は Piwinski の式にエミッタンス・σδ・σz と局所の Twiss) を使う。局所のレート分布は比べていない |
| pysad の式の近似 | `touschek.py` の `touschek_f` は C(x)/x の解析的な当てはめ (定数 5.62966・0.75159・7.98221 の有理式 × exp(−x) × log)、位置を固定したときの運動量分散の 3 つの固有値の和 (ptrans²) で横方向の運動量の広がりを等方に扱う (`tintrb.f` の翻訳)。elegant (Piwinski) は x・y・s の運動量の広がりを別々に扱う厳密な積分 |
| 結合・電流への依存 | `T1_touschek_scan.py` (PBUNCH = 1e6 で IBS を小さく、MINCOUP = 0.01・0.1・1): ASTRID2 の elegant/pysad は (δ = 0.4%・0.6%・1.0%・δ_rf): MINCOUP = 0.01 で 0.957・0.965・0.992・1.025、0.1 で 1.004・0.947・0.908・0.915、1 (丸いビーム) で 1.176・1.069・0.957・0.885。差は δ と結合の両方に依存し、単純な係数でない。丸いビームでも一致しないので、等方の近似だけでは説明できず、当てはめの式 (`touschek_f`) の誤差も含む |
| 結論 | **pysad (SAD K64) の Touschek の式は elegant (Piwinski) と ±5% (結合 1%)、±18% (丸いビーム) の範囲で違う。どちらが正確かは、第三の独立な方法 (elegant の `touschek_scatter` の Monte Carlo、または Piwinski の式の独立な実装) で確かめていないので決められない**。Piwinski の式は広く検証されている側。K64 の式は近似であることをコードが示す。pysad のコードは変えていない (k64 は gs に合わせる。v2 でも `touschek.py` の式は SAD の仕様) |

## 6. K64 の新しい誤りの候補 (B 番号を付けるもの)

**B160** (`docs/21_sad_bug_report.md`): K1≠0 の BEND の本体で、勾配の力に曲率の因子 (1 + h x) が掛からない。

- 症状: 一様な磁場指数 n = 0.4 の扇形磁石 16 台のリング (3 GeV) の dν/dδ が、gs・pysad (k64・v2) で (−0.17213、+0.21082)。K1 を一定の勾配とする曲線座標の解析式と elegant (CSBEND) は (−0.60246、+0.73786)。ASTRID2 (K1 = −1.678 /m²、h = 0.616 /m) の自然な ξy は SAD −11.8、elegant −8.2 (pyAT −8.3)。
- 確かめたこと: gs と pysad の追跡のチューンは 5 つの δ で 3e-13 以内 (`T1_gs_bend_k1.out.txt`)。elegant に K2 = −h K1 を足すと pysad・gs の値に 5 桁で一致 (K2 = 0 と −2 h K1 では合わない。`T1_bend_k1_elegant.out.txt`)。
- 確度: **疑い〜確定の間**。解析式 (独立) と elegant (独立) が同じ側。ただし、SAD の K1 (BEND) の定義が「曲線座標の半径方向の一様な勾配」でない (例えば直線座標の勾配、または磁場の展開の定義が別) 可能性は排除できない (K64 のソースは未確認)。
- 影響: オフモメンタムの色収差 (ξ)・クロマティック ADTS・LMA・DA。δ = 0 の光学・エミッタンスは変わらない (ANGLE ≠ 0 の BEND の x0 = 0 の写像)。ASTRID2 の LMA は影響を受けなかった (§3.2)。
- pysad の扱い: **直していない (k64・v2 とも K64 と同じ)**。v2 で物理として正しくするには、BEND の本体 (CALC・追跡・`Emittance[]` が共有する numba のカーネルと解析行列) に (1 + h x) の因子を入れる必要があり、影響が大きい (要判断)。elegant との比較では CSBEND に K2 = −h K1 を足して SAD に合わせた (§3.2)。

## 7. 未確認・限界・要判断

- **Touschek の式の差 (§5) は原因を完全には切り分けていない**。第三の独立な方法が無い。差は ASTRID2・kek-ls とも ±5% 程度 (結合 1%、PBUNCH 1e9 の IBS 込み)。局所の LMA の寿命は同じ範囲の差。
- elegant の `momentum_aperture` は RF バケットから出ただけでは損失にならない。ASTRID2 (1 周の損失 1e-5) は 2 周期で足りたが、kek-ls (1 周 1e-4 だが ηx が 0.15 m で水平アパーチャに届かない) は 491 周 (2 周期) では δ+ の限界が見つからず、さらに**限界が見つからないときの elegant (serial・Pelegant とも `soft_failure = 1` でも) は探索が終わらなかった** (最初の試行は 90 分で打ち切り、4 プロセスが 45 分以上走り続けた)。周回数を 1500 にして解決した。CLEAN 要素 (|t| を切る) でバケットの判定を入れる方法は、t が周回で増える絶対時間なので使えなかった。
- ビーム電流は 1 つ (PBUNCH = 1e9)、結合は 1% (MINCOUP の下限)。それ以外 (単独の `touschekLifetime` の結合・電流) は §5.1 の走査 (ASTRID2 のみ) だけ。
- kek-ls の elegant の LMA は 14 位置 (最初のセルの 11 位置 + 9 番目のセルの 3 位置)。pysad は 52 位置。ASTRID2 の LMA は 1 セルを pysad・全周を elegant。
- 誤差・結合のあるリング、FLUC (量子励起) つきの LMA、PF リング、挿入光源つきのリングは確かめていない。
- elegant の Touschek (`touschekLifetime`) は位置の標本化を要素の出口 (MAXAMP の位置) で行う。pysad は要素ごと。局所の LMA の寿命の標本化の違いは分けていない。
- 色収差が合ったのは 1 次 (ξ) だけ。2 次 (∂²ν/∂δ²) は y で 3 倍違う (ASTRID2 33 対 88)。LMA は ASTRID2 で厳密な勾配 (ξy が 4 違う) とも一致したので、影響は小さいと見ている。
- elegant の `touschek_scatter` (Monte Carlo)・`touschekLifetime` の偏極の式は使っていない。
- 計算時間 (WSL の elegant 2026.4.0): ASTRID2 全周 199 位置 512 s (Pelegant 4 並列)、kek-ls 14 位置・1500 周 1810 s (serial 4 本同時)。pysad は ASTRID2 1 セル 363 s、kek-ls 52 位置 1378 s (2 並列)。使った CPU は最大 4 コア。elegant・mpirun・xargs のプロセスは終了後に残っていないことを確かめた (止まったものは PID で kill)。
