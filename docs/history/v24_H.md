# v2.4.0 H: 結合した光学の RDT の拡張 (4 次の h・δ≠0・ref・DX/DY/DROTATE) と KEK-LS の補正つき LMA (2026-11-22)

方針 (ユーザー指示): 解析式は摂動論の定義された次数と入れた効果の範囲で原理的に作り、追跡に合わせる補正項は足さない。v2 では誤りを指摘して直す。F の F1 (ROTATE した磁石の結合した経路) の未対応を閉じ、F2 で直した「補正後の状態を TrackSetup に渡す経路」を KEK-LS で実走した。
`ampnf.py` (A1・F1・G の領域) は編集せず、新しいファイル `pysad/ampnf_coupled.py` がその部品 (`build_ops`・`_compose`・`linear_modes`・`Seg`・`normal_form`・`tune_series`) を呼ぶ形にした。`resdrive.py` は呼び出しの追加と案内文だけ。

## H1: 結合した経路の拡張

### 何を入れたか (摂動論の次数・入れた効果)

- **共通の核 (`ampnf_coupled.taylor_map`)**: 模型 (ampnf と同じ: 線形の厳密な転送行列 + 6 極・8 極の kick + 偏向磁石の曲率・端の 3 次の項 + 運動学 + フリンジ) の 1 周の写像を、(x, px, y, py, δ) の 5 変数のべき級数 (TPSA、次数 D) で、**閉軌道から出発して**作る (閉軌道は模型の数値の追跡の Newton 法。閉軌道が 2〜5 mm でも各素子の展開は閉軌道のまわりで厳密)。閉軌道のまわりの 1 周の線形写像から 4×4 の固有モード (`linear_modes`) を作り、正規化座標の写像 R + T (2 次) + T3 (3 次) にして、`rdttrack` と同じ手順 (kick の生成関数 → 角度・作用の調和、3 次の Dragt–Finn の f4) で h3 (j+k+l+m = 3)・h4 (= 4) を出す。δ はこの写像では δ̃ = δ/sd の変数で、最後に δ0 を代入する。
- **4 次の h**: 写像 e^{−:h3 + h4:} の h4 (非共鳴の項を消す前の係数。docs/49 §10 の定義)。含まれるもの: 8 極の 1 次、運動学、フリンジ、3 次の項どうしの 2 次 (6 極・偏向磁石の曲率・端の Magnus の第 2 項)。含まれないもの: 偏向磁石の K1 の 4 次以上、K64 の四極の積分器の台形則 (模型は厳密な線形 + 運動学の流れ)。**次数の注意**: 運動学・フリンジ・偏向磁石の 4 次のハミルトニアンは TPSA の次数 D に入らないと消える (D=3 では `_kin_h`・`_fringe_h` が 0 になる。写像の次数 D は 3 次のテイラー係数に H4 が入るのに D ≥ 4 が要る)。そこで既定は D = 4。既存の `ampnf.amplitude_tune(D=3, kin=True)` も kin・fringe が落ちる (J¹ の ADTS には D ≥ 4 が要る。A1 の検証は D = 5〜7 なので影響なし。`resdrive._adts_rolled` は D=3 から D=4 に上げた)。
- **δ≠0**: 模型の写像の δ のべき級数 (全次数 D の打ち切り) を δ0 で評価し、δ0 の閉軌道のまわりで展開し直す = そのエネルギーの光学 (β・結合・分散による軌道のずれ) の h3・h4。T3 の δ^p の係数は p ≤ D−4 まで正しいので、既定は D = 6 (p ≤ 2、誤差 O(δ³))、`rdt4_options={'D': 5}` で p ≤ 1 (δ = 1e-3 では D = 5 と 6 で追跡との差が 5.0e-4 → 4.2e-4 で、残りは模型に入れていない効果。D = 6 は 125 秒)。
- **ref≠None**: resdrive の ref と同じ定義 (位相の基準)。h の絶対値は変わらず、角度の原点だけが動く。ref の素子の入口でのモードの位相進み ψ1 = arg (M e1)_x、ψ2 = arg (M e2)_y (M = リング先頭から ref までの線形写像、e_k = リング先頭の固有モード) で h に exp(−i[(j−k)ψ1 + (l−m)ψ2]) を掛ける (結合がなければ Floquet の μx(ref)・μy(ref))。**別の量として** `taylor_map(start=)` は 1 周の写像の始点を素子 start にする (素子列を循環させる。厳密)。始点が違うと h の絶対値 (非共鳴の部分) も変わる (一次の Magnus の和は同じ素子の集合だが、Dragt–Finn の f3 は始点に依る)。
- **DX・DY・DZ・DROTATE (SAD の tchge)**: `lattice._bend_chg_args` と同じ引数で、tchge の入口・出口をそのまま TPSA にした (回転 → y のずれ → tbrote: x のずれ dx1 = dxr c0 − dz s0、ドリフト dz1 = dz c0 + dxr s0 (運動学の項つきの厳密なドリフト)、DROTATE≠0 のとき tbgrote の 3 次元の回転 (pz の平方根・割り算の TPSA)。出口は alg − L・phig − ANGLE を渡す (elkern.k_bend と同じ)。出口の (dx1, dz1) の符号は幾何として正しい A2 の符号に固定 (H3-3。K64 の追跡 tbshift と同じ)。素子の中身は誤差を 0 にした素子として `ampnf.build_ops` に渡す (素子 1 個ずつ)。SAD の tchge が DROTATE を使うのは ANGLE≠0 の BEND だけ (QUAD・6 極・8 極・ANGLE=0 の BEND の DROTATE は SAD でも効かない) なので同じにした。
- **ADTS (`resdrive.adts`)**: `.rotate` (傾き・ずれ・ロール誤差による J¹ の変化) を (1) δ≠0 の J¹ の δ 依存 (模型の ν の級数 D=5 の c_(a,b),p δ^p、p ≤ 2) で評価 (以前は δ=0 の値で警告)、(2) DX・DY・DROTATE のある lat は `ampnf_coupled.amplitude_tune_ext` (閉軌道のまわりの正規形。`one_turn_series_ext`) で J¹ を作って差を取る。
- **API**: `resonance_terms(lat, ['h22000', ...], delta=, ref=)` が結合した経路 (ロール・ずれ・DROTATE のある lat) で 4 次の名前・δ・ref を受ける (以前は NotImplementedError → 従来の式でロールを飛ばす)。DX・DY のある lat も結合した経路に回る (以前は DX・DY が黙って無視された)。δ の項 (p ≥ 1) は δ=0・ref=None・ずれなしだけ (理由は下)。`rdt4_options={'D': n}` が TPSA の次数。

- **ADTS の追跡 + NAFF** (閉軌道 ≠ 0、FODO、四極 3・6 極 2・DROTATE 2 台、閉軌道 1.6 mm、結合 0.058): 正規形の J¹ が追跡 + NAFF のフィットと、J の格子の選び方で 1e-3〜5e-3 (J = 3e-7)、J = 3e-8 で 2〜4% (NAFF の雑音)、J = 1e-6 で 2〜6% (J³ の項)。傾きだけの場合の 3e-4 より悪いのは、閉軌道のずれと結合のフィード・ダウンで非線形が強く、J² までのフィットの適用範囲が狭いため。

### 不能・未対応として閉じたもの (理由を確定)

- **δ の項 (p ≥ 1) と h10002 の、δ≠0・ref≠None・ずれ (DX・DY・DROTATE) つき**: 閉じた。`rdt_series` の δ の項は閉軌道 0 のまわりの 2 次の部分と δ の展開を使う定義で、閉軌道のずれた展開では δ の項の定義 (どの点のまわりの δ の微分か) が変わる。δ≠0 の h そのものは `taylor_map(delta=)` で原理的に作れるので、δ の微分は δ の中心差分で作れる (定義は p ≥ 1 の h とは別の量)。
- **k64 モードの BEND の DX (追跡と 4e-8)**: 原因を確定して解消した (追記 H3 参照)。
- **ADTS の追跡 + NAFF の J の格子の選び方が 1e-3〜1e-2 を左右する (閉軌道が大きい場合)**: 検証の限界として書く。h の追跡との差は NAFF に依らない。
- **ASTRID2 の DROTATE (結合 0.7 以上) の h の 3e-3〜4e-3 の差**: 閉じた (次数と結合の強さによる。弱い結合の FODO・ASTRID2 の傾き・ずれは 1e-4 台)。

## H2: KEK-LS の誤差つき・補正つき LMA の実走

F2 で `FrequencyMap`・`MomentumAcceptance`・`NormalFormTune` が NOCALEXP のとき成分ごとの値を保つように直したが、小さな FODO でしか確認していなかった。KEK-LS の 2 つのラティスで、台本の経路 (誤差 → COD の補正 → 同じ FFS の中で `MomentumAcceptance[]`) を実走した。台本は `example/kek_ls/errors/KEKLS_correct_cod.sad` の誤差・補正の部分に LMA を足したもの (`example/v2_4/H2_kekls_lma_corrected.template.sad` (v03_68)・`H2b_kekls_v03_12_lma_corrected.template.sad` (v03_12))、実行は `H2_run.py`、出力は `H2_kekls_*.out.txt` (v03_68)・`H2_kekls12_*.out.txt` (v03_12)。
- **v03_68** (`example/kek_ls`、3 GeV、570.72 m、**3224 要素**、RF 2 MV・バケット 3.98%)、位置 4 (Distance = 143 m ごと)。
- **v03_12** (`pysad/tests/kek-ls_v03_12.lat`、3 GeV、603.12 m、**3563 要素**、RF 1.4 MV・バケット 2.994%。docs/48 §4 の A4・L2 の「大きなリング A」)、位置 5 (Distance = 150 m ごと。最初と最後は同じ位置)。モニター名は BPM (v03_68 は PM)、補正磁石は HD 140・VD 60。
誤差は `KEKLS_correct_cod` のもの (位置ずれ ae = 四極・6 極の DX・DY の GaussRandom (v03_68 は 40 μm、v03_12 は 50 μm = A4 の level 1 と同じ大きさ)、強さの誤差 4e-4 (偏向磁石・四極・6 極)、回転 100 μrad (同)、GCUT = 1 (σ 単位の打ち切り))。補正は COD 応答行列の特異値分解の疑似逆行列を 0.5 倍ずつ 10 回。A4 の level 1 (四極・6 極・偏向磁石の位置ずれ 50 μm、ロール 0.2・0.1 mrad) とは誤差の種類が違う (A4 は TrackSetup に直接与えた誤差、ここは SAD の台本の誤差コマンド。偏向磁石の位置ずれはなく、強さの誤差がある)。
LMA の条件: v2、RFSW ON、FLUC なし、Aperture ±10 mm、周回数は自動 (シンクロトロン振動 2 周期: 428〜491 周)、バケットの判定あり、CheckEvery = 1。**RAD は台本の `FFS["RAD"]` で ON にした (A4 と同じ条件)**。v03_12 は RAD OFF だと同期位相 0 になりバケットが 3.58% に広がる (RAD ON は 2.994% で A4 の値と一致するので、RAD ON を主とする)。v03_68 は RAD ON と OFF で δ± が同じ (二分法の格子の同じ点)。

### H4-2: 閉軌道 ≠ 0 の ADTS の追跡 + NAFF のフィットの J の格子 (整理)
閉軌道 1.6 mm・結合 0.06 の FODO (四極 3・6 極 2 の DX・DY、BEND 2 台の DROTATE)。基準は `amplitude_tune_ext` の J¹ (D=5)。J の格子 (a j, b j)、a・b ∈ {1, 2, 3}、1024 周 (一部 2048 周) で ν を J の 2 次式にフィットし、J¹ の相対誤差を見た。
- **J が小さいほど悪化する原因は、フィットに定数項がないこと**: 模型の ν0 と追跡 (K64 の積分器) の線形のチューンが 5e-7 (x)・1.2e-6 (y) 違い、この定数の差が J¹ の見積もりに δν/J として入る (定数項なし: J = 3e-8 で 2〜6%、1e-7 で 0.7〜1.8%、3e-7 で 0.1〜0.5%、6e-7 は J³ の項が効き 0.1〜0.6%。3 次式にすると悪化)。
- **定数項を自由にしてフィットすると安定する** (`ampnf_coupled.tracked_adts_fit`): J = 3e-8 で 0.08〜0.15%、1e-7 で 0.05〜0.11%、3e-7 で 0.08〜0.3%、6e-7 で 0.2〜0.3% (a, b ∈ {1,2,3})。推奨は **J = 1e-7 (FODO。振幅 √(2Jβ) ≈ 1 mm) の定数項つき、2 次式、a, b ∈ {1, 2, 3}、1024 周**。2048 周は変わらない。a, b ∈ {1,2,3,4} は J = 6e-7 で悪化 (J³)。**定数項の大きさ (ν(0) − ν0) を一緒に見る** (5e-7〜1e-6 なら積分器の差、それ以上なら模型・格子の問題)。J の目安: c₁ J が NAFF の精度 (1e-8) の 1000 倍以上、かつ c₂ J² が c₁ J の 10% 以下。リングごとに J = 3e-9 (ASTRID2)〜1e-7 (FODO)。
- 試験 `test_adts_with_closed_orbit_matches_tracking_nafffit_with_constant` (定数項つきが 3e-3 以内、定数項なしの J = 3e-8 は 1e-2 以上外れる)。
