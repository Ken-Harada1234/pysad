## 2. 追及した結果

### 2.1 入れていなかった項: 運動学的な項と四極の端部のフリンジ (**実装した**)
FODO の 6 極なし (K2=0) の追跡の ADTS は (74.6, 68.2, 73.6) だった。偏向磁石を外しても (78.0, 71.9, 76.1)、運動学的な項 p⁴/8 の 1 次の式 (5.6, 3.1, 3.9) の 14〜23 倍。
SAD の追跡では DISFRIN=0 (既定) で四極と K1≠0 の偏向磁石の端に Lee-Whiting の非線形フリンジ (`ttfrin4_1`) が入る。この写像の 3 次の項は H_f = σ (K1/12)[(x³+3xy²)px − (y³+3x²y)py] δ(s−s端) (σ = +1 入口、−1 出口、K1 は符号つき) の流れ。平均して
 ∂νx/∂Jx = −(1/8π) Σ σ K1 αx βx、∂νx/∂Jy = (1/8π) Σ σ K1 (αy βx − αx βy)、∂νy/∂Jy = (1/8π) Σ σ K1 αy βy (α、β は端の値)。
運動学的な項: ∂νx/∂Jx = (3/16π)∮γx² ds、∂νx/∂Jy = (1/8π)∮γxγy ds、∂νy/∂Jy = (3/16π)∮γy² ds (γ = (1+α²)/β。素子内は線形の転送行列で伝播して Simpson 則)。
実装: `resdrive.kinematic_adts`・`quad_fringe_adts`、`adts()` の結果の `.kin`・`.fringe`・`.total`・`.total_xx` など (`include_kinematic=False` で 0)。従来の `.dnux_dJx` などは**変えない** (6 極 + 8 極)。台本の `AmplitudeTuneShift[]` に `Kinematic->`・`QuadFringe->`・`Total->` を追加 (`DNuxDJx->` などは従来のまま)。
確認 (6 極・8 極なし、追跡 k64 − 解析): FODO 偏向磁石なし 77.98/71.85/76.10 対 77.79/71.67/75.84 (0.2%)、FODO 74.61/68.18/73.57 対 74.53/68.05/73.00 (0.1%、0.2%、0.8%)、大きなリング A 877.85/2073.70/2484.77 対 871.16/2065.85/2468.53 (0.8%、0.4%、0.7%)、ASTRID2 83.16/235.44/238.56 対 82.17/209.75/261.10 (1.2%、**12%**、**9%**: 30° の複合機能偏向磁石 (h = 0.62/m、K1≠0) の K1 の端と曲率の項)。
フリンジを切った追跡 (DISFRIN=1) は運動学的な項と 0.2〜6% (絶対値 0.06〜0.25 以内) で一致 (FODO の偏向磁石なし: 5.93/3.28/4.51 対 5.84/3.15/3.95、yy だけ 14%: 四極本体の 4 次の項 (未確認の小さな差))。
互換モード: 解析機能の追加なので k64・v2 で同じ。

### 2.2 残った差: 6 極 × 偏向磁石の曲率・硬い端の交差項 (**未実装、原因は特定**)
フリンジを切っても、6 極の強さを +1/−1 にした追跡の奇数次 (f(+1)−f(−1))/2 は変わらない: FODO で (11.05, −6.76, −49.13) (全部入りの差と同じ)。曲率に比例 (偏向角を 1/4 にすると 1/6.4、1/4.3、1/3.9)。端 E1=E2=0 (セクター型) でも同じ。
**FODO (セクター型の偏向磁石 E1=E2=0) で、線形行列 + 薄い 6 極に次の 2 つを足した追跡が、奇数次を 3 桁で再現した** (`adtsdirect.paraxial_tracker(bend_cubic=True, bend_edge=True)`):
 (i) 偏向磁石の本体の曲率による 3 次の項 H3b = (h/2) x (px² + py²)
 (ii) 硬い端 (E=0 の理想的な端) の 3 次の項 H_edge = ±(h/2) px y² (入口 +、出口 −。SAD の `fa`・`f` の項: Δx = ±h y²/2、Δpy = ∓h px y)
 奇数次 (xx, xy, yy): 追跡 (K64) 13.09, −6.77, −51.64。足した模型 13.09, −6.77, −51.63 (曲率の項だけでは 13.09, −9.79, −12.7 で xx だけ合う)。SAD の偏向磁石の写像はシンプレクティック (ヤコビ行列の J^T S J − S が 1e-11〜1e-12) で、y の 2 次の項は理想的な硬い端の物理で、K64 の誤りではない。
大きさ: FODO (6 極が強い玩具) で xx +2.8%・xy −1.7%・yy −8.6%、ASTRID2 −9.9%・−13%・+7%、大きなリング A −0.19%・−1.2%・−3.7%、大きなリング A の 6 極の C (86842, −75097, −1608) に対しては 0.1%・0.4%・12% (yy は小さい数の引き算)。ASTRID2 の複合機能偏向磁石 (K1) では、K1 の端のフリンジ × 6 極の交差項が加わり、フリンジを切ると奇数次の差が (−51.5, −60.4, −46.9) に小さくなる (全部入りは (−51.5, −199.5, +97.2))。
**実装しなかった理由**: 運動量 px・py を含む単項式 (w の微分) を 2 次の摂動の枠組み (`elem_integrals`・`elem_pair_integrals`) に入れ、x と y で別の周波数 (偏向磁石は x が h²+K1、y が −K1。いまは四極の κ と −κ の対しか持たない) をもつ素子の内部の光学を作る必要があり、範囲が大きい。**ADTS の基準値には `adtsdirect.direct_adts` (追跡 + NAFF + フィット、K64 または gs) を使うのが確実。解析の合計は、曲率の小さなリング (大きなリング A) で 4% 以内、強い複合機能偏向磁石のリング (ASTRID2) で 10〜13% 外れる**。

### 2.3 8 極 (K3)・6 極×8 極・8 極の 2 次 (`R2_octupole_kekls.pysad.txt`、大きなリング A)
8 極の K3 を μ = 0, 1, 2, 4, 8 倍した追跡 (order=3、Jmax = 2e-9) の ∂ν/∂J の μ に対する傾き: (−36904.81, 32479.83, −7154.13) 対 解析の 8 極 1 次 (−36904.89, 32479.72, −7154.01) (2e-6、3e-6、2e-5)。**8 極の 1 次は強い 8 極 (μ = 8、ADTS が 6 極の 2 次の 2.4 倍) でも成立**。解析の合計に対する差は μ = 8 で −0.05%・−0.26%・−0.41%。
8 極の 2 次・6 極 × 8 極は ADTS の J 依存 (b_ab = ν の J² の係数) として現れ、小振幅の極限では ADTS に効かない。μ の 2 次フィットで b_xx = 1.58e10 − 3.7e9 μ − 2.8e8 μ² (b0 = 6 極の 4 次ほか。μ² は 8 極の 2 次): 1 次の項の 10% になる J は xx で ~4e-7 (μ=1)、~7e-7 (μ=8)。大きなリング A の通常の J (∼1e-9) では 1e-3 未満。つまり**入れていない 8 極の 2 次・6 極×8 極の誤差は小さな J で無視できる** (J の 2 次の補正として、フィットの order≥2 が拾う)。
(b の μ に対する 2 次フィットの最大残差は b の 1〜15% で、b1・b2 は目安。)

### 2.5 共鳴線の近く・文献との照合 (`R2_resonance.pysad.txt`)
- **文献との符号・規格化**: 薄い 6 極の Bengtsson 型の式 (h21000 = −(1/16) ΣK2L βx^{3/2} e^{iμx}、h30000 = −(1/48) ΣK2L βx^{3/2} e^{3iμx}、h10110 = +(1/8) ΣK2L βx^{1/2}βy e^{iμx}、h10020 = +(1/16) ΣK2L βx^{1/2}βy e^{i(μx−2μy)}、h10200 = +(1/16) ΣK2L βx^{1/2}βy e^{i(μx+2μy)}。h30000 の係数と符号は APS の技術メモが Bengtsson の SLS の論文の式として −(1/24) b3L β^{3/2} e^{3iμ} (b3 = K2/2) と書いているのと合う。それ以外の 4 項の式の形は記憶による) と pysad の `resonance_terms` を FODO の 5 項で比べると、**5 項とも pysad = −(文献) (比 −1.000000 ± 6e-7、位相も一致)**。つまり pysad の h は H の係数そのもの (H = +K2/6 (x³ − 3xy²) の符号)、文献の h は H の符号を反転した定義 (文献の符号の定義は著者によって違い、APS のメモも符号が追跡コードの実装と違うことがあると書いている)。規格化 (1/(j!k!l!m!)・2^{-(j+k+l+m)/2} の因子) は一致。
- **共鳴線の近くの応答**: FODO の νx を 20/3 − 6 の近くに動かし (QF の K1 の調整、ε = νx − 20/3 = −3e-4〜−2e-3)、y=0 の 3 周写像の周期点 (24 の位相から Newton) の振幅 J の最小・最大を、h30000 と ADTS から予測 (2π(ε + aJ) = ∓6|h30000|√(2J)) と比べた。ADTS の a に追跡のフィットの値を使うと、予測 (最小, 最大) と追跡の差は ε = −3e-4: 7.408/7.833e-7 対 7.419/7.856e-7 (0.15%、0.3%)、−6e-4: 0.4%・0.6%、−1e-3: 0.3%・0.6%、−2e-3: 0.85%・1.3%。解析の a (全部入りの合計) を使うと a が 2.8% 小さいため予測が 1.5〜3% ずれる。**h30000 の大きさ (周期点の J の分裂幅) は 3% 以内**。ε > 0 (a>0 なので共鳴線は J>0 に無い) は周期点が原点だけで、予測 (解なし) と一致。

## 4. 限界・未確認
- ADTS の合計は 6 極 × (偏向磁石の曲率・硬い端) の交差項を入れない (上記 2.2。ASTRID2 で 10〜13%、大きなリング A で 1〜4%)。K1 つき偏向磁石の端のフリンジの式は ASTRID2 の 6 極なしで 12% (xy) 外れる。複合機能の偏向磁石の本体の非線形 (h·K1 x³ など) は未確認。E1・E2≠0 の偏向磁石の端の非線形は入れていない。四極本体の 4 次の項は yy で 6% 残る (6 極なし、フリンジなしの FODO)。

- gs は 2026-11-19 の 10-19 ビルド (WSL)、`NORFSW;`。他の gs のビルドは未確認。
- K64 の新しい誤りの候補: なし (B 番号の追加なし)。偏向磁石の写像は物理的で、シンプレクティック。
