# v2.5.0 記録: SOL 内の QUAD の (x, δ)・(y, δ) のシンプレクティック欠陥の切り分け (不確定、コード変更なし)

日付: 2026-11-26。B333 (p_y の更新順序の修正) のあとも v2 に残る欠陥を gs で調べた。台本は B333 と同じ構成 (3 GeV/c、`SOL SA=(L=0 BZ=13 BOUND=1)` → `QUAD (L=0.4 K1=0.144 [積分値])` → `SOL SB=(L=0 BZ=0 BOUND=1)`、bz = 1.3 /m、NORAD)。点 (x, px, y, py) = (1e-3, p, −5e-4, 0.4p)、各成分 ±1e-6 の 13 点の中心差分の 6×6 ヤコビアン J の |JᵀSJ − S| の成分。

- 4×4 ブロックの欠陥 (B333 の分) は EPS に比例して減る (スライスを細かくすれば消える)。(x, δ)・(y, δ) の欠陥は **スライスの数に依らない** (EPS 1 → 0.01 でも 1.9e-7、6.5e-6 のまま)。
- 振幅の依存は (y, δ) が p の約 3 乗 (8.4e-7 → 6.6e-6 → 2.2e-5)、四極の強さに比例 (K1 2 倍で 2 倍)。ソレノイドだけ・四極だけでは出ない (1e-10 以下、中心差分の丸め)。
- v2 は gs と同じ欠陥 (1.9e-7・6.6e-6)。k64 は gs と 1e-15 以内 (EPS = 1)。したがって pysad の翻訳の誤りではない。

## 2. 判断

(x, δ)・(y, δ) の欠陥が刻みを細かくしても残るのは、K64 の 1 スライスの写像が、スライス数 → ∞ でもシンプレクティックな (正準な) 写像に収束しないことを示す (z の更新と、δ に依存するソレノイドの回転 w(pz)・四極の力の更新との整合が O(h) で崩れている疑い)。ただし、確定には:

- 独立な基準 (SOL + QUAD の厳密なハミルトン流) との比較が要る。正準運動量 (px − bz y/2、py + bz x/2) の H = −sqrt((1+δ)² − π²) + K1 (x² − y²)/2 を DOP853 (rtol 1e-13) で積分して gs の出力 (x, px, y, py) と比べたが、K1 = 0 (ソレノイドだけ) でも gs と 9.4e-5 (p = 0.1)、p に対し p^1.6〜p^2.7 で違い、SOL の境界 (BOUND の端・運動量の規格化) の取り扱いを合わせられていない。四極の効果だけを切り出せなかった。
- z の更新 (`tsolqu.f` の dz1・dz2、`tztafs`) の導出を、δ に依存する生成関数から導くところまで行っていない。

結論: **不確定** (K64 の誤りの疑いは強いが、確定せず、v2 のコードは変えない)。

## 3. 別に見つかったこと (翻訳の抜け、未修正)

SOL 領域内の QUAD の EPS (`tsolqu` のスライス数 ndiv = 1 + int(|L·hypot(K1, bz)/(0.2 EPS)|)) を、pysad の追跡 (`track6n_ext.k_sol_quad`・`tsolqu_bz_all`) は使わない (eps0 = 0 固定。`tquad.f:83` は eps0 を渡す)。EPS = 0.1 で pysad の k64 と gs が 4.7e-7 (x, px) 違う。EPS = 1 (既定) では全桁一致。K_SOL_QUAD の引数・`track6.py`・`solemit`・`solmap` の経路に EPS を通す必要があり、未着手。
