# v2.5.0 記録: WSPAC の縦の力の電位の基準 (K64 は軸上で ln((1+r)/2)。v2 の翻訳の誤りを修正)

日付: 2026-11-26。試験 `pysad/tests/script_tests/test_v250_wspac_axis.py` (3 件)。gs の保存した出力 `scripts/v250_wspac_axis__ring.{sad,gs.txt}`。

## 1. 経緯

前の作業 (`dd0c4b1`) は「WSPAC の縦の力の電位の基準は軸上 0 で、K64 と同じ」とし、仕様か誤りかを未決としたが、gs で軸上の粒子の確認ができなかった (台本の WSPAC ON の追跡が粒子を動かさなかった)。原因は、**`Do` の中の `WSPAC;` / `NOWSPAC;` が gs で効かない** こと (`Do` の外にトップレベルで並べると効く)。

## 2. gs での確認

台本: 0.5 GeV の電子リング (8 セル、周長 35.3 m、弱いスキュー四極 QS、RF 0.2 MV。`example/05_tracking/flag_WSPAC_tracking_beam.sad` と同じ)、`CODPLOT; WSPAC; EMIT;` のあと `NORAD; NORADCOD;`、PBUNCH = 2e10 と 4e10 で、WSPAC ON と OFF の 1 周の追跡の差。8 粒子 (軸上 (x = y = 0) の z = σz・2σz・−σz (σz = 18.43 mm)、x = 1e-3・y = 1e-4 の z = −σz・σz・2σz、δ = 0.01、y = 0)。

- 軸上の粒子の Δδ: z = σz で +9.69e-10、2σz で +4.33e-10、−σz で −9.69e-10 (PBUNCH = 4e10 で 2 倍)。z に奇で、比 4.33/9.69 = 0.4466 = 2e^(−3/2) (z e^(−z²/2σz²) の形)。
- K64 の式 (`tintrb.f:440`) Δδ = −(z − zc)/σz²·az·fu に対し、az の和 (f = PBUNCH r_e L/(p² h √(2π)σz) を 1 周で足す) から、fu_eff = −0.64 (r ≈ 0.06 のときの ln((1+r)/2) = −0.635 と 1% で合う)。
- K64 の `twspu` は 2(a + b/r) + ln(0.5 + 0.5 r) (小さい引数)、2 ∫ + ln(0.5 + 0.5 r) (それ以外) で、積分部分が pysad の U (軸上 0) に当たる。基準は軸上 0 ではなく ln((1+r)/2) (丸いビームで 0)。
- v2 (修正前): 軸上の粒子の Δδ は −4e-12 (0)。x = 1e-3・y = 1e-4 の粒子は、gs との差がちょうど軸上の粒子の値に等しい (gs = v2 + 軸上の項)。
- δ = 0.01 の粒子と δ = 0 の粒子 (同じ x・y・z) の違い (1.74e-9 と −4.9e-10) は、分散による軌道のずれ (ΔΦ(x, y)) で、v2 も同じ (1.742e-9、−4.76e-10)。δ に直接依存するのではない。

## 3. 修正 (v2。k64 は追跡に WSPAC を入れない)

`spch.WSpace.kick` が基準 U_ref = −ln(0.5 + 0.5 σ2/σ1) を使う (`WSPACRADIUS` > 0 のときは壁の半径の電位。これは K64 にないオプション)。修正後の v2 は、gs と 8 粒子の Δδ が最大 Δδ の 2.5% 以内 (軸上 9.83e-10 対 9.69e-10)、Δx・Δy が 3% 以内。残る差は、gs の追跡のビーム行列と v2 のゼロ電流の行列の 1〜2%。

試験 `test_v2_C2_spch.py::test_wspac_kick_formula_tilted_beam` の縦の基準を K64 の値 (U + ln((1+r)/2)) に更新。

## 4. 仕様か誤りか (壁の半径)

K64 の WSPAC は壁のないモデルで、縦の電位に壁の半径 b に依る ln(b/σ) の項がない。壁の半径を変えたときの主要項の変化は、K64 に壁のパラメータが無いので gs で見られない (physics_guide 17 章 §12 の解析のまま。**未決**)。軸の基準が ln((1+r)/2) (O(1) の定数) であることは確定。

## 5. 限界・未確認

- 0.5 GeV・結合のある 1 つのリング (r ≈ 0.06)・1 周・PBUNCH = 2e10・4e10。ビーム行列は v2 の既定 (ゼロ電流の平衡値)。
- 1 周後の z の差 Δz は gs が v2 の約 2 倍 (gs −9.2e-9、v2 −4.9e-9 (軸上の粒子、PBUNCH = 2e10))。Δδ は合うので、kick 後の dv の更新 (K64 の `dv(i)` の更新式) の違いが疑われる。未調査。
- 丸くないビームの fu の遠方の値 (基準が遠方で丸い形に合うこと) は確かめていない。
