# v2.4.0 G: K0≠0 の偏向磁石 (挿入光源・逆曲げ・MPW・傾けた MPW) を ampnf・resdrive に入れる (2026-11-22)

担当 G (ampnf の K0≠0 関連、resdrive の K0≠0 の傾き、新規 `pysad/ampnf_k0.py`)。方針 (ユーザー指示): K0≠0 の偏向磁石は重要。解析式は摂動論の定義された次数と入れた効果の範囲で原理的に作り、追跡に合わせる補正項は足さない。

## G1: 問題と方法

F1 の時点で、ampnf は K0≠0 の偏向磁石を `NotImplementedError` にしていた。F の試行では、磁石の出口が原点でなく (x = −5e-5、px = −1e-3)、写像に定数項があるため、原点のまわりで `bendnl.extract_map` を使う方法が成り立たなかった。

**採った方法**: K64 の偏向磁石の追跡 (`track6n.tbendcore1`: K1 = 0 の ANGLE≠0 の本体 + 端の楔 E1・E2 + 硬い端の Maxwell の項、`k_steer`: ANGLE=0) は閉じた式である。その式を **そのままべき級数 (TPSA) の演算で評価する** (`pysad/ampnf_k0.py`。定数部分を持つ級数 `TP` と、定数部分 a0 のまわりの厳密な sqrt・1/x・asin の級数)。

- 入力の級数は磁石の入口の軌道を定数項に持ち、出力の級数は **その軌道のまわりで厳密に (次数 D まで) 展開した写像**、定数項が出口の軌道。磁石の内部の軌道 x0(s) のまわりの展開は、閉じた式を軌道のまわりに展開することそのもの。スライス分割・Lie 級数の打ち切り・数値の積分は無く、近似は次数 D の切り捨てだけ。
- 曲率・運動学 (全次数)・端の楔・硬い端の項を含む。K0=0 の模型のオプション (`bend_cubic`・`kin`・`fringe`) は、どれかが True なら全部入り、3 つとも False なら軌道のまわりの 1 次だけ (G4 (4))。δ は 5 番目の変数で、全次数の δ の依存が入る (硬い端の 1/(1+δ) も閉じた式の通り)。
- 運動量は ampnf の正準運動量 (p0 で規格化) と追跡の内部の px/(1+δ) の変換を入口・出口で行う。
- **ANGLE=0 の `k_steer` の枝**: K64 は `pxi·pxf < 0` (または d = 0) で phsq の枝、そうでなければ d の枝で u・w を計算する (数値の安定のため。同じ関数)。d の枝は pxi + pxf = 0 (3 極の挿入光源の中央の極など) で 0/0 になり、そのまわりの級数が作れないので、**常に phsq の枝を使う** (追跡の写像と 1e-13 で一致することで同値を確認)。
- ROTATE (傾き) は F1 の `_expand_rolls` (R⁻¹ ∘ 磁石 ∘ R、全次数の θ) をそのまま使う。垂直の軌道・結合が入る。
- **1 周の写像の軌道**: K0≠0 の磁石があるときの `one_turn_series` は 2 段。第 1 段で物理座標 (原点が入口) の 1 周の写像を作り、不動点 c (閉軌道) とそのまわりのヤコビ行列 A を求める。第 2 段で、c を定数項に入れ、A の固有モードの正規化座標で全素子をもう一度通す (c = 0 なら第 1 段の写像を座標変換するだけ)。`res['orbit']` に c。`initial_from_nf`・`nf_action`・`tracked_tunes`・`model_tune` も c を足し引きする。
- L = 0 の K0≠0 の BEND (薄いステアリング) は `element_linear` の δ に依らない kick (正準運動量で −K0)。
- 未対応は `NotImplementedError`: ANGLE=0 で K1≠0 かつ K0≠0 (K64 は track6 の `tmulti`)、K1≠0 かつ K0≠0 の F1・FB1・FB2、ANGLE=0 の CHI2 (K64 の `tsteer` が使わない)。**G の続き (後半) で入ったもの**は G4。

resdrive は変更が小さい: ampnf が K0≠0 を扱えるので、`rolled_elements` の K0≠0 の傾いた磁石が結合した経路 (`resonance_terms`) と `.rotate` (`adts`) に自動で入る (以前は飛ばして警告)。`adts` のロールを外した lat の項は A2 の解析式のまま。

## G4: 続き (2026-11-22 後半。コーディネーターの 6 項目)

### (1) K1≠0 かつ K0≠0 の磁石: K64 の `tbendi` の数値積分器そのものを TPSA で評価

`ampnf_k0._tbendi` が `track6n.k_bendi` を行ごとに TPSA に直訳したもの (入口の Lee–Whiting のフリンジ `ttfrin4`、入口の端 = v2 の厳密な `tbedge` (drift・Maxwell・body) または K64 の薄い端、ndiv = 1 + |ANGLE|/1e-3 のスライス (すべて同じ長さなので x・y の伝播の定数 (cosh・sinh の級数) は 1 回、δ の整関数の級数で評価 = akxsq の符号の枝が要らない)、スライスごとの補正 `tbendicorr`、出口の端、K1 の定義 'log'・'lin' (`compat.bend_k1_lin`)、`bend_k1_edge='face'` の四極の蹴り)。**積分器そのものを評価する**ので、K64 の追跡との差は丸め誤差だけ。
- 素子の写像: K1 = 0.4・−0.3 (E1・E2 あり・なし)、入口の軌道・δ≠0 で追跡と 1.2e-16 以内 (k64・v2 とも。v2 では DISFRIN=0 の端が `edge_exact1`)。
- 3 極の挿入光源 (ang = 0.01、E = 0.5、K1 = 0.03、軌道 7.8e-4 m が漏れる): ν が追跡と 1e-6 以内 (δ = 0・1e-3、J = 1e-6)。
- 磁石 1 台の計算時間は ndiv の分だけ重い (ANGLE = 0.1 で 101 スライス、D = 5 で約 0.1 s)。K1≠0 かつ K0 = 0 の磁石は従来の模型 (§13.1) のまま。
- ANGLE=0 で K1≠0 かつ K0≠0 は K64 の `tmulti` (track6 の経路。閉じた式でも積分器でもない) なので未対応。

### (2) F1・FB1・FB2、DX・DY・DROTATE・CHI2、ANGLE + K0 = 0

- **F1・FB1・FB2 (端のフリンジの長さ)**: K1 = 0 の `tbendcore1` と ANGLE=0 の `k_steer` の dxfr・dyfr・dyfra の項をそのまま入れた (mfring・FRINGE の規則も `_compile` と同じ。FRINGE ≤ 0 のとき FB は 0 化される)。追跡と 1e-17 以内 (E あり・なし)。K1≠0 かつ K0≠0 の F1 は未対応 (`tbendi` の fb)。
- **DX・DY・ROTATE・DROTATE・CHI2**: ANGLE≠0 は `tbshift`・`tbrot` の TPSA 版 (設計軌道の中点まわりの幾何) を磁石の内部で行う (追跡と 1.4e-17 以内)。ANGLE=0 の磁石は K64 の `tent`・`texit` なので、`ampnf._expand_rolls` が ('shift', −DX, −DY)・('rot', ROTATE + ROTATION + DROTATE)・磁石・逆の列に展開する (F1 の傾きの展開と同じ構造)。CHI2 は `tsteer` が使わない (NotImplementedError)。リングでの検証: ν が追跡と 1.2e-6 (δ = 0)・6e-6 (δ = 1e-3、`dx_bend`) 以内 (J = 1e-6)、軌道が 1e-4〜4.5e-4 m 漏れ、結合 1e-2〜4e-2。
- **ANGLE + K0 = 0 (場が 0 で幾何だけ曲がる磁石)**: K64 の式は `rhob = al/phib` で phib = 0 を割り、追跡は NaN を出す (pysad の追跡も `FloatingPointError`)。K64 の誤りというより、場が 0 の磁石を想定していない式。この写像は自由な直進 + 座標系の回転 (+ 入口・出口の面は影響しない) で一意に決まるので、phib → 0 の極限 (phib = 1e-9 ANGLE、桁落ちは ~1e-8) で入れ、独立な基準 (場 0 の自由な直進の運動方程式) と 1.4e-8 (E あり)・3.5e-9 (E なし) で一致を確認した。

### (3) 独立な基準 (K64 の式を使わない運動方程式の積分) との比較

`example/v2_4/G_independent_flow.py` (出力 `G_independent_flow.out.txt`、試験 `test_k64_formula_equals_independent_equations_of_motion`): 実験室の直交座標 (X, Y, Z) で、相対論的な荷電粒子の運動方程式 dr/ds = p/|p|、dp/ds = (p/|p|) × b (b = qB/p0、DOP853、rtol 1e-13) を、一様な双極子 b = (ANGLE + K0)/L の領域を 2 枚の面 (E1・E2、tanh の端の幅 w) で切った場で積分する。場は Y の依存をスカラーポテンシャル φ = −b [Y G − Y³∇²G/6] (∇² は X-Z 面) から Maxwell の式を満たす形 (Bx・By・Bz とも Y³ まで) にした。参照軌道は ANGLE の弧、座標は入口・出口の参照軌道に垂直な面。
- **水平面 (y = 0、w = 2e-5 = 硬い端の極限)**: K64 の `tbendcore1`・`k_steer` (E なし) が **1e-13〜1e-12 以内** (ANGLE≠0 で E1・E2・逆曲げ・δ = 2e-3 を含む)。楔・曲がる軌道の幾何と運動学の式は厳密。
- **4 次元 (Maxwell の項・楔の垂直収束を含む)**: w = 4e-3・2e-3・1e-3 の差が **w に比例して半分ずつ減る** (steer 1.1e-8 → 5.7e-9 → 2.8e-9、bend_edge 2.3e-8 → 1.1e-8 → 5.3e-9)。つまり w → 0 の極限で K64 の硬い端の Maxwell の項 (縦方向の y² の項) と一致 (外挿の残りは検出限界以下)。K64 の式に **物理的な誤りは見つからなかった**。
- **見つけた K64 の近似・仕様**: (a) k64 モードの `tsteer` は出口の楔 E2 を入れない (B140。独立な基準との差 9e-5、K0 = 0.06・E2 = −0.05・L = 0.3)。(b) v2 の `tsteer` は (G の前半の時点で) 楔を薄い蹴り x tan(E)/ρ (線形) だけで入れ、軌道が傾く磁石の内部の楔の形 (二次) が欠けて 3e-7 の差が残っていた。**同じ時期に放射担当が B221 で v2 の tsteer の端の面を CALC と同じ厳密な硬い端の鎖にし、独立な基準との差が 5e-13 になった** (その後 F1・FB があるときも、F1 の tblfre → 鎖 (出口は鎖 → tblfre) の順で厳密な鎖にした。ampnf の `_tsteer` も同じ順序)。ampnf の `_tsteer` は B221 に合わせて v2 で厳密な鎖 (`_edge_exact`、rhoc = −rhob) を使う (追跡と 1e-16)。ANGLE≠0 の `tbendcore1` は楔を厳密な幾何で入れ、残らない。(c) 読んで気づいただけの未確認: `k_bendi` の `xsxkx` は akxsq < 0 の枝が akxsq → 0 の極限と符号が逆 (z = 行路だけで、効果は δ/ρ² × alx³ 程度 ~1e-8)。x・y・px・py に影響しない。
