# v2.4.0 E: 組込の数学関数・特殊関数・リスト関数の監査 (B180〜B199)

2026-11-22。担当ファイル: `specfn.py`・`specfn_cx2.py`・`sadscript.py` の基本関数・`sadlist.py`・`fileops.py`。

## 手順
1. 参照値: collective312 の venv の mpmath 1.4.1 (`mp.dps = 40`) で、関数 × 引数 (負・小・大・境界・整数次・非整数次・複素の 20 点の格子) の表を作る (約 4000 点)。pysad (v2) を同じ式で `Print` し、相対 1e-9 (後に 1e-12) で比べる。
2. gs との照合: リスト・文字列・パターン・論理・複素数の約 600 式を gs と pysad (k64・v2) で並べ、数値を `%g` にそろえて違いだけを見る。gs が途中で止まる式 (`x=!=y` の構文、`StringReplace[s,""->..]` の無限ループ、`AtomQ` 以降) は式を外して再実行した。
3. 修正は v2 の分岐 (`compat.v2()`、`specfn._install_v2_fixes`)。pysad 自身の誤りで gs が正しいものは k64 も直した。

## 結果
mpmath と合わなかった v2 の値は 90 点 (実数) + 61 点 (複素の格子) + 小さな引数の 3 点など。すべて直した。残る不一致は、出力が 12 桁 (指数が ±100 を超える値) の表示の限界・零点近傍・オーバーフロー・`Pochhammer[-.5,-.5]` (ComplexInfinity) のみ。

gs の誤りを再確認した B43〜B47・B53・B54・B118〜B122・B158 は、v2 が全点で真値。

## 見つけたこと (詳細は docs/21 の B180〜B199)
- gs が誤る (pysad v2 は真値): ArcCosh (|x|<1)・ArcTanh (|x|>1)・ArcSin/ArcCos (x>1) の符号と NaN、`Insert`・`StringInsert` の負の位置、`Inner` の行列、`{x,1}/.x:_Symbol->k`、`Names["Sin*"]`、`Sum[x^i,{i,0,2}]`。
- pysad 自身の誤り (gs は正しい): `Inner`・`MapIndexed` のレベル・決まらない条件の `If`/`And`/`Or`/`Equal`・虚部 0 の複素数・`Floor[Infinity]`・奇数乗のオーバーフローの符号・`StringTake[s,0]`。
- scipy の不足: 複素の `hyp1f1` の |z| ≳ 12 (相対 1e-4〜1)、実数の `hyperu` (相対 7e-11)、`gammaincc` の a < 0、`lambertw` の分岐点の NaN、複素の `Shi`・`Chi` (虚部を捨てる)。
