## 2. check_every の既定 (項目 1)

`TrackSetup.check_every` の既定 (0 = SAD の tapert: 最初の要素・15 要素ごと・区間の終わり) は変えない (gs と同じ判定、周波数マップ、Q1 の gs 比較)。LMA の `momentum_acceptance(check_every=None)` は **1** (`setup.check_every` が 0 でないときはその値)、
0 を明示したときは、アパーチャで決まる位置があれば警告する。台本 `MomentumAcceptance[]` の `CheckEvery` の既定も 1。

ASTRID2 の最初のセル 25 位置 (`L2_check_every.py`、1312 周、±10 mm):

|---|---|---|---|---|
| check_every = 0 | 0.829% → 1.048% (位置 17)〜1.635% | δ+ 3.8e-3、δ− 4.5e-3 | δ+ 1.457、δ− 1.523 | 515 s |
| **1 (既定)** | 0.829%〜1.598% | **3.5e-5、7.0e-5** | — | 550 s (+7%) |

大きなリング A (11 位置、491 周): 全位置が RF バケットで決まり、0・1・5 の結果は同じ (最大の差 0)。時間は 156 s (0)・383 s (1、×2.45)・171 s (5)。3563 要素を要素ごとの区間に分けるので遅い (kernel の呼び出しの回数)。

## 3. RF バケットの限界とアパーチャの限界 (項目 2)

`pysad/lmabucket.py`。縦方向の運動を独立に取り出す。

- **解析式** (`rf_bucket_analytic`): α 一定・U0 一定・減衰なしのセパラトリクス δ_rf² = (2A/(kCα)) [2 cos φs − (π − 2φs) sin φs]、A = V/E0。ASTRID2 で 1.61757%、`Emittance[]` の bucket_height 1.61757% (差 1e-6)。
- **1 次元の写像** (`bucket_limits_1d`): z' = z − C (a1 δ + a2 δ²)、δ' = δ + (V/E0) sin(φs + k z) − U0/E0 + r1 δ + r2 δ²。RF の力は解析式のまま、a1・a2・r1・r2 は追跡で測る (`longitudinal_params`: 空洞のすぐ後ろから 1 周、δ の閉軌道の上)。
  空洞の力を追跡で測った値との最大の差は 1.8e-10 (V/E0 = 8.6e-5)。ASTRID2: a1 = 0.01053 (αc の 0.987 倍)、a2/a1 = −0.76、放射 r1 = −1.75e-5 (理想 −2U0/E0 = −2.13e-5)、r2 = −9.2e-5 (理想 −U0/E0 = −1.06e-5)。
  (a2・r を追跡から測って入れるのは、非線形の経路長・放射の δ 依存という物理の効果を入れるためで、追跡に合わせて端数を足すためではない。切り分けは下の表。)
- **6 次元の追跡** (`bucket_limits_6d`): アパーチャ無限大 (alost = 1e30)、|z| > バケットの長さ (LMA の判定) で損失。
- **アパーチャの限界** (`aperture_limits_4d`): RF・放射なし、δ 固定の 4 次元の追跡 (256 周)。

ASTRID2 (位置 2、1312 周) のバケットの限界 δ+ / δ−:

| 方法 | δ+ [%] | δ− [%] |
|---|---|---|
| 解析式 (理想化) | 1.6176 | −1.6176 |
| 1 次元の写像 (a2 = 0、r なし) | 1.629 | −1.628 |
| 〃 (a2 = 0) | 1.637 | −1.631 |
| 〃 (r なし) | 1.635 | −1.622 |
| 〃 (全部) | 1.643 | −1.624 |
| 6 次元の追跡 (位置 2) | 1.6350 | −1.6175 |
| 6 次元の追跡 (位置 17、δ = 0 の閉軌道から出発) | 1.6600 | −1.6275 |
| 6 次元の追跡 (位置 17、δ の閉軌道から出発) | 1.6375 | — |

- 1 次元の写像と 6 次元の追跡 (位置 2) は δ+ で 8e-5、δ− で 6e-5 (6 次元の走査の刻み 5e-5 を含む)。解析式との差 (+1.5% = δ+、+0.4% = δ−) は、放射の減衰 (r1)・α2・離散写像の寄与で説明がつく (上の表)。
  **LMA の δ+ が δ_rf を 1.1% 超える (Q1・T1) のは、バケットの外へ出るのに時間がかかる (有限の周回数) ことと、この減衰・α2 の効果**。位置 17 の 6 次元の限界が 1.660% と位置 2 より 1.3% 高いのは、δ = 0 の閉軌道から出発すると分散の不一致によるベータトロン振幅 (√(Hβ)δ) が経路長を変えるため
  (δ の閉軌道から出発すると 1.6375% で位置 2 と同じ。追跡で確認)。
- **位置ごとの種類** (`limit_types`、`L2_limit_types_*.table.txt`): LMA の値は min(RF バケットの限界、実効のアパーチャの限界) と一致する。実効のアパーチャの限界は min(δ+_aper, |δ−_aper|): シンクロトロン振動で半周期のうちに δ の符号が反転するので反対側にも当たる
  (δ = −0.0086 の粒子は 356 周 (νs の周期 656 周の 0.54) で δ = +0.0086 になって x = +10 mm で失われた。追跡で確認)。ASTRID2 25 位置 (δ+): LMA − min の最大 2.6e-5。δ−: 最大 2.6e-4 (分散の大きい 12 位置、LMA −0.856% に対し実効の限界 0.829%。LMA が反対側の限界を 3% 超える原因は
  スイング中のベータトロン振幅の位相と減衰によると考えられるが、切り分けていない)。
- **ASTRID2 の分類**: ±10 mm で、25 位置の δ+・δ− はすべて**アパーチャ**で決まる (実効のアパーチャ 0.829%〜1.595% は RF バケット 1.617%〜1.635% より小さい)。T1 の「25 点すべて aper」が正しい。docs/48 §5 が位置 2 を RF としていたのは、check_every = 0 の値 (δ+ = 1.635%、理由 'rf') の取り違え
  (check_every = 0 は判定点が少なく、アパーチャに当たる前に |z| の判定が先に効く)。`reason` は最初に失われた粒子を落とした直接の原因で、限界の種類ではない。バケットの限界でも、バケットから出てすべった粒子はアパーチャに当たって落ちるので 'aper' と記録されうる。
- 大きなリング A (±10 mm): 11 位置は、RF バケットが小さい 7 点 (δ+ = 3.021〜3.026%、アパーチャ 3.13〜3.74%) と、バケットとアパーチャ (3.031%) が 2 tol 以内の 4 点 ('both') で、**LMA = min(rf, aper) が全位置で差 0**。1 次元の写像は 491 周で δ+ = 3.0121%、δ− = −3.0130% (6 次元の δ+ 3.021〜3.026%、δ− 3.007〜3.021% と 1e-4 以内)。a1 = 0.000232 (αc の 1.007 倍)、a2/a1 = +0.48、r1 = −1.42e-4 (理想 −2U0/E0 = −1.97e-4)、r2 = −8.2e-4。項の寄与 (491 周、δ+/δ−): a2 = 0 で 3.027/−2.998%、r なしで 2.970/−2.998%、両方なしで 2.984/−2.983%。
- MPW 版 ASTRID2 (32 位置、1316 周): δ+ 0.836%〜1.590%、δ− −0.856%〜−1.572%。直線部 20 位置は RF バケット (δ+ = 1.590%、δ_rf = 1.571% の +1.2%) とアパーチャ (1.595%) が 2 tol 以内 ('both')、分散の大きい 12 位置はアパーチャ (0.828%)。

## 4. 狭い損失の窓 (項目 3)

`momentum_acceptance(verify=n)`: 二分で見つけた限界 lo (全部残れば dpmax) の手前 [0, lo] を n 点の等間隔で再追跡し、失われる点があれば最初のものを新しい上の端として二分をやり直す (最大 5 回)。`LMAResult.nwin_*` (失われた手前の点の数)・`win_*` (最初の窓の δ)・旗 `W±`・警告。
ASTRID2 (1312 周、25 位置、n = 100、刻み 1.6e-4 = tol の 1.6 倍): 窓の点 **0**、verify あり − なしの最大の差 0。大きなリング A (491 周、11 位置、n = 150、刻み 2e-4): 窓の点 **0**、差 0。
(窓の模擬 = 追跡の損失判定を差し替えた試験で、粗い走査 (刻み 1.04e-3) のあいだの窓 (3.3〜4.0e-3) を verify = 100 が見つけ、限界が 3.3e-3 まで下がることを確認。)
verify なしの粒子は 1075 個・時間 495 s、verify = 100 は 6075 個・2914 s (×5.9)。大きなリング A は 355 s → 1003 s (×2.8)。この 2 リング・±10 mm では窓は起きないので、既定は verify = 0 のまま。窓が起きうる条件 (強い高次の共鳴・小さいダイナミックアパーチャ) では有効にする。
**未確認**: 上の 0 個は刻み 1.6〜2e-4 より狭い窓 (δ の幅 < 2e-4) を排除しない。限界より外側の残る島は見ない。

## 6. 1 セルから全周への延長 (項目 5)

RF 空洞は 1 か所なので、閉軌道の δ はセルごとに U0/E0 ずつ変わる (ASTRID2 1.06e-5、大きなリング A 9.9e-5、24 セルの FODO 5.2e-4)。同じ位置の全セルの LMA (`L2_cell.py`):

|---|---|---|---|---|---|---|
| ASTRID2 | 位置 2・17・中間 (3) | 6 | 2.6e-5 | 1e-4 | 1.06e-5 | なし (空洞のセル 4 でも同じ) |
| ASTRID2 | 位置 2・17 | 6 | **4.9e-6** (最初のセルとの差。全セルの幅は δ+ 3.3e-6、δ− 8.2e-6) | **5e-6** | 1.06e-5 | なし |

差は二分の刻み以下で、U0/E0 より小さい (ASTRID2 で半分以下)。δ± は閉軌道の δ ではなく、局所の運動量に対する量で、アパーチャ・バケットの限界は閉軌道の δ に弱くしか依らない。
**周期性の許容 1e-4 の根拠**: (1) 二分の幅 (既定 tol = 1e-4)、(2) U0/E0 (ASTRID2 1e-5、大きなリング A 1e-4)。上の測定は、差が tol・U0/E0 の小さい方以下であることを示す。
`periodicity_report` の閉軌道の許容は 1e-7 + 2 (U0/E0) max(|η|, |η'|) (RF が 1 か所なので正常な周期的なリングでも分散の分だけ x がセルで違う。FODO で 3.8e-4、ASTRID2 で 5.2e-9)。
**限界**: 24 セルの FODO (U0/E0 = 5.2e-4) のように U0/E0 が tol より大きいリングでは、1 セルの結果の誤差が tol を超えうる (測っていない)。誤差つきは §7。

| 位置 | FLUC なし δ+ / δ− | pysad FLUC 平均 δ+ (σ) / δ− (σ) | elegant ISR 平均 δ+ (σ) / δ− (σ) (6 種) | elegant ISR なし |
|---|---|---|---|---|
| 2 | 1.5981 / −1.6086 | 1.5964 (1.4e-5) / −1.6100 (2.2e-5) | 1.6016 (0) / −1.6040 (4.0e-5) | 1.6016 / −1.6016 |

| 100 | 1.5955 / −1.6086 | 1.5959 (1.1e-5) / −1.6090 (3.2e-5) | 1.6016 (0) / −1.6070 (4.0e-5) | 1.6016 / −1.6016 |

(単位 %)。FLUC なしとの差は −1.8e-5〜+1.3e-5 (平均)、elegant の ISR あり − なし は ≤ 9e-5 (最終刻み 7.8e-5 の 1 つ)。pysad と elegant の ISR あり同士の差は、ISR なしの差 (T1: 最大 3.5e-5・7.0e-5) と同じ大きさ (≤ 1e-4)。
**2 周期では量子励起のランダムウォーク (σδ(N) = σδ √(1 − exp(−2N/τ))、τ = 1/(−r1/2) = 11.5 万周で 1312 周は σδ の 15%、6.5e-5) が二分の幅より小さいので効果は見えない**。13120 周 (20 周期、σδ の成長は定常の 45%) で 2 位置 (2・17)・5 種・tol 5e-5 でも、FLUC あり − なしは δ+ −2.1e-5・0、δ− −2.1e-5・+1.0e-5 (σ ≤ 1.4e-5)。**振幅 (1.6%・0.83%) が σδ (4.3e-4) の 20〜40 倍なので、量子励起による振幅の変化 ≈ σδ²/δ が 2e-6〜2e-5 と小さい**ためで、周回数を増やしても二分の幅以下。
FLUC つきの警告 (結果が 1 つの標本) を出す。大きなリング A (σδ = 6.9e-4、位置 16・89、6 種、tol 1e-4): pysad の FLUC あり (491 周と 1500 周で同じ) は δ+ = 3.027%・3.029% (σ 1.1〜1.3e-4)、δ− = −3.017%・−3.005% (σ 4e-5〜5e-5)、FLUC なしとの差 +0.8e-5〜+8.1e-5 (σ 以内)。elegant の ISR あり 1500 周 (6 種) は δ+ = 3.008%・3.010% (σ 1.0e-4・1.2e-4)、δ− = −3.022%・−3.009% (σ 5.9e-5・7.7e-5)、pysad との差は δ+ で +1.9e-4 (σ の 1.5〜2 倍)、δ− で +0.5e-4〜+0.4e-4 (T1 の ISR なしの差 +5.7e-5〜+1.05e-4 に近い)。elegant の ISR あり 491 周は位置 89 で δ± = +3.19%・−3.25% (σ 7e-4・1.4e-3) と収束しない (バケットから出た粒子がアパーチャに届かないため。T1 と同じ理由。pysad はバケットの判定があるので 491 周でよい)。
