## 4. 要判断・未確認・限界

- **6 極の 2 次の共鳴駆動項 (νx − νy などの 2 次の共鳴、4 次以上) の解析式が無い**。docs/49 の 2 次の項は振幅依存チューンシフトだけで、これを実装すれば ASTRID2 の D の大きい領域を予想できる見込み (R4 の担当範囲 (`resdrive.py`) なので触っていない)。
- 誤差つきは ASTRID2 の 1 つの種だけ。誤差の原因 (フィードダウンと考えたが要素ごとに切って確かめていない) は未検証。KEK-LS の誤差つき、補正つき、結合の強さの測定は未確認。
- MPW の 4νy = 9 が失われる点の原因という確認 (νy を動かした比較) はしていない。MPW の内部の RDT・ADTS は `resdrive` の対象外。
- k64 は 2 つのリングで同じだった。v2 と k64 の動作が違う要素 (`set_bend_k1_edge('face')` など) を使う周波数マップは未確認。
- RFSW ON・放射つき・FLUC つきの周波数マップ、PF リングは未確認。δ ≠ 0 の偏向磁石の 3 次の項は ADTS・RDT に入らない。
