## A1. ADTS の J² の項と δ 依存 (`pysad/ampnf.py`、docs/49 §13)

**できるか → できた**。摂動論の次数を明記して解析的に: 模型の 1 周の写像を (x, px, y, py, δ) の 5 変数のべき級数 (TPSA、全次数 D) で厳密に作り、Birkhoff の正規形で ν(Jx, Jy, δ) を級数にした。係数 c_abp のうち 2a + 2b + p ≤ D − 1 が正しい。
J² は D = 5 (6 極の K2⁴・K2² K3・K3²)、ξ1〜ξ4 と J δ² も D = 5、J² δ は D = 6〜7。**追跡のフィットから係数を取らない** (模型の写像の正規形)。

模型は 3 段階で足せる (`bend_cubic`・`kin`・`fringe`): 線形 + 6 極・8 極 (δ の線形の写像は厳密、複素 δ の円周上の Cauchy の公式) → + 偏向磁石の曲率の 3 次の項 (+ E1・E2 の端の 3 次の生成関数、K1 の 3 次の項) → + 運動学的な項 (ドリフト・四極・偏向磁石) + 四極・K1 の偏向磁石の端部のフリンジ。非線形の項は Lie 級数でハミルトン流を次数 D まで厳密に求め、Strang 分割で線形の部分とつなぐ (分割誤差 O(1/n²))。

### 検証と、見つけたこと

1. **J¹ は解析式に収束**: 6 極・8 極だけの模型の J¹ は `resdrive.adts` の 6 極 2 次 + 8 極 1 次に 1/n² (n = 6 極の分割数) で収束 (5.4e-3 → 2.1e-5。比 4.0)。J¹ は K2² だけで決まるので、これは模型・正規形の式・符号の検証。
2. **同じ模型の追跡 + NAFF と 1e-9〜1e-10**: ただし追跡の初期条件の J は正規形の J と O(√J) 違う。Twiss の J で出発して J² の係数をフィットすると c_10 × (J の 2 次の補正) の分だけ偏る。初期条件を正規形の座標から作る (`initial_from_nf`)・追跡の初期座標の J を直す (`nf_action`) と合う。
   **最初の実装の誤り (直した)**: n = 1 (δ の 1 次の単項式 = 分散による軌道のずれ) の変換を飛ばして n = 2 から始めていたので、6 極つきの δ 依存が追跡と 1e-3 違った。もう 1 つは、共鳴の項を残すときに `=` で上書きして線形の λ ζ を消したこと (J¹ が 3 倍に出た)。どちらも追跡との比較 (δ・J の組み合わせ) で見つけた。
3. **偏向磁石の曲率の項を入れないと δ ≠ 0 が合わない**: 6 極なしの FODO で ξ の差 = h11001/π = +0.345 ちょうど (R4 の偏向磁石の分)。ASTRID2 では ν_y の δ = ±1e-3 の差が 3.5e-3。曲率の 3 次の項を入れると 3e-4・7e-5 (ξ)。
4. **端部のフリンジの強さは K1/(1+δ)** (`ampnf.FRINGE_POWER = 1`): 運動学・フリンジを入れた模型の ξ2 は CALC に x 3e-4 (y 2%) で合ったが、ξ3 は δ に依らないフリンジで x 22% ずれた。K1/(1+δ) にすると x 6e-4、y 2.3%。Lee–Whiting の生成関数はスロープ x' = px/(1+δ) で書かれる量 ((x³+3xy²) x' − (y³+3x²y) y') なので、K1/(1+δ) になる。R6 の「端部のフリンジも δ に依らない」は薄い 6 極・四極の kick には正しいが、フリンジの 3 次の項には当てはまらない (影響: ADTS の δ 微分で 0.2% × 68 [1/(m rad)]、R6 の結果は変わらない)。診断のため `FRINGE_POWER` を変えられる。
5. **実際の追跡 (pysad k64) との比較**: FODO・ASTRID2 とも、全部入りの模型 (D = 6) で δ = 0・±1e-3、J 〜 3e-6 (FODO)・3e-8 (ASTRID2) まで |Δν| ≤ 1.2e-6 (FODO)・2.7e-8 (δ = 0)・4.5e-6 (ASTRID2、δ = ±1e-3)。J¹ は `adts().total` と 0.06〜0.15% (残りは K64 の四極の積分器の台形則、§10)。

### 入れなかったもの・理由

- K0≠0・ROTATE の偏向磁石、結合、誤差: 模型の外 (`NotImplementedError`)。
- 偏向磁石の K1 の 4 次以上、K64 の四極の積分器の台形則: 入れていない (J¹ で 0.1% 台)。
- **大きなリング (KEK-LS、3563 要素) の全部入りは測っていない** (ASTRID2 の 200 要素で D = 6 が 22〜32 秒、D = 8 が 255 秒。要素数にほぼ比例するので D = 5 で数分〜十数分と見込む)。6 極だけの模型は DDBA 3540 要素で 2〜3 秒。

## A2. K0≠0 の偏向磁石の E1・E2・ANGLE≠0・ROTATE (resdrive の解析式)

方法: FODO の 1 セルに、5 台の K0≠0 の偏向磁石のブロック (L = 0.1 m、K0 と ANGLE の列 (1/2, −1, 1, −1, 1/2) 倍で、軌道が局所の閉じたバンプ) を入れ、解析式を追跡の 1 周の写像のテイラー展開 (独立な数値) と比べた ([`example/v2_4/A2_k0_bend_check.py`](../../example/v2_4/A2_k0_bend_check.py)、試験 [`test_v24_A2_k0_bend.py`](../../pysad/tests/test_v24_A2_k0_bend.py))。
SAD の E1・E2 は ANGLE の倍率なので、ANGLE ≠ 0 のときだけ端の角が付く。

| E1 = ANGLE (入口だけ) | 1e-7〜8e-7 | 同 |

| ROTATE = 0.02 rad、ANGLE ≠ 0 (警告あり、入れていない) | 1.4e-7〜2.6e-6 | 同上 |

| ROTATE = 0.02 rad、ANGLE = 0 | 8e-10〜3e-9 | |

**見つけた誤り (直した)**: `resdrive.chromaticity_natural` が K0≠0 の偏向磁石の自然なクロマティシティ (K1・h²・端) を足し、`chromaticity_bend` (要素の追跡から全体を取る) もそれを持っていたので **K1≠0 の K0 の偏向磁石で自然な項が 2 重に入っていた** (ξ − CALC が (−0.104, +0.108) → K0≠0 の磁石を飛ばして (+0.015, +0.008))。K1 = 0 の K0 の偏向磁石 (MPW) では自然な項が 0 なので気づかなかった。

**未確認・限界**: (1) ROTATE の入った偏向磁石は入れていない (警告)。理由は、傾いた偏向磁石は垂直分散・結合を作り、`resdrive` の前提 (結合なし・垂直分散なし) を外れるから。入れるには結合した Twiss と傾いた偏向磁石の 3 次の項 (スキューの項) が要る。上の試験では偏向磁石の寄与が小さいので ROTATE の効果は 3e-6 以下で、強い磁石では ROTATE × (磁石の寄与) の誤差が出ると見られる (確認していない)。
(2) K1≠0 の K0 の偏向磁石で ξ が CALC と 0.015 (x)・0.008 (y)、ADTS が数値の正規形と 4e-3 (xx) 違う。K1≠0 の偏向磁石は R6 で本体の閉形式が 1e-4〜3e-4 (K64 の `tbendi` の積分器と推定、照合は未実施) 違っていた分と同じ原因と見られる (K0 を持つと閉軌道が傾くので、近似の誤差が大きくなる)。
(3) 軌道が大きくずれる場合 (K0 の列が局所のバンプでなく、軌道が通常の偏向磁石を通る) は、軌道による光学の変化 (偏向磁石の 3 次の項のフィードダウン) が 1e-3 の程度で `resonance_terms` に入っていない (警告 `スライスの線形写像で伝播した w・分散が Twiss と違う`)。

## A3. Touschek のバンチ内の δ 分布 (`pysad/touschek_bunch.py`、`TouschekLifetimeLMA[BunchDelta->True]`)

**実装した (オプション、既定は入れない)**。散乱後の粒子の δ は δ_c + Δ (δ_c = 対の重心の δ = (δ1+δ2)/2、Δ は相対運動量の散乱だけで決まる)。ガウス分布のバンチでは δ_c ~ N(0, σδ²/2) で相対運動量と独立なので、損失率は R(a ∓ δ_c) の平均。
`touschek_piwinski_bunch(result, ap=, am=)`・`lma.touschek_lifetime_local_piwinski(..., bunch_delta=True)`・台本 `TouschekLifetimeLMA[BunchDelta->True]` (Piwinski 型のみ)。

**独立な検証 (実験室系の 2 粒子の対のモンテカルロ、厳密な相対論の運動学。[`example/v2_4/A3_mc_bunch.py`](../../example/v2_4/A3_mc_bunch.py))**: 同じ標本で判定だけ変えて数えた。
- δ_c の効果だけ (絶対値の判定 / δ_c を基準にした kick の判定 − 1): ASTRID2 (a/σδ = 9.1・13.7) MC +2.84・+1.32% に理論 +2.70・+1.28%、KEK-LS (a/σδ = 8.0・13.3) MC +4.38・+1.75% に理論 +4.32・+1.78% (統計 ±0.3%、スライス 3 つで同じ)。**理論は δ_c の効果を 2% 以内で再現する**。
- 打ち切り floor (a − δ_c の下限) 0.1・0.5 で結果が同じ (a ≳ 5σδ)。

**T2 の概算 (`T2_limits.py` の C) との関係**: 概算は元の δ の分散を σδ² としていた。MC の全体の増え (絶対値の判定 / 通常の kick の判定) は ASTRID2 で +4.8%・+2.2%、KEK-LS で +4.5%・+1.8% で、δ_c の効果 (+2.6%・+1.3% / +4.0%・+1.6%) より ASTRID2 で大きい。**差は相対運動量の縦成分 q_s の効果** (診断: 相対運動量の δ 成分を 0 にすると、通常の kick の判定 = δ_c を基準にした判定になる。ASTRID2 で −2.0%、KEK-LS で −0.5%)。q_s の効果は位置の分散関数との相関 (位置を固定したときの相対 δ の分散) に依る。**q_s の効果は A10 で実装した** (`BunchQs->True`。3 次元の積分で MC と 0.3% 以内)。この節の「入れなかった理由」はそれまでの記述。
T2 の概算 (分散 σδ²) は ASTRID2 では MC の全体と同程度、KEK-LS では 2 倍近く過大。

**elegant との比較**: elegant の `touschekLifetime` には δ の分布を入れる機能が無い (Piwinski の式のまま)。elegant との比較 (T1・T2、δ_c = 0 の値) は変わらない (既定のまま)。`touschek_scatter` による追跡の MC は走らせていない (WSL の elegant の追加の設定と長い計算が要る。上の独立な MC で原理は確認した)。

**既定の判断 (docs/47 の流儀)**: 既定は**入れない**。理由: (1) 入れた分 (δ_c のみ) は物理的に正しいが、q_s の効果 (0.5〜2%) が入っておらず、半分の補正にとどまる、(2) elegant・K64・Piwinski の式と同じ定義 (kick の基準 δ_old = 0) との比較を保つ、(3) a ≲ 3σδ では使えない (警告)。補正の大きさを見積もりたいときにオプションで使う (ASTRID2 a/σδ = 9 で +2.7%、KEK-LS a/σδ = 8 で +4.3% の寿命の短縮)。
**限界**: 小角散乱の発散 (Rutherford の 1/K²) による a − δ_c → 0 の粒子は IBS・量子励起と区別できない (floor で打ち切る)。δ の分布はガウス、σδ はスライスの lab 共分散から (IBS 込み)。受容は位置ごとの LMA (シンクロトロン位相に依らない)。

## A5. DDBA v07_14 の 5 GeV の誤差計算の DA: gs 0〜1σ・pysad 27〜38σ の食い違いの原因

**原因は pysad の `DynamicApertureSurvey` が `ExpandElementValues` を読まなかったこと、および例の台本がこのオプションを使っていなかったこと**。切り分けの手順 (スクラッチで台本を変えて gs と pysad の両方で走らせた):

1. **設計のリング (誤差なし) では gs と pysad が一致**: 5 GeV、RAD・FLUC・COD・RFSW・RADCOD ON、200 周、δ = 0 の x・y の DA が gs・pysad とも 36σ (放射・RF の設定の違いではない)。
2. **誤差つきで補正した状態 (種 1) を DA の前に調べた**: 補正後のチューン (47.8649, 16.6597)、COD が数 μm、補正磁石の K0 は HD.5 = −2.35e-5・HD.9 = 3.08e-5 (成分ごとに違う、gs・pysad とも)。`TrackParticles` で COD から 0.5〜30 × 6.6e-5 m (5 点) 200 周追跡すると、gs・pysad とも全部生き残る。
3. **`DynamicApertureSurvey` (既定) のあと**: gs も pysad も **チューンが (47.9601, 16.6851) に変わり、COD が −1.8 mm になり、HD.5 = HD.9 = 3.656e-5 (成分ごとの K0 が代表の値に揃う)**。つまり既定の `ExpandElementValues->True` (gs の help: `set the values of the components according to the values of elements. Machine errors may be reset`) が補正した K0 を消し、そのあと追跡した DA は補正していないリングの値。種 1 は DA = 0 (gs・pysad とも)、種 2 は gs が 0・1σ・0、pysad が 0・38σ・0 になったのは、補正が消えたあとのカオス的な縁の値。
4. **`ExpandElementValues->False` にすると gs の DA は補正した状態のまま**: チューン・K0 が保たれ、DA は種 1 で x・y とも **34σ**、種 2 で **29σ** (δ = ±5% は 0)。DDBA の記録 (最悪 30σ・平均 40σ) と同じ水準。
5. **pysad は False を読まず、常に揃えていた** (`ffscmd.fn_dasurvey` が先頭で `spread_pending()` を呼び、`ExpandElementValues`・`ReferenceOrbit` を読まない。docs/09 の「未対応」)。そこで `ExpandElementValues->False` なら揃えない、`ReferenceOrbit->{x0,…}` を追跡の初期軌道にする、を入れた ([`ffscmd.py`](../../pysad/ffscmd.py) に 6 行、[`dapert.py`](../../pysad/dapert.py) に 3 行。他の作業者のファイルだが、原因を確定した最小の変更)。
   直したあとの pysad の DA: 種 1 で x 35σ・y 33σ (gs 34σ・34σ)、種 2 で 29σ・29σ (gs 29σ・29σ)。チューン・K0 も gs と同じ (DA のあとも変わらない)。1σ の差は RAD・FLUC の乱数の違い。
6. 副次的に見つけたこと: pysad は台本の `FFS["USE RING NOEXPAND;"]` (文字列の FFS 呼び出し) で `?Undefined command or element: noexpand` を出す (gs は受ける)。結果には影響しない (各種の最後に誤差・K0 を 0 に戻すので)。parser/fit の担当に渡す。

## A6. 6 極検討 (sxtopt) と周波数マップの予想 (S3) の位置づけ

### sxtopt (R7)
A1 の `ampnf` で J² と δ 依存の量が解析量になったので、R7 の 32 組に足して追跡の判定との順位相関を見た ([`example/ddba/v07_14/sextupole/sextupole_j2_check.py`](../../example/ddba/v07_14/sextupole/sextupole_j2_check.py)、`results/j2_correlation.out.txt`)。ampnf は 6 極・8 極だけの模型 (D = 5、DDBA 3540 要素で 1 組 2〜3 秒)。
- **J² の項 (‖c‖) は単独で R7 の目的関数と同じ水準以上の順位相関を持つ**: 全 32 組で DA 面積 ρ = −0.93 (目的関数 −0.89、|ADTS| −0.79)、x-δ 幅 −0.85 (−0.76)、LMA −0.78 (−0.64)。最終設定の近く (20 組) で DA 面積 −0.78 (−0.66)、x-δ 幅 −0.51 (−0.15)、LMA −0.49 (−0.07)。J¹ (|ADTS|) より J² の方が強い。
- **∂ADTS/∂δ・∂²ADTS/∂δ²** (ampnf): 全組で −0.68〜−0.80。最適化の結果 11 組では ∂ADTS/∂δ が x-δ 幅と −0.85 (R7 の nform の値 −0.81 と同じ)。
- **しかし最終設定と最適化の結果の差は J² で説明できない**: |J²| が最も小さい 6 組はほぼ最適化の結果 (9e9〜1.4e10) で、最終設定 (1.7e10) より小さいが、DA 面積は最適化の結果 35〜36 mm² で最終設定 51 mm²・rev9 61 mm² より小さい (R7 の J_ref = 3e-7 の変種と同じ)。
**位置づけ (結論)**: sxtopt は 6 極の組の**検証・スクリーニング**の道具 (大きなダイナミックレンジの順位付け、J²・δ 依存を足すとさらに良い) で、**最終設定より DA の広い解を作る最適化には使えない**。最適化の結果が J²・δ 依存でも最終設定に及ばない不足は、解析量に入れていない効果 (5 次以上の共鳴の駆動項、6 極と偏向磁石の交差項の J²、δ ≠ 0 の h) と見られる。**J² を目的関数に入れた最適化は行わなかった**: J² は K2 の 4 次式で、sxtopt の勾配 (K2L の 2 次式の係数のテーブル) に載らない。数値勾配は 1 回の評価 2 秒 × 21 変数で、SLSQP の 1 反復が 40 秒、収束まで数時間かかる。J² が最終設定との差の原因でないことは上の表で分かっているので、行っても結論は変わらないと判断した。

### 周波数マップの共鳴線の予想 (S3)
原因 (確定): **ν(J) の誤差ではない**。S3 の診断 (追跡のチューンを与える) で ASTRID2 (AUC 0.68 → 0.64)・KEK-LS (0.59 → 0.47) は上がらない (ν(J) を完全に直しても判別力が出ない)。A1・A5 で ν(J) の J²・次数を入れても、ASTRID2 の格子の ν(J) の誤差が J¹ のみ → J² まで 1/2〜1/5 に減るだけ (小〜中振幅)、予想の判別力は ν(J) に依らない。原因は S3 に書いた次数 5 以上の共鳴 (D > −5 の点の 17% はどの線にも近くない、31% が 5 次の線)、共鳴の重なり、D の確率的な大きさ。**実装しない理由**: 5 次以上の共鳴の駆動項の解析式は 6 極の 3 次の項まで (正規形で 5 次以上の h を取るには 4 次のテイラー展開 T₄ が要り、差分の取り出しは 7 次以上の項と丸め誤差の兼ね合いで 3 次より悪い。`ampnf` の正規形は共鳴の項を残すので、h の係数としては使えるが、h は共鳴ごとの有限の係数で、D の大きさを決める島の重なり・拡散の式は摂動論の範囲外)。
