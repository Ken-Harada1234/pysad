# v2.3.0 担当 R1: ADTS の gs と pysad の不一致の原因 (2026-11-20)

課題 (Q2 の未解決): ASTRID2 と大きなリング A (kek-ls_v03_12.lat、3 GeV、603 m) で、6 極の強さを ×0・×−1 にした gs (SAD K64) の TrackParticles の ADTS が pysad (k64)・解析と違う (×1 と FODO は一致)。
結論: **原因は gs の台本の RFSW。K64 のバグでも pysad の誤りでもない。pysad・gs のコードは変えていない。**

## 原因

FFS に入ると RFSW は ON に強制される (track.f:146-149。gs の起動時の表示 `RFSW F` は MAIN の値)。したがって台本の TrackParticles は、RF つきのラティスで空洞を働かせる (tcav.f: RFSW OFF のときだけ tlim = 0 で t = 0、z = 0)。
Q2 の gs の台本は 1 周ずつ z を 0 に戻して回したが、1 周のあいだの z (横方向の振幅による経路長の変化、∝ J) に応じて空洞が δ を与える (ASTRID2: V = 50 kV、104.95 MHz、1 周目で δ ≈ −3e-9 (x = 1 mm))。
この δ は周を重ねて蓄積し (δ は戻さない)、(自然クロマティシティ) × δ(J) の**偽の ADTS** になる。
- 6 極 ×1: クロマティシティがほぼ 0 (補正済みの設計) なので見えない。→ 全部入りは一致。
- FODO: 空洞なし。→ 一致。
- 6 極 ×0・×−1: 自然クロマティシティが大きい (×−1 は 2 倍) ので大きく食い違う。追跡の周数にも依る (大きなリング A の ×0: 512 周で 19106、1024 周で 35320)。
- チューンの 1.1e-5 の差 (大きなリング A) も同じ (振幅 J = 2e-10 での δ 起因)。

## 直したもの

- コードは変更なし (pysad・gs とも)。互換モードの分岐も不要。
- `example/v2_3/Q2_adts_gs.py`: 台本に `NORFSW;` を入れる (既定)。`--rfsw` で旧来 (RFSW ON) に戻せる (対照実験)。旧版 (`Q2_adts_gs_*.txt`) は消さず、RF なしの新しい出力を `R1_adts_gs_*_norfsw.txt`、対照を `R1_adts_gs_*_rfsw*.txt` に置いた。
- 試験 `pysad/tests/test_v23_R1_rfsw_adts.py` (2 件): ASTRID2 ×0 の ADTS が、RF なしで gs の `NORFSW;` と 1e-6、RF ON (z を毎周 0) で gs の既定と 1e-3 で一致し、RF の有無で 5% 以上違う。
- 文書: docs/49 (§5 の注意、§6)、docs/47・46、`example/v2_3/Q2_README.md`、`R1_README.md`、00_RESUME、CHANGELOG の「未解決」から ADTS の不一致を外した。

## 使える範囲・限界・未確認

- 一致を確かめた条件: k64、δ = 0 の初期条件、1 周ずつ z を 0 に戻す (RF ON の場合)、RF なし (NORFSW)。ASTRID2 (0.58 GeV、45.7 m、V = 50 kV)、大きなリング A (3 GeV、603 m、RF つき)。FODO は空洞なし。
- RF ON の gs と pysad の ADTS は、NAFF の窓が 1 周ずれる (pysad は初期値を含む) ため 2e-4 だけ違う (座標は 1e-16 で一致)。RF ON の ADTS はシンクロトロン振動の位相と周数に依るので、ADTS の基準値には使えない。
- gs の TrackParticles の RFSW の既定が ON であることは新しい発見ではなく (track.f:146-149、`ffscmd.py` の `_FLAGS_DEFAULT` が既に再現している)、Q2 の台本が見落としていた。K64 の誤りではないので B 番号は付けない。
- Q2 の「gs の z の持ち越し」(RFSW OFF でも z を返す) の記述は、正しくは「RFSW ON (既定) だから z を返す」。NORFSW なら z = 0 (空洞が止まる)。
- 未解決: なし (この課題について)。他の ASTRID2・大きなリング A での gs の追跡の比較 (Q1 の周波数マップなど) は RF ON で pysad と一致を確認済みの設定なので影響しない。
