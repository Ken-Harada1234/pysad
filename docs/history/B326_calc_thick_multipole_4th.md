# v2.5.0 記録: CALC・Emittance[] の厚い多極を追跡と同じ 4 次の分割にする (B326)

試験 `pysad/tests/script_tests/test_v250_calc_thick_sext_4th.py` (35 件)、`test_v250_chromaticity_bend.py` (19 件)。コードは `lattice._tthine_cod`・`_thin4_corr`・`_thin4_active`、`emit6d._jac_thin4`・`_jac_thin`、`elkern._tthine_map`・`_jac_thin4`・`_thin4_corr`・`_jac_thin`。

## 1. 症状

3 GeV・周長 41.6 m・8 セル (QF D1 B D2 SF QD D1 B D2) のリングで SF を厚い 6 極 (K2 = 2、L = 0.2 m) にすると、`Lattice.chromaticity()` (= CALC) の dν/dδ が追跡のヤコビアンと水平で 4.4e-4 (相対) ずれた。差は L² に比例し、薄い 6 極 (L = 0) では消える。追跡は gs の `TrackParticles` と 1e-16 で一致する。

## 2. 原因

K64 の CALC の厚い多極 (`tthine.f`) は L/6・キック/2・2L/3・キック/2・L/6 の 2 次の分割で、補正キックがない。追跡 (`tquad.f` の `tthin`) は L(1/2−α)・キック/2・αL・補正キック・αL・キック/2・L(1/2−α) (α = 1/√12) の 4 次の力勾配型。動いた軌道のまわりの線形化 (行列) は、分割の誤差の分だけ違う (physics_guide/03 §8、07 §5〜§7)。

## 3. 修正 (v2 のみ。`compat.v2()` で分岐、k64 は K64 のまま)

- 対象: SEXT・OCT・DECA・DODECA の L ≠ 0 (`_thin4_active`: v2 かつ L ≠ 0 かつ ak ≠ 0 かつ kord ≥ 2)。CALC (`twiss_table`・`chromaticity()`)・Emittance[]・Touschek の CALC 部 (`emit6d._tthine`・`elkern.k_thin`・`turnkern`) の全部が同じ関数を通る。L = 0 は変えない。
- COD の写像: 係数 (α、β、γ) と補正キックの式は `tquad.f:208-285` (f1〜f5) と `track6._tthin_gen` に一致させた。CALC の運動量は正準なので、補正キックは追跡の規格化した運動量の式に (1+δ) を掛けた形 (physics_guide/07 §7)。追跡の `_tthin_sext` の 1 刻みの写像との差は 1e-14 以内 (実測 3e-20、k = 2〜5、L = 0.1・0.4 m)。
- 行列: 4 次の写像の COD まわりの微分を、解析式の連鎖律で作る (厳密なドリフトの行列、キックの行列、補正キックの (x, y, δ) での微分の積)。数値微分は使わない (ドリフトの pz が潰れるときだけ従来の数値微分に落ちる)。
- 刻み数: `tthin` と同じ 1 刻み (`setndivelm(l, 1)`)。軌道の振幅に依らない。

## 4. 確認

- 写像と行列の厳密な積分との比較 (運動方程式と変分方程式を DOP853 rtol 1e-13 で積分、x = 3 mm、y = −2 mm、px = 1 mrad、py = 0.5 mrad、δ = 2e-3): 行列の最大差は、6 極 (κ = 50 /m³) で L = 0.4・0.2・0.1 m に対し v2 が 1.7e-6・5.0e-8・1.5e-9 (比 33〜34、L⁵)、k64 が 2.8e-4・3.4e-5・4.2e-6 (比 8、L³)。8 極・10 極・12 極も同じ (L = 0.2 m で v2 が k64 の 1/260〜1/17000)。
- シンプレクティック性: 6×6 で 1e-16 (k = 2〜5、dv 項つき)。numba 版と python 版の行列は 1e-12 以内 (フリンジあり・なし、ロールあり)。数値微分との差は 1e-8 以下。
- リング: 上のリングの dν/dδ (水平、垂直) は、v2 の CALC (3.32016, −19.99794) が追跡 (3.32017, −19.99798) と 3e-6 (相対) 以内、k64 (3.32163, −19.99773) は 4.4e-4。K2 = 4・L = 0.4 は v2 が追跡と 1e-10。`bend_k1_edge_sext` (E1 = E2 = 0.05、K1 = 0.02、SF・SD の 6 極) で v2 の (−21.15706, −1.44869) は追跡と 1.5e-9、gs (K64) の (−21.15869, −1.44809) とは 7.7e-5・4.2e-4 離れる。
- k64 のビット同一: 変更前のコミットで計算した COD・ヤコビアン・numba 版の行列・chromaticity() (28 項目の float.hex) が k64 で全部一致。v2 の L = 0 (COD・ヤコビアン・numba 版・薄い 6 極リングの chromaticity()) も変更前とビット単位で同じ。

## 5. 影響範囲

設計軌道上 (COD = 0) の 6 極のキックのヤコビアンは 0 (k ≥ 2) で、補正キックのヤコビアンも 0 なので、行列はドリフト。したがって、COD が 6 極の中を通らない量は動かない。動くのは、動いた軌道のまわりの線形化を使う量: `chromaticity()`・δ ≠ 0 の Twiss・ずれた 6 極・steering のある軌道・Emittance[] の分散軌道の部分。

| 量 | 条件 | v2 の変更前 | v2 (4 次) | 動き |
|---|---|---|---|---|
| `chromaticity()` (水平、垂直) | 大きなリング A (3 GeV、L = 0.045 m の 6 極、`pysad/tests/kek-ls_v03_12.lat`) | (−0.06134, 0.05393) | (−0.05904, 0.05600) | +2.3e-3、+2.1e-3 (追跡 δ = ±1e-4 の差分 (−0.05903, 0.05602) と 2e-5 以内に一致) |
| 同上 | ASTRID2 (0.58 GeV、`example/astrid/lattice/ASTRID2_v01_01.sad`) | (−2.1e-4, −2.8e-4) | (0.02337, 0.03462) | +0.0236、+0.0349 (追跡 (0.02337, 0.03462) と 2e-9 以内に一致) |
| ADTS (`adts().sext`)・共鳴駆動項 h30000 | 同じ 2 リング | | | 変化なし (差 0。解析式は COD = 0 の薄レンズ。`optics='calc'` の線形光学も COD = 0) |
| ampnf・周波数マップ・LMA・Touschek の追跡 | | | | 追跡は元から 4 次なので変化なし。CALC の光学 (δ = 0、COD = 0) も変化なし |

chromaticity() の動きは、変更前の値が追跡から 4 次の分割の誤差の分だけ外れていたのを直したもので、値が追跡に一致する方向。ASTRID2 は 6 極で補正した残りの色収差がほぼ 0 から +0.02〜0.03 になる (自然色収差の 1e-3 程度)。

## 6. 未確認・限界

- 試験の条件: 1 つの軌道、L = 0.1〜0.4 m、K2 = 2〜50 (8 極以上はそれに合わせた強さ)、3 GeV の 8 セルのリング 1 つと、大きなリング A・ASTRID2 の chromaticity()。他のエネルギー・分散の大きい所の強い 6 極での値は未確認。
- ずれ (DX・DY)・ロールつきの 6 極は、行列のシンプレクティック性と numba・python の一致だけ見た (追跡の 1 周写像との比較はしていない)。
- MULT の厚いキック (`tmulte` の `tmulke` の分割、ndiv 刻み) と、BEND の 6 極成分 (`tbende`) は対象外 (従来のまま)。
- 放射 (`tradke`) の経路は本体の写像の前後で呼ぶだけで、本体の分割次数が変わるだけ。Emittance[] の値の動きは測っていない。
- 補正キックの `1/(1+δ)` の依存 (δ の列の微分) は、数値微分との一致 (1e-8) と厳密な積分の δ の列との一致 (L⁵) で確認した。
