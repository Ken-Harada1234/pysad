# v2.5.0 記録: Polarization の側帯の和の打ち切り (B341)

試験 `pysad/tests/script_tests/test_v250_sideband_truncation.py`、`test_v2_P1_st.py::test_rotated_insertion_device_polarization_v2`。コードは `spin.sideband_depolarization`・`spin.slim_depolarization`。

## 1. 症状

B326 (CALC の厚い 6 極を 4 次の分割に、`B326_calc_thick_multipole_4th.md`) の後、`test_rotated_insertion_device_polarization_v2[0.3-0.008]` (ASTRID2 + MPW の ROTATE = 0.3 rad、0.58 GeV) の P_eq / P_dk − 1 が −1.16% → −1.94% に広がった。P_eq 0.580877 → 0.576289、τ は不変、独立な P_dk = 0.587714 は不変。B326 は追跡に近づく修正なのに、DK との差が広がった。

## 2. 切り分け

P = PST (sdamp − kin)/(srel + rate) を DK (`_p1_dk.py`) の対応する量と成分ごとに比べた (B326 後):

| 量 | CALC | DK | 差 |
|---|---|---|---|
| 分子 / 緩和率 (sdamp/srel と Σwn/c1) | 0.759582 | 0.759620 | 5e-5 |
| 運動論的偏極 / 分子 | −5e-6 | −4e-6 | 同じ |
| τ (taup/τ_ST − 1) | 1.336e-3 | | B326 の前後で不変 |
| 脱偏極率 / 緩和率 | 0.2176 | 0.1940 | +12% |

差は脱偏極率だけ。脱偏極率の内訳 (CALC、B326 後): 線形 (放射の刻みごとの積分) 0.2052、側帯込み 0.2176。B326 の前は線形 0.2054、側帯込み 0.2080。つまり **B326 が動かしたのは線形の部分でなく側帯の部分** (側帯の増分 0.0026 → 0.0124)。

- 要素ごとの比較 (DK の COD の周りで、各要素の T・R・D を CALC の `tturne` と追跡の差分で比べた): 6 極の T は 1.7e-12、R は 1e-19、D は 4e-9 (|D| = 7e-3) で追跡と一致 (SD・SF)。6 極のスピン側は問題ない (仮説 (a) は否定)。
- 6 極を切る (K2 = 0): P_eq/P_dk − 1 は (補正前) −4.8%。6 極の有無で差が出るのではなく、側帯の部分が大きく動いた。
- `SIDEBAND = False` (線形だけ): B326 後 −0.93%、B326 の前 −0.95%。**B326 の有無で 0.02% しか動かない**。
- 側帯の和の中身 (`spin.sideband_depolarization`): K = 300001 で kmax に当たっている。1 周の写像の |λ|max = 0.9999927 (減衰時間 1.4e5 周)、tol = 1e-7 に必要な K = 2.2e6。kmax を 1e5・3e5・6e5・1.2e6・2.5e6 に上げて、変調なしの和 (厳密な線形の脱偏極率 1.427354e-12。線形の周期解 N0 から作った値) と比べた:

| kmax | B326 後: 変調なし | 変調あり/なし | B326 の前: 変調なし | 変調あり/なし |
|---|---|---|---|---|
| 1e5 | 1.7528e-12 | 0.9986 | 0.9896e-12 | 1.0236 |
| 3e5 (既定) | 1.5188e-12 (+6.4%) | 0.9967 | 1.4470e-12 (+1.3%) | 0.9997 |
| 6e5 | 1.4355e-12 | 0.99984 | 1.4490e-12 | 0.9993 |
| 1.2e6 | 1.4271e-12 | 1.00022 | 1.4286e-12 | 1.00022 |
| 2.5e6 | 1.427355e-12 | 1.00021 | 1.428798e-12 | 1.00021 |

収束した和では、変調あり/なし = 1.0002 (側帯の効果は 0.02%)。線形の和は厳密な線形の値 (1.427354e-12) に 6 桁で一致する。打ち切った和 (kmax = 3e5) は、残り e^{-K/τ} ≈ 0.1 の位相 e^{-iμK}λ^K を持ち、これはチューンの 1e-6 の変化 (K × 2π × 1e-6 ≈ 1.9 rad) で回る。B326 は 6 極の線形化を 1e-5 の大きさで動かし、チューンが動いて残りの位相が回った。B326 の物理 (追跡との整合) とは無関係。

## 3. 原因 (確定)

pysad 自身の数値の誤り (K64 のバグではない)。`kmax` を超えて必要な項数があるとき、打ち切りを検出しておらず、打ち切りの残りを含む和をそのまま使っていた。放射減衰が弱い低エネルギーのリング (ASTRID2) で起きる。

## 4. 修正 (v2 のみ)

`sideband_depolarization` が、打ち切られた (ln tol/ln|λ|max > kmax) とき、同じ K・同じ試料の変調なしの和 (`rate_lin_sameK`・`spread_lin_sameK`) を返す。`slim_depolarization` は、脱偏極率を
rate = rate_step (放射の刻みごとの線形の積分) + (変調あり − 変調なし、同じ K)
とする (従来は rate_step + (変調あり − 厳密な線形の `rate_el`) で、打ち切りの残りが入っていた)。n の広がり (`spin_spread_sb`) も同じ。収束している場合は従来と同じ。

結果 (ASTRID2 + MPW ROTATE = 0.3):

| | P_eq | P_eq/P_dk − 1 | 脱偏極率/緩和率 |
|---|---|---|---|
| B326 後、補正前 | 0.576289 | −1.944% | 0.2176 |
| B326 の前、補正前 | 0.580877 | −1.163% | 0.2080 |
| **B326 後、補正後** | 0.582578 | −0.874% | 0.2044 |
| B326 の前、補正後 | 0.582136 | −0.949% | 0.2053 |
| B326 後、SIDEBAND = False | 0.582229 | −0.933% | 0.2052 |
| B326 後、補正後、K2 = 0 (6 極なし) | 0.545871 | −0.979% | 0.2854 |
| B326 後、補正後、chi = π/2 | 0.701027 | −0.106% | 0.0011 |
| 6 極を薄いキック 1・4・16 個に分ける (補正後) | 0.581789・0.582022・0.581562 | −0.977%・−0.893%・−0.969% | |

B326 の寄与は +0.075% で、追跡に近づく向き。6 極の有無・薄い極限・厚い 4 次 (B326) のどれでも P_eq/P_dk − 1 は −0.87〜−0.98% の範囲に入る。

## 5. 残る約 −0.9% の原因 (部分的に確定、全部は未確認)

6 極とは無関係 (K2 = 0 でも −0.98%)。脱偏極率の部分で、CALC の線形の step 積分 0.2052 対 DK の 0.1940 (緩和率の比)。偏向磁石 BH (K1 ≠ 0) の寄与の差 (CALC 1.4266e-12、DK 1.3518e-12)。

- DK の側が刻みに強く依存する: `ds_max` = 0.2・0.1・0.05・0.025・0.0125 m で P_dk = 0.585493・0.585458・0.587714・0.592846・0.603491 (脱偏極率の比 0.1985・0.1986・0.1940・0.1836・0.1628)。収束していない。
- 同じ刻みに切った要素の列を CALC (`slim_depolarization` の step 積分) に渡すと同じ向きに動く (0.2052 (刻みなし)・0.2020・0.1988・0.1924・0.1800・0.1558)。K1 = 0 の BEND の追跡のスピン軌道結合 D も、刻みを細かくしたときの合成が、そのまま 1 要素で追跡したときと合わない (K1 = 0・17 分割で 4.5%、68 分割で 17%。1 要素の追跡の D 対 分割した追跡の D の合成。同じ要素の CALC でも 7〜9%)。
- これは docs/30 の B136 (py ≠ 0 の偏向磁石の本体で B∥ = B·v̂ の歳差 (1+a)B∥ を入れない) と B137 (K1 = 0 の BEND の追跡の D の刻み依存。「P の脱偏極率の部分の 2〜3% の残差の原因の一つ」) と同じ現象。**K64・追跡・Emittance[] の 3 つとも同じ省略**で、直していない (要判断)。この ASTRID2 + 傾いた MPW のリングでは垂直の軌道の傾きが大きく (MPW の中で y = 0.4 mm、py = 9 mrad。ほかの所は y ~ 1e-7 m)、BH の D の y・py 列 (X[0,2:4]) が刻みで 15% 動く。DK の 0.05 m の刻みは追跡の側の D を使うので、P_dk の値自体が ±1% の幅を持つ。

## 6. 未確認・限界

- 追跡 (TrackParticles) の脱偏極 (FLUC つき) の測定との比較は未実施。どちらが正しいか (CALC か DK か) は、B136 を直さずには決まらない。
- 補正後の側帯の和は、kmax = 3e5 での打ち切りの残りを「変調あり − なし」の差で消すので、脱偏極率の 0.4% (この ASTRID2、kmax = 3e5 で変調あり/なし 0.9967 対 収束値 1.0002 の差から) 程度の誤差が残る。収束させるには K を増やす (計算が K に比例して重い。1024 試料で 2.5e6 周は約 7 分)。
- 試験は模型のリング (1 要素、減衰 1e-5、チューンの 1e-6 の変化) と、ASTRID2 + MPW (0.58 GeV) だけ。減衰が弱い大きなリングでは `CHROM_KMAX` (6e4) を超えると色収差の項は元々入れない。
- B326 そのものの確認 (追跡との一致 3e-6) は変わらない。
