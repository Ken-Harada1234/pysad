## 2. 項目 2: n が傾く・非平面のリングの緩和率 (B116)

### 2.1 厳密式の導出

Baier-Katkov (Jackson 1976) のスピン反転の率: 磁場の向き b、速度 v、スピンの向き n (量子化軸) の電子が磁場 (曲率半径 ρ) の中で放射するとき、n の向きと反対向きに反転する率は
W↑↓ = A (c1 + c2)、W↓↑ = A (c1 − c2)、A = (5√3/16) r_e ƛ_C c γ⁵ |ρ|⁻³、c1 = 1 − (2/9)(n·v)²、c2 = (8√3/15) n·b。
偏極 P = N↑ − N↓ の変化は dP/dt = −2A (c1 P + c2) = −(1/τ_ST) (P + P_ST n·b/…) の形で、**緩和率は c1 の項だけ**: 1/τ_ST = (5√3/8) r_e ƛ_C c γ⁵ ⟨|ρ|⁻³ (1 − 2/9 (n·v)²)⟩、n·b の項は平衡偏極度 (P = −(8/5√3) ⟨ρ⁻³ n·b⟩/⟨|ρ|⁻³ c1⟩) だけを決める。
軌道の振幅についての 1 次の補正 (Derbenev-Kondratenko): 分子に −b·∂n/∂δ (運動論的偏極)、分母に (11/18)|∂n/∂δ|² (脱偏極)。∂n/∂δ は**位置と角度を固定した δ の偏微分** (放射の跳びが動かすスピン軸の変化) で、SLIM の N の δ 列。
閉軌道で δ を変えたときの n の変化 (分散軌道に沿った全微分) ではない (§2.4 で確かめた)。

v2.1.0 (A2) の緩和率 Σ r_i (b_i·n)² は、n ∥ b (平面リング) では c1 の和と同じだが、n が b に垂直 (垂直の偏向の中、水平磁場の挿入光源) では 0 になり、反転を数えない。傾いた n では 1 − (b·n)² の分だけ過小になる。

### 2.3 追跡の ROTATE のスピン (K64 の新しい誤りの候補)

ROTATE = 90°・K0 = 0.064・L = 0.0875 m の BEND (磁場は水平) 1 台で、追跡 (track6) のスピン回転行列は y (鉛直) 軸のまわりの回転 (R[0,2] = −0.1479) で、厳密な Thomas-BMT の積分 (実験室系、`test_v2_C2_spin._tbmt`) と Emittance[] の srot (tchge でスピンの系を回す) は x のまわりの回転 (R[1,2] = +0.1479)。
追跡の `tbshift`・`tent` は座標 (x, y, px, py) を回すがスピンを回さない (QUAD の `tsolrot` は回す)。v2 の修正後は厳密な積分と 1e-9。k64 は 0.1 以上違う (`test_tracking_spin_of_rotated_bend_*`)。
gs (K64) の追跡のスピンも同じかどうかは **gs で確かめていない** (pysad の k64 は K64 の翻訳なので同じと推定。`B` 番号は親が決める。docs/21 の候補)。Emittance[] (CALC 側) は正しい。

### 2.4 独立な計算 (`_p1_dk.py`) と結果

方法: BEND を 0.05 m の刻みに分け (QUAD は刻まない: 端のフリンジが刻みごとに入るので。四極の ρ⁻³ は偏向磁石の 1e-6 倍以下)、追跡 (RAD ON・損失は `emit6d.CAVE` の 1e-9 倍) で 6 次元の閉軌道と刻みごとの写像 T_i・スピンの回転 R_i・スピン軌道結合 D_i (有限差分) を作り、
N の周期解 (N_{i+1} T_i = R_i N_i + [n_{i+1}]× D_i) から刻みごとの ∂n/∂δ = N の δ 列、ρ⁻¹ = |B⊥| と b̂ = B⊥/|B⊥| (B = (k y, h + k x, 0)·Bρ。要素の系から ROTATE・DX・DY で ring の系に直す)、v̂ を取り、DK の式を足す。
Emittance[] の POL の量 (tradke・gintd・SLIM の N)・放射積分は使わない。**ただし N の元の D は追跡から取る**ので、追跡と Emittance[] の D の違い (§5) は P の独立な値の幅に入る。
検算: 平面リング (n ∥ b) で τ が v2 と 2e-6、P = 8/(5√3)。分散軌道に沿った全微分 (n の閉軌道の δ 微分) と SLIM の N の δ 列・x 列の組 (N·η) が 1〜5% で合う (δ 列そのものは §5)。

### 2.5 使える範囲と条件 / 使えない範囲

- 使える: Polarization・PolarizationTime (v2)。n が傾く (ソレノイド・スピンローテータ)・垂直の偏向・水平磁場の挿入光源・垂直の分散のあるリング。τ は DK の積分と 1e-5〜2e-3。P は ±1% (脱偏極率が分母の 10% 以下のとき)。

  (4) 放射の刻みの重み w は K64 の磁場の向き ĝ (歳差ベクトルの向き。B∥ があるとき b̂ と違う) ではなく b̂ を運動論的偏極と脱偏極率に使い、緩和率は ĝ の n·b の分子 (sdamp) と並ぶ K64 の混在のまま (ソレノイド領域以外は ĝ ≈ b̂)。

## 4. 項目 1: 脱偏極率が追跡の 2.3 倍小さい件

### 4.1 切り分けの方法 (E の続き)

蹴り (放射の光子 1 個 = δ に h) へのスピン軸の応答 G を、FLUC なし・損失なしの追跡でスピンチューンの線の複素振幅 (NAFF) から測る (E §4.1)。同じ初期条件 (振幅は平衡のビーム行列の f 倍) で次の模型を比べる (`_p1_models.py`):
M1 (線形の軌道 + 線形のスピン軌道結合 = 式の前提)、M2 (追跡: 非線形の軌道 + 厳密なスピン)、Mx (追跡の軌道 + 線形のスピン: 軌道の非線形だけ)、My (線形の軌道 + 厳密なスピン: スピンの非線形だけ)、My[d]・My[dx] (My で厳密なスピンに渡す座標を δ だけ・x, px, δ にする)、
chr (線形のスピン + 1 周の写像の 2 次のテイラー展開の δ×横方向の項だけ残した軌道 F(u) = Mu + δ C u_β)。4.2 GeV・12 MV の 12 セル FODO (四極の縦ずれ ±3 mm、νs = 0.030)。NAFF は 1000 周。

- (a) 振幅依存のスピンチューン: 閉軌道上のスピンチューンは ν = aγ(1+δ) で厳密に δ の 1 次 (偏向磁石の中のスピンの歳差は運動量に依らず a e B t/m、軌道の全曲げ角が 2π なので和は aγ(1+δ)2π)。My[d] (δ だけ厳密) の応答は 0.02 (線形のスピン軌道結合の δ 列だけが残り、x 列がないので小さい)。**(a) は効かない**。
- (b) 分散のある場所の x×δ の 2 次のスピン結合: My[dx] 0.61 → My 0.75 で、スピンの非線形 (My) は全体で 0.75 倍。**(b) は応答を減らす向きで、増やす向きではない**。
- (c) δ の非ガウス性: FLUC の高速追跡 (400 粒子、6000 周の後 2000 周) の δ: rms 1.867e-3 (Emittance[] 1.839e-3)、歪度 −0.012、超過尖度 −0.08、|δ| > 2σ・3σ の割合 0.0442・0.00225 (ガウス 0.0455・0.0027)。**(c) は効かない** (RF の sin の非線形: bucket の位相 ±0.25 rad (2σ) で νs の変化 0.4% 以下)。
- **本体は軌道のチューンの δ 依存**。このリングの ν_spin の端数 (−0.2359) = νx の端数 (−0.2906) + 0.0547 = νx + 2νs − 0.005 (νs = 0.030): スピンチューンが水平ベータトロンの 2 次のシンクロトロン側帯の共鳴に離調 0.005 まで近く、スピンの位相の変調 (aγ_eff = 4.76 /δ) とベータトロンの位相の変調 (dν/dδ = 2.66 /δ = 1σ で変調指数 0.16) の**差**が側帯の重み (ベッセル関数) を決める。
  6 MV (νs = 0.020)・24 MV (νs = 0.043) では共鳴から離れ、E の δ の応答の比が 1.08・1.29 と小さいことと合う。

### 4.3 式への取り込み (`spin.sideband_depolarization(..., C6=...)`)

B3 の式 α*(u) = −Σ_k e^{−iμk} e^{−iS_k} G·u_k (S_k = Σ_{t≤k} P·u_t) の u_k を、ベータトロンの固有モード j の位相が δ_t で変調される軌道に替える:
u_{k,j} = c_j λ_j^k exp(i ξ_j Δ_k)、Δ_k = Σ_{t<k} δ_t (δ_t = 線形のシンクロトロン解 = e_δ·M^t u)、ξ_j = Im[(V⁻¹ C6 V)_jj / λ_j] (rad/δ)。C6 = 1 周の写像 (T + D) の δ 微分 = 閉軌道を分散軌道の向き (η_x, η_px, η_y, η_py, 0, 1) に ±1e-4 ずらして要素ごとのヤコビアンを掛けた中心差分 (`_chromatic_matrix`。2 周分の `tturne`)。
S_k と勾配 ∂α*/∂u も同じ軌道で組み直す (∂Δ_k/∂u を通る項が増える)。シンクロトロンのモード (z・δ 成分が大きい 2 つ) の ξ は 0 (RF の非線形・α₂ は入れない)。
この模型の 12 MV の ξ_x = 2π × 2.656、ξ_y = 2π × 2.609 (dν/dδ。追跡の 4 次元ブロックの固有位相の δ 差分と 1e-3)、変調指数 (ベータトロン) 0.163、(スピン) 0.298。

導出の検算 (`t17`、16 試料): 式の δ の蹴りへの応答 |∂α*/∂u_δ| は、ξ = 0 で M1 と 12% 以内、クロマティックは M2 と同じ向きに動く (対数比の相関 0.95)。**<G²> の平均は式が M2 の 1.5 倍** (M2/M1 = 1.62、式 2.44。chr 模型は M2 の 1.12 倍): 式のモード分解は振幅と位相の混合 (ビート) を落としている。

### 4.5 限界・要判断 (項目 1)

- 追跡の測定が 4.2 GeV・12 MV 以外にない (6 MV・24 MV は FLUC のスピン追跡が 1 条件 数時間かかるので未実施。PF・A は 1 粒子 1 周が 0.1〜0.4 s)。式の値は MC (chr) と 12% 以内の見込みだが、追跡との比は 12 MV の 1 点。
- 式の導出 (モードごとの位相の変調) は決定論的な応答を M2 の 1.5 倍に見積もる (§4.3)。12 MV の率が追跡と合うのは、応答の過大評価と B3 が指摘した結合項 b(u) の 2 次の項の欠落 (MC に対し −10%) が打ち消している可能性がある。
- 追跡の D と Emittance[] の D の違い (§5)・B∥ の欠落 (§3) は追跡と式に共通 (K64 の仕様)。厳密な物理の値は追跡とも違う。
- 六極のあるリング (PF・A・ASTRID2): 振幅依存のチューンシフト (六極) と、自然クロマティシティが補正された小さな ξ (≈ +2〜5) の模型は未検証 (自然クロマティシティのリングだけ測った)。式の ξ は実際の ξ をそのまま使う (六極は C6 に入る) が、六極の振幅依存は入れていない。
- 要素数 > 1200 (`CHROM_NEL`) と K > 6e4 (`CHROM_KMAX`) ではクロマティックな変調を入れない (計算量)。大きなリング A の変調指数 0.088 は影響があるかもしれない。

## 5. Emittance[] の D と追跡の D の違い (E の 13% の差の関連、未解決)
