# v2.4.4 記録: 四極の線形フリンジの係数 F1 の符号 (B323)

日付: 2026-11-23。試験 `pysad/tests/script_tests/test_v244_quad_linear_fringe_f1.py` (68 件)。gs の保存した出力は `pysad/tests/script_tests/scripts/v244_quad_linear_fringe_f1__ring_{a..e}.{sad,gs.txt}`。

## 1. 症状

四極 (と K1≠0 の MULT) の線形フリンジ (FRINGE = 1・2・3 の F1・F2) の係数を、K64 の追跡と CALC で別の式で作っている。

- 追跡 (`tffs.f` の `tsetfringep`、969 行): `-abs(akk*f1in*f1in)/24` → F1 の符号を捨て、常に a ≤ 0。
- CALC (`tqlfre.f`、12 行): `af1 = -ak/al*f1*abs(f1)/24` → F1 の符号が a の符号を決める。

K1 = 0.6・L = 0.3 m・FRINGE = 3・DISFRIN = 1・F1 = −0.1 で、追跡のヤコビアンと CALC の 4×4 が 2.1e-3 食い違う (F1 = +0.1 は 1.8e-13)。k64 も v2 も同じだった。

## 2. どちらが正しいか

端で K(s) = K0·g(s) が 0 → 1 に立ち上がるとき、硬い端 K0·Θ(s − s0) との差 δK のモーメント I_n = ∫(s − s0)^n [g − Θ] ds を使うと、K の 1 次の摂動で端の挿入行列 (1 + a, b; 0, 1 − a) の a = K0·I1/p、b = K0·I2/p。ヘルプの定義 F1 = sgn(α)√|α|、α = 24(I0²/2 − I1) (I0 = 0 なら F1·|F1| = −24·I1)、F2 = I2 − I0³/3 から a = −K0·F1·|F1|/(24p)。F1 の符号がそのまま a の符号を決める。F1 < 0 は I1 > 0 (立ち上がりが硬い端より内側へ偏る・過剰に突き出る)。CALC の式が正しく、追跡の式は F1 < 0 で a の符号が逆になる。K < 0 は追跡も CALC も 90 度回して |K| で通すので、係数は |K| で作る (符号は F1 だけ)。

| −0.15 / −0.15 | 1.077343222823 | 1.058873627313 (+0.15 と同じ) | −1.85e-2 |

### 3.2 独立な数値積分

K(s) = K0·[½(1 + tanh(s/d)) + A·exp(−((s − c)/σ)²)] (d = 0.01、A = 0.3、c = 0.05、σ = 0.02 m。内側に盛り上がる) の線形運動 x'' = −K(s)x を DOP853 (rtol 1e-13) で積分した 2×2 行列と比べた。I0 = 0 の s0 = −0.010635 m、I1 = +5.4716e-4 m²、I2 = 3.995e-5、F1 = −0.114594 m (F1 < 0 を確認)、F2 = 3.995e-5。長さ 0.6 m (入口と出口は鏡像) の磁石で:

| K0 (/m²) | 硬い端 | (i) 符号を残す (CALC) | (ii) 符号を捨てる (K64 の追跡) |
|---|---|---|---|
| 1e-3 | 5.8e-7 | 7.1e-11 | 1.3e-6 |
| 2e-3 | 1.15e-6 | 2.8e-10 | 2.6e-6 |
| 4e-3 | 2.3e-6 | 1.1e-9 | 5.3e-6 |

(i) は K の 2 次 (K0 を 2 倍で 4 倍)、(ii) は K の 1 次 (2 倍で 2 倍) の誤り。pysad の要素では、v2 の CALC・追跡とも 2.8e-10、k64 の追跡は 2.6e-6、k64 の CALC は 2.8e-10 (K0 = ±2e-3 の両符号)。

## 4. 同型の誤りの調査

追跡の線形フリンジの係数は `tsetfringep` 1 か所 (QUAD 用と MULT 用の呼び出し。MULT の F1・F2 のヘルプの定義は QUAD と同じ)。pysad では `track6._tsetfringep` が、`_tquad_ens`・`_tmulti_ens` (python)・`track6n.prog` (numba の `k_quad` に渡す) から呼ばれる。ほかに複製はなかった (CALC・Emittance[] の `elkern`・`emit6d`・`lattice` の `tqlfre` は元から符号を残す)。

同型でないもの: BEND の F1・FB1・FB2 (`tblfre`、ANGLE=0 の BEND の `tsteee`・`tsteer`)・MULT の FB1/FB2 は K0 の端の線形フリンジで、ヘルプの定義が F1 = 6∫(b − b²)ds (長さ) と別。式の中の F1² と F1 の項は定義どおりに符号を持つので、同じ型の誤りではない (未確認の点: この F1 < 0 の物理的な意味の検証はしていない)。SOL の F1 は放射の長さだけ。

## 5. 修正 (v2 のみ)

- `track6._tsetfringep`: v2 は f1 = −copysign(|akk·F1²|, F1)/24 (= −|akk|·F1·|F1|/24)、f2 = |akk|·F2。F1 ≥ 0 は k64 の式と同じ値 (ビット同一)。k64 は従来の式。
- 放射の `tradk` の長さの引数 (K64 は係数 f1 を長さとして渡す癖): 従来 (f1 ≤ 0) のまま渡すため、`track6._tquad_ens` と `track6n.k_quad` で −|f1| を渡す (k64 は f1 ≤ 0 なのでビット同一)。この癖自体は直していない。
- 確認: 560 通りの組 (QUAD・MULT × K1 ±0.6 × F1 0・±0.1・±0.25 × FRINGE 0〜3 × DISFRIN 0・1 × F2・F1K1F/B・RAD) × 追跡 (python 版・numba 版)・CALC の行列 2 軌道 (計 2240 個) を、修正の前後で repr 比較した。k64 は 2240 個全部が同一。v2 は F1 < 0 (と F1K1F/B < 0) の追跡 368 個だけが変わり、F1 ≥ 0 と CALC の行列は同一。

## 6. 限界・未確認

- F1 < 0 の RAD の追跡を gs と比べていない (k64 は符号を捨てる動作が gs と同じ)。放射の引数は K64 の癖のまま。
