SADHelp (1.4.4.2k64 Updated: 10/19/2026) と pysad の対応・翻訳方針のまとめ

このページの読み方。SAD/FFS と SADScript のヘルプ (K64 版 Documents/SADHelp.html、CERN の SADHelp と同系統) に載っている FFS コマンド・関数・特別変数・フラグ・要素を、次の 3 つの観点で整理したものです。

  1. SAD 側の定義場所 — その名前がどこで作られているか: Fortran (src/*.f: コマンドは tffsa.f、関数は tfinitn.f の itfunaloc、変数は ktfsymbolz/rgetgl1)、 C (src/*.c の REGn: System、Tk、ファイル、乱数、プロセス)、.n (Packages/*.n の SADScript 定義: dapert.n、emit.n、Optics.n、element.n など)。 ? 付きは登録の形が見つからず文字列として現れるだけのもの。
  2. pysad の対応 — 名前が pysad に登録されているか (コマンドは FFS の表、関数は Interp.builtins、変数はソース中の参照、フラグは _FLAGS_DEFAULT)。 実装の深さや SAD との一致の度合いは docs/03・04・12 を参照。「無視」は読み飛ばして [pysad] FFS command … は未対応 と表示するもの。
  3. 翻訳方針 (2026-11-06 のユーザー方針) — 直接翻訳: ソースが Fortran/C で内容が物理計算 (式・分割数・反復順序・乱数の引き方まで写す)。 Python で書き直し: ソースが .n のもの、要素の操作や表示 (直訳ではない)。インタプリタの言語機能: リスト・文字列操作はユーザースクリプトを走らせるために sadscript.py が Python で実装。 Python ライブラリで代替: ファイル操作・数値計算・GUI・描画・プロセスは open/numpy/scipy/matplotlib/subprocess に置き換えるので翻訳対象外 (必要なら Python で書き直す)。

元の表: docs/13_sad_help_index.md (ヘルプの一覧)、docs/14_pysad_vs_sadhelp.md (対応と定義場所)、docs/15_sadhelp_purpose_policy.md (分類と方針)。 生成: /sadhelp_index.py → pysad_vs_sadhelp.py → sadhelp_purpose.py → sadhelp_html.py。SADHelp を更新したら順に再実行する。

2. 分類ごとの方針

分類 (件数)方針具体的に
物理計算 (26)直接翻訳Fortran/C の式・分割・反復順序を写す (pysad の本体)。ソースが .n のものは Python で書き直す
マッチング・最適化の仕組み (21)直接翻訳tffsmatch/tffscalc/qdcell の直訳 (フックの呼び出しを含む)。.n のもの (OptimizeOptics, DownhillSimplex) は Python で書き直す
要素・ビームラインの操作 (7)Python で書き直しpysad のデータ構造 (Element, Lattice, Env) の上で同じ意味になるよう書く。直訳ではない
乱数 (6)直接翻訳FLUC の照合に SAD と同じ乱数列が要るので C (tfRandom_.c) を写す (sadrandom.py)
数値計算・フィット (6)Python ライブラリで代替numpy/scipy (curve_fit, integrate, interpolate, optimize) に置き換える。翻訳対象外、必要なら Python で書き直す
リスト・関数型 (言語機能) (21)Python で書き直し (インタプリタ)ユーザースクリプトを走らせるために sadscript.py が Python のリスト演算で実装する。pysad を Python から直接使うときは list/numpy
文字列・式 (言語機能) (13)Python で書き直し (インタプリタ)sadscript.py が Python の str で実装。直接使うときは str
ファイル・入出力 (15)Python ライブラリで代替open/print/csv/json に置き換える。翻訳対象外 (OpenRead の失敗の扱いなどは移植しない)
GUI・描画 (14)Python ライブラリで代替matplotlib (plt.plot, scatter, contourf, hist) に置き換える。翻訳対象外
システム・プロセス・並列 (7)Python ライブラリで代替subprocess / multiprocessing / tempfile に置き換える。翻訳対象外
ユーティリティ (時刻・計測・デバッグ) (5)Python ライブラリで代替time / datetime / logging に置き換える。翻訳対象外
表示 (表・一覧) (9)Python で書き直しDISP/TYPE のように SAD と同じ文字列を出すものは照合のため書き直す。それ以外 (SHOW, STATUS 等) は必要になったら
制御・入出力 (FFS コマンド) (19)Python ライブラリで代替入力の切り替え・停止・中断は Python の制御構造とファイル操作で置き換える。翻訳対象外
要素編集・変数 (FFS コマンド) (12)Python で書き直しFREE/FIX/SAVE/RESET/COUPLE 等は pysad の要素値の仕組みで書く
誤差 (FFS コマンド) (1)直接翻訳terror.f の乱数の引き方まで写す (照合済み)
FFS フラグ・物理パラメータ (変数) (30)直接翻訳tfsetparam/tffsa が読む意味のとおりに使う
表示・書式 (変数) (4)Python で書き直し$FORM/PageWidth/TITLE/CASE は出力の書式。照合に要る $FORM/PageWidth は書き直し済み、描画用は対象外
フック・特殊 (変数) (6)直接翻訳FitFunction/MatchingAmplitude/InitialOrbits/OpticsProlog 等は SAD が評価する仕組みごと写す
