# pysad の試験が使う SAD スクリプトと、gs・pysad の画面表示

最終更新: 2026-11-17

pysad の試験 (`pysad/tests/test_*.py`) が `run_sad_string` に渡す SAD スクリプト (試験の中の文字列の台本) を、そのまま `scripts/NAME.sad` に取り出し、同じ台本を pysad と gs で走らせた画面表示を `NAME.pysad.txt`・`NAME.gs.txt` として並べたものです。ファイル名は `<試験ファイル名 (test_ を除く)>__<試験関数 (クラス名を含む)>` で、同じ試験に台本が複数あるときは `_2`、`_3`…が付きます。表は `py -3.12 pysad/tests/make_outputs_md.py` で作ります。`scripts/` の `.pysad.txt` は、試験が走るときの互換モード (`k64`、gs と同じ K64 の動作。`pysad/tests/conftest.py`) での出力で、既定の `v2` モードの出力ではありません。

## 読むときの注意

- 試験は `scripts/` を読まない (台本は試験の文字列のまま)。`scripts/` は試験の実行から取り出した写しで、試験の判定は変えていない。台本を直したら取り出し直す。
- `.pysad.txt` は試験の実行中に台本が走ったときの画面出力 (標準出力 + 標準エラー)。`PYSAD_SAD_PACKAGES` を設定して全試験を通したときのもの。試験が途中でパラメータを変えて走らせるもの (`fallback` など) は、別の台本として `_2` 以降に入る。
- `.gs.txt` は同じ台本を WSL の `gs` (K64、2026-10-19 ビルド) にそのまま渡した画面表示 (`gs NAME.sad < /dev/null`、40 秒で打ち切り)。試験の台本は pysad 専用の整形 (`FFS;` の有無、`Exit;` ほか) のため、gs では走らないもの・出力が少ないものがある。gs の列にその状態を書いた。**gs の表示と pysad の表示の一致は、ここでは判定していない** (試験の判定は、試験に埋め込んだ SAD の参照値で行う)。
- 画像 (PNG): pysad の試験に画像を書き出すものは無い。描画・GUI の図は `example/11_graphics`・`example/12_gui_tkinter` ほかの PNG にある (`example/README.md`)。
- gs の `.gs.txt` に日付・時刻 (`Today:`)・一時ファイル名が入る。実行ごとに変わる。

## 回帰ベンチ (リポジトリ直下。コピーは作らない)

`run_regression.py` (50 ベンチ) の台本と SAD の参照結果は、リポジトリ直下に既にある。

| 何 | 場所 |
|---|---|
| SAD (gs) 用の台本 | `bench_levelN.sad` (N = 1〜31 ほか) |
| SAD (gs) の画面表示 (参照結果) | `bench_levelN.result` |
| pysad 用の台本 | `bench_levelN_pysad.py` (一部は `.sad` を `run_sad.py` で走らせる) |
| pysad の画面表示 | `bench_levelN_pysad.result`、実行ごとの出力は `regression_out/<名前>.txt` |
| 判定と許容 | `run_regression.py`、`docs/10_benchmarks.md` |
