fn_GaussianCoulomb と fn_BBBrem1

種別: 関数 / フォルダ: 06_collective / ラティス: なし (関数値だけ)。参考: docs/06_sadscript_library.md

何を見る例か

GaussianCoulomb[x, y, sigx, sigy] は大きさ (σx,σy)(\sigma_x,\sigma_y)(σx​,σy​) の 2 次元ガウス分布が点 (x,y)(x,y)(x,y) に作る力 fx+ifyf_x+if_yfx​+ify​ (ビーム・ビームの Bassetti-Erskine の力。複素数で、虚部が 0 なら実数)。GaussianCoulombU はポテンシャル、GaussianCoulombFitted は力・ポテンシャル・勾配の補間版。BBBrem1[sqrt(s), ds/s] は、ビーム・ビーム制動放射の 1 事象 (4 元運動量と近似断面積) を乱数で生成する。

スクリプト

GaussianCoulomb[xx, 0, 1, 1]               ! 丸いビームの x 軸上 (xx = 0.01, 1, 3, 10)
GaussianCoulomb[0.01, 0, 2, 1]             ! 平たいビーム (sigx=2 sigy=1)
GaussianCoulomb[1, 1, 1, 1]
GaussianCoulombU[1, 0, 1, 1]; GaussianCoulombFitted[1, 0, 1, 1]
SeedRandom[3]; BBBrem1[2*3e9, 1e-3]         ! 3 事象

結果の読み方

  • GaussianCoulomb は符号が負 (力の向きは原点向き: 収束)。値は全て同じ規約で、解析式と比べる (下表)。
  • GaussianCoulombFitted は {fx,fy,U,fxx,fyy,fxy}={−0.78690,0,0.44384,−0.42542,−0.80998,0}\{f_x,f_y,U,f_{xx},f_{yy},f_{xy}\}=\{-0.78690,0,0.44384,-0.42542,-0.80998,0\}{fx​,fy​,U,fxx​,fyy​,fxy​}={−0.78690,0,0.44384,−0.42542,−0.80998,0}。
  • BBBrem1 は {{px,py,pz,E}, 近似断面積}: 3 事象で 4 元運動量は違い (E=1.2808e9, 2.9932e9, 2.6009e9 eV)、近似断面積 6.8699894×10−296.8699894\times10^{-29}6.8699894×10−29 は同じ。

未確認・限界

  • BBBrem1 の戻りの 4 元運動量がどの粒子のものか (光子か、散乱電子か) と、第 2 引数 ds/s の意味は、SADHelp とソース (tbbbrem.f) の記述を精読していない。値の再現性 (SeedRandom 固定で gs と一致) だけを確認した。
  • GaussianCoulombFitted の第 2 成分は 0 の丸め誤差 (gs は 1.1×10−161.1\times10^{-16}1.1×10−16、pysad は 7×10−187\times10^{-18}7×10−18) で、桁の差は雑音。
  • 点は軸上と対角の少数だけ (docs/06 の検証は 15 点)。
