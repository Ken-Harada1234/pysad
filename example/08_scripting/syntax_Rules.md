# syntax_Rules (/. -> :> //. Replace)
種別: 文法 / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
置換規則 `->` (即時) と `:>` (遅延)、`/.` (1 回)、`//.` (変化がなくなるまで)、パターン付き規則。

## スクリプト
```
{a, b, a} /. a -> 1;   f[x,y] /. {x -> 1, y -> 2};   c = 1; r1 = {u -> c}; r2 = {u :> c}; c = 2;
u /. r1;  u /. r2;   {1,2,3,4} /. n_?EvenQ -> 0;   x /. {x->y, y->z};  x //. {x->y, y->z};
```

## 結果の読み方
`u /. r1`=1、`u /. r2`=2 (`->` は規則を作る時点の `c` を使い、`:>` は置換する時点で評価)。`x /. {x->y,y->z}`=y (1 回)、`//.` は z。`Table[k /. k -> (cnt++), {3}]` のように規則を式の中に直接書くと、`->` も `:>` も `Table` の反復ごとに評価されて {0,1,2} と {3,4,5} (違いは出ない。違いが出るのは規則を変数に入れておく `r1`・`r2` の形)。
