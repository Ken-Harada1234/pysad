# fn_Table (Table, Sum, Product)
種別: 関数 (制御構文) / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
`Table[expr, 反復子]` でリスト・多次元リストを作る。`Sum`・`Product` は同じ反復子。

## スクリプト
```
Table[i^2, {i, 5}];  Table[i*j, {i, 2}, {j, 3}];  Table[x, {x, 0, 1, 0.25}];
Table[i, {i, 5, 1, -2}];  Table[7, {3}];  Table[j, {i, 3}, {j, i}];
Sum[i, {i, 10}];  Product[i, {i, 5}];
```

## 結果の読み方
{1,4,9,16,25}、{{1,2,3},{2,4,6}}、{0,.25,.5,.75,1}、降順 {5,3,1}、{7,7,7}、三角の入れ子 {{1},{1,2},{1,2,3}}。`Sum[1/i^2,{i,1,100}]`=1.6349839... ($\pi^2/6=1.6449$ に近づく途中)。

## gs と pysad の比較
○ 一致 (出力の全行が同じ)。
- リストを走る反復子 `{i, {2,3,5}}` は gs も pysad もエラー (fn_Do と同じ)。

## 未確認・限界
- 出力は `.gs.txt` / `.pysad.txt` の通り。SADHelp の記述 (Expression の項) と gs の実動作を照合した。
- 乱数・時刻・ファイルの順序に依存する出力は入れていない。
