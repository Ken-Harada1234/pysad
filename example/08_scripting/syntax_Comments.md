# syntax_Comments (! と (* *))
種別: 文法 / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
SAD のコメントは `!` (行末まで) と `(* ... *)` (複数行可)。文字列の中の `!` と `(*` はコメントにならない。

## スクリプト
```
! 行頭のコメント
Print["a"]; ! 行末のコメント
(* ブロック *) Print["b"];   x = 1; (* 文の後 *) y = 2;
```

## 結果の読み方
`Print` の出力が 5 行と、`x+y`=3 が出る。`(* *)` は入れ子にできない (最初の `*)` で閉じる)。そのため `(* a (* b *) c *)` の ` c *)` は式として読まれ、エラーになる (確認済み。例には入れていない)。

## gs と pysad の比較
○ 一致 (出力の全行が同じ)。

## 未確認・限界
- 出力は `.gs.txt` / `.pysad.txt` の通り。SADHelp の記述 (Expression の項) と gs の実動作を照合した。
- 乱数・時刻・ファイルの順序に依存する出力は入れていない。
- コメントの中の日本語は gs・pysad とも問題ないが、入れ子のコメントの中の日本語で pysad が別のエラーになる例があった (入れ子が非対応なので例から外した)。
