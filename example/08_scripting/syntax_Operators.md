# syntax_Operators (= := == === など)
種別: 文法 / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
代入 `=` (右辺を今評価) と `:=` (呼ぶたびに評価)、`==` (等しいか、リストは要素ごと)、`===` (同一か)、`<>`・`<=>`、複合代入、`++`・`--`、同時代入、部分への代入、`=.` (解除)、演算子の優先順位。

## スクリプト
```
n = 1; a = n + 1; b := n + 1; n = 10;   (* a=2, b=11 *)
1 == 1; {1,2} == {1,3}; {1,2} === {1,3}; 1 === 1.0;
v = 10; v += 5; v -= 3; v *= 2; v /= 4;     (* 6 *)
{p, q} = {q, p};  t[[2]] = 5;  w =.;  h[1] = "one";
2 + 3*4^2;  -2^2;  2^3^2;  1 - 2 - 3;
```

## 結果の読み方
`a`=2、`b`=11。`==`: 1→1、1==2→0、`{1,2}=={1,3}`→`{1,0}` (gs)、文字列も `==` で比較。`===`: `1===1.0`→1 (SAD は数値型を区別しない)。`2+3*4^2`=50、`-2^2`=-4、`2^3^2`=512 (右結合)、`1-2-3`=-4。

## gs と pysad の比較
○ 一致する (2026-11-17 に修正: リストどうしの比較は要素ごと、`{1,2} == {1,3}` は {1,0})。
