# fn_Map_MapThread (Map, /@, MapAll, MapThread)
種別: 関数 / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
`Map`・`/@`・レベル指定・`//@` (MapAll)、`MapThread` で複数のリストを要素ごとに関数へ渡す。

## スクリプト
```
f[x_] := x^2 + 1;
Map[f, {1,2,3}];  f /@ {1,2,3};  (#^2 &) /@ {1,2,3};
Map[f, {{1,2},{3,4}}, {2}];  f //@ {1,{2,3}};
MapThread[Plus, {{1,2,3},{10,20,30}}];  MapThread[#1*#2+#3 &, {{1,2},{3,4},{5,6}}];
```

## 結果の読み方
`Map` は {2,5,10}。`Map[f, 入れ子, {2}]` はレベル 2 だけに適用して {{2,5},{10,17}}。`f //@ {1,{2,3}}` は全ての部分式 (内側のリストの要素にも、リストそのものにも) に内側から適用する。`f` はリストに対して要素ごとに働くので、要素が何度も `f` を受け、結果は {5,{677,10202}} (1 は $f(f(1))=5$、2 は $f^4(2)=677$、3 は $f^3(3)=10202$)。`MapThread[Plus, {{1,2,3},{10,20,30}}]` は {11,22,33}。

## gs と pysad の比較
○ 一致 (出力の全行が同じ)。

## 未確認・限界
- 出力は `.gs.txt` / `.pysad.txt` の通り。SADHelp の記述 (Expression の項) と gs の実動作を照合した。
- 乱数・時刻・ファイルの順序に依存する出力は入れていない。
- SADHelp の MapThread の例 (`{f[1,3], f[1,4]}`) は転置の書き方が実際と違い、実際は第 $i$ 要素同士が組になる ({f[1,3], f[2,4]})。
