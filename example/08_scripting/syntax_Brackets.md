# syntax_Brackets (() [] {} [[ ]])
種別: 文法 / フォルダ: 08_scripting / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は `run_sad_string`。

## 何を見る例か
`()` は優先順位、`[]` は関数の引数 (と文字列の部分)、`{}` はリスト、`[[ ]]` は部分の取り出し、`@` と `/@`、純関数 `#`・`&`。

## スクリプト
```
2*(3+4);  Sqrt[16];  {1,2,3};  l[[2]];  l[[{1,3}]];  l[[-1]];  {{1,2},{3,4}}[[, 2]];
"abcdef"[2, 4];  f@2;  f /@ {1,2};  Head[1 + a];  (#^2 &)[3];
```

## 結果の読み方
`[[, 2]]` は第 2 列 {2,4}。`"abcdef"[2,4]`="bcd"、`[-2,-1]`="ef"。`Head[a+b]`=Plus、`Length[a+b]`=2、`(a+b)[[1]]`=a。

## gs と pysad の比較
○ 一致 (出力の全行が同じ)。
