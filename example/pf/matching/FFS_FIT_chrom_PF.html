FFS FIT (PF): 色収差補正の6 極フィット

種別: FFS コマンド FIT・FREE・GO・FITP・DP (KEK の SAD チュートリアルの話題をもとにした)。加速器: PF 2.5 GeV リング (lattice/v9_16_asym.sad、周長 187.035 m、チューン 9.5975 / 5.2790)。

何を見る例か

6 極 (SFH・SDH の 2 ファミリー) を 0 にして自然色収差を出し、±DP の 2 点でチューンが設計値になるように FREE S* でフィットし直す。設計の6 極値が戻るかを見る。

スクリプト

S* 0;  cell calc;                  ! 6 極なし (自然色収差)
fit nx nx0 2;  fit ny ny0 2;       ! 場所は省略 = リング終点。2 = DP の 2 点 (-DP, +DP)
DP = 0.0001;                       ! 運動量の幅 (既定 1%)
free S*;  go;
FITP 1;                            ! 点数を 1 に戻す (戻さないと次の fit も 2 点になる)
type SFH;  type SDH;  SAVE S*;

ChromFD[] は DP0 = ±1e-4 で cell calc し $(\nu_+ - \nu_-)/(2\times10^{-4})$ を返す関数 (ξ の確認用)。

結果の読み方

ξx ξy SFH K2 SDH K2
設計の6 極 -4.2e-4 -1.26e-3 3.960643 -3.917196
6 極 0 (自然色収差) -13.2986 -17.2514 0 0
フィット後 -3.5e-6 -2.1e-5 3.960795 -3.917392
  • 自然色収差 (-13.3, -17.3) が 2 ファミリーの6 極で ±1e-4 の 2 点において打ち消され、元の設計の6 極 (3.9606, -3.9172) とフィット値 (3.9608, -3.9174) が 4 桁で一致する。このラティスの6 極は「線形の色収差ゼロ」の条件で決まっていると読める。
  • 収束は Matched. (8.2e-12)。

物理・解析式

$\xi_x = -\frac1{4\pi}\oint\beta_x K_1 ds + \frac1{4\pi}\oint\beta_x\eta_x K_2\, ds$ (K1・K2 は SAD の積分強度)。四極と6 極の和の照合は pf/optics/calc_chromaticity_PF。

gs と pysad の比較

v2 モードと k64 モード: .pysad.txt は既定の v2 モードの出力。v2 は K64 のバグを含まない計算なので (docs/28_v2_vs_k64.md。主に Emittance[]・EMIT・追跡の Jx の端の項 B75 と MomentumCompaction B77)、この例の出力のうち Emittance[] の表示 (εx が数 % 大きい、εz・減衰率・α・バケット高さなど) と、それに依る量が gs と違う。以下の「一致」の判定は k64 モードの結果。gs と同じ値が要るときは PYSAD_COMPAT=k64 を付ける。

○ 自然色収差の ξ は全桁一致。フィット後の6 極は gs 3.960795117 / pysad 3.960795576 で 7 桁一致 (FIT の収束の途中経過の違い)。フィット後の ξ の残り (gs -3.5e-6、pysad -1.2e-6) はどちらも 0 とみなせる。

未確認・限界

  • DP=1e-4 の 2 点だけを合わせるので、高次 (δ² 以上) の色収差は補正されない (fn_PolynomialFit_PF の図)。
  • FIT の途中表示 (残差) の行数は gs の方が多い (表示のみ)。
