# lattice: PF (2.5 GeV) のラティス

PF リングの低エミッタンスラティス (周長 187.035 m、28 台の偏向磁石) の台本 2 本と、PF の履歴ラティス 4 本 (1981・1986・1997・2005 年)。元の台本のコピーを改変せずに置いた (改行コードだけ LF に変えた)。ASTRID2 のラティスは `astrid/lattice/` にある。

| ファイル | 内容 | 使う例 |
|---|---|---|
| `v9_16_asym.sad` | PF 2.5 GeV の周回ラティス (asym = 始点が B01 側の直線部の端。ラティスの鏡面対称点が始点のものは sym)。ライン `RING` (756 要素)、標準セル 1 個の `NCELL`、入射点マーク `INJ`、モニター `PM` (65 台)、四極 `Q*`、六極 `SFH`・`SDH` (2 ファミリー)、八極 `OCT` (K3=0)、偏向磁石 `B01`〜`B28` (矩形、各 0.2244 rad、L = 1.9427 m)、ステアリング `PH`・`PV`・`VD`・`VS` (K0 = 0)、空洞 `CAVI` (VOLT 0.85 MV、FREQ 499.99 MHz) | `cell calc emit`・`disp`・`type` などの基本の例、軌道応答・分散・色収差・DA・運動量依存・振幅依存・放射積分・位相空間・topdrawer の例 |
| `v9_16_inj_noSF.sad` | 入射バンプの計算用。キッカー `KK1`〜`KK4` (BEND、L=0.3 m、K0=0)、入射点を含む部分ライン `INJL` (114 要素)。入射バンプの内側の六極 2 台のうち 1 台を外した (ケーブルでバイパスした実機の状態を反映、というチュートリアルの説明による) 版で、末尾で `SFH`・`SDH` の K2 を 3.879 / -4.396 に再定義している。空洞は `HARM = 312` | 入射バンプの例 (`FFS_FIT_injbump_PF`)、入射軌道の例 (`calc_traj_*_PF`) |

履歴ラティス 4 本 (`pf_1981_460nmrad`〜`pf_2005_036nmrad`) の説明・表・図・ヘッダとの食い違い (要確認) は [`PF_history.md`](PF_history.md)。

## 確認した値 (gs と pysad で全桁一致、`pf/optics/FFS_cell_calc_emit_PF`)
- エネルギー 2.5 GeV、周長 187.0355 m、チューン (9.59753, 5.27896)、エミッタンス 34.54 nm rad、エネルギー拡がり 7.337e-4、運動量コンパクション率 6.56e-3、U0 0.3991 MV。
- 台本の末尾に、各 MARK のツイスの保存値が付いている (`INJ`、`U19` など)。`cell calc` を実行するたびに上書きされるので、そのまま使ってよい。

## 使い方
- `FFS;` の前にラティスを置き、後ろに計算を続ける (gs はラインや要素の定義を `FFS;` の前に置く必要がある)。各例の `.sad` は、このラティスを先頭に貼った自己完結のファイル。作り方は `tools/mkpf.py` (`mk(rel, body, lat)`)。
- `ON RAD FLUC COD RFSW RADCOD;` は KEK のチュートリアルと同じ (光学・チューン・放射の例)。追跡の例 (DA、位相空間、TrackParticles) は決定性のため `OFF RAD FLUC; ON COD RFSW RADCOD;`。

## 未確認・限界
- 元の台本には、誤差入りではなく**設計値のラティス**が入っている (ASTRID2 の誤差入りとは違う)。
- `v9_16_inj_noSF` でどの六極を外したか (台本のどこに反映されているか) は確かめていない。リング全体の周期解 (チューンなど) が `v9_16_asym` と同じかも確かめていない。
- 周長・チューンなどは `v9_16_asym` について確認した値。
