calc_chromaticity (PF): 自然色収差と6 極の寄与

種別: スクリプト (サンプル集 calc_chromaticity.sad)。加速器: PF 2.5 GeV リング (lattice/v9_16_asym.sad、周長 187.035 m、チューン 9.5975 / 5.2790)。フラグ: ON RAD FLUC COD RFSW RADCOD。

何を見る例か

DP0 を -1%〜+2% (31 点) で動かしてチューンを PolynomialFit[..., 6] で当てはめ、c1 を色収差とする (サンプル集の書き方)。6 極あり (設計値) と、S* 0 の6 極なし (自然色収差)。 さらに、四極と6 極による色収差を、Twiss 関数からの和で計算して比べる。

スクリプト

DP0 = (i-11)*0.001;  FFS["cell calc"];  tunex[i] = {DP0, Twiss["NX","$$$"]/2/Pi}; ...      ! i = 1..31 (-1%〜+2%)
Print[PolynomialFit[tunex,6]];  ... S* 0;  FFS["cell calc"];  同じ当てはめ
ChromSum[]  ! 四極: -ΣK1 <βx>/4π (x)、+ΣK1 <βy>/4π (y)。6 極 (SFH,SDH): +ΣK2 ηx βx/4π (x)、-ΣK2 ηx βy/4π (y)。<β> = Simpson (入口・中央・出口)

範囲を -1%〜+2% (平均が 0 でない) にしたのは、SAD の PolynomialFit が平均 0 の範囲では最高次以外の係数を壊すため (pf/optics/fn_PolynomialFit_PF 参照)。サンプル集の -1%〜+1% のままだと c1 が正しく出ない。

結果の読み方

量 x y
四極の和 (式) -13.4349 -15.7741
6 極の和 (式、設計値) +13.3008 +17.2620
四極 + 6 極 (式) -0.1341 +1.4879
ξ 差分 (±1e-4、設計の6 極、FFS_FIT_chrom_PF) -0.0004 -0.0013
ξ 差分 (±1e-4、6 極 0) -13.2986 -17.2514
当てはめの c1 (6 次、設計の6 極) -0.000434 -0.001615
当てはめの c1 (6 次、6 極 0) -13.2983 -16.979 (残差 5e-3、当てはまりが悪い)
  • 6 極の寄与は、式 (13.3008 / 17.2620) と SAD の差 (6 極あり-なしの ξ の差: 13.2979 / 17.2501) が 0.02% / 0.07% で一致する。
  • 四極の和 (式) と自然色収差 (差分) の差は x で +0.14、y で -1.48 (四極の和が x は 1.0% 大きく、y は 8.6% 小さく出る)。この差は偏向磁石の寄与 (SAD の CHRO が数えないものと同じ) と見られる。 概算では、偏向磁石の本体の収束 (1/ρ²) が x に 0.12、矩形磁石の端の収束 (tan e / ρ) が y に 2×0.80 の桁 (符号と係数は確かめていない) で、桁は合う。厳密な式は書いていない。
  • 6 次当てはめは、自然色収差の y では当てはまりが悪い (残差 5.3e-3)。範囲 -1%〜+2% では 6 次でも足りない (高次の項が大きい)。

物理・解析式

$\xi_x = -\frac1{4\pi}\oint\beta_x(K_1-K_2\eta_x)\,ds$、$\xi_y = +\frac1{4\pi}\oint\beta_y(K_1-K_2\eta_x)\,ds$ (K1・K2 は SAD の積分強度で、符号は上の和のとおり。偏向磁石の項を除く)。

未確認・限界

  • 偏向磁石の寄与は解析式で再現していない (上の概算のみ)。
  • 六次の当てはめは、チューンの運動量依存が ±1% を超えると高次が大きく、c1 だけを見るべきで、c2 以上は壊れやすい。
