PF の例集 (2.5 GeV)

PF のラティスを使った、SAD の基本的な使い方と計算の例です。KEK の SAD チュートリアルの話題を、PF の実際のラティスで作り直しました。各例は .sad、.gs.txt、.pysad.txt、.md の 4 点です。式と数値の照合は各 .md にあります。
