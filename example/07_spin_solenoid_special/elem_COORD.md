# elem_COORD
種別: 要素 / フォルダ: 07_spin_solenoid_special / ラティス: `00_lattice/coord_ring.sad` (新規。`FODO_ring.sad` に COORD 要素を入れた `RINGC`、`RINGC3`、`RINGCP`)。3 GeV / フラグ: `NORFSW NORAD NOFLUC`。参考: `docs/19_other_elements.md`

## 何を見る例か
`COORD` は座標系を変える要素 (ずらし `DX DY DZ`、回転 `CHI1 CHI2 CHI3`)。(1) 1 要素の変換を解析式と照合、(2) COORD で挟んだ (座標系ごとずらした) リングと、COORD の直後に逆変換を置いたリングの違いを確かめる。

## スクリプト
```
COORD C1 = (DX=1E-3 CHI3=0.01) C2 = (DX=1E-3 CHI3=-0.01 DIR=1)
      C3 = (DX=1E-3 DY=-2E-3 CHI3=0.01);
LINE RINGC  = (ORIGIN C1 RF 24*CELL C2);     ! リング全体を C1 と C2 で挟む
LINE RINGCP = (ORIGIN C1 C2 RF 24*CELL);     ! C1 の直後に C2: 打ち消す
LINE RINGC3 = (ORIGIN C3 RF 24*CELL);
r = TrackParticles[{pc, beam}, pc+1, 1, 1];  ! C3 だけを通す
```
- `DIR=0` (既定): 入口で $DX,DY,DZ$ だけずらしてから、$CHI1,CHI2,CHI3$ で回す。`DIR≠0`: 回してからずらす (逆の順序)。`tcoord.f` では DIR≠0 の分岐で `dy1=-dy`、`dz1=-dz` の符号が反転しているので、**COORD の逆変換は $DX$ と回転角 (符号反転) だけを使い、$DY$・$DZ$ は使わない** (C2 の `CHI3=-0.01`)。

## 結果の読み方
- 1 要素 `C3` (DX=1e-3、DY=−2e-3、CHI3=0.01) を通した 4 粒子 $(x,p_x,y,p_y)$ [m, rad]:

| 入力 | 出力 (gs = pysad) |
|---|---|
| (0, 0, 0, 0) | (−1.0199497e-3, 0, 1.9899002e-3, 0) |
| (1e-3, 0, 0, 0) | (−1.9999667e-5, 0, 1.9999000e-3, 0) |
| (0, 0, 1e-3, 0) | (−1.0299495e-3, 0, 2.9898502e-3, 0) |
| (1e-3, 1e-3, 0, 0) | (−1.9999667e-5, 9.9995000e-4, 1.9999000e-3, 9.99983e-6) |

- リング: RINGC のチューン `NX=6.6963289409 NY=4.9060560399` (COORD なしのリングと同じ)、閉軌道 `DX(ORIGIN)=1.0e-3`、`DY(ORIGIN)=0`。1 周の追跡 ($x_0=y_0=10^{-5}$): RING と RINGCP は同じ ($x=1.71342561\times10^{-5}$ など)、RINGC は $x=-6.9684585\times10^{-4}$、$p_x=-1.0584039\times10^{-3}$、$y=1.69849\times10^{-5}$、$p_y=1.06377\times10^{-5}$。

## 物理・解析式
$CHI1=CHI2=0$ の `DIR=0` は、ずらしてから $z$ 軸まわりの回転 ($\chi=CHI3$):

$$x'=\cos\chi\,(x-DX)-\sin\chi\,(y-DY),\quad y'=\sin\chi\,(x-DX)+\cos\chi\,(y-DY),\quad (p_x',p_y')=R(\chi)(p_x,p_y).$$

| 入力 | 式 $x'$、$y'$ | gs = pysad |
|---|---|---|
| (0, 0) | −1.019950e-3、1.989900e-3 | −1.0199497e-3、1.9899002e-3 |
| (1e-3, 0) | −2.0000e-5、1.99990e-3 | −1.9999667e-5、1.9999000e-3 |
| (0, 1e-3) | −1.029950e-3、2.989850e-3 | −1.0299495e-3、2.9898502e-3 |
| 4 つめの $p_x',p_y'$ | 9.99950e-4、1.0000e-5 | 9.9995000e-4、9.99983e-6 |

COORD で挟んだリング (RINGC) の閉軌道は、座標系のずれ DX そのもの: $x_{co}(ORIGIN)=DX=10^{-3}$ ✓。座標系ごとずれたリングなので、リングの Twiss (チューン、β) は変わらない。
1 周の追跡 ($x_0=10^{-5}$、RINGC) は、閉軌道からのずれ $u=x_0-DX$ が 1 周行列で進む: $x_1\approx DX+M_{11}(x_0-DX)=10^{-3}+1.7134\times(10^{-5}-10^{-3})=-6.963\times10^{-4}$ (追跡 $-6.968\times10^{-4}$: CHI3 の回転による $y$ との結合の分だけ差)。

## gs と pysad の比較
○ 一致 (全 13 行が印字桁まで同じ。`DY(ORIGIN)` だけ $10^{-14}$ 台の数値雑音の違い)。

## 未確認・限界
- CHI1・CHI2 (縦方向の回転)、`DZ`、粒子の $z\ne0$、運動量のある場合の座標変換は見ていない。
- COORD で `dv` は更新されない (tcoord.f のまま)。
- `DIR` の逆変換で $DY$、$DZ$ の符号が反転する癖は `tcoord.f` の読みから (gs の結果は CHI3、DX の組で確認、DY を含む組は打ち消さなかったことの確認のみ)。
