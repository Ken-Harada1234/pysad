# fn_LDSolve (LDSolve.n の LDSolve)

種別: パッケージ (Packages/LDSolve.n)・フォルダ 13_packages・ラティスなし

## 何を見る例か
`LDSolve[A, b, y0, {s,s0,s1,ds}]` は線形微分方程式 $\mathbf y'=A(s)\mathbf y+\mathbf b(s)$ を初期値 $\mathbf y_0$ から $s_0\to s_1$ まで解き、`SplineData` を返す。(1) 振動子 $y''=-y$ ($A=\begin{pmatrix}0&1\\-1&0\end{pmatrix}$)。(2) $A=\begin{pmatrix}0&s\\-1&0\end{pmatrix}$、$\mathbf b=(0,\sin s)$ の非同次の例。

## スクリプト
```
u=LDSolve[{{0,1},{-1,0}},{0,0},{1,0},{s,0,1,0.1}];       (* 戻り値は SplineData (長さ 1) *)
u[[1,2,-1]]                                              (* 終点 s=1 の {y, y'} *)
v=LDSolve[{{0,s},{-1,0}},{0,Sin[s]},{1,0},{s,0,2,0.1}];
```

## 結果の読み方
`Head=SplineData Length=1`。`R:s_end` は終点の位置 (1)、`R:y1`・`R:yp1` は終点の $y,y'$、`R:v2`・`R:vp2` は (2) の終点 ($s=2$) の 2 成分。

## gs と pysad の比較
$y=\cos s$ なので $y(1)=0.5403023$、$y'(1)=-0.8414710$。(2) は解析解が無いので数値積分 (`scipy.solve_ivp`、許容 1e-12) と比べる。

| 項目 | 解析解・scipy.solve_ivp | gs | pysad | gs の相対差 | pysad の相対差 (参照値が 0 の行は絶対差) |
|---|---|---|---|---|---|
| $y(1)$: $y''=-y$、$y(0)=1$、$y'(0)=0$ の $\cos 1$ | 0.540302305868 | .5403023059 | .5403023059 | 5.9e-11 | 5.9e-11 |
| $y'(1)=-\sin 1$ | -0.841470984808 | -.8414709848 | -.8414709848 | 9.4e-12 | 9.4e-12 |
| 非同次: $y_1(2)$ | 0.349760007215 | .3498135932 | .3498135932 | 1.5e-04 | 1.5e-04 |
| 非同次: $y_2(2)$ | -0.0693194436645 | -.0693201755 | -.0693201755 | 1.1e-05 | 1.1e-05 |

- gs と pysad は表の全桁が一致 (○)。(1) は解析解と 10 桁一致。
- (2) は数値積分と **$1.5\times10^{-4}$ の相対差** (0.349814 対 0.349760)。LDSolve の既定の精度 (`AccuracyGoal`) と刻み 0.1 による誤差である。pysad も gs と同じ誤差なので、LDSolve の仕様の範囲と考える。
