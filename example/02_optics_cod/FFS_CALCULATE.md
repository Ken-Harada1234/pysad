# FFS_CALCULATE (CALCULATE: 光学関数の計算)
種別: FFS コマンド。フォルダ: 02_optics_cod。ラティス: `00_lattice/FODO_ring.sad` (24 セル、周長 105.6 m、`CAVI RF`、SF/SD は K2=0)。エネルギー 3 GeV。フラグ: CELL (周期解)、COD (既定 ON)、CALC4D (既定)。

## 何を見る例か
最も基本の流れ: `USE` でラインを決め、`CELL` (リングの周期解) を選び、`CALCULATE` (略 `CALC`) で閉軌道と Twiss パラメータを計算する。
計算した関数は `Twiss[...]` で読める。ここではリング全体のチューン NX NY を読む。

## スクリプト
```
FFS;
$FORM = "10.6";
USE RING;
CELL;
CALCULATE;
Print["NX=", Twiss["NX","$$$"]/2/Pi, "  NY=", Twiss["NY","$$$"]/2/Pi];
```
- `FFS;` で FFS (光学計算の部分) に入る。ラインや要素の定義はこの前 (MAIN 部) に書く。
- `$FORM = "10.6";` は `Print` の数値の書式。
- `Twiss["NX","$$$"]` はラインの終端 `$$$` の位相進み [rad] で、`/2/Pi` でチューンになる。

## 結果の読み方
`Matched. ( 0.000 ) ...` の行は計算が収束した印。続く 3 行の表は **ライン末尾 (`$$$`) での** AX BX NX、AY BY NY、LENG (`f` は FIT 位置の印。マッチング条件が無いので現在値だけが出る)。
- `AX=-2.166305`、`BX=5.025185` は周期解の入口 (= 末尾) の α、β [m]。
- `NX=6.696329`、`NY=4.906056` がリング 1 周のチューン。`LENG`=105.6 m が周長。

## 物理・解析式
24 セルの 2x2 行列 (セルの周期行列 $M_{\rm cell}$、全要素の積。`tools/ana_fodo_ring.py`) から、安定条件 $|{\rm tr}M|/2<1$、
$$\cos\mu=\tfrac12{\rm tr}M_{\rm cell},\quad \beta=\frac{M_{12}}{\sin\mu},\quad \alpha=\frac{M_{11}-M_{22}}{2\sin\mu},\quad \nu=24\mu/2\pi$$
(BEND の E1/E2 は ANGLE に対する比で、辺の収束 $\pm\tan e/\rho$ を入れた。elem_BEND 参照。)

## 未確認・限界
