FFS_MATRIX (MATRIX: 転送行列)

種別: FFS コマンド。フォルダ: 02_optics_cod。ラティス: 00_lattice/FODO_ring.sad。エネルギー 3 GeV。フラグ: CELL、CALC4D (4x5 行列)。

何を見る例か

MATRIX [SYMPLECTIC|PHYSICAL] [from to] は from から to までの転送行列を表示する (CALC4D のときは 4x5。4 列は x px y py、5 列目は運動量偏差 δ に対する変位)。 SYMPLECTIC (既定) は規格化された座標での行列、PHYSICAL は TRPT (輸送路で加速があるとき) の物理座標の行列。リングでは同じ。 関数形 TransferMatrix[from, to] の戻り値 (4x4) から、1 セルのトレースと行列式、位相進みも確かめる。

スクリプト

MATRIX SF.1 SF.2;       MATRIX PHYSICAL SF.1 SF.2;       MATRIX QF.1 QD.1;
m = TransferMatrix["SF.1","SF.2"];
Print["trace x = ", m[[1,1]]+m[[2,2]], "  trace y = ", m[[3,3]]+m[[4,4]]];
MATRIX ORIGIN $$$;          ! リング 1 周

結果の読み方

Symplectic transfer matrix from SF.1 to SF.2 の 4 行 × 5 列。x-y が分離しているので 2x2 ブロックが対角に並ぶ。trace x =、det x = の行。 MATRIX ORIGIN $$$ が 1 周の行列 (安定ならトレースが 2cos(2πν))。

gs と pysad の比較

全桁一致 (MATRIX の表、PHYSICAL、Print)。1e-16 程度の雑音の要素 (x-y 結合要素の 0) は gs が -1.479E-31 などを出し、pysad は 0 を出す (表示の差だけ)。
