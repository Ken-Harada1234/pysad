FFS_FITPOINTS (FITPOINTS: オフモメンタム・マッチング、DP)

種別: FFS コマンド + 特殊変数 DP。フォルダ: 03_matching。ラティス: 00_lattice/FODO_ring.sad (SF/SD の K2 を変数に使う)。エネルギー 3 GeV。フラグ: CELL。

何を見る例か

FITP n (FITPOINTS) と、条件の第 2 引数「点数」で、運動量の異なる軌道 (オフモメンタム) の条件を課す。NX 6.7 3 は「運動量偏差 $-DP, 0, +DP$ の 3 点で NX=6.7」で、特殊変数 DP (運動量バンド幅 [相対]) が必要 (?No momentum bandwidth.)。 これでチューンの運動量依存 (クロマティシティ) を 0 にするには6 極 (SF・SD の K2) が必要なので、QF QD SF SD の 4 変数で、$\nu_x(\delta)=6.7$、$\nu_y(\delta)=4.9$ を 3 点で課す。

スクリプト

FREE QF QD SF SD;     DP = 0.01;     FIT $$$;
NX 6.7 3;     NY 4.9 3;     FITP 3;     SHOW;     GO;

結果の読み方 (gs)

  • GO のあとの表: DP −0.010000 0.000000 0.010000 と各点の Res. (残差) の行、各関数の 3 点の値 (NX: 6.700851、6.699892、6.700873 など)。
  • K1 (QF, QD) = (0.700211, -0.599628)、K2 (SF, SD) = (1.6952, -2.4391)。
  • 3 点でチューンがほぼ揃う (±δ で 1e-3 以内): クロマティシティはほぼ 0 になる。

物理・解析式

6 極の寄与は 1 次では (FFS_CHROMATICITY の積分を使って) $\xi_x=\xi_x^{\rm nat}+\frac{24}{4\pi}\bigl(\tfrac{K_{2F}}{0.2}I^{\eta\beta_x}{SF}+\tfrac{K{2D}}{0.2}I^{\eta\beta_x}_{SD}\bigr)$、$\xi_y=\xi_y^{\rm nat}-\frac{24}{4\pi}(\dots)$。自然クロマティシティ (有限差分、FFS_CHROMATICITY) $\xi^{\rm nat}=(-7.512,\,-6.565)$ を打ち消す K2 の 1 次の解:

量 式の値 (1 次) gs pysad
K2(SF) 1.69245 1.69523 1.69528
K2(SD) -2.43595 -2.43906 -2.43893

(厳密には 3 点の条件の最小二乗なので 2 次以上の項で少しずれる。)

gs と pysad の比較

△ 実行は完走し、値も近い。 K2 (SF, SD) は gs (1.6952, -2.4391)、pysad (1.6953, -2.4389) で 5e-5 (相対) 以内、K1 は 1e-6 以内。 差が出る点: (1) pysad は DP −0.01 0 0.01 / Res. の行 (点ごとの残差の表) と、各点の関数値の列を出さない (最後の表が 1 点分だけ)。(2) gs は *****qcod---> Overflow & closed orbit not found を 2 回、pysad は 4 回出す (途中の試行点で閉軌道が見つからない)。(3) 収束の表示 (Residual = 6.3321E-06) も gs・pysad で 1e-4 ほど違う。docs/03 には「FITP>1 の GO で SAD が再起動する」とあるが、今回の gs の実行では再起動せず完走した。
