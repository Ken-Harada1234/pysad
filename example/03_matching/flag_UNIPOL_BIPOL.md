# flag_UNIPOL_BIPOL (UNIPOL と BIPOL)
種別: フラグ。フォルダ: 03_matching。ラティス: `00_lattice/FODO_ring.sad`。エネルギー 3 GeV。フラグ: CELL。

## 何を見る例か
`BIPOL` (既定): マッチング中に変数 (K1 など) の符号が変わってよい。`UNIPOL`: 符号を変えない (正の K1 は負にならない)。ただし各要素の `MIN`/`MAX` や `VariableRange` があればそちらが優先 (SADHelp)。
- **A**: 解の K1 の符号が変わらない目標 (NX=6.2、NY=4.2): BIPOL でも UNIPOL でも同じ解になる。
- **B**: 解のない目標 (NX=0.2、NY=0.2。安定領域の外) では収束せず (`Residual` が大きいまま)、どこで止まるかが経路 (フラグ) に依存する。

## スクリプト
```
FREE QF QD;   FIT $$$;
NX 6.2 NY 4.2;   GO;                     ! A BIPOL
QF K1 0.7; QD K1 -0.6;   UNIPOL;   GO;   ! A UNIPOL
BIPOL;   QF K1 0.7; QD K1 -0.6;   NX 0.2 NY 0.2;   GO;     ! B BIPOL
QF K1 0.7; QD K1 -0.6;   UNIPOL;   GO;                      ! B UNIPOL
```

## 結果の読み方 (K1 の QF, QD)

| A BIPOL | (0.648109, -0.539021) | (0.648109, -0.539021) |
| A UNIPOL | (0.648109, -0.539021) | (0.648109, -0.539021) |
| B BIPOL | (-0.005524, -0.005792) → NX,NY = (1.42, 1.299) | (-0.008547, -0.008878) → (1.275, 1.443) |
| B UNIPOL | (0.111921, -0.138159) → (1.43, 1.913) | (0.111921, -0.138159) → (1.43, 1.913) |

## 物理・解析式
A: 2 変数 2 条件なので解は一意で、FODO の 2x2 行列の模型 (`tools/ana_fodo_ring.py`) で解ける: (0.648109, -0.539021) (gs・pysad の値 (0.648109, -0.539021) と 6 桁一致)。
B: 安定領域 ($|\mathrm{tr}M|<2$) の外へ目標があり、**解は存在しない** (式のとおり)。

## gs と pysad の比較
- A: **一致** (BIPOL・UNIPOL とも、解析解とも)。
- B UNIPOL: **一致** (K1 と最終チューンが全桁同じ)。
- **B BIPOL: 不一致 (△)。** 解のない問題なので、gs と pysad で最終的に止まる点が違う (gs: K1=(-0.005524, -0.005792)、pysad: (-0.008547, -0.008878))。収束しない最適化の経路 (反復の刻み・特異値の扱い) に依存し、どちらが SAD の動作かは決められない。意味のある比較は収束する A。docs/04 の `fit1.sad` では gs と全桁一致とあるが、この目標では一致しない。

## 未確認・限界
- 実際に UNIPOL が効く (符号を変えたい解があるが禁止される) ケースを、安定領域の中で作れなかった (ここでは安定領域の外の B でだけ差が出る)。
- `VariableRange` との優先関係は fn_FitValue_... の例で、K1 の限界だけ確認。
