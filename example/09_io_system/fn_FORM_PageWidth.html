fn_FORM_PageWidth ($FORM, PageWidth, StandardForm)

種別: 関数 / 特殊変数 / フォルダ: 09_io_system / FFS 内の SADScript (ラティスなし)。gs は SAD 1.4.4.2k64、pysad は run_sad_string。ファイルは TemporaryName[] か実行ディレクトリの作業ファイルで、最後に DeleteFile で消す。

何を見る例か

$FORM は実数の出力書式 ("w.f"、"Sw.f" 末尾 0 を省く、"Fw.f" FORTRAN の F 形式、"Mw.f" 指数を $10^n$ で)。PageWidth は 1 行の桁数 (超えると改行)。StandardForm[expr] は両方を既定に戻して評価する。

スクリプト

$FORM = "10.4";  $FORM = "S10.4";  $FORM = "F10.4";  $FORM = "M10.4";  $FORM = "6.2";
StandardForm[Pi];
PageWidth = 40;  Print[Range[30]];

結果の読み方

x=Pi*1000 のときの出力は次のとおり。既定は 3141.592653589793。"10.4" (幅 10、小数 4 桁) は 3141.5927、Pi/1000 が .0031、整数 1 が 1.0000。"S10.4" は末尾の 0 を省いて 2.5・1。"F10.4" は Pi/1000 が 0.0031。"M10.4" は $3.1416\times10^{-13}$ を 3.1416 10^-13。"6.2" は幅 6 で 3.14。リストにも効く。StandardForm[Pi]=3.14159265358979 (17.15 の既定書式)。PageWidth=40 では 40 桁で改行 (次の行は 1 文字ずらして開始)、130 では 1 行。PageWidth の初期値は 131 (環境変数 WIDTH)。$FORM の初期値は、gs・pysad とも Print すると空白 1 文字 (SADHelp には "S17.15")。

gs と pysad の比較

○ 値の書式は一致。差は 2 点だけ (表示の体裁): "M" 形式の指数部が gs 10^-13、pysad E-13。PageWidth=40 の折り返しの位置が 1 要素ずれる (gs は ...25, で改行、pysad は ...26,)。

未確認・限界

  • $FORM を変えると以降の Print 全体に効く (FFS のコマンド表示にも効く)。
  • 文字列連結 // で数を文字列にするときは $FORM を使わず 17 桁になる (gs。pysad は $FORM を使う: "pi=" // Pi を $FORM="10.4" で試して pysad が 3.1416、gs が 3.141592653589793。例からは外した)。
