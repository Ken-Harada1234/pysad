# fn_TrackParticles (損失の扱い)
種別: 関数 / フォルダ: 05_tracking / ラティス: `00_lattice/FODO_ring.sad` (3 GeV) / フラグ: `LOSSAMPL=0.05`、`NORFSW NORAD NOFLUC`

## 何を見る例か
`TrackParticles` の戻りの 7 列目 (flag) の意味。大振幅の粒子は `LOSSAMPL` (m) を超えた所で損失扱い (flag=0) になり、以後は追跡されない。最初から flag=0 で渡した粒子は損失のまま。

## スクリプト
```
LOSSAMPL = 0.05;                                   ! 既定は 1 m
x0 = {1e-3, 0.02, 0.04, 0.045, 1e-3};              ! 5 粒子 (最後の 1 粒子は flag=0)
flag = {1, 1, 1, 1, 0};
beam = {x0, zero, zero, zero, zero, zero, flag};
r = TrackParticles[{1, beam}, 1, 1, nt];           ! nt = 1, 2, 3, 5, 20
```
- 判定は `tapert`: 最初の要素の前、以後 15 要素ごと、周の終わりに行う (`docs/10_tracking.md` §2.3)。|x| と |y| が `LOSSAMPL` を超えた粒子が落ちる。
- 損失した粒子の座標は初期値に戻らず、落ちた時点の値 (limittrack で丸めた値) が残る。

## 結果の読み方
| nt | flag (出力) | 生存数 |
|---|---|---|
| 1, 2, 3, 5, 20 | {1, 1, 0, 0, 0} | 2 |

$x_0=0.04, 0.045$ の粒子は最初の 1 周で落ちる (nt=1 から flag=0)。20 周後の $x$ は {0.001852, −0.045458, 0.091082, 0.051290, 0.001000} で、落ちた粒子 (3、4 番目) は $|x|>0.05$ の値で止まっている。flag=0 で渡した 5 番目は動かない ($x=0.001$ のまま)。

## 物理・解析式
線形の範囲で、初期条件 $(x_0,0)$ の粒子の最大振幅は位置 $s$ で $x_{\max}(s)=\sqrt{J\beta(s)}$、$J=\gamma_0x_0^2$ ($\gamma_0=(1+\alpha^2)/\beta=1.1327$ m$^{-1}$)。このリングの $\beta_x$ の最大は約 6.57 m (要素の境界で、行列から計算) なので、全周で $|x|<0.05$ を保てる限界は $x_0\lesssim0.05/\sqrt{1.1327\times6.57}=0.018$ m。
ところが $x_0=0.02$ の粒子は 20 周生き残る。判定は 15 要素ごとの点でしか行われず、$\beta$ が最大の点を通らないため。損失の判定位置は要素の並びで決まるので、解析的な限界値はあくまで目安になる。
