# flag_SPAC
種別: フラグ / フォルダ: 05_tracking / ラティス: `00_lattice/spac_ring.sad` (`FODO_ring.sad` の `DRIFT` に `RADIUS=0.03` を付けた版。運動量 20 MeV、空洞の電圧 0、1 m のドリフトだけの輸送路 `TL` つき) / フラグ: `SPAC`、`RFSW NORAD NOFLUC`

**出力のモード**: `flag_SPAC.pysad.txt` は pysad の **v2 モード** (既定。`PYSAD_COMPAT` を指定しない) の出力、`flag_SPAC.gs.txt` は gs (K64、2026-10-19 ビルド) の出力 (2026-11-17)。pysad の k64 モード (`PYSAD_COMPAT=k64`) では空間電荷は追跡に入らない (K64 の SPAC の誤りを再現する翻訳はしていない。RADIUS<0 の絞りも k64 モードでは入らない)。

## 何を見る例か
`SPAC` を ON にすると、追跡 (`TrackParticles`) で空間電荷が入る (1 バンチの実粒子数 `PBUNCH`。マクロ粒子 1 個の電荷は PBUNCH/粒子数)。真空ダクトは設計軌道を軸とする円筒で、半径を `DRIFT` (と `MULT`) の `RADIUS` で与える: RADIUS>0 なら空間電荷を入れ、その半径の絞りも置く。RADIUS<0 なら空間電荷なしで半径 |RADIUS| の絞りだけ。RADIUS=0 は何もしない (SADHelp)。

この例は 3 つの部分からなる。
- (A) 1 m のドリフト: 一様なビームの広がりを、包絡方程式 $a''=K/a$ と比べる。
- (B) リング 1 周: 試験粒子のチューンシフトを Laslett の式と比べる。空間電荷は RADIUS>0 の DRIFT の中だけなので、周長の 50% (52.8 m / 105.6 m) にしか入らない。
- (C) RADIUS<0: 絞りだけ。

## スクリプト (要点)
```
RFSW; NORAD; NOFLUC;             ! フラグは FFS の最上位に書く
USE TL; INS; CALC;               ! (A)
PBUNCH = 1e12;
NOSPAC;  r = TrackParticles[{1, beam}][[2]];
SPAC;    r = TrackParticles[{1, beam}][[2]];
USE RING; CELL; CALC;            ! (B)
PBUNCH = 1.5e9;  SPACSTEP = 0.1;
NOSPAC;  nu0 = tune[];           ! tune[]: 試験粒子 1 個をビームと一緒に 1 周させて 1 周の行列の対角和を作る関数
SPAC;    nu1 = tune[];
Element["RADIUS","D1"] = -4e-4; ...                   ! (C) 負の RADIUS = 絞りだけ
```
- **フラグは最上位に書く。** `Do[..., NOSPAC; ...; SPAC; ...]` のように式の中に書くと、フラグの命令にならず切り替わらない。式の中で切り替えるなら `FFS["SPAC"]`。
- **`RFSW` を ON にする。** `NORFSW` は区間 (周) ごとに粒子の z を 0 にするので、バンチの線密度が決まらない。pysad v2 は `NORFSW` で空間電荷 (RADIUS>0) を入れようとするとエラーにする。そのためラティスの空洞の電圧は 0 にした (20 MeV のビームに 1.5 MV の空洞を掛けると、空間電荷と関係なくビームが乱れる)。RADIUS<0 の絞りだけなら `NORFSW` でも走る。
- 粒子は乱数を使わない決定的な分布。(A) は半径 1 mm の一様な円 × 長さ 0.1 m の一様なバンチ (2000 個、角度 0)、(B) は整合したガウス分布 (εx = εy = 1e-6 m、σz = 1 cm、4000 個)、(C) は 200 個。
- `PBUNCH` は効果が見えて破綻しない値にしている (`PBUNCH = 1e13` は桁外れで、チューンシフトが 100 を超える): (A) 1e12 (20 MeV で半径が 1.44 倍)、(B) 1.5e9 (Δν ≈ −0.01)。
- `SPACSTEP` (キックの間隔 [m]) は pysad v2 の変数 (既定 0.05)。gs では普通の変数で、意味を持たない (5 cm 固定)。

## 結果

### (A) 1 m のドリフト (20 MeV、1e12 個/0.1 m、半径 1 mm → rms 0.5 mm)

| | rms x [mm] | rms y [mm] |
|---|---|---|
| 空間電荷なし (NOSPAC、gs・pysad とも) | 0.5003 | 0.4997 |
| 解析式 (包絡方程式、K = 9.397e-7) | 0.7197 | 0.7197 |
| **pysad v2** (SPAC) | 0.7159 | 0.7151 |
| 解析式で力を 1/γ 倍にしたもの (K/γ) | 0.5060 | 0.5060 |
| **gs (K64)** (SPAC) | 0.5060 | 0.5047 |

pysad v2 は解析式と 0.6% で合う (差は、バンチの両端で線密度が下がる分。試験 `test_spac_kv_envelope_in_drift` はバンチの中央部だけで 0.5% 以内)。gs は「力が 1/γ 倍」の式に合う: **K64 の SPAC は力が 1/γ 倍に弱い** (SPC1。`spkick.f` の `spfield` が、バンチの静止系の電位の勾配をそのまま実験室系の場として使う。γ = 39.2 なので 1/39)。

### (B) リング 1 周のチューンシフト (ν = (6.696, 4.906)、1.5e9 個、σz = 1 cm)

| | Δνx | Δνy |
|---|---|---|
| Laslett の式、DRIFT の中だけ (52.8 m) | −0.011087 | −0.012541 |
| **pysad v2** (SPAC、追跡) | −0.011795 | −0.013227 |
| Laslett の式、全周 (105.6 m。参考) | −0.022172 | −0.025083 |
| Laslett の式 (DRIFT だけ) を 1/γ 倍したもの | −2.832e-4 | −3.203e-4 |
| **gs (K64)** (SPAC、追跡) | −1.853e-4 | −2.079e-4 |

- pysad v2 は Laslett の式 (DRIFT だけ) の 1.064 倍、1.055 倍。差は主にマクロ粒子の雑音 (中心の勾配はビームの中心付近の少数の粒子で決まる): 同じリングで、分布を Sobol 列の 4096 個に替えると 0.964 倍、0.978 倍、この例の分布の 1000 個では 1.10 倍、1.15 倍になる。粒子を増やすと式に近づく (小さなリングの試験では 16384 個で 0.98)。
- gs は「1/γ 倍」の式の 0.65 倍 (SPC1 に加えて、K64 のメッシュが粗い: SPC4)。正しい値の 1/60 しか入らない。
- 作動点: νx の小数部 0.696、νy は 0.906 (整数 5 から 0.094)。空間電荷でチューンは下がるので整数からは離れる向きで、半整数 (0.5) までは 0.196、0.406 ある。
- SPAC が入るのは RADIUS>0 の DRIFT の中だけなので、このリング (四極は `QUAD`、偏向は `BEND`) では全周の 50% の分しか入らない。全周に入れる方法 (pysad v2): 四極を `MULT` で書いて `RADIUS` を付ける (`example/05_tracking/flag_SPAC_MULT_radius.sad`。偏向磁石の中は未対応)、`PSPAC` + `SPCH` 要素、`WSPAC` (`example/05_tracking/flag_WSPAC_tune_shift.sad`)。

## 物理・解析式
- 一様な円柱のビーム (半径 $a$、線密度 $\lambda$): $x''=K\,x/a^2$、ペルビアンス $K=\dfrac{2 r_e\lambda}{\beta^2\gamma^3}$ ($r_e=2.818\times10^{-15}$ m)。電場の反発 (∝γ) と磁場の引力の打ち消し ($1-\beta^2=\gamma^{-2}$)、慣性 γ で $1/(\beta^2\gamma^3)$ になる。エミッタンス 0 の包絡は $a''=K/a$ (スクリプトの `env[]` が 1 m 積分する。一様な円の rms は $a/2$)。
- ガウスビームの中心の収束力の変化: $k_x=\dfrac{2 r_e\lambda_{peak}}{\beta^2\gamma^3}\dfrac{1}{\sigma_x(\sigma_x+\sigma_y)}$ (y も同様)、$\lambda_{peak}=N/(\sqrt{2\pi}\sigma_z)$。チューンシフト (Laslett、1 次の摂動): $\Delta\nu_u=-\dfrac{1}{4\pi}\oint\beta_u k_u\,ds$。スクリプトは $\sigma_u=\sqrt{\beta_u\varepsilon}$ として、各要素を Simpson 則 (`Twiss["BX", k+0.5]` が要素の中点) で積分する。

## gs と pysad の比較
- (A)・(B): pysad v2 は解析式に合い、gs (K64) は力が 1/γ 倍に弱い (上の表)。K64 の誤り (SPC1〜SPC9) と v2 の実装は `docs/history/v2_changes_C_spch.md`、MULT の RADIUS と WSPAC は `docs/history/v2_changes_C2_spch.md`。
- (C): 一致 (生存数 84)。
- **gs は SPAC の粒子数が少ないと落ちる**: 小さい RADIUS>0 (0.4 mm) で gs が不正終了する原因。`spkick.f` の `spmesh` は縦を 10 枚のスライスに分け、最後のスライスが空 (粒子数 np が 9·ceil(np/10)+1 より小さい) だと配列の外を読み、1 粒子だと厚さ 0 で割る。gs で確かめた: np = 2、15、33 は SIGSEGV、5 は Bus error、9・10・11・19・25・28・81・82 は NaN で全粒子が失われ、20・30・40・…・100・200 と 1 は正常。小さい絞りで粒子が減っていくと、これに当たる。pysad v2 は粒子数によらず走る (試験 `test_spac_small_particle_number`)。

## 未確認・限界
- 使った条件: 電子、20 MeV (γ = 39.2)、周長 105.6 m、ダクトの半径 3 cm、ビームの大きさ 0.5〜3 mm、1.5e9〜1e12 個/バンチ、2000〜4000 マクロ粒子。
- (B) の追跡と式の差 (+6%) はマクロ粒子の雑音の範囲で、この例の粒子数ではこれ以上の精度の比較にならない。1 周の線形のチューンシフトだけを見ており、多数周の追跡 (エミッタンスの増大、共鳴) は確かめていない。
- gs の値は K64 の誤りを含むので、正しさの根拠にはならない (根拠は解析式)。pysad の k64 モードは gs の SPAC を再現しない (空間電荷なし)。
- SPAC は偏向磁石・`QUAD`・`SEXT` の中には入らない。真空ダクトは円筒だけ。複数バンチ、壁の抵抗は扱わない。
- FFS の中の `MOMENTUM = …` の再設定は pysad の追跡に反映される (2026-11-17 確認)。この例は運動量をラティスの先頭 (MAIN レベル) に置いている。
