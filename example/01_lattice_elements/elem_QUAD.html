elem_QUAD (四極磁石)

種別: elem。フォルダ: 01_lattice_elements。ラティスは START-QUAD-FIN の輸送路 (INS、初期 BX=BY=10 m、AX=AY=0)。エネルギー 3 GeV (K1 は積分強度なので結果はエネルギーによらない)。

何を見る例か

QUAD Q = (L=0.3 K1=0.7): K1 は積分強度 (K1=k1LK_1=k_1LK1​=k1​L [1/m]、正で水平収束)。1 台の転送行列と β の変換を、厚いレンズ (L=0.3) と、ほぼ薄いレンズ (L=0.001, K1=0.021) の両方で見る。

スクリプト

QUAD Q = (L=0.3 K1=0.7) QT = (L=0.001 K1=0.021);
MARK START = (BX=10 BY=10 AX=0 AY=0) FIN = ();
LINE T = (START Q FIN);   LINE TT = (START QT FIN);
FFS;
USE T; INS; CALC;
m = TransferMatrix["START","FIN"];
Print["thick Q  M11 M12 M21 M22 = ", m[[1,1]], " ", m[[1,2]], " ", m[[2,1]], " ", m[[2,2]]];

TransferMatrix[from, to] は 4x4 (CALC4D) の行列 ({x, px, y, py})。全文は elem_QUAD.sad。

結果の読み方

thick Q ... の 2 行が x と y の 2x2 ブロック、BX FIN/BY FIN が出口の β、NX FIN/NY FIN が位相進み [rad]。最後の 1 行が薄い四極の M21M_{21}M21​ と M43M_{43}M43​。

横軸は四極の入口 (START、s = 0) からの距離 [m]、縦軸は √β [√m]。四極の中で √βx (実線、水平に収束) は小さくなり、√βy (破線、垂直に発散) は大きくなる。出口 (s = 0.3 m) の値は βx = 8.05 m、βy = 12.26 m (下の表の BX(FIN)・BY(FIN)) に対応する。
