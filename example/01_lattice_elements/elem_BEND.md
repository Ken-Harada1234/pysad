# elem_BEND (偏向磁石: ANGLE・E1・E2・FRINGE)
種別: elem。フォルダ: 01_lattice_elements。ラティスは START-BEND-FIN の輸送路 (INS、初期 BX=BY=10 m、分散 0)。エネルギー 3 GeV。

## 何を見る例か
`BEND B = (L=1.2 ANGLE=0.2618 E1=.. E2=.. [F1=.. FRINGE=..])`。**`ANGLE` は偏向角 [rad]、`E1` `E2` は入口・出口の面の角度を ANGLE に対する比で与える** (実効の面の角は `E1*ANGLE`)。
長方形磁石は `E1=E2=0.5`。3 つの磁石を比べる。
- `BS`: セクター型 (E1=E2=0)
- `BR`: 長方形 (E1=E2=0.5)
- `BF`: 長方形 + 線形フリンジ (`F1=0.3 FRINGE=3`: 入口と出口の両方)

(注: `00_lattice/FODO_ring.sad` の BEND は `E1=E2=0.1309` と書かれていて、これは ANGLE=0.2618 の半分の rad の値だが、SAD は比と読むので実効の面の角は 0.0343 rad。長方形ではない。この例は E1=E2=0.5 で長方形にした。)

## スクリプト
```
BEND BS = (L=1.2 ANGLE=0.2617993877991494 E1=0 E2=0);
BEND BR = (L=1.2 ANGLE=0.2617993877991494 E1=0.5 E2=0.5);
BEND BF = (L=1.2 ANGLE=0.2617993877991494 E1=0.5 E2=0.5 F1=0.3 FRINGE=3);
LINE TS = (START BS FIN);  (TR、TF も同様)
FFS;
USE TS; INS; CALC;
m = TransferMatrix["START","FIN"];   Print["BS EX EPX = ", Twiss["EX","FIN"], " ", Twiss["EPX","FIN"]];
```
各ラインを `USE` して `INS; CALC;` し、転送行列と出口の分散を表示する。最後に `LINE["GX","FIN"]` などで幾何 (座標) も出す。

## 結果の読み方
`BS`/`BR`/`BF` それぞれ 3 行: 水平 2x2、垂直 2x2、`EX EPX` (出口の分散)。`geometry` の行は設計軌道の座標 (GX GY GZ [m]) と回転角 (GCHI1..3 [rad])。
SAD の幾何では水平な偏向は CHI1 の回転、局所の進行方向が GX、水平の横方向が GY に出る (GZ は 0)。

## 物理・解析式
$\rho=L/\theta=4.5837$ m。セクター型:
$$M_x=\begin{pmatrix}\cos\theta&\rho\sin\theta\\-\sin\theta/\rho&\cos\theta\end{pmatrix},\quad
\eta=\rho(1-\cos\theta),\ \eta'=\sin\theta,\quad M_y=\begin{pmatrix}1&L\\0&1\end{pmatrix}$$
面の角度 $e$ の硬い縁は水平に $\tan e/\rho$、垂直に $-\tan e/\rho$ の薄い収束 $\begin{pmatrix}1&0\\\pm\tan e/\rho&1\end{pmatrix}$。
長方形は $e=\theta/2$ なので水平は $M_{11}=1$、$M_{21}=0$ (ドリフトと同じ)、垂直は縁で収束される。

`BF` (F1=0.3、FRINGE=3) は、水平は `BR` と同じ ($M_{11}$=1、$M_{21}$=-2.760e-17) で、垂直の収束が変わる: gs $M_{43}$=-0.051852、pysad -0.051852 (BR は -0.056454)。フリンジの式 (SADHelp の `F1` の項、$V=-\frac1p(\frac{F_1^2}{24\rho}p_x-\frac{F_1}{12\rho}y^2+\dots)$) を解析値と照合するところまでは行っていない (gs と pysad の一致だけ確認)。

## gs と pysad の比較
全項目が一致 (1e-12 以内。0 になるべき行列要素の雑音 1e-17〜1e-13 だけ両者で値が違う)。

## 未確認・限界
- `FRINGE` の効きの解析値との照合なし (上記)。`K1`≠0 の BEND (複合機能)、`K0`、`AE1`/`AE2`、`DISFRIN`、`ROTATE`、`DROTATE` は扱っていない。
- 長方形磁石の垂直収束の式 $\tan e/\rho$ は硬縁のモデル。SAD は `F1`=0 でこの形を使う (表のとおり 6 桁一致)。
