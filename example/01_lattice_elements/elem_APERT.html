elem_APERT (開口)

種別: elem。フォルダ: 01_lattice_elements。ラティスは FODO_ring.sad と同じ光学のリング (定義はファイル内、ORIGIN の次に APERT AP を 1 個置いた。RF なし)。エネルギー 3 GeV。

何を見る例か

APERT AP = (AX=0.01 AY=0.005): 追跡 (TrackParticles) だけで効く楕円の開口。粒子が $\frac{(x-DX)^2}{AX^2}+\frac{(y-DY)^2}{AY^2}>1$ の外に出ると失われ、flag が 0 になる (DX1 DX2 DY1 DY2 を使う矩形も指定できる。SADHelp の APERT の項)。 x=1 mm (内側) と x=20 mm (外側。AX=10 mm より外) の 2 粒子を 1 周追跡して flag を見る。

スクリプト

APERT AP = (AX=0.01 AY=0.005);
LINE RING = (ORIGIN AP 24*CELL);
...
beam = {1, {{0.001,0.02}, {0,0}, {0.001,0.001}, {0,0}, {0,0}, {0,0}, {1,1}}};
r = TrackParticles[beam, LINE["LENGTH"], 1, 1];      (* 1 周 *)
Print["1st call: flag = ", r[[2,7]], "  x = ", r[[2,1]]];

TrackParticles[{ls, {x,px,y,py,z,dp,flag}}, 到達位置, 周回の始め, 終わり]。粒子ごとの列の並びは 6 座標 + flag。K64 は最初の TrackParticles では最初から開口の外の粒子を落とさない癖があるため (docs/29 の A52)、同じ呼び出しを 2 回している。

結果の読み方

flag が 1 なら生存、0 なら失われた粒子。失われた粒子の x は落ちた時点の値で止まる。

呼び出し gs の flag pysad の flag
1 回目 flag = [1.0, 0.0]、x = [0.001715, 0.02] flag = [1.0, 0.0]、x = [0.001715, 0.02]
2 回目 flag = [1.0, 0.0]、x = [0.001715, 0.02] flag = [1.0, 0.0]、x = [0.001715, 0.02]

物理・解析式

なし (開口の判定は上の楕円の式のとおり)。

gs と pysad の比較

○ 一致 (2026-11-17)。 flag と落ちた粒子の x は 1 回目・2 回目とも gs と同じ (内側は x=1.715 mm、flag=1。外側は x=20 mm で flag=0)。pysad は APERT の追跡を実装している。互換モードによらず同じ結果 (PYSAD_COMPAT=k64 でも上の表のとおり)。 違いは TYPE AP の表示だけ: gs は APERT AP =(AX =.01 AY =.005 )、pysad は DRIFT AP =(L =0 AX =.01 AY =.005 ) (種別を DRIFT と表示し、AX・AY は保持する)。値の違いではなく表示の差。
