# fn_LINE (LINE 関数)
種別: SADScript 関数 (MAIN 部の `LINE` 定義とは別物)。フォルダ: 01_lattice_elements。ラティス: `00_lattice/FODO_ring.sad`。エネルギー 3 GeV。フラグ: CELL。

## 何を見る例か
`LINE[キー, 成分]`: ビームライン上の**成分** (配置された 1 台ごと) の情報を返す。キー: `"LENGTH"` (成分数)、`"NAME"`、`"POSITION"`、`"TYPENAME"`、`"ELEMENT"` (成分が属する要素)、`"S"` (入口の s)、`"MULT"` (同じ要素の何番目か)、`"GEO"` (幾何)、`"GAMMA"`、そして要素のキーワード (`"K1"` `"L"` …)。位置は名前、パターン、番号、リスト、小数 (要素の途中) で与える。
`LINE["K1","QF.1"] = 0.75;` のように代入すると**その成分だけ**を変える (要素全体は `Element`)。

## スクリプト
```
Print["NAME 1..8    = ", LINE["NAME",{1,2,3,4,5,6,7,8}]];
Print["S at QF.1 B.1 $$$ = ", LINE["S",{"QF.1","B.1","$$$"}]];
Print["S at 7.5 (mid of B.1) = ", LINE["S",7.5]];
Print["MULT QF.1..QF.3 = ", LINE["MULT",{"QF.1","QF.2","QF.3"}]];
LINE["K1","QF.1"] = 0.75;
Print["after LINE[K1,QF.1]=0.75: ", LINE["K1",{"QF.1","QF.2"}]];
```

## 結果の読み方
LENGTH = 243 (ORIGIN、RF、24×10 要素、`$$$`)。名前は ORIGIN, RF, SF.1, DS.1, QF.1, D2.1, B.1, D2.2。`S` は QF.1 の入口 0.3 m、B.1 の入口 1.1 m、リング末 105.6 m、`S` の 7.5 (B.1 の途中) は 1.7 m。`GAMMA` = 5870.85 (3 GeV の電子)。代入後 `K1 {QF.1, QF.2}` = {0.75, 0.7} (QF.1 だけ変わる)。

## 物理・解析式
- 周長 = Σ要素の長さ: 24 セル × (0.2+0.1+0.3+0.5+1.2+0.5+0.3+0.1+0.2+1.0 = 4.4 m) = 105.6 m。
- B.1 の中点の s = 1.1 + 1.2/2 = 1.7 m (入口 1.1 は 0.2+0.1+0.3+0.5)。
- γ = E/(mc²) = 3 GeV / 0.5109989 MeV = 5870.85 (SAD の MOMENTUM は運動量 p なので γβ = 5870.85、γ = √(1+(γβ)²) = 5870.85)。

## gs と pysad の比較
**○ 一致 (2026-11-17 確認)。** `LINE["MULT"]` は gs と同じく同名の要素の通し番号 (QF.1..QF.3 が 1, 2, 3)。同名が 1 台だけの要素と `$$$` は 0。ほかの項目は全桁一致。
