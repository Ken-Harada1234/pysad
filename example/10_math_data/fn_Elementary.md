# fn_Elementary (初等関数)
種別: 関数 (SADHelp functions の Elementary-functions) / フォルダ: 10_math_data / ラティスなし

## 何を見る例か
`Sin Cos Tan ArcSin ArcCos ArcTan Sinh Cosh Tanh ArcSinh ArcCosh ArcTanh Exp Log Sqrt` と定数 `Degree`。実数の値を式の値と比べ、定義域の外 (負の `Log`、$|x|>1$ の `ArcSin`、負の `Sqrt`) の複素数の扱いを見る。

## スクリプト
```
Sin[1.]  ArcSin[.5]  ArcTan[2.]  ArcTan[1.,-1.]  Sinh[1.]  ArcCosh[2.]  ArcTanh[.5]  Exp[1.5]  Log[10.]  Sqrt[2.]  Sin[30*Degree]
Log[-1.]  ArcSin[2.]  Sqrt[-4.]  ArcCosh[.5]  ArcTanh[2.]  Exp[I*Pi/3]
```
`$FORM="S17.15"` で 15 桁出し、`R:` の行を表にした。引数は実数 (`1.`) にする (整数のままだと `Sin[1]` は記号式のまま)。

## 結果の読み方
`R:名前=値` の行が実数の値。最後の 6 行 (`LogNeg=` 以降) は定義域の外の例で、複素数は `(実部+虚部 I)` の形で出る。

## 物理・解析式
定義どおりの式。逆双曲線関数は $\mathrm{arcsinh}\,x=\ln(x+\sqrt{x^2+1})$、$\mathrm{arccosh}\,x=\ln(x+\sqrt{x^2-1})$、$\mathrm{arctanh}\,x=\frac12\ln\frac{1+x}{1-x}$。
`ArcTan[x,y]` は Mathematica と同じ引数の順で、$\mathrm{atan2}(y,x)$ を返す ($\arg(x+iy)$)。

## gs と pysad の比較
実数の 18 値は、gs と pysad が表示した全桁で一致 (○)。複素数の例は、`ArcSin[2.]` の虚部の末尾 1 桁 (gs ...816、pysad ...817) と、`ArcCosh[.5]` の実部 (gs は丸め誤差の -5.55E-17、pysad は 0) が違う。

## 未確認・限界
大きな引数 (オーバーフロー、桁落ち)、`Tan` の極の近傍、複素引数の双曲線関数は試していない (`Exp[1000.]` は var_Constants で `INF` を確認)。
