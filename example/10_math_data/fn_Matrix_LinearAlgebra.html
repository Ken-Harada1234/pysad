fn_Matrix_LinearAlgebra (Det・Inverse・LinearSolve・Transpose・Outer・Inner・IdentityMatrix・Dot)

種別: 関数 (SADHelp functions の Matrix-operations) / フォルダ: 10_math_data / ラティスなし

何を見る例か

3×3 の実対称行列 $A=\begin{pmatrix}2&1&0\1&3&1\0&1&4\end{pmatrix}$ について、行列式、逆行列、連立一次方程式 $Ax=b$ ($b=(1,2,3)$)、積、転置、外積・内積を一通り使う。

スクリプト

a={{2.,1.,0.},{1.,3.,1.},{0.,1.,4.}}; b={1.,2.,3.};
Det[a]   inv=Inverse[a]   a.inv   x=LinearSolve[a,b]   a.x-b
Transpose[{{1,2,3},{4,5,6}}]   Outer[Times,{1,2},{3,4,5}]   Inner[Times,{1,2,3},{4,5,6},Plus]   IdentityMatrix[3]   {{1,2},{3,4}}.{{0,1},{1,0}}

Inner は 4 引数 Inner[f, x, y, g] で g@@f[x,y] (内積は g=Plus)。3 引数だと gs は General::wrongnum: Number must be 4、pysad は ValueError: not enough values to unpack (expected 4, got 3) と、どちらもエラーになる (エラー文は違う)。

結果の読み方

Inverse= は逆行列。I=Chop[...] は $A A^{-1}$ (単位行列から $10^{-16}$ の丸め誤差だけずれる)。x= が解、resid= が残差 $Ax-b$。

物理・解析式

$\det A=2(3\cdot4-1)-1(1\cdot4-0)=18$、逆行列は余因子行列 / 18 (例: $(A^{-1})_{11}=11/18$)、解は $x=A^{-1}b=(1/3,\,1/3,\,2/3)$。

gs と pysad の比較

  • 数値は 1e-14 程度で一致 (逆行列の最後の桁で gs は ...112/...445/...278、pysad は ...111/...444/...278 と 15 桁目が違う。LinearSolve は同じ)。Det は gs が 18 を返し、pysad は 17.99999999999999。
  • Chop[a.inv]・resid の丸め誤差の形は違う (gs は 1e-16 台の非零要素が出る、pysad は一部が 0 になる)。丸めの違いで、値の問題ではない。
  • 判定: ○ (表示の丸め誤差の違いのみ)。
