10_math_data 一覧

数値・データ処理の例。当てはめ・補間・積分・最小化、特殊関数、行列関数、定数。ラティスは使わない (FFS; の後に直接書く)。式で値を検算できるものは、md に式と数値の照合表がある (R: で始まる出力行が表の元)。

○一致 / △差あり (理由は各 .md) / ×gs 失敗 / ×pysad 未対応・失敗

例 (NAME.sad・.gs.txt・.pysad.txt・.md) 内容 gs と pysad
fn_Fit_FitGaussian_FitEmit Fit・FitGaussian・FitEmit ○ (DesignMatrix の表示だけ pysad が数値微分の値。v2 は InverseErf が真値で FitGaussian が 1e-8 の桁で違う: B47)
fn_PolynomialFit PolynomialFit (2 次・1 次) ○
fn_Spline Spline (自然・傾き指定)、導関数、積分 ○
fn_NIntegrate NIntegrate (滑らか・特異・複素) △ (特異点の収束の警告の数値が違う。複素数は一致)
fn_DownhillSimplex DownhillSimplex (SADHelp の例ほか) ○ (反復の出力形式が違う。A・B は最小に届かない K64 の動作)
fn_Elementary 初等関数 (三角・指数・対数・双曲線・逆関数) ○
fn_Gamma_Erf Gamma・Erf・GammaRegularized ほか ○ (LogGamma1 に対応。InverseErf は v2 が真値を返し gs の 1e-8 の誤差と違う: B47。k64 モードは一致)
fn_Bessel BesselJ・I・K △ (gs が J0(100)・I0(0) で誤り)
fn_BesselY_JZero BesselY・BesselJZero ×gs 失敗 (NaN または応答なし。pysad は値を返す)
fn_SpecialFunctions_D LegendreP・HermiteH・Ei・Si・Fresnel・Airy・Zeta・PolyLog ほか △ (gs が HermiteH・Ei で誤り)
fn_NumericalFunctions Abs・Round・Mod・FractionalPart ほか ○
fn_Matrix_LinearAlgebra Det・Inverse・LinearSolve・Transpose・Outer・Inner・Dot ○ (丸め誤差の差)
fn_Eigensystem Eigensystem (対称・回転・1 ターン行列) ○
fn_SingularValues SingularValues (既定は逆数を返す) ○
var_PhysicalConstants 物理定数 13 個と定義式の再計算 ○
var_Constants Pi・Degree・GoldenRatio・I・INF・NaN △ (I*I の表示、NaN==NaN)
fn_SpecialFunctions_gs_errors K64 (gs) が誤値・NaN・INF・無応答になる特殊関数の式 (Hypergeometric2F1・BesselJ・ExpIntegralEi・HermiteH・LegendreP・Binomial・HypergeometricU・BesselY・BesselK・Fresnel・AiryAi・InverseErf)。各行のコメントに真値と K64 の値 v2 は真値を返す。gs の出力なし (InverseErf[.3] だけ v2 は .272462714727、k64 モードは K64 と同じ .272462711811)
fn_SpecialFunctions_complex 複素引数の PolyLog・Zeta・HurwitzZeta・HypergeometricU。独立な参照 (Borwein、Euler–Maclaurin、spence、積分表示) と相対 1e-11 以内 gs の出力は .gs.txt。pysad の値は独立な参照と合う
fn_SpecialFunctions_complex_scan 複素引数の特殊関数の走査。12 個の複素数 × 60 の関数・形 = 732 式 641 式が gs と 1e-9 で一致。残りは gs の誤り・不正確 (scipy と比べて pysad が正しい)。試験 test_v2_P5_specfn_cx.py

数値の桁・表示の細かい違いは追っていない (大きな差だけ md に書いた)。
