fn_DownhillSimplex (DownhillSimplex)

種別: 関数 (最小化、ネルダー・ミード法) / フォルダ: 10_math_data / ラティスなし

何を見る例か

DownhillSimplex[initial, f, options] で 2 変数関数 $$f(x,y)=(r^2-1)r^2-\frac{x-0.5}3,\qquad r^2=x^2+y^2$$ を最小化する。初期単体は {f[v], v} を値の昇順に並べたリスト。オプション MaxIteration、Tolerance、VariableRange、Output を使う。

スクリプト

f:=Apply[Function[{x,y},((x^2+y^2)-1)*(x^2+y^2)-(x-.5)/3.],#]&;
v={{1.,1.},{0.,-1.},{0.,1.}}; p=Sort[Map[{f[#],#}&,v]];
r=DownhillSimplex[p,f,MaxIteration->100,Tolerance->1e-4,VariableRange->{{-0.5,-1.5},{0.65,1.5}}];

A は SADHelp の例そのまま。B は同じ初期単体で制限なし・許容 1e-12 (Output->0 で途中経過を出さない)。C は最小点の近くの初期単体 {{.5,.2},{.6,-.1},{.7,.1}}、制限なし。D は C と同じ初期単体に VariableRange を付けたもの。

結果の読み方

A は Output が既定 (6、標準出力) なので、反復ごとの単体の 3 頂点の関数値が表示される (最後は 3 値が同じに収束)。r= の行が最終の単体 (3 点、関数値の昇順)、最初の要素が最良点。

物理・解析式

$y\ne0$ なら $\partial_y f=y(4r^2-2)=0$ から $r^2=1/2$ となるが、このとき $\partial_x f=-1/3\ne0$ なので停留点にならない。したがって最小は $y=0$ 上にあり、 $$\partial_x f=4x^3-2x-\tfrac13=0\ \Rightarrow\ x\simeq0.77908,\quad f_{\min}=-0.33159$$ $x\le0.65$ の制限つきの最小は境界の $x=0.65,\ y=0$ ($f=-0.29399$)。

gs と pysad の比較

  • 値は A〜D ともに gs と pysad が 10 桁で一致 (○)。
  • A・B は最小点ではない点 ($x=0.473,\ y=0.621$、$f=-0.2290$) に収束した。初期単体 {(1,1),(0,-1),(0,1)} から単体が潰れて止まったためと思われる (原因は未確認)。gs と pysad で同じ点になるので K64 の Amoeba の動作。C は正しい最小 (0.77908, 0) に収束する。
  • D: 制限が効かなかった。初期単体の頂点 (0.7, ...) が既に $x\le0.65$ の外にあり、VariableRange は新しい頂点を制限するだけで、単体が動かないまま止まる (gs・pysad とも (0.7,0.1))。制限の中から始めること。
  • 出力形式: gs は反復の行を { .104938, .166667, .166667} と波括弧つきで出し、前に DownhillSimplex {limit, Option}: {...} の行 (引数の表示) を付ける。pysad は波括弧なしの数字列で、前の行は DownhillSimplex {limit, Option}: ... と短い。反復の数値は同じ。

未確認・限界

3 変数以上、MaxIteration に達した場合の戻りは試していない。
