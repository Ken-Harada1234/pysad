# fn_Bessel (Bessel 関数 J・I・K)

種別: 関数 (SADHelp functions の Special-functions)・フォルダ 10_math_data・ラティスなし (`BesselY`・`BesselJZero` は fn_BesselY_JZero)

## 何を見る例か
`BesselJ[n,x]`、`BesselI[n,x]`、`BesselK[n,x]` を、整数次・半整数次、小さい引数・大きい引数 ($J_0(100)$)・ゼロ ($I_0(0)$) で評価し、式の値と比べる。

## スクリプト
```
BesselJ[0,1.]  BesselJ[1,2.5]  BesselJ[2.5,3.]  BesselJ[3,2.]  BesselJ[0,100.]
BesselI[0,1.]  BesselI[1,2.5]  BesselI[0,0.]   BesselK[0,1.]  BesselK[1,2.5]
```

## 結果の読み方
`R:` の行が値。gs だけ `hgu 0.5000 1.000 2.000` のような行を `BesselK` の呼び出しごとに出す (K64 ビルドに残るデバッグ表示と思われる。値には影響しない)。

## 物理・解析式
$J_n(x)=\sum_k\frac{(-1)^k}{k!\,\Gamma(n+k+1)}(x/2)^{2k+n}$、$I_n(x)=i^{-n}J_n(ix)$、$K_\nu(x)=\frac\pi2\frac{I_{-\nu}-I_\nu}{\sin\nu\pi}$。$J_0(100)=0.01998585$ ($\sim\sqrt{2/\pi x}\cos(x-\pi/4)$ の振幅 0.080 の範囲内)。

## gs と pysad の比較
- J・I・K の通常の値は 14 桁以上一致 (pysad は scipy)。
- **gs の誤り (2 件)**: `BesselJ[0,100.]` が -1.47E25 (真値 0.01999)、`BesselI[0,0.]` が `NaN` (真値 1)。pysad は正しい値を返す。どちらが「SAD の動作」かといえば gs (K64 ビルド) の出力は上記で、pysad は真値にしている (docs/19 の方針)。△
- 他の誤りは確認していない。

## 未確認・限界
$n$ が大きいとき、$x$ が負のとき、複素引数 (pysad は未対応) は試していない。gs の J0(100) が誤る境界の引数 (どの $x$ から誤るか) は調べていない。
