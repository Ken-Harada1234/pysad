解析式の物理の項 (K0≠0 の偏向磁石・δ≠0・閉形式・非対角の正規形の補正) と精密版 adts() (a)〜(e)

この文書で分かること: ADTS・RDT の解析式を、挿入光源型の偏向磁石 (K0≠0)・δ≠0・偏向磁石の生成関数の閉形式・非対角の調和の正規形の補正まで広げたとき、追跡との差がどこまで縮むか。adts() の既定は物理的な項だけ (fourth='r3'・optics='calc')、数値積分器の端数まで入れる精密版は fourth='r6' のオプション。 前提: adts_bend_cubic.md と rdt4_normal_form.md。 読む順: 表の前の説明 → 「既定の解析と精密版の表」。

式・導出・検証の表は docs/25 §11、入門は docs/24 §7.6、試験は pysad/tests/script_tests/test_v23_R6_bend_orbit.py (14 件)、コードは pysad/bendnl.py (閉軌道・δ のまわりの分解、K0≠0、閉形式)・pysad/resdrive.py (adts の fourth・optics)・pysad/rdt2nd.py (非対角の正規形の補正、4 次の ADTS)・pysad/rdttrack.py (tracked_rows、element_h4 の軌道・δ)・pysad/nform.py (δ の ADTS と δ 微分)。 ラティス: FODO (example/00_lattice/FODO_ring.sad、SF・SD の K2L = 4, −6、3 GeV、105.6 m)、ASTRID2 (example/astrid/lattice/ASTRID2_v01_01.sad、0.58 GeV、45.7 m)、ASTRID2 MPW (ASTRID2_v01_02_id.sad の RINGMPW)、KEK-LS (pysad/tests/kek-ls_v03_12.lat、大きなリング A。ESRF 型の HMBA、3 GeV、603 m)。 条件 (すべて): pysad k64 (gs と同じ式) の追跡 (RF 空洞止め、放射なし、結合なし、閉軌道のまわり)、6 極 ×1 (指定以外)、直接の追跡は J の格子 6×6 (±位相の対 = 70 粒子)・1024 周・NAFF Hann p=1・order 2 のフィット (Jmax は FODO 1e-7、ASTRID2・MPW 2e-8、KEK-LS 2e-10)、3 次のテイラー展開の振幅 amp3 = 1e-4 √m (KEK-LS 1e-5)、偏向磁石の分割 16。実行は PYTHONUTF8=1。スクリプトは出力を example/14_nonlinear_dynamics/adts_rdt/ へ上書きする。

既定の解析と精密版の表 (解析と追跡の相対差)

以下の「精密版」の列は、精密版 (fourth='r6'、δ≠0 は optics='tracked' も) の値 (数値積分器の 0.1〜0.3% の端数を含む)。既定 (fourth='r3'・optics='calc') は物理的な項だけで、追跡との差は (e) の表の左の列の値 と δ≠0 の表 (docs/25 §11.4)。追跡との一致は入れた効果の検証の結果で、追跡に合わせて項を足したのではない。

コマンド

set PYTHONUTF8=1
py -3.12 example/14_nonlinear_dynamics/adts_rdt/adts_exact.py mpw          (数分。追跡 6 回)
py -3.12 example/14_nonlinear_dynamics/adts_rdt/adts_exact.py delta astrid (追跡 3 回 × 35 s。fodo は 7 s ずつ、kekls は大きなリングの追跡で数十分)
py -3.12 example/14_nonlinear_dynamics/adts_rdt/adts_exact.py bend         (数秒)
py -3.12 example/14_nonlinear_dynamics/adts_rdt/adts_exact.py nf           (数秒)
py -3.12 example/14_nonlinear_dynamics/adts_rdt/adts_exact.py adts         (KEK-LS を含めて 10 s、追跡は `rdt4_*` の保存値)

Python から: R.adts(lat) (既定: fourth='r3'・optics='calc')、R.adts(lat, fourth='r6') (精密版)、R.adts(lat, delta=0.002, fourth='r6', optics='tracked') (δ≠0 の精密版)、nform.adts_delta_derivative(lat, p, 2e-3, method='nform') (δ 微分)、rdt2nd.rdt4_normal_form(lat) (4 次の 35 調和の正規形の値)。

使えない範囲・未確認

docs/25 §11.8・§11.9 のとおり。主なもの: δ 微分の解析式の yy (精密版で ASTRID2 28%、FODO で xy が 21% 外れる。原因は未特定。数値の正規形を使う)、K1≠0 の本体の閉形式の 1e-4 (K64 の積分器と推定)、K0≠0 の磁石に E・ROTATE がある場合、共鳴線の上での非対角の補正、other_atoms は四極を分割しない、KEK-LS の δ≠0 の解析は 20 秒程度。
