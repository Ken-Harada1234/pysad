偏向磁石の 3 次の項を入れた解析の ADTS と追跡の比較

この文書で分かること: 偏向磁石の 3 次の項 (曲率・硬い端・複合機能の本体の K1・E1/E2 ≠ 0 の端) を入れた解析の ADTS が、追跡 + NAFF の直接のフィットと何 % まで一致するか (入れない場合は FODO・ASTRID2 で 3〜15% ずれ、入れると 0.3% 以内)。 前提: adts_direct.md (直接のフィットの手順と、偏向磁石の 3 次なしの解析との差)。 読む順: 結果の要約の表 → 残った差の原因。解説は docs/25_resonance_terms_adts.md (§8)。実装は pysad/bendnl.py と resdrive.adts(bend_cubic=True) (既定 ON)。 ラティス: FODO (example/00_lattice/FODO_ring.sad、SF・SD の K2L = 4, −6、3 GeV、105.6 m、24 セル、偏向磁石 E1=E2=0.0343 rad)、FODO 長方形 (E1=E2=ANGLE/2)、FODO 非対称 (E1=0.8·ANGLE、E2=−0.3·ANGLE)、ASTRID2 (example/astrid/lattice/ASTRID2_v01_01.sad、0.58 GeV、45.7 m、30° の複合機能偏向磁石 K1=−1.68)、ASTRID2 MPW (ASTRID2_v01_02_id.sad の RINGMPW)、大きなリング A (pysad/tests/kek-ls_v03_12.lat、3 GeV、603 m)。 条件 (すべて): pysad k64 (gs と同じ式) の追跡 (RF 空洞止め rfsw=False、放射なし、結合なし、δ=0、閉軌道 0)、gs は NORFSW;、1024 周、NAFF は Laskar の Hann 窓 (p=1) で線形のチューン ± 0.02 を探す、J の格子 Jx, Jy ∈ {0, 1/5, …, 1}·Jmax の 35 点 × (φ, φ+π) の対 = 70 粒子 (Jmax = FODO 1e-7、ASTRID2 2e-8、大きなリング A 2e-10、単位 m rad、リング先頭の J)、全次数 ≤ 2 の多項式のフィット、偏向磁石の分割 nslice=16。6 極の強さは K2 を λ 倍 (8 極は変えない)。
