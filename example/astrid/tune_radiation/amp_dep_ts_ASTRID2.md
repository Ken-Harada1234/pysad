# amp_dep_ts_ASTRID2 (振幅依存チューンシフト)
KEK の SAD チュートリアルの「amp_dep_ts.sad 振幅依存チューンシフトの計算」をもとにした例。加速器: ASTRID2 (0.58 GeV、周長 45.7044 m、チューン 5.17999 / 2.14018)。ラティス: `lattice/ASTRID2_v01_01.sad` の `RING` (6 極は色収差補正値 SF 8.681、SD -11.729)。フラグ: `RAD COD RFSW RADCOD` (`FLUC` は OFF)。

## 何を見る例か
リング先頭の `MKS` に初期のずれ (x, x', y, y') を与え、`ins calc` (INS: 初期条件から 1 周伝搬する光学計算) でチューンを読む。初期位相 θ を 8 通りに振って平均し、振幅 (betatron σ の倍数) ごとのチューンのずれを調べる。水平だけ励起する掃引と垂直だけ励起する掃引の 2 本。振幅の単位は $\sigma_{x,y}=\sqrt{\epsilon\beta_{x,y}}$ ($\epsilon$ は `EMITX`=1.268e-8 m、水平も垂直も同じ $\epsilon$ を使う。MKS で $\beta_x=3.8916$ m、$\beta_y=1.6225$ m なので $\sigma_x=0.222$ mm、$\sigma_y=0.143$ mm)。

## スクリプト
要点 (全文は `.sad`、元のスクリプトの `AmplitudeDependentTuneShift`・`CalcAmpDepTS`・`SetInitialParameters` を使った):
```
inidx  = nx*Sqrt[w]*Sqrt[betax]*Cos[theta];   inidpx = nx*Sqrt[w]/Sqrt[betax]*(Sin[theta]-alphax*Cos[theta]); ...
LINE["DX", ininame] = inidx;  LINE["DPX", ininame] = inidpx; ... (* MKS の初期のずれ *)
FFS["ins calc"];   nux = Twiss["NX","$$$"]/2/Pi;           (* 1 周の位相進み *)
```
元から省いたもの: 振幅を 1〜200 σ・10 刻みで振るところを {10, 20, 30, 40, 60, 80} σ に縮めた (垂直 200 σ では不安定で gs は 1e199、pysad は NaN になる)。θ の分割を 36 から 8 に縮め、`NPARA=64` を外した。

## 物理・解析式
6 極 (と、色収差補正の結果ある 2 次の非線形) による振幅依存チューンシフトは、作用変数 $J_{x,y}$ で
$$\nu_x(J_x,J_y)=\nu_{x0}+\alpha_{xx}J_x+\alpha_{xy}J_y+O(J^2),\qquad \nu_y=\nu_{y0}+\alpha_{xy}J_x+\alpha_{yy}J_y+\dots,\quad J=\frac{A^2}{2\beta}\ (A:\text{振幅})$$
最低次では $\Delta\nu\propto A^2$ になる。表の $\Delta\nu/A^2$ が 10〜20 σ でほぼ一定 (水平励起 Δνx: 7.04 → 7.02、垂直励起 Δνy: 1.897 → 1.898 (e-5/σ²)) で、40 σ 以上で 4 次の項が増えて大きくなる。6 点の最小二乗で $\Delta\nu=a_2A^2+a_4A^4$ を作ると、水平励起の Δνx は $a_2=6.91\times10^{-6}$/σ²、$a_4=2.1\times10^{-10}$/σ⁴、垂直励起の Δνy は $a_2=1.922\times10^{-5}$/σ²、$a_4=1.0\times10^{-10}$/σ⁴ (A は σ 単位)。$J=A^2/(2\beta)=n^2\epsilon/2$ より $\alpha=2a_2/\epsilon$: $\alpha_{xx}=1.09\times10^{3}\ {\rm m^{-1}}$、$\alpha_{yy}=3.03\times10^{3}\ {\rm m^{-1}}$。6 極 2 組だけの閉じた式で値を出すところまでは行っていない。

| 量 | 値 |
|---|---|
| $A^2$ 則 (10 → 20 σ で Δν が 4 倍になるか): Δνx (水平励起) | 3.99 倍 (gs・pysad) |
| 同: Δνy (垂直励起) | 4.00 倍 |

## 未確認・限界
- この方法のチューンは「その 1 周の線形化 (Jacobian) の位相進みを θ で平均したもの」で、振幅 A の周期的な運動が持つ本来の振幅依存チューンとは違う。`phase_x_ASTRID2` のトラッキング (300 周、x/√β + i√β x' の位相進みの平均) と比べると、水平 20 / 40 / 60 σ のチューンのずれは トラッキング 0.00125 / 0.00518 / 0.01389 に対し、この表の Δνx は 0.00281 / 0.01159 / 0.02760 で、比は 2.25 / 2.24 / 1.99 (約 2 倍)。$\nu=\nu_0+\alpha J$ なら 1 周の Jacobian の位相進みは $\nu_0+2\alpha J$ になるので、約 2 倍は理屈に合う。**本来の振幅依存チューンには、この表の値のおよそ半分を使う** (定量は上の比のみ。厳密な式での比較はしていない)。
- 水平励起の Δνy と垂直励起の Δνx (振幅依存チューンの交差項 $\alpha_{xy}$) は 8.4e-6/σ² と 9.3e-6/σ² で 10 % ほど違う。理論的には $\alpha_{xy}$ が共通のはずだが、上の方法の誤差か、1 σ の励起 (もう一方の面) の影響かは未調査。
- 振幅 100 σ 以上と、運動量ずれを伴うシフト (`DP0` ≠ 0) は見ていない。垂直方向の 200 σ はリングが不安定で値が出なかった (表の範囲外)。
