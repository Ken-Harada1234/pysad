# KEKLS_match_injcell
種別: FFS の `ins calc`・`fit`・`free`。フォルダ: `design`。元のスクリプト: matching2_03_INJ。ラティス: `../lattice/kek_ls_v03_68.sad` (3 GeV、周長 570.72 m、標準セル 20 個)。フラグ: `ON RAD FLUC COD RFSW RADCOD`。

## 何を見る例か
入射セルの半分 `ARCINJH` の四極 `QS0`〜`QS5` の K1 を変数にして、入射点 `MKSI` で位相進みを標準セルの半分、AX = AY = EPX = 0、βx = 30 m に合わせる。v03_68 の `QS*` はすでにこの解なので、K1 を 1.2 倍して始め、解に戻ることを見る。

## スクリプト
`KEKLS_match_injcell.sad` (先頭に `../lattice/kek_ls_v03_68.sad` を貼った自己完結のファイル。台本の本体は `FFS;` から。説明のコメントは台本の先頭にある)。

## 結果の読み方
`before` が 1.2 倍にしたとき (位相 1.2413/0.6770、AX 2.73、βx(MKSI) 53 m)、`iteration 1` で解 (位相 1.21450/0.44050、AX・AY・EPX ≈ 0、βx 30.0 m) に戻る。2 回目以降は動かない (元の台本は 50 回繰り返す)。末尾の `type Q*` に K1 の値 (元の設計値と 1e-5 以内)。

## gs と pysad の比較
判定: **○** (比べた行 5、最大の相対差 0.0e+00、k64 モードの pysad)。1 回目の結果が 1e-10 以内で一致 (K1 も 12 桁)。

所要時間: gs 1 秒、pysad 2 秒 (この PC。k64 モード)。

## 未確認・限界
- 整理前後の比較: 元の matching2_03_INJ (50 回、設計値から) の gs の最終の `QS*` の K1 は設計値と 1e-6 違い (最適化の残り)、この例の解 (摂動から 1 回) とも 3e-6 以内。βx(MKSI) は 29.9999 (元 29.999896、この例 29.999925)。
- 入射セルの AX・AY の目標はあくまで 0 (入射セルの両端を標準セルの対称点につなぐ条件)。入射点の設計値 βx = 30 m の理由は確認していない。
