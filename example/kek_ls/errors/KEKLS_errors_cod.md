# KEKLS_errors_cod
種別: 誤差 (COD・分散・チューン)。フォルダ: `errors`。元のスクリプト: print_all_error.sad、print_dk_effect.sad、print_dt_error.sad、print_cod_magnitude.sad (他の print_*.sad は補正後の表示違い)。ラティス: `../lattice/kek_ls_v03_68.sad` (3 GeV、周長 570.72 m、標準セル 20 個)。フラグ: `ON RAD FLUC COD RFSW RADCOD`。

## 何を見る例か
誤差の種類ごとの影響。乱数の種 3 本 (17・111・3) × 4 通り (全部、位置ずれだけ、強さだけ、回転だけ) で、モニター PM.* (201 台) の COD の rms・最大値、分散のずれ、チューンのずれを表示する。位置ずれ ae = 40 μm、強さ fe = 4e-4、回転 te = 100 μrad (GCUT = 1σ で打ち切り)。

## スクリプト
`KEKLS_errors_cod.sad` (先頭に `../lattice/kek_ls_v03_68.sad` を貼った自己完結のファイル。台本の本体は `FFS;` から。説明のコメントは台本の先頭にある)。共通モジュールは `Get["../modules/..."]` で読む (台本のあるフォルダをカレントにして走らせる)。

## 結果の読み方
`R seed type | Δνx Δνy | COD rms x y [μm] | COD max x y [μm] | η のずれ rms x y [mm]` の行。位置ずれが COD の主因 (rms x 0.2〜0.4 mm、y 0.6〜1 mm)、回転は垂直の COD (rms 50〜100 μm)、強さの誤差は COD に効かずチューン・分散にだけ効く。

## gs と pysad の比較
判定: **△** (比べた行 13、最大の相対差 7.2e-01、k64 モードの pysad)。種 111・3 は 1e-9 で一致。種 17 の「全部」「位置ずれ」の 2 行は違う (COD rms gs 184 / pysad 301 μm)。この種は垂直の COD が 2 mm 近い大きな場合で、閉軌道の解が前の状態に依り、gs・pysad で別の解に落ちる (乱数列は GCUT = 1 で全桁一致を確認)。

所要時間: gs 1 秒、pysad 6 秒 (この PC。k64 モード)。

## 未確認・限界
- 元は 115 個の種 (SeedRandom[187] と Random[1000] で作る)、結果を datas_e.txt に書く。例は 3 本。完全な設定は `seeds` を 115 個に (1 つの種 (4 通り) あたり gs で約 0.3 秒、pysad で約 2 秒)。
- 位置ずれは `DELX`・`DELY` ではなく成分ごとの `LINE["DX"/"DY", ...]` (K64 の `DELX`・`DELY` は閉軌道に効かない。`modules/modules_errors.n`)。`USE RING NOEXPAND` と `cell calc noexpand` が必要 (`docs/29_sad_quirks.md` A56)。
- 元の `FFS["MON 0 0 0 0 PM*;"]` は K64 では何もしない (エラーになる) ので除いた。
- `GCUT = 0` のとき、gs の `GaussRandom[]` は 1e-9 程度の値を返し、pysad は打ち切りなしのガウス乱数を返す (差の確認のみ。pysad は変えていない)。
