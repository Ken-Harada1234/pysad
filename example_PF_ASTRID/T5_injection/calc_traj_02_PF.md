# calc_traj_02_PF (PF 入射軌道 その 2: 計算の関数化と Courant-Snyder 不変量)
元の話題: KEK SAD チュートリアル Tutorial5「モジュール化」(`calc_traj_02`)。加速器・ラティス・線・フラグは `calc_traj_01_PF` と同じ (PF 2.5 GeV、`lattice/v9_16_inj_noSF.sad`、`INJL`、放射などは OFF)。

## 何を見る例か
`calc_traj_01` の計算を関数にまとめ、キッカーの値を変えて繰り返せるようにする。関数は `名前[引数_]:=( 文; 文; 戻り値 )` の形で、メインレベルのコマンドは `FFS["..."];` に入れる。さらに、振動のエミッタンス (Courant-Snyder 不変量) を、ライン終端の Twiss パラメータと (x, x') から計算する。GUI のボタン (Up/Down) の代わりに、`Do` で KK4 を 0.2 mrad ずつ振る。

## スクリプト
```
CalcSBBump[] := ( Twiss["DX","^^^"] = 0; Twiss["DPX","^^^"] = 0; FFS["ins calc;"]; );   (* 初期の軌道をゼロにして INS *)
DispCSInv[dx0_,dxp0_] := ( b0 = Twiss["BX","$$$"]; a0 = Twiss["AX","$$$"]; g0 = (1+a0*a0)/b0;
    csinv = g0*dx0*dx0 + 2*a0*dx0*dxp0 + b0*dxp0*dxp0;  csinv*1e9 );                   (* 最後の式が戻り値、nm rad *)
SetKicker[k1_,k2_,k3_,k4_] := ( LINE["K0","KK1"] = k1/1000; ... FFS["ins calc;"]; );
CalcTrajectories[dxinj_,dxpinj_,dpinj_] := ( ... TrackParticles ... {x(INJ), x(end), x'(end), CS蓄積, CS入射, CS入射dp} );
Do[ SetKicker[-1.89, 0, -1.4, k4]; CalcSBBump[]; r = CalcTrajectories[21.5, 2, 1]; Print[...]; ,{k4,-3.2,-2.4,0.2}];
```
元のスクリプトの GUI 用の変数の型の扱い (`ToExpression[ToString[x]*1.00]`) は、ここでは窓が無いので使わない (`calc_traj_03_PF` で使う)。

## 結果の読み方
`END BX AX PSIX(end)` と `KK4 ...` は照合用の Twiss。`BASE` の 3 行 (基準のキッカー値: 入射点の蓄積ビームの x、終端の x・x'、CS 不変量 3 つ)。`SCAN` の 5 行 (KK4 を -3.2 から -2.4 mrad まで)。

| KK4 [mrad] | 蓄積ビーム x(入射点) [mm] | 終端の x [mm] | 終端の x' [mrad] | CS 不変量 [nm rad] |
|---|---|---|---|---|
| -3.2 | 11.2447 | 0.8625 | -0.5591 | 1828.8 |
| -3.0 | 11.2447 | 0.6907 | -0.4014 | 976.2 |
| -2.8 (基準) | 11.2447 | 0.5187 | -0.2437 | 391.5 |
| -2.6 | 11.2447 | 0.3467 | -0.0859 | 74.5 |
| -2.4 | 11.2447 | 0.1747 | +0.0718 | 25.3 |

基準の CS 不変量 (nm rad): 蓄積ビーム 391.5、入射ビーム 7115.8、δ=+1 % の入射ビーム 4870.9 (PF の εx=34.5 nm に対して、入射ビームの振動のエミッタンスは 200 倍ほど大きい)。

## 物理・解析式
- 入射点 (KK4 より上流) の蓄積ビームの x は、KK4 に依らず 11.2447 mm で一定 (表のとおり)。
- KK4 は終端より上流にあるので、終端の x は KK4 に 1 次で比例する。傾きは $\partial x_{\rm end}/\partial\theta_4=-\sqrt{\beta_4\beta_{\rm end}}\sin(\psi_{\rm end}-\psi_4)$。
- 不変量: 蓄積ビームの終端での $\gamma x^2+2\alpha xx'+\beta x'^2$ の式を、表の x・x' と終端の Twiss ($\beta=4.6293$ m、$\alpha=-0.2202$) で手計算して比べた。

| 量 | 式 | gs | pysad |
|---|---|---|---|
| 傾き $\partial x_{\rm end}/\partial k_4$ [mm/mrad] ($\beta_4$=3.3454、$\psi_4$=6.1392、$\beta_{\rm end}$=4.6293、$\psi_{\rm end}$=9.0605) | 0.863 (符号は K0 の向き) | 0.860 (表の -3.2 と -2.4 の差から) | 0.860 |
| 基準の CS 不変量 [nm rad] ($\gamma x^2+2\alpha xx'+\beta x'^2$、x=0.518722 mm、x'=-0.243671 mrad) | 391.46 | 391.46 | 391.46 |

傾きは 0.4 % で一致 (厚いキッカーを中点で近似)。CS 不変量は同じ式を別に評価した検算で、全桁一致。KK4 を -2.4 から -3.2 へ強めると不変量が増える (KK4 が弱いほど蓄積ビームの終端のずれが小さく、-2.4 mrad で 25 nm rad まで下がる)。

## gs と pysad の比較
○ 一致 (`BASE`・`SCAN` の 8 行、`END`・`KK4` の行が全桁一致)。

## 未確認・限界
- KK4 の値を変えても入射点の蓄積ビームの位置が変わらない (KK4 は入射点の下流) ので、入射ビームとの分離は KK1〜KK3 で決まる。この例は KK4 だけ振っており、KK1・KK3 の組み合わせでバンプを最適化する (FIT) ことはしていない。
- 不変量は線の終端 (INJL の端) での値で、リングを 1 周した値ではない (`INJL` は直線部の終わりまで)。
- 関数名・引数の型 (`dx0_` など) の指定は元と同じ書き方。引数に型を付けない `_` だけのパターンのみ使い、`Module`・`Block` での局所変数化はしていない (変数はすべて大域)。
