pysad のドキュメント

pysad は、加速器コード SAD (K64 版) の計算 (光学・エミッタンス・マッチング・粒子追跡・ダイナミックアパーチャ) を Python で再現し、SAD の台本をそのまま動かせるようにしたものである。

道具 (tools)

  • tools: md を図入りの HTML にする — リポジトリ内の md を、目次つき・図入りの 1 枚の HTML にする。使うのは markdown パッケージだけで、外部通信・外部ライブラリの読み込みはない。HTML は md から作る生成物なので、md を直したら作り直す。
