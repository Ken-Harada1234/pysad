CLAUDE.md

pysad は加速器設計コード SAD (K64 版) の Python への翻訳。既定の v2 は K64 のバグを直した動作で、PYSAD_COMPAT=k64 で K64 と同じ動作に切り替える。最新は v2.6.0 (2026-11-28、pysad.__version__ = 2.6.0。物理ガイド physics_guide/ を含む)。PyPI・GitHub (main・タグ v2.6.0・リリース (Latest)・ブランチ release/pypi-v2.6.0) とも v2.6.0 まで公開済み (2026-11-28。v2.4.3 は単独では公開せず、v2.4.4 に含む)。pip のパッケージには、例 (example/)・文書 (docs/)・物理ガイド (physics_guide/)・試験を入れない (GitHub と GitHub Pages にある)。作業の前に次を読むこと。

  1. docs/history/00_RESUME.md: 引き継ぎメモ (方針、構成、環境、現状、残課題、手順、落とし穴)。未解決の差の最新は docs/history/work_unimpl.md。
  2. docs/01_overview.md: 全体像とモジュールの地図。
  3. 必要に応じて docs/29_sad_quirks.md (SAD の癖)、docs/12_pysad_api.md (API)、docs/31_unimplemented_and_unverified.md (未実装・未確認・限界の一覧)、docs/28_v2_vs_k64.md (v2 と k64 の動作の違いの表)。K64 側のバグは docs/30_sad_bug_report.md (B01〜B162 とそれ以降の番号)。B160 は誤りではなく K1 の暗黙の定義 ((1 + hx)∂b/∂x 一様、docs/29 A59)、B161 は CALC の行列の dk の不整合 (v2 は直してある)、B162 は Touschek の損失率の式 touckf の適用範囲 (v2 は Piwinski 型が既定)。
  4. 要素・機能別 (使い方・式・K64 の癖・限界を 1 本にまとめてある): docs/13_wake.md (WAKE)、docs/14_beambeam.md (BEAMBEAM・BBBrem)、docs/15_csr.md (CSR)、docs/16_spin_pol.md (POL・スピン追跡)、docs/17_sol.md (SOL)、docs/18_radlight.md (RADLIGHT・放射場)、docs/19_other_elements.md (COORD・TCAVI・UND・MULT ANGLE・MAP)、docs/20_tcltk_gui.md (GUI/Tcl)、docs/21_graphics.md (描画)、docs/22_lattice_dxf.md (DXF)。FFS の小コマンド・DELCOR は docs/04_ffs_small_commands.md、特殊関数・Fit・GaussianCoulomb・SAD パッケージは docs/06_sadscript_library.md。 物理と理論: docs/23_physics_guide.md (K64 の計算の式)、docs/24_adts_rdt_primer.md (入門: ADTS・RDT・周波数マップ・LMA を何をどう求めたか。25・26 を読む前にこれ)、docs/25_resonance_terms_adts.md (共鳴駆動項・ADTS・クロマティシティ)、docs/26_frequency_map_lma.md (周波数マップ・局所運動量アクセプタンス)。旧い文書番号・名前の対応は docs/history/docs_renumbering.md。

作業ルール

  • md を作り直したら、同じ名前の .html も作り直す (py -3.12 tools/build_html.py --changed。ツールは tools/ にある)。md にも HTML にも、履歴や版番号は入れない (必要なら本文に書く)。履歴は docs/history/ だけに置く。
  • 解説文書 (docs/*.md) は現状の説明だけ。経緯は docs/history/ に書く。未確認・限界・使った条件 (エネルギー、磁場、周長) を必ず書く。

  • 解析式 (RDT・ADTS・共鳴線の予想) の方針: 摂動論の定義された次数と入れた効果の範囲で原理的に作り、追跡に合わせるための補正項は足さない。文書は「入れている効果と次数」「入れていない効果」「差の原因」の形で書く (docs/25 §11.9)。追跡から係数を取り出すのは偏向磁石の生成関数だけ (原理は docs/25 §8.1)。
  • ADTS: 基準値は追跡 (adtsdirect.direct_adts)。adts() の .total は運動学・四極の端部のフリンジと、偏向磁石の 3 次の項 (曲率・硬い端・複合機能の本体・E1/E2) の対の項・6 極との交差項 (bendnl.py が追跡の写像から取り出す。bend_cubic=True が既定、False でそれを入れない) を足した値。既定は物理的な項だけ (fourth='r3'・optics='calc')。fourth='r6' (四極の積分器の台形則と偏向磁石の 4 次の項。数値積分器の 0.1〜0.3% の端数) と optics='tracked' は精密版のオプション。追跡との差は 6 極 ×1 で 0.01〜0.26% (残りは 6 極に依らない 4 次の定数、ASTRID2 1.1・1.1・2.6 [1/(m rad)]。原因は、K64 の四極の本体が ∫p⁴/8 の台形則 (kinematic_h4(quad_rule="k64")) であること)。δ≠0 の kick の強さの 1/(1+δ) 倍の補正は入れてある。
  • 共鳴駆動項 resonance_terms() の .total は 6 極 + 偏向磁石の 3 次の項 (bend_cubic=True が既定、.total_sext・.total_bend、6 極のみは bend_cubic=False。δ の項は分散による軌道のずれの展開、δ≠0 では入れない)。4 次の名前 h22000 などを渡すと 4 次の項が回る (order2=True が既定、台本 Order2->)。追跡の 1 周の写像の 2 次のテイラー展開との差は、6 極の分は 6 リングで 1e-6 以内、偏向磁石つきの全体は 1e-8 (FODO・ASTRID2)〜4e-7 (大きなリング A)・5e-5 (MPW)。ADTS との整合は、写像の対角 + 正規形の補正 (nf_correction) = adts(fourth='r6')。
  • 周波数マップ・LMA の既定: LMA の check_every = 1、FrequencyMap[] は RFSW・RAD・FLUC OFF、RAD OFF の RF の同期位相 0。
  • elegant との比較 (example/15_lma_touschek/touschek_elegant/、docs/history/v23_T1.md): LMA は ASTRID2・kek-ls とも elegant と 0.5% 以内、Touschek 寿命の式は ±5% 違う。B160 (K1≠0 の BEND の K1 の暗黙の定義) は誤りではなく、elegant には K2 = −hK1 を足す (docs/history/v23_U1.md)。
  • 6 極の検討の試作 (pysad/sxtopt.py、例 example/ddba/v07_14/sextupole/、試験 test_ddba_sextupole.py 8 件): 6 極の組 32 通りで、解析式の目的関数と追跡の x–y DA 面積の順位相関は ρ = −0.89。検証 (小〜中振幅の DA の健全性チェック) には条件つきで使える。LMA の予測には使えない。最適化の試作は、最終設定より DA の広い解を出せない (DA 面積は最終設定の 0.60〜0.71 倍)。不足は、J² の ADTS・δ 依存・5 次以上の駆動項。
  • パーサ・評価器・FIT の扱い (docs/31 §4): ユーザー定義の関数名 At (メンバー参照の内部の頭は SAD$Member)、FitFunction を併用する fit (NaN の行は条件にしない・末尾の数 3. のパース・FitFunction の行は k64 で不等式型・USE のたびに DP を MARK に戻す)、pm1.sad の NaN (qcod が見つからないとき tcod は 0 から始める)。パーサは、逆向きの文脈の -LINE を二重に反転せず、k64 の 1.7MV など数に隣接する単位を解釈する。
