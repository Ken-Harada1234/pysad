pysad — SAD (K64 版) の Python 直訳

直訳と v2 の違い (注釈): 以下の「直訳」は、K64 に忠実な翻訳 (v1 系) の方針です。現在の pysad (v2 系) は直訳ではありません。 v2 は K64 を出発点に、K64 のバグの修正、物理の誤りの修正、機能の追加を行ったもので、gs (K64) と結果が変わる箇所があります (docs/28_v2_vs_k64.md)。gs と同じ結果が要るときは、環境変数 PYSAD_COMPAT=k64 (互換モード。K64 と同じ動作) を指定してください。なお、v2 でも、K64 の式・分割数・反復順序を写したコードの大部分は、そのままです。

インストール (PyPI)

pip install pysad-k64

パッケージ本体のほかに、文書 (docs/、HTML 版を含む) と例 (example/、図・出力を含む) の全ファイルも一緒に入ります (約 90 MB。場所は pysad-share で表示: <prefix>/share/pysad/docs・example)。SAD の台本は pysad-run lattice_file [script_file ...] で実行できます (リポジトリの run_sad.py と同じ)。

PyPI: https://pypi.org/project/pysad-k64/。import 名は pysad です (パッケージ名と違います)。K64 のバグの修正と機能の追加を含み、互換モード PYSAD_COMPAT=k64 で K64 と同じ動作をします (直訳ではありません)。インストールした版は pysad.__version__ で確認できます。ソースに忠実な翻訳 (v1 系) は pip install pysad-k64==1.0.0 で入ります。

使い方

SAD の gs に渡すのと同じ順にファイルを並べる (複数ファイルは連結される。Get[] は最後のファイルのフォルダ基準)。

py -3.12 run_sad.py lattice.sad script.sad > script.pysad.out
py -3.12 run_sad.py lattice_and_script.sad              # ラティスとコマンドを 1 ファイルにしてあれば 1 つ

Python から:

from pysad.ffscmd import run_sad_string
ffs, I = run_sad_string(open('script.sad', encoding='utf-8').read(), cwd='.')
print(I.get('EMITX'), ffs.rows[-1].betx)
ffs.run_text('fit NX 47.3; free QF* K1; go;')

下位の API (Lattice, Matcher, emittance6d, TrackParticles など) は docs/12_pysad_api.md。

解析式の位置づけ: RDT・ADTS・共鳴線の予想などの解析式は、摂動論の定義された次数と、入れた効果の範囲で原理的に作ります。追跡 (全非線形) とは入れている効果が違うので、厳密な一致は目的ではなく、追跡に合わせるための補正項・当てはめは足していません。追跡との一致の数値は、入れた効果と次数の検証の結果として載せ、入れていない効果と差の主因は docs/25 §11.9 にあります (原因が分からないものは「未特定」)。追跡から係数を取り出す唯一の部分 (偏向磁石の生成関数) の原理は、写像の 2 次のテイラー係数が生成関数を一意に決める、です (docs/25 §8.1、docs/24)。
